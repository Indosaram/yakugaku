**예: 산화제인 과망가니즈산 칼륨(황산 산성)의 반쪽 반응식**

1. 반응물 MnO<sub>4</sub><sup>−</sup>을 왼쪽에, 생성물 Mn<sup>2+</sup>을 오른쪽에 쓴다.

   MnO<sub>4</sub><sup>−</sup> → Mn<sup>2+</sup>

2. 왼쪽의 O 원자가 4개이므로 오른쪽에 4H<sub>2</sub>O을 더한다.

   MnO<sub>4</sub><sup>−</sup> → Mn<sup>2+</sup> + 4H<sub>2</sub>O

3. 오른쪽의 H 원자가 8개이므로 왼쪽에 8H<sup>+</sup>을 더한다.

   MnO<sub>4</sub><sup>−</sup> + 8H<sup>+</sup> → Mn<sup>2+</sup> + 4H<sub>2</sub>O

4. 전하의 총합은 왼쪽이 +7, 오른쪽이 +2이므로 왼쪽에 5e<sup>−</sup>를 더한다.

   MnO<sub>4</sub><sup>−</sup> + 8H<sup>+</sup> + 5e<sup>−</sup> → Mn<sup>2+</sup> + 4H<sub>2</sub>O

**표 1. 주요 산화제(酸化剤)와 환원제(還元剤)의 반쪽 반응식**

*1. 산화제의 반응에 산성 조건(H<sup>+</sup>)이 필요할 때는 묽은 황산을 넣어야 하며 염산이나 질산을 넣어서는 안 된다. 질산 자체가 산화제로 작용하고 염산 속 염화 수소가 환원제로 작용하기 때문이다.

*2. 이산화 황은 강한 환원제(H<sub>2</sub>S 등)에 대해서는 산화제로 작용한다.

*3. 과산화 수소는 강한 산화제(KMnO<sub>4</sub> 등)에 대해서는 환원제로 작용한다.

### 3. 산화제와 환원제의 반응식

**산화 환원 반응식을 만드는 방법**²

1. 산화제와 환원제의 반쪽 반응식을 각각 만든다.
2. 두 반쪽 반응식의 전자 e<sup>−</sup> 수를 맞춘 뒤 더하면 e<sup>−</sup>가 소거되어 하나의 이온 반응식을 얻는다.
3. 양변에 반응에 관여하지 않은 이온을 더하여 반응식을 정리하면 화학 반응식이 완성된다.

**주 2.** 산화 환원 반응은 복잡한 것이 많아 처음부터 바로 쓰기 어렵다. 그래서 산화제의 반쪽 반응식과 환원제의 반쪽 반응식을 따로 쓴 뒤 두 식을 더하여 하나의 반응식을 만드는 방법을 쓴다.
