## 제3장 산화 환원 반응

p.126

### 1

(1) ○　(2) 더 환원되어　(3) 감소한다　(4) ○　(5) 반드시 0이 된다

### 2

(1) +7　(2) +7　(3) −1　(4) +6　(5) −3　(6) +6　(7) +6　(8) +5　(9) 0

**사고 방법:** 화합물에서는 **수소 H의 산화수(酸化数)를 +1, 산소 O의 산화수를 −2**로 하고, 구성 원자의 산화수 총합을 0으로 놓는다. 이온에서는 산화수 총합이 이온의 전하와 같아진다.

밑줄 친 원자의 산화수를 x라고 하면,

(1) (+1) + x + (−2) × 4 = 0　따라서 x = +7

(2) (+1) + x + (−2) × 4 = 0　따라서 x = +7

(3) **과산화물 속 산소 O의 산화수는 −1이다.**

(4) (+1) × 2 + 2x + (−2) × 7 = 0　따라서 x = +6

(5) x + (+1) × 4 = +1　따라서 x = −3

(6) x + (−2) × 4 = −2　따라서 x = +6

(7) (+1) × 2 + x + (−2) × 4 = 0　따라서 x = +6

(8) (+1) + x + (−2) × 3 = 0　따라서 x = +5

(9) **홑원소 물질 속 원자의 산화수는 0이다.**

### 3

ア: I<sup>−</sup>, −1 → 0　ウ: Fe, 0 → +3　オ: Cu, 0 → +2

**사고 방법:** **홑원소 물질이 관여하는 반응은 산화 환원 반응(酸化還元反応)이라고 판단해도 좋다.**

イ와 エ는 모두 화합물 → 화합물의 반응이므로 산화 환원 반응이 아니다.

ア, ウ, オ는 모두 홑원소 물질 ⇄ 화합물의 반응이므로 산화 환원 반응이다.

### 4

(1) エ　(2) ① Cl<sub>2</sub>　② H<sub>2</sub>S

**사고 방법**

(1) Cl 원자의 산화수는 0 → −1, S 원자의 산화수는 −2 → 0이므로 원자 1개당 산화수 변화량은 다르다. 한편 Cl 원자는 2개, S 원자는 1개이므로 **반응 전체에서는 산화수의 증가량과 감소량이 같다.**

(2) <strong>산화제(酸化剤)</strong>는 상대 물질을 산화시키는 물질이다. 자신은 환원되어 산화수가 감소한다. 한편 <strong>환원제(還元剤)</strong>는 상대 물질을 환원시키는 물질이다. 자신은 산화되어 산화수가 증가한다.

![그림: Cl₂ + H₂S → 2HCl + S의 산화수 변화. Cl의 산화수는 0에서 −1로 감소하므로 Cl₂는 산화제이다. S의 산화수는 −2에서 0으로 증가하므로 H₂S는 환원제이다. 위쪽 파란 표시의 '산화수가 감소, 산화제'와 아래쪽 분홍 표시의 '산화수가 증가, 환원제'가 각 원소의 변화를 연결한다.](data/textbook/chem-basic/fig/p0142-1.webp)

### 5

5.0 × 10<sup>−3</sup> mol

**사고 방법:** 반쪽 반응식(半反応式)의 계수에서 남거나 모자람 없이 반응하는 과망가니즈산 이온 MnO<sub>4</sub><sup>−</sup>과 철(Ⅱ) 이온 Fe<sup>2+</sup>의 물질량비는 1 : 5이다.

MnO<sub>4</sub><sup>−</sup>의 물질량은,

0.10 mol/L × (10 / 1000) L = 1.0 × 10<sup>−3</sup> mol

따라서 반응하는 Fe<sup>2+</sup>의 물질량은,

1.0 × 10<sup>−3</sup> mol × 5 = 5.0 × 10<sup>−3</sup> mol
