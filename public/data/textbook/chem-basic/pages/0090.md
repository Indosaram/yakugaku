## 2. 산·염기의 가수와 세기

### 1. 산·염기의 가수

**산의 가수(酸の価数)** 산의 화학식에서 **수소 이온 H<sup>+</sup>이 될 수 있는 수소 원자 H의 수**를 산의 가수라고 한다. 예를 들어 염화 수소 HCl은 1가 산, 황산 H<sub>2</sub>SO<sub>4</sub>는 2가 산이다. 또 2가 이상의 산을 **다가 산(多価の酸)**이라고 한다.

| 1가 산 | 화학식 | 2가 산 | 화학식 | 3가 산 | 화학식 |
|---|---|---|---|---|---|
| 염산 | HCl | 황산 | H<sub>2</sub>SO<sub>4</sub> | 인산 | H<sub>3</sub>PO<sub>4</sub> |
| 질산 | HNO<sub>3</sub> | 황화 수소 | H<sub>2</sub>S | | |
| 아세트산¹ | CH<sub>3</sub>COOH | 옥살산 | (COOH)<sub>2</sub> | | |
| | | 탄산 | H<sub>2</sub>CO<sub>3</sub> | | |

**표 1. 주요 산과 그 가수**

**주 1.** 아세트산 CH<sub>3</sub>COOH은 분자에 수소 원자 H가 4개 있지만, 그중 수소 이온 H<sup>+</sup>이 되는 것은 COOH 부분의 1개뿐이므로 1가 산으로 분류한다.

**염기의 가수(塩基の価数)** 염기의 화학식에서 **수산화 이온 OH<sup>−</sup>이 될 수 있는 OH의 수**를 염기의 가수라고 한다. 예를 들어 수산화 나트륨 NaOH은 1가 염기, 수산화 칼슘 Ca(OH)<sub>2</sub>는 2가 염기이다. 또 2가 이상의 염기를 **다가 염기(多価の塩基)**라고 한다.

| 1가 염기 | 화학식 | 2가 염기 | 화학식 | 3가 염기 | 화학식 |
|---|---|---|---|---|---|
| 수산화 나트륨 | NaOH | 수산화 칼슘 | Ca(OH)<sub>2</sub> | 수산화 알루미늄 | Al(OH)<sub>3</sub> |
| 수산화 칼륨 | KOH | 수산화 바륨 | Ba(OH)<sub>2</sub> | | |
| 암모니아 | NH<sub>3</sub> | 수산화 구리(II) | Cu(OH)<sub>2</sub> | | |

**표 2. 주요 염기와 그 가수**

**산·염기의 가수와 세기** 산·염기의 가수는 산·염기의 세기와 관계가 없다.

### 2. 산·염기의 이온화도란

염산과 아세트산은 모두 1가 산이지만 같은 농도의 염산과 아세트산에 아연판을 넣으면 염산에서 기체가 더 격렬하게 발생한다(그림 1). 이는 **염산에서는 염화 수소 분자 HCl이 거의 모두 이온화하는 데 비해, 아세트산에서는 아세트산 분자 CH<sub>3</sub>COOH의 일부만 이온화하기 때문**이다.

**이온화도(電離度)** 산이나 염기 등의 전해질이 수용액에서 이온화하는 비율을 이온화도라고 한다.

> **핵심** 이온화도 α² = 이온화한 산·염기의 물질량〔mol〕 / 녹인 산·염기의 물질량〔mol〕

**주 2.** 이온화도 α는 0 < α ≤ 1의 값을 갖는다.
