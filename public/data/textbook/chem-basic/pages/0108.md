# 3장 산화 환원 반응

## 1. 산화·환원과 산화수

### 1. 산화·환원의 정의는

**산소의 주고받음과 산화·환원** **물질이 산소를 얻는 변화**를 **산화(酸化)**라고 하며, 이때 물질은 **산화되었다**고 한다. 한편 **물질이 산소를 잃는 변화**를 **환원(還元)**이라고 하며, 이때 물질은 **환원되었다**고 한다.

CuO + H<sub>2</sub> → Cu + H<sub>2</sub>O

- H<sub>2</sub> → H<sub>2</sub>O: O를 얻음(산화)
- CuO → Cu: O를 잃음(환원)

![그림: 구리의 산화와 산화 구리의 환원. 왼쪽 검은색 산화 구리 CuO가 수소 H2 속에서 오른쪽 붉은 구리 Cu로 변한다.](data/textbook/chem-basic/fig/p0108-1.webp)

**그림 1. 구리의 산화·산화 구리의 환원** 구리선을 버너로 가열하면 표면이 검게 된다. 뜨거울 때 수소 H<sub>2</sub> 속에 넣으면 구리의 광택이 되돌아온다.

**수소의 주고받음과 산화·환원** 황화 수소 H<sub>2</sub>S를 산소 O<sub>2</sub>와 반응시키면 황 S의 흰 연기가 생성된다.

2H<sub>2</sub>S + O<sub>2</sub> → 2S + 2H<sub>2</sub>O

- O<sub>2</sub> → H<sub>2</sub>O: H를 얻음(환원)
- H<sub>2</sub>S → S: H를 잃음(산화)

H<sub>2</sub>S가 O<sub>2</sub>와 반응하여 산화될 때 H<sub>2</sub>S는 수소를 잃는다. 즉 **물질이 수소를 잃는 변화를 산화**, 반대로 **물질이 수소를 얻는 변화를 환원**이라고 한다.

| | 산화 | 환원 |
|---|---|---|
| 산소 O | 얻는다 | 잃는다 |
| 수소 H | 잃는다 | 얻는다 |
| 전자 e<sup>−</sup> | 잃는다 | 얻는다 |

**표 1. 산화·환원의 정의**

**전자의 주고받음과 산화·환원** 구리 Cu가 산화 구리(II) CuO가 되는 변화를 화학 결합의 관점에서 생각하면, 구리 원자 Cu가 전자 2개를 잃고 구리(II) 이온 Cu<sup>2+</sup>이 되며 산소 O<sub>2</sub>의 산소 원자 O는 전자 2개를 얻어 산화 이온 O<sup>2−</sup>이 된다. 이들이 이온 결합하여 CuO가 된다.

2Cu → 2Cu<sup>2+</sup> + 4e<sup>−</sup>  
O<sub>2</sub> + 4e<sup>−</sup> → 2O<sup>2−</sup>

전자는 구리에서 산소로 이동한다. 생성된 이온들이 결합하여 2CuO가 된다.

> **핵심**  
> **산화**: 물질(원자)이 **전자를 잃는** 변화  
> **환원**: 물질(원자)이 **전자를 얻는** 변화

**산화 환원 반응의 동시성** 어떤 물질이 전자를 잃으면 반드시 그 전자를 얻는 물질이 존재한다. 따라서 **산화와 환원은 항상 동시에 일어난다.** 이러한 반응을 **산화 환원 반응(酸化還元反応)**이라고 한다.

### 다음 변화를 아래와 같이 표현한다

![그림: A + B → A′ + B′에서 전자가 B에서 A로 이동하는 모형.](data/textbook/chem-basic/fig/p0108-2.webp)

1. A는 환원되어 A′이 된다.
2. A가 B를 산화하여 B′으로 만든다.
3. B는 산화되어 B′이 된다.
4. B가 A를 환원하여 A′으로 만든다.

화학에서는 보통 ①, ③처럼 수동적인 표현을 쓴다. 반응 내용을 더 정확하게 전달할 수 있기 때문이다.
