### 미정 계수법

복잡한 반응식에서는 양쪽의 각 원자 수에 관한 연립 방정식을 세우고 이를 풀어 계수를 정한다. 이 방법을 <strong>미정 계수법(未定係数法)</strong>이라고 한다.

예를 들어 암모니아 NH<sub>3</sub>와 산소 O<sub>2</sub>가 반응하여 일산화 질소 NO와 물 H<sub>2</sub>O가 생성되는 반응에서 각 물질의 계수를 a, b, c, d로 놓으면,

aNH<sub>3</sub> + bO<sub>2</sub> → cNO + dH<sub>2</sub>O

각 원자 수에 관한 방정식을 세우면,

- N 원자: a = c ··· ①
- H 원자: 3a = 2d ··· ②
- O 원자: 2b = c + d ··· ③

방정식이 3개, 미지수가 4개이므로 그대로는 풀 수 없다. 그러나 a~d의 비는 구할 수 있다.

예를 들어 **a = 1**로 놓으면 c = 1, d = 3/2.

이를 ③에 대입하면 2b = 5/2, b = 5/4.

따라서 a : b : c : d = 1 : 5/4 : 1 : 3/2 = 4 : 5 : 4 : 6이며 이 반응의 화학 반응식은 다음과 같다.

**4NH<sub>3</sub> + 5O<sub>2</sub> → 4NO + 6H<sub>2</sub>O**

### 3 이온 반응식이란

**이온 반응식(イオン反応式)**: 이온이 관련된 반응에서 반응에 참여하지 않는 이온은 생략하고 반응에 참여하는 이온만으로 나타낸 화학 반응식을 특별히 이온 반응식이라고 한다. 이온 반응식에서는 **양쪽 전하의 합도 같게 해야 한다**.

예를 들어 질산 은 AgNO<sub>3</sub> 수용액과 염화 나트륨 NaCl 수용액이 반응하여 염화 은의 흰색 침전이 생기는 변화를 화학 반응식으로 나타내면,

AgNO<sub>3</sub> + NaCl → AgCl + NaNO<sub>3</sub>

수용액 속에서 이온으로 존재하는 것을 화학식으로 나타내면,

Ag<sup>+</sup> + NO<sub>3</sub><sup>−</sup> + Na<sup>+</sup> + Cl<sup>−</sup> → AgCl + Na<sup>+</sup> + NO<sub>3</sub><sup>−</sup>

이 가운데 반응 전후에 변하지 않은 Na<sup>+</sup>와 NO<sub>3</sub><sup>−</sup>를 생략하고 침전 생성에 관계한 이온만으로 반응식을 나타내면 다음과 같은 이온 반응식을 얻는다.

**Ag<sup>+</sup> + Cl<sup>−</sup> → AgCl**
