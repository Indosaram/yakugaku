**여러 단계의 이온화(多段階の電離)** 황산 H<sub>2</sub>SO<sub>4</sub>과 같은 다가 산은 먼저 첫 번째 수소 이온 H<sup>+</sup>이 이온화하고, 이어서 두 번째 H<sup>+</sup>이 이온화한다.³

- 제1단계: H<sub>2</sub>SO<sub>4</sub> → H<sup>+</sup> + HSO<sub>4</sub><sup>−</sup>(황산수소 이온)
- 제2단계: HSO<sub>4</sub><sup>−</sup> ⇌ H<sup>+</sup> + SO<sub>4</sub><sup>2−</sup>(황산 이온)

**주 3.** 제1단계의 이온화도가 가장 크고, 제2단계, 제3단계로 이온화가 진행될수록 이온화도가 작아진다.

### 예제: 산의 이온화도

1가 산 0.020 mol을 물에 녹였더니 수소 이온 H<sup>+</sup> 2.6 × 10<sup>−4</sup> mol이 생겼다. 이 산의 이온화도(電離度)를 구하라.

**풀이**

이온화도 α = 이온화한 산의 물질량〔mol〕 / 녹인 산의 물질량〔mol〕  
= (2.6 × 10<sup>−4</sup> mol) / (0.020 mol) = **1.3 × 10<sup>−2</sup>** …… 정답

### 3. 산·염기의 세기

**이온화도와 산·염기의 세기** 같은 농도의 산·염기 수용액이라도 **이온화도가 클수록 용액 속에 수소 이온 H<sup>+</sup>이나 수산화 이온 OH<sup>−</sup>이 많이 존재**하므로 산·염기로서의 작용이 강해진다.

**이온화도가 1에 가까운 산·염기를 강산(強酸)·강염기(強塩基)**, **이온화도가 1보다 훨씬 작은 산·염기를 약산(弱酸)·약염기(弱塩基)**라고 한다.

| 산·염기의 종류 | 이온화식 | 분류 |
|---|---|---|
| 염산 | HCl → H<sup>+</sup> + Cl<sup>−</sup> | 강산 |
| 질산 | HNO<sub>3</sub> → H<sup>+</sup> + NO<sub>3</sub><sup>−</sup> | 강산 |
| 황산 | H<sub>2</sub>SO<sub>4</sub> → 2H<sup>+</sup> + SO<sub>4</sub><sup>2−</sup> | 강산 |
| 인산 | H<sub>3</sub>PO<sub>4</sub> ⇌ H<sup>+</sup> + H<sub>2</sub>PO<sub>4</sub><sup>−</sup> | 약산 |
| 아세트산 | CH<sub>3</sub>COOH ⇌ H<sup>+</sup> + CH<sub>3</sub>COO<sup>−</sup> | 약산 |
| 탄산 | H<sub>2</sub>CO<sub>3</sub> ⇌ H<sup>+</sup> + HCO<sub>3</sub><sup>−</sup> | 약산 |
| 수산화 칼륨 | KOH → K<sup>+</sup> + OH<sup>−</sup> | 강염기 |
| 수산화 나트륨 | NaOH → Na<sup>+</sup> + OH<sup>−</sup> | 강염기 |
| 수산화 바륨 | Ba(OH)<sub>2</sub> → Ba<sup>2+</sup> + 2OH<sup>−</sup> | 강염기 |
| 암모니아 | NH<sub>3</sub> + H<sub>2</sub>O ⇌ NH<sub>4</sub><sup>+</sup> + OH<sup>−</sup> | 약염기 |

**표 3. 주요 산·염기의 이온화식** →는 완전히 오른쪽으로 진행함을, ⇌는 완전히 오른쪽으로 진행하지 않음을 나타낸다.

![그림: 산의 농도와 이온화도의 관계. 가로축 농도(mol/L), 세로축 이온화도 α. 염산(강산)은 α가 거의 1이고, 아세트산(약산)은 농도가 낮아질수록 α가 커진다.](data/textbook/chem-basic/fig/p0091-1.webp)

**그림 2. 산의 농도와 이온화도의 관계** 일반적으로 약산의 이온화도는 농도가 작아질수록 1에 가까워진다. 이에 비해 염화 수소나 수산화 나트륨 같은 강산·강염기의 이온화도는 항상 1에 가깝다.

**주의** 농도가 작아지면 이온화도가 1에 가까워지므로 산성이 강해진다고 성급하게 판단해서는 안 된다. α가 1에 가까워져도 농도가 작아진 영향이 더 크기 때문에 수소 이온의 농도는 작아진다(표 4 참고).

| 아세트산의 농도 (mol/L) | 이온화도 | 수소 이온의 농도 (mol/L) |
|---:|---:|---:|
| 1.0 | 0.0052 | 0.0052 |
| 0.1 | 0.016 | 0.0016 |
| 0.01 | 0.051 | 0.00051 |
| 0.001 | 0.15 | 0.00015 |
| 0.00001 | 0.75 | 0.0000075 |
