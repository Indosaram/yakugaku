### 중요 실험: 산화제의 산화 작용 알아보기

### 방법

1. 0.01 mol/L 과망가니즈산 칼륨 수용액 10 mL에 2 mol/L 황산 1 mL를 넣는다. 이를 시험관 3개 (A)~(C)에 나누어 넣는다.
2. 시험관 (A)에 0.1 mol/L 아이오딘화 칼륨 수용액을 한 방울씩 넣으며 잘 흔들어 색 변화를 관찰한다.
3. 2의 수용액에 녹말 수용액을 1~2방울 넣고 색 변화를 관찰한다.
4. 시험관 (B)에는 0.1 mol/L 옥살산 수용액을 넣고 따뜻하게 하면서 변화를 관찰한다. 시험관 (C)에는 3% 과산화 수소수를 넣고 변화를 관찰한다.
5. 다른 시험관 3개 (D)~(F)를 준비하여 구리 조각을 넣는다. 시험관 (D)에 진한 황산을 넣고 가열하여 변화를 관찰한다. 시험관 (E)에는 묽은 질산, 시험관 (F)에는 진한 질산을 넣고 변화를 관찰한다.

### 결과

1. 방법 2에서는 과망가니즈산 칼륨 수용액의 적자색이 사라지고 용액이 갈색이 되었다(아이오딘 생성).
2. 방법 3에서는 수용액이 청자색이 되었다(아이오딘-녹말 반응).
3. 방법 4에서는 (B), (C) 모두 기체가 발생하였고 수용액이 무색이 되었다.
4. 방법 5의 (D)에서는 자극적인 냄새가 나는 기체가 발생하고 수용액이 약간 파랗게 되었다. (E)에서는 무색 기체가 발생하였지만 시험관 입구 부근에서 갈색으로 변하였다. 또 수용액이 파랗게 되었다. (F)에서는 갈색 기체가 발생하고 수용액이 청록색이 되었다.

### 고찰

**1. 방법 2, 4, 5에서 일어나는 반응을 각각 화학 반응식으로 나타내라.**

- 방법 2: 2KMnO<sub>4</sub> + 10KI + 8H<sub>2</sub>SO<sub>4</sub> → 2MnSO<sub>4</sub> + 6K<sub>2</sub>SO<sub>4</sub> + 8H<sub>2</sub>O + 5I<sub>2</sub>
- 방법 4 (B): 2KMnO<sub>4</sub> + 5(COOH)<sub>2</sub> + 3H<sub>2</sub>SO<sub>4</sub> → 2MnSO<sub>4</sub> + K<sub>2</sub>SO<sub>4</sub> + 8H<sub>2</sub>O + 10CO<sub>2</sub>
- 방법 4 (C): 2KMnO<sub>4</sub> + 5H<sub>2</sub>O<sub>2</sub> + 3H<sub>2</sub>SO<sub>4</sub> → 2MnSO<sub>4</sub> + K<sub>2</sub>SO<sub>4</sub> + 8H<sub>2</sub>O + 5O<sub>2</sub>
- 방법 5 (D): Cu + 2H<sub>2</sub>SO<sub>4</sub> → CuSO<sub>4</sub> + SO<sub>2</sub> + 2H<sub>2</sub>O
- 방법 5 (E): 3Cu + 8HNO<sub>3</sub> → 3Cu(NO<sub>3</sub>)<sub>2</sub> + 4H<sub>2</sub>O + 2NO
- 방법 5 (F): Cu + 4HNO<sub>3</sub> → Cu(NO<sub>3</sub>)<sub>2</sub> + 2H<sub>2</sub>O + 2NO<sub>2</sub>

**2. 방법 5에서 구리가 수소보다 이온화 경향이 작은데도 녹은 까닭은 무엇인가?**

뜨거운 진한 황산, 묽은 질산, 진한 질산은 강한 산화력(酸化力)을 가진 산이기 때문이다.
