### 중요 실험: 수용액의 pH 측정
### 방법
1. 시험관 3개에 염산(塩酸), 아세트산(酢酸), 수산화 나트륨(水酸化ナトリウム)의 각 0.1 mol/L 수용액을 취하고 만능 pH 시험지(万能pH試験紙)로 각각의 pH 어림값을 구한다(그림 1). 다음으로 pH 시험지 세트에서 적절한 시험지를 골라 각 수용액의 pH를 소수 첫째 자리까지 구한다. pH 미터를 사용해도 된다(그림 2).
2. 1의 염산, 아세트산, 수산화 나트륨 수용액을 각각 순수한 물로 10배 희석하여(그림 3) 0.01 mol/L 수용액을 만든다.
3. 2의 0.01 mol/L 수용액의 pH를 1과 같은 방법으로 구한다.
4. 2의 0.01 mol/L 수용액을 각각 순수한 물로 10배 희석하여(그림 3) 0.001 mol/L 수용액을 만든다.
5. 4의 0.001 mol/L 수용액의 pH를 1과 같은 방법으로 구한다.

### 결과
측정 결과는 다음 표와 같았다.

| 수용액 | 농도(mol/L) | pH |
|---|---|---|
| 염산 | 0.1 | 1.1 |
| 염산 | 0.01 | 2.2 |
| 염산 | 0.001 | 3.2 |
| 아세트산 | 0.1 | 2.9 |
| 아세트산 | 0.01 | 3.4 |
| 아세트산 | 0.001 | 4.0 |
| 수산화 나트륨 수용액 | 0.1 | 13.1 |
| 수산화 나트륨 수용액 | 0.01 | 12.1 |
| 수산화 나트륨 수용액 | 0.001 | 11.1 |

### 고찰
1. 같은 농도의 염산과 아세트산에서 pH가 다른 이유를 생각해 보자.
   - **답:** 염산과 아세트산은 이온화도(電離度)가 다르기 때문이다.
2. 순수한 물로 농도를 10배 희석하면 pH는 각각 어떻게 변하는가?
   - **답:** 염산은 약 1씩 커진다. 아세트산은 약 0.5씩 커진다. 수산화 나트륨 수용액은 약 1씩 작아진다.
3. pH = 3.4일 때 [H<sup>+</sup>] = 4.0 × 10<sup>−4</sup> mol/L라고 하여 0.01 mol/L 아세트산의 이온화도를 구하라.
   - **답:** [H<sup>+</sup>] = cα이므로 α = [H<sup>+</sup>]/c = (4.0 × 10<sup>−4</sup> mol/L)/(0.01 mol/L) = **4.0 × 10<sup>−2</sup>**.
