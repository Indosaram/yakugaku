### 과산화 수소와 아이오딘화 칼륨의 반응

1. 황산으로 산성으로 만든 과산화 수소 H<sub>2</sub>O<sub>2</sub> 수용액은 산화제(酸化剤)로 작용하여 반응 후 물 H<sub>2</sub>O이 된다.

   H<sub>2</sub>O<sub>2</sub> + 2H<sup>+</sup> + 2e<sup>−</sup> → 2H<sub>2</sub>O …… ①

   또한 아이오딘화 칼륨 KI 수용액 속 아이오딘화 이온 I<sup>−</sup>(무색)은 환원제(還元剤)로 작용하여 반응 후 아이오딘 I<sub>2</sub>(갈색)이 된다.

   2I<sup>−</sup> → I<sub>2</sub> + 2e<sup>−</sup> …… ②

2. ①식 + ②식에서 e<sup>−</sup>를 소거하면 이온 반응식을 얻는다.

   H<sub>2</sub>O<sub>2</sub> + 2H<sup>+</sup> + 2I<sup>−</sup> → I<sub>2</sub> + 2H<sub>2</sub>O …… ③

3. ③식의 양변에 반응에 관여하지 않은 황산 이온 SO<sub>4</sub><sup>2−</sup>과 칼륨 이온 2K<sup>+</sup>을 더하여 식을 정리하면 화학 반응식을 얻는다.

   H<sub>2</sub>O<sub>2</sub> + H<sub>2</sub>SO<sub>4</sub> + 2KI → I<sub>2</sub> + 2H<sub>2</sub>O + K<sub>2</sub>SO<sub>4</sub>

![그림: 과산화 수소와 아이오딘화 칼륨의 반응. 산화제인 과산화 수소수(황산 산성)와 환원제인 아이오딘화 칼륨 수용액을 섞으면 아이오딘이 유리되어 갈색이 된다.](data/textbook/chem-basic/fig/p0112-1.webp)

**그림 3. 과산화 수소와 아이오딘화 칼륨의 반응** 수용액에서 아이오딘화 이온 I<sup>−</sup>은 무색, 아이오딘 I<sub>2</sub>는 갈색이다.

### 과망가니즈산 칼륨과 과산화 수소의 반응

1. 과망가니즈산 칼륨 KMnO<sub>4</sub> 수용액은 과망가니즈산 이온 MnO<sub>4</sub><sup>−</sup> 때문에 적자색이다. 황산 산성 조건에서³ MnO<sub>4</sub><sup>−</sup>이 산화제로 작용하면 무색의 망가니즈(II) 이온 Mn<sup>2+</sup>이 된다.

   MnO<sub>4</sub><sup>−</sup> + 8H<sup>+</sup> + 5e<sup>−</sup> → Mn<sup>2+</sup> + 4H<sub>2</sub>O …… ④

   과산화 수소는 보통 산화제로 작용하지만, **강한 산화 작용을 가진 KMnO<sub>4</sub>에 대해서는 환원제로 작용하여** 산소 O<sub>2</sub>가 발생한다.

   H<sub>2</sub>O<sub>2</sub> → O<sub>2</sub> + 2H<sup>+</sup> + 2e<sup>−</sup> …… ⑤

2. ④식 × 2 + ⑤식 × 5에서 e<sup>−</sup>를 소거하면 이온 반응식을 얻는다.

   2MnO<sub>4</sub><sup>−</sup> + 5H<sub>2</sub>O<sub>2</sub> + 6H<sup>+</sup> → 2Mn<sup>2+</sup> + 5O<sub>2</sub> + 8H<sub>2</sub>O …… ⑥

3. ⑥식의 양변에 반응에 관여하지 않은 3SO<sub>4</sub><sup>2−</sup>과 2K<sup>+</sup>을 더하여 식을 정리하면 화학 반응식을 얻는다.

   2KMnO<sub>4</sub> + 5H<sub>2</sub>O<sub>2</sub> + 3H<sub>2</sub>SO<sub>4</sub> → 2MnSO<sub>4</sub> + 5O<sub>2</sub> + 8H<sub>2</sub>O + K<sub>2</sub>SO<sub>4</sub>

![그림: 과망가니즈산 칼륨과 과산화 수소의 반응. 산화제인 적자색 과망가니즈산 칼륨 수용액(황산 산성)에 환원제인 무색 과산화 수소수를 섞으면 망가니즈(II) 이온이 생성되어 거의 무색이 된다.](data/textbook/chem-basic/fig/p0112-2.webp)

**그림 4. 과망가니즈산 칼륨과 과산화 수소의 반응** 망가니즈(II) 이온 Mn<sup>2+</sup>은 결정이나 진한 수용액에서는 연한 분홍색이지만 묽은 수용액에서는 거의 무색이다.

**주 3.** 과망가니즈산 칼륨 KMnO<sub>4</sub>를 산성 수용액에서 반응시킬 때 염산을 쓰지 않는다. 염산 속 염화 이온 Cl<sup>−</sup>이 환원제로 작용하기 때문이다.
