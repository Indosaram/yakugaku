### 정기 시험 예상 문제

정답 → 140쪽

### 1 산화수

다음 문장이 맞으면 ○를 쓰고, 틀리면 밑줄 친 부분을 고쳐 올바른 문장으로 만들어라.

1. 원자 번호와 같은 수의 전자를 가진 원자의 산화수(酸化数)는 <u>0</u>이다.
2. 산화수가 음의 값을 갖는 것은 홑원소 물질 상태보다 <u>더 산화된</u> 상태일 때이다.
3. 전자 2개를 받은 원자의 산화수는 <u>2만큼 증가한다</u>.
4. 나트륨 Na, 칼륨 K의 화합물 속 산화수는 <u>반드시 +1이다</u>.
5. 구성 원자의 산화수 합은 다원자 이온에서는 반드시 이온의 전하와 같지만, 분자로 이루어진 물질에서는 <u>반드시 0이라고 할 수는 없다</u>.

### 3 산화 환원 반응의 판정

다음에서 산화 환원 반응(酸化還元反応)을 골라 기호로 답하여라. 또 산화된 원자 또는 이온의 산화수 변화를 (+1 → +2)처럼 나타내라.

- ㄱ. 2KI + Br<sub>2</sub> → I<sub>2</sub> + 2KBr
- ㄴ. NaCl + H<sub>2</sub>SO<sub>4</sub> → NaHSO<sub>4</sub> + HCl
- ㄷ. 2Fe + 3H<sub>2</sub>O<sub>2</sub> + 6HCl → 2FeCl<sub>3</sub> + 6H<sub>2</sub>O
- ㄹ. Fe<sup>2+</sup> + 2OH<sup>−</sup> → Fe(OH)<sub>2</sub>
- ㅁ. Cu + 4HNO<sub>3</sub> → Cu(NO<sub>3</sub>)<sub>2</sub> + 2NO<sub>2</sub> + 2H<sub>2</sub>O

### 4 산화 환원 반응

다음 반응에 대하여 물음에 답하여라.

Cl<sub>2</sub> + H<sub>2</sub>S → 2HCl + S

1. 이 반응을 올바르게 설명하지 않은 것을 다음 ㄱ~ㅁ에서 골라라.
   - ㄱ. Cl<sub>2</sub>는 H<sub>2</sub>S에 의해 환원된다.
   - ㄴ. Cl<sub>2</sub>는 H<sub>2</sub>S에서 전자를 빼앗는다.
   - ㄷ. HCl은 환원되어 생성되었다.
   - ㄹ. Cl 원자와 S 원자의 산화수 변화량은 같다.
   - ㅁ. S 원자의 산화수는 증가한다.
2. 다음 문장의 [ ]에 알맞은 화학식을 써라.

   이 반응의 산화제(酸化剤)는 ① [ ], 환원제(還元剤)는 ② [ ]이다.

### 5 산화제의 작용

0.10 mol/L 과망가니즈산 칼륨 수용액 10 mL를 황산 산성에서 사용하면 철(Ⅱ) 이온 Fe<sup>2+</sup> 몇 mol을 산화시킬 수 있는가? 단, 다음 반응이 일어난다고 한다.

MnO<sub>4</sub><sup>−</sup> + 8H<sup>+</sup> + 5e<sup>−</sup> → Mn<sup>2+</sup> + 4H<sub>2</sub>O

Fe<sup>2+</sup> → Fe<sup>3+</sup> + e<sup>−</sup>

### 6 산화제와 환원제의 양적 관계

0.10 mol/L 과산화 수소수 10 mL에 황산을 넣어 산성으로 만든 뒤 농도를 모르는 과망가니즈산 칼륨 수용액을 떨어뜨렸더니 16 mL를 넣었을 때 종말점에 도달하였다. 다음 물음에 답하여라.

1. 과산화 수소와 과망가니즈산 칼륨의 반응을 이온 반응식으로 나타내라.

   MnO<sub>4</sub><sup>−</sup> + 8H<sup>+</sup> + 5e<sup>−</sup> → Mn<sup>2+</sup> + 4H<sub>2</sub>O … ①

   H<sub>2</sub>O<sub>2</sub> → O<sub>2</sub> + 2H<sup>+</sup> + 2e<sup>−</sup> … ②
