## 3. 결합 엔탈피

### 1. 결합 엔탈피 알아보기

### 결합 엔탈피

원자 사이의 공유 결합을 끊거나 원자 사이에 공유 결합이 형성될 때에는 열의 출입이 있다. 일반적으로 **기체 분자에서 공유 결합 1 mol을 끊는 데 필요한 에너지**를 그 결합의 **결합 엔탈피(結合エンタルピー)**라고 하며, 단위는 kJ/mol이다.

예를 들어 수소 분자 1 mol을 수소 원자 2 mol로 만들려면 436 kJ의 에너지가 필요하다. 즉, H<sub>2</sub> 분자 속 H−H 결합의 결합 엔탈피는 436 kJ/mol이다.

H<sub>2</sub>(기체) → 2H(기체)　ΔH = 436 kJ

반대로 H 원자 2 mol이 H<sub>2</sub> 분자로 될 때에는 436 kJ의 에너지가 방출된다.

2H(기체) → H<sub>2</sub>(기체)　ΔH = −436 kJ

| 결합 | 결합 엔탈피 [kJ/mol] |
|---|---:|

| H−Cl | 432 |

| N−H (NH<sub>3</sub>) | 391 |
| O=O | 498 |

결합 엔탈피는 보통 공유 결합의 끊어짐과 생성 양쪽에 적용할 수 있도록 절댓값으로 나타낸다.

### 2. 결합 엔탈피와 반응 엔탈피의 관계

각 결합 엔탈피 값을 알면 여러 화학 반응의 반응 엔탈피(反応エンタルピー)를 계산으로 구할 수 있다.

**예:** H−H, Cl−Cl, H−Cl의 결합 엔탈피를 각각 436 kJ/mol, 243 kJ/mol, 432 kJ/mol로 하여 다음 반응의 반응 엔탈피 ΔH를 구하여라.

H<sub>2</sub>(기체) + Cl<sub>2</sub>(기체) → 2HCl(기체) … Ⓐ

**열화학 반응식을 이용하는 방법**

H<sub>2</sub>(기체) → 2H(기체)　ΔH = 436 kJ … ①

Cl<sub>2</sub>(기체) → 2Cl(기체)　ΔH = 243 kJ … ②

HCl(기체) → H(기체) + Cl(기체)　ΔH = 432 kJ … ③

Ⓐ식의 반응 엔탈피를 x [kJ/mol]라 놓으면, Ⓐ식은 ①식 + ②식 − ③식 × 2로 구성된다. ΔH 부분에도 같은 계산을 하면,

x = (436 + 243) − (432 × 2) = −185 kJ … ④

여기서 (436 + 243)은 반응물의 결합 엔탈피, (432 × 2)는 생성물의 결합 엔탈피, −185 kJ는 반응 엔탈피이다.

④식으로부터 반응 엔탈피와 각 결합 엔탈피 사이에는 다음 관계가 성립한다.

**반응 엔탈피 ΔH = 반응물의 결합 엔탈피의 총합 − 생성물의 결합 엔탈피의 총합**

**보충 1.** 이 관계는 반응물과 생성물이 모두 기체인 경우에만 성립한다.
