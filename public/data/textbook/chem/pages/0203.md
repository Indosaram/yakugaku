### 에틸렌의 성질
1. 달콤한 냄새가 나는 무색 기체이며 물에 잘 녹지 않는다.
2. 공기 중에서 밝은 불꽃을 내며 잘 탄다.

### 에틸렌의 반응
1. **첨가 반응(付加反応)**: C=C 결합의 강도는 같지 않아 하나는 강하고 다른 하나는 비교적 약하다. 따라서 이중 결합을 가진 탄소 원자는 다른 원자와 결합하는 경우가 많다. 일반적으로 불포화 결합이 열리고 다른 원자나 원자단이 새로 결합하는 반응을 첨가 반응이라고 한다. 예를 들어 에틸렌은 촉매 없이도 할로젠과 첨가 반응을 하며, 다른 분자와는 촉매가 있을 때 첨가 반응을 한다.

   - **브로민의 첨가**: 그림 3처럼 브로민수의 적갈색이 사라진다. 불포화 결합 검출에도 이용된다.

     CH<sub>2</sub>=CH<sub>2</sub> + Br<sub>2</sub> → CH<sub>2</sub>Br–CH<sub>2</sub>Br (1,2-다이브로모에테인)

   - **수소의 첨가**: Ni, Pt 등의 촉매를 사용한다.

     CH<sub>2</sub>=CH<sub>2</sub> + H<sub>2</sub> → CH<sub>3</sub>–CH<sub>3</sub> (에테인)

   - **물의 첨가**: 인산 H<sub>3</sub>PO<sub>4</sub> 등의 촉매를 사용한다.

     CH<sub>2</sub>=CH<sub>2</sub> + H<sub>2</sub>O → CH<sub>3</sub>CH<sub>2</sub>OH (에탄올)

   ![그림: 에틸렌을 브로민수에 통과시키기 전후의 색 변화](data/textbook/chem/fig/p0203-1.webp)

   그림 3. 에틸렌에 브로민을 첨가하는 반응. 에틸렌을 브로민수(적갈색)에 통과시키면 색이 사라진다.

2. **산화 반응(酸化反応)**: 에틸렌을 과망가니즈산 칼륨 수용액에 통과시키면 MnO<sub>4</sub><sup>−</sup>의 적자색이 사라지고 산화 망가니즈(IV) MnO<sub>2</sub>의 갈색 침전이 생긴다. 이 반응도 불포화 결합 검출에 이용된다.
3. **첨가 중합(付加重合)**: 촉매를 사용하거나 가압 가열하여 처리하면 많은 알켄 분자가 서로 결합하여 분자량이 큰 화합물[고분자 화합물(高分子化合物)]을 만든다. 이런 반응을 첨가 중합이라고 한다. 중합에 사용되는 분자량이 작은 화합물을 단량체(単量体, 모노머), 중합으로 생성된 고분자 화합물을 중합체(重合体, 폴리머)라고 한다(→ p.248).

   nCH<sub>2</sub>=CHX → [–CH<sub>2</sub>–CHX–]<sub>n</sub>

   주 2. 이때 에틸렌 외에 프로펜과 뷰텐 등의 알켄도 생성된다.

   주 3. 이때의 열화학 반응식: C<sub>2</sub>H<sub>4</sub> + 3O<sub>2</sub> → 2CO<sub>2</sub> + 2H<sub>2</sub>O(액체), ΔH = −1411 kJ.

   주 4. 비닐기 CH<sub>2</sub>=CH–를 가진 화합물을 비닐 화합물(ビニル化合物)이라고 한다. 비닐 화합물은 이중 결합이 있으므로 같은 분자끼리 다수 첨가 중합하여 사슬형 고분자 화합물을 만든다(→ p.284).

| 치환기 X | 고분자 화합물 |
|---|---|
| –Cl | 폴리염화 비닐 |
| –CH<sub>3</sub> | 폴리프로필렌 |
| –CN | 폴리아크릴로니트릴 |
| –OCOCH<sub>3</sub> | 폴리초산 비닐 |
