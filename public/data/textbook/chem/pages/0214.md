## 2. 알데하이드와 케톤

### 1. 카보닐 화합물이란

카보닐기(カルボニル基) >C=O에 H 원자가 결합한 폼일기[ホルミル基, 알데하이드기(アルデヒド基)] −CHO를 갖는 화합물을 알데하이드(アルデヒド)라고 한다. 또한 카보닐기에 두 탄화수소기가 결합한 화합물을 케톤(ケトン)이라고 한다. 알데하이드와 케톤을 합쳐 카보닐 화합물(カルボニル化合物)이라고 총칭한다.

### 2. 폼알데하이드 알아보기

**폼알데하이드(ホルムアルデヒド) HCHO의 제법**: 메탄올을 촉매(Pt, Cu)를 사용하여 공기 중 산소로 산화시킨다(그림 1).

CH<sub>3</sub>OH + (O) → HCHO + H<sub>2</sub>O

![그림: 그림 1. 폼알데하이드의 실험실 제법. 약 50 ℃의 물에 메탄올을 넣은 시험관을 담그고 가열한 구리선을 메탄올 증기에 접촉시킨다. 표기: 약 50 ℃의 물, 가열한 구리선, 메탄올.](data/textbook/chem/fig/p0214-1.webp)

주 1. 산화제가 제공하는 산소를 (O)로 나타낸다.

**폼알데하이드의 성질**

1. 무색이며 강한 자극적인 냄새가 나는 기체이고 독성이 강하다.
2. 물에 잘 녹는다. 약 37% 수용액을 포르말린(ホルマリン)이라고 하며 살균·소독제나 생물 표본의 보존액으로 사용한다.
3. 산화시키면 폼산[ギ酸, 카복실산의 한 종류]이 된다.

   HCHO + (O) → HCOOH(폼산)

4. 알데하이드는 산화되어 카복실산이 되기 쉬우므로 환원성이 강하며, 펠링 용액(フェーリング液)을 환원시키고 은거울 반응(銀鏡反応)을 보인다. 이들 반응은 알데하이드 검출에 이용된다(그림 2).

   - **펠링 용액의 환원**: 포르말린을 펠링 용액에 넣어 가열하면 붉은색 산화 구리(Ⅰ) Cu<sub>2</sub>O 침전이 생긴다.

     HCHO + 2Cu<sup>2+</sup> + 5OH<sup>−</sup> → HCOO<sup>−</sup> + Cu<sub>2</sub>O + 3H<sub>2</sub>O

   - **은거울 반응**: 포르말린을 암모니아성 질산 은 수용액에 넣고 따뜻하게 하면 시험관 안쪽 벽에 은이 석출되어 은거울을 만든다.

     HCHO + 2Ag<sup>+</sup> + 3OH<sup>−</sup> → HCOO<sup>−</sup> + 2Ag + 2H<sub>2</sub>O

![그림: 그림 2. 펠링 용액의 환원(왼쪽)으로 생긴 붉은색 침전과 은거울 반응(오른쪽)으로 시험관 안쪽에 석출된 은](data/textbook/chem/fig/p0214-2.webp)

주 2. 펠링 용액: CuSO<sub>4</sub> 수용액(A액)과 타타르산 나트륨 칼륨 KNaC<sub>4</sub>H<sub>4</sub>O<sub>6</sub>을 NaOH 수용액에 녹인 용액(B액)을 사용 직전에 같은 양씩 섞어 만든 짙은 청색 수용액이다.

주 3. 암모니아성 질산 은 수용액은 AgNO<sub>3</sub> 수용액에 과량의 암모니아수를 넣은 것이다. 한 번 생성된 Ag<sub>2</sub>O 침전이 다이암민 은(Ⅰ) 이온 [Ag(NH<sub>3</sub>)<sub>2</sub>]<sup>+</sup>이 되어 녹아 있다.
