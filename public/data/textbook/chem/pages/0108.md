**평형 상수(平衡定数)의 이용(2)** 어느 시점에서 각 성분의 농도를 평형 상수 식에 대입하여 K′ 값을 구하고, 그 값을 실제 평형 상수 K와 비교하면 반응이 앞으로 어느 방향으로 진행될지 추정할 수 있다.

주 8. K′ < K이면 정반응이 진행되어 평형 상태에 도달한다. 또 K′ > K이면 역반응이 진행되어 평형 상태에 도달한다.

### 예제 · 평형 상수와 반응이 진행되는 방향

가역 반응 H<sub>2</sub> + I<sub>2</sub> ⇌ 2HI의 어느 온도에서 평형 상수는 8.0이다. √5 = 2.24이다.

(1) 같은 온도에서 10 L의 밀폐 용기에 H<sub>2</sub> 1.0 mol, I<sub>2</sub> 1.0 mol, HI 2.0 mol을 넣었다. 이 반응은 어느 방향으로 진행되는가?

(2) 같은 온도에서 10 L의 밀폐 용기에 H<sub>2</sub> 2.0 mol, I<sub>2</sub> 1.0 mol을 넣고 놓아두었다. 평형일 때 HI의 양(mol)을 구하시오.

**해설**

(1) **주어진 각 물질의 농도를 평형 상수 식에 대입하고, 얻어진 계산값 K′와 실제 평형 상수 K를 비교한다.**

- K′ < K일 때: 정반응(오른쪽 방향)으로 반응이 진행된다.
- K′ = K일 때: 평형 상태. 반응은 겉보기로 진행되지 않는다.
- K′ > K일 때: 역반응(왼쪽 방향)으로 반응이 진행된다.

K′ = [HI]<sup>2</sup>/([H<sub>2</sub>][I<sub>2</sub>])

= [(2.0/10) mol/L]<sup>2</sup> / {[(1.0/10) mol/L] × [(1.0/10) mol/L]} = 4.0

K′ < K이므로 반응은 오른쪽으로 진행된다.

(2) H<sub>2</sub>와 I<sub>2</sub>가 각각 x[mol]씩 반응하여 평형에 도달했다고 하자.

| 상태 | H<sub>2</sub> | I<sub>2</sub> | 2HI | 단위 |
|---|---:|---:|---:|---|
| 반응 전 | 2.0 | 1.0 | 0 | mol |
| 변화량 | −x | −x | 2x | mol |
| 평형일 때 | 2.0 − x | 1.0 − x | 2x | mol |

K = [HI]<sup>2</sup>/([H<sub>2</sub>][I<sub>2</sub>])

= [(2x/10) mol/L]<sup>2</sup> / {[(2.0 − x)/10] mol/L × [(1.0 − x)/10] mol/L} = 8.0

4x<sup>2</sup> = 8(2 − 3x + x<sup>2</sup>)　따라서 x<sup>2</sup> − 6x + 4 = 0

x = [6 ± √(36 − 16)]/2 = (6 ± 2√5)/2 = 3 ± √5

0 < x < 1.0이므로 x = 0.76 mol이다.

따라서 HI의 양(mol)은

2x = 2 × 0.76 = 1.52 ≒ 1.5 mol

x = [−b ± √(b<sup>2</sup> − 4ac)]/(2a)

**답** (1) 오른쪽　(2) 1.5 mol
