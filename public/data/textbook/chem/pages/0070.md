### 3. 반응 엔탈피의 계산 방법은?

### 반응 엔탈피 구하는 방법

1. 주어진 반응 엔탈피(反応エンタルピー)를 열화학 반응식(熱化学反応式)으로 나타낸다.
2. 구하려는 반응 엔탈피를 열화학 반응식으로 나타낸다.
3. 1에서 필요한 화학식을 골라 2의 식을 구성한다.
4. 3에서 정한 계산 방법에 따라 ΔH 부분도 계산한다.

**다른 풀이:** 반응에 관계되는 모든 물질의 생성 엔탈피(生成エンタルピー)를 알면 다음 공식을 사용할 수 있다.

**반응 엔탈피 ΔH = 생성물의 생성 엔탈피의 합 − 반응물의 생성 엔탈피의 합**

단, 홑원소 물질의 생성 엔탈피는 0으로 한다.

**보충 2.** 어떤 발열 반응을 다음과 같이 나타내자.

반응물 → 생성물　ΔH = −x [kJ] … (1)

(1)식에서 홑원소 물질의 엔탈피를 0(기준)으로 하여 엔탈피 그림으로 나타내면 아래와 같으며, 위 공식을 이끌어 낼 수 있다.

![그림: 생성 엔탈피와 반응 엔탈피의 관계. 세로축은 엔탈피로 위가 높고 아래가 낮다. 홑원소 물질의 0 kJ를 기준으로 반응물까지의 차이가 반응물의 생성 엔탈피, 생성물까지의 차이가 생성물의 생성 엔탈피, 반응물에서 생성물까지의 차이가 반응 엔탈피 ΔH이다.](data/textbook/chem/fig/p0070-1.webp)

### 예제: 열화학 반응식의 계산

다음 열화학 반응식을 이용하여 메테인 CH<sub>4</sub>의 생성 엔탈피 [kJ/mol]를 구하여라.

C(흑연) + O<sub>2</sub>(기체) → CO<sub>2</sub>(기체)　ΔH = −394 kJ … ①

H<sub>2</sub>(기체) + ½O<sub>2</sub>(기체) → H<sub>2</sub>O(액체)　ΔH = −286 kJ … ②

CH<sub>4</sub>(기체) + 2O<sub>2</sub>(기체) → CO<sub>2</sub>(기체) + 2H<sub>2</sub>O(액체)　ΔH = −891 kJ … ③

### 해설

구하려는 메테인의 생성 엔탈피를 x [kJ/mol]라 놓고 열화학 반응식을 쓴다.

C(흑연) + 2H<sub>2</sub>(기체) → CH<sub>4</sub>(기체)　ΔH = x [kJ] … ④

④식에 포함되는 화학식을 ①~③식에서 골라 목적하는 열화학 반응식을 구성한다.

| 주목하는 화학식 | 필요한 계산 |
|---|---|
| 왼쪽의 C(흑연) | ①식 × 1 |
| 왼쪽의 2H<sub>2</sub>(기체) | ②식 × 2 |
| 오른쪽의 CH<sub>4</sub>(기체), 이항 필요 | ③식 × (−1) |

따라서 **④식 = ①식 + ②식 × 2 − ③식**이다.

ΔH 부분에도 같은 계산을 하면,

x = (−394) + (−286 × 2) − (−891) = −75 kJ

**답: −75 kJ/mol**

**보충 3.** 이처럼 목적하는 열화학 반응식에 필요한 화학식을 고르고 이를 조합하는 방법을 조립법(組立法)이라고 한다.

**다른 풀이:** ①식은 CO<sub>2</sub>(기체), ②식은 H<sub>2</sub>O(액체)의 생성 엔탈피를 나타내므로, ③식에 공식을 적용할 수 있다.

−891 = {(−394) + (−286 × 2)} − (x + 0)

여기서 {(−394) + (−286 × 2)}는 생성물의 생성 엔탈피의 합, (x + 0)은 반응물의 생성 엔탈피의 합이다.

x = −75 kJ
