# 2 이성질체
## 1 이성질체란 무엇인가
같은 분자식(分子式)을 가지지만 구조의 차이 등으로 서로 다른 성질을 지닌 화합물을 서로 이성질체(異性体)라고 한다.

### 이성질체의 분류

이성질체 → **구조 이성질체(構造異性体)**: 탄소 골격이 서로 다른 것, 작용기의 종류나 위치가 서로 다른 것.

이성질체 → **입체 이성질체(立体異性体)**: 시스-트랜스 이성질체[기하 이성질체(幾何異性体)], 거울상 이성질체[광학 이성질체(光学異性体)].

주 1. 유기 화합물은 비교적 적은 종류의 원소 원자로 이루어져 있음에도 화합물의 수가 방대한 이유 중 하나는 이성질체가 존재하기 때문이다. 예를 들어 알케인(アルカン, → p.198)의 구조 이성질체 수는 다음 표와 같다.

| C<sub>7</sub>H<sub>16</sub> | 9 |
| C<sub>8</sub>H<sub>18</sub> | 18 |
| C<sub>9</sub>H<sub>20</sub> | 35 |
| C<sub>10</sub>H<sub>22</sub> | 75 |
| C<sub>11</sub>H<sub>24</sub> | 159 |
| C<sub>12</sub>H<sub>26</sub> | 355 |

## 2 구조 이성질체 이해하기
### 탄소 골격이 다른 경우
예: 부탄(ブタン)과 2-메틸프로판(2-メチルプロパン)은 모두 C<sub>4</sub>H<sub>10</sub>이다. 부탄은 일렬 탄소 사슬, 2-메틸프로판은 가지형 탄소 골격이다.

### 작용기의 종류가 다른 경우
예: 에탄올(エタノール)과 다이메틸 에테르(ジメチルエーテル)는 모두 C<sub>2</sub>H<sub>6</sub>O이다. 에탄올의 구조는 CH<sub>3</sub>CH<sub>2</sub>OH, 다이메틸 에테르는 CH<sub>3</sub>OCH<sub>3</sub>이다.

### 작용기의 위치가 다른 경우
1. **사슬형 화합물**: 1-프로판올과 2-프로판올은 모두 C<sub>3</sub>H<sub>8</sub>O이지만 하이드록시기의 위치가 다르다.
2. **방향족 화합물**: 벤젠의 H 원자 2개 이상을 다른 원자나 작용기로 치환하면 구조 이성질체가 생긴다.[주 2] 예: o-크레솔, m-크레솔, p-크레솔.

주 2. 벤젠의 이치환체에는 치환기의 위치에 따라 오르토(o-), 메타(m-), 파라(p-)의 세 구조 이성질체가 있다. 그림 표기: 오르토 위치, 메타 위치, 파라 위치.
