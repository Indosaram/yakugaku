### 3 기체를 모으는 방법을 정리한다

기체의 포집 방법(捕集法)은 물에 대한 용해성과 공기에 대한 비중에 따라 다음과 같이 정해진다.

![그림: 기체의 포집 방법. 왼쪽부터 하방 치환, 상방 치환, 수상 치환 장치이다.](data/textbook/chem/fig/p0150-1.webp)

**그림 5. 기체의 포집 방법** 하방 치환으로는 H<sub>2</sub>S, HCl, NO<sub>2</sub>, SO<sub>2</sub>, Cl<sub>2</sub>, CO<sub>2</sub> 등을 모은다. 상방 치환으로는 NH<sub>3</sub> 등을 모은다. 수상 치환으로는 H<sub>2</sub>, O<sub>2</sub>, N<sub>2</sub>, CO, NO, CH<sub>4</sub> 등을 모은다.

![그림: 포집 방법을 고르는 흐름도. 기체가 물에 녹지 않으면 수상 치환, 물에 녹고 공기보다 가벼우면 상방 치환, 물에 녹고 공기보다 무거우면 하방 치환을 이용한다.](data/textbook/chem/fig/p0150-2.webp)

| 기체의 성질 | 포집 방법 |
| --- | --- |
| 물에 녹지 않는다 | 수상 치환(水上置換) |
| 물에 녹고 공기보다 가볍다 | 상방 치환(上方置換) |
| 물에 녹고 공기보다 무겁다 | 하방 치환(下方置換) |

### 4 불순물과 수분을 제거하는 방법

**기체 속 불순물의 제거** 기체 속 불순물이 수용성일 때는 기체를 물에 통과시킨다. 또 산성 불순물은 염기성 수용액에, 염기성 불순물은 산성 수용액에 통과시키면 제거된다.

**기체 속 수분의 제거** 기체 속 수분을 제거하려면 기체를 건조제(乾燥剤)에 통과시킨다. 산성 기체에는 산성 또는 중성 건조제를, 염기성 기체에는 염기성 또는 중성 건조제를 사용한다. 중성 기체에는 대부분의 건조제를 사용할 수 있다.

![그림: 기체의 건조 장치. 왼쪽 두 장치는 솜으로 막은 고체 건조제를 넣고, 오른쪽 두 장치는 액체 건조제를 넣어 기체를 통과시킨다.](data/textbook/chem/fig/p0150-3.webp)

**그림 6. 기체의 건조 장치**

### 핵심: 건조제의 분류

| 분류 | 건조제 |
| --- | --- |
| 산성 건조제 | 십산화 사인(十酸化四リン) P<sub>4</sub>O<sub>10</sub>, 진한 황산 H<sub>2</sub>SO<sub>4</sub> |
| 염기성 건조제 | 산화 칼슘 CaO, 소다 석회(ソーダ石灰, CaO + NaOH) |
| 중성 건조제 | 염화 칼슘 CaCl<sub>2</sub>, 실리카 겔 |

**주 1** 환원성을 가진 H<sub>2</sub>S를 건조할 때 진한 황산을 쓰면 H<sub>2</sub>S가 산화되어 S로 변하므로 적절하지 않다.

**주 2** 소다 석회는 CaO에 진한 NaOH 수용액을 넣고 가열하여 알갱이 모양으로 만든 것이다.

**주 3** NH<sub>3</sub>를 건조할 때 CaCl<sub>2</sub>를 쓰면 반응하여 CaCl<sub>2</sub>·8NH<sub>3</sub>를 생성하므로 적절하지 않다.

### 5 주요 성질에 따라 기체를 분류한다

| 성질 | 기체 |
| --- | --- |
| 1. 물에 매우 잘 녹는 기체 | HCl, NH<sub>3</sub> |
| 2. 물에 녹는 기체 | Cl<sub>2</sub>, H<sub>2</sub>S, SO<sub>2</sub>, NO<sub>2</sub>, CO<sub>2</sub> |
| 3. 물에 잘 녹지 않는 기체 | H<sub>2</sub>, O<sub>2</sub>, N<sub>2</sub>, NO, CO, CH<sub>4</sub> |
| 4. 색이 있는 기체 | NO<sub>2</sub>(적갈색), Cl<sub>2</sub>(황록색), O<sub>3</sub>(연한 파란색) |
| 5. 자극성 냄새가 있는 기체 | Cl<sub>2</sub>, HCl, NO<sub>2</sub>, SO<sub>2</sub>, H<sub>2</sub>S(썩은 달걀 냄새), NH<sub>3</sub> |
| 6. 가연성 기체 | H<sub>2</sub>, H<sub>2</sub>S, CO, NH<sub>3</sub>(산소 속에서) |
| 7. 수용액이 산성을 나타내는 기체 | Cl<sub>2</sub>, HCl, H<sub>2</sub>S, SO<sub>2</sub>, NO<sub>2</sub>, CO<sub>2</sub> |
| 8. 수용액이 염기성을 나타내는 기체 | NH<sub>3</sub> |
| 9. 산화 작용을 하는 기체 | Cl<sub>2</sub>, O<sub>3</sub>, NO<sub>2</sub> |
| 10. 환원 작용을 하는 기체 | H<sub>2</sub>(고온), NO, CO(고온), SO<sub>2</sub>, H<sub>2</sub>S |
