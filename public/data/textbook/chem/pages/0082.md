### 5. 니켈·수소 전지란?

### 니켈·수소 전지

음극 활물질로 **수소 저장 합금(水素吸蔵合金) MH**(수소를 흡수·방출할 수 있는 합금), 양극 활물질로 산화 수산화 니켈(III) NiO(OH), 전해액으로 수산화 칼륨 KOH 수용액을 사용하는 이차 전지이다. **니켈·수소 전지(ニッケル・水素電池)**의 전지식은 다음과 같으며 기전력은 약 1.3 V이다.

(−) MH | KOHaq | NiO(OH) (+)

음극: MH + OH<sup>−</sup> ⇄ M + H<sub>2</sub>O + e<sup>−</sup>

양극: NiO(OH) + e<sup>−</sup> + H<sub>2</sub>O ⇄ Ni(OH)<sub>2</sub> + OH<sup>−</sup>

두 식에서 오른쪽 방향은 방전, 왼쪽 방향은 충전이다.

![그림: 니켈·수소 전지의 반응 원리. 왼쪽 음극은 수소 저장 합금 MH와 M, 오른쪽 양극은 NiO(OH)와 Ni(OH)₂로 표시되어 있다. 방전할 때 음극은 MH에서 M으로, 양극은 NiO(OH)에서 Ni(OH)₂로 변하며 OH⁻는 양극에서 음극 쪽으로 이동한다. 충전할 때에는 모든 방향이 반대가 된다. H₂O도 반응에 관여한다.](data/textbook/chem/fig/p0082-1.webp)

그림 6. 니켈·수소 전지의 반응 원리. 니켈·수소 전지는 전기 자전거, 휴대용 음악 재생기, 무선 전화기 등에 이용된다.

방전·충전으로 KOH 수용액의 농도가 변하지 않으므로 오랫동안 일정한 기전력을 유지하는 특징이 있다.

### 6. 리튬 이온 전지란?

### 리튬 이온 전지

음극 활물질로 Li<sup>+</sup>를 수용한 흑연(LiC<sub>6</sub>), 양극 활물질로 코발트(III)산 리튬 LiCoO<sub>2</sub>, 전해액으로 유기 용매에 리튬염을 녹인 것을 사용하는 이차 전지이다. **리튬 이온 전지(リチウムイオン電池)**의 전지식은 다음과 같으며 기전력은 약 4.0 V이다.

(−) LiC<sub>6</sub> | Li염(유기 용매) | LiCoO<sub>2</sub> (+)

방전할 때에는 다음 반응이 일어난다.

음극: Li<sub>x</sub>C<sub>6</sub> → C<sub>6</sub> + xLi<sup>+</sup> + xe<sup>−</sup>　(0 < x < 0.5)

양극: Li<sub>(1−x)</sub>CoO<sub>2</sub> + xLi<sup>+</sup> + xe<sup>−</sup> → LiCoO<sub>2</sub>　(0 < x < 0.5)

![그림: 리튬 이온 전지의 기본 원리. 왼쪽 음극(−)은 흑연 C층, 오른쪽 양극(+)은 CoO₂층이다. 방전할 때 Li⁺는 흑연층에서 전해액을 거쳐 CoO₂층으로 이동하며 전자 e⁻는 외부 도선을 통해 양극으로 흐른다. 충전할 때 Li⁺는 반대 방향으로 이동한다.](data/textbook/chem/fig/p0082-2.webp)

그림 7. 리튬 이온 전지의 기본 원리

**보충 3.** 흑연은 C 원자 6개당 최대 1개의 Li<sup>+</sup>를 수용할 수 있으므로 완전히 충전된 음극은 LiC<sub>6</sub>으로 나타낸다.

**보충 4.** 화합물을 구성하는 원자의 수를 정수로 나타낼 수 없는 경우에는 소수 x를 사용한다. 예를 들어 Li<sub>(1−x)</sub>CoO<sub>2</sub>는 LiCoO<sub>2</sub>에서 x개(0 < x < 0.5)의 Li<sup>+</sup>가 빠져나간 상태를 나타낸다.

방전할 때 음극에서는 흑연층에 수용되어 있던 Li<sup>+</sup>의 일부가 전해액 속으로 빠져나온다. 양극에서는 Li<sup>+</sup>의 일부가 빠져 있는 CoO<sub>2</sub>층 속으로 Li<sup>+</sup>가 들어간다.

충전할 때에는 방전과 반대 방향의 반응이 일어난다.

리튬 이온 Li<sup>+</sup>가 음극과 양극 사이를 왕복하는 단순한 구조로, 반복적인 방전·충전에 강하며 작고 가볍고 기전력이 높기 때문에 휴대 전화, 노트북 컴퓨터, 전기 자동차 등에 널리 이용된다.
