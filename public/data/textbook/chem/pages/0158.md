### 암모니아 소다법의 공정

- **a.** 석회로에서 석회석 CaCO<sub>3</sub>를 높은 온도로 가열하여 CO<sub>2</sub>를 얻는다.

  CaCO<sub>3</sub> → CaO + CO<sub>2</sub>↑

- **b.** 반응탑에서 NH<sub>3</sub>, CO<sub>2</sub>, NaCl 수용액을 반응시키면 물에 비교적 잘 녹지 않는 NaHCO<sub>3</sub>가 침전한다.

  NaCl + NH<sub>3</sub> + CO<sub>2</sub> + H<sub>2</sub>O → NaHCO<sub>3</sub>↓ + NH<sub>4</sub>Cl

- **c.** 회전로에서 NaHCO<sub>3</sub>를 가열하여 Na<sub>2</sub>CO<sub>3</sub>를 만든다.

  2NaHCO<sub>3</sub> → Na<sub>2</sub>CO<sub>3</sub> + H<sub>2</sub>O + CO<sub>2</sub>↑

- **d.** 산화 칼슘에 물을 넣어 수산화 칼슘을 만든다.

  CaO + H<sub>2</sub>O → Ca(OH)<sub>2</sub>

- **e.** b에서 생성된 NH<sub>4</sub>Cl에 Ca(OH)<sub>2</sub>를 넣고, 발생하는 NH<sub>3</sub>를 회수하여 재이용한다.

  2NH<sub>4</sub>Cl + Ca(OH)<sub>2</sub> → CaCl<sub>2</sub> + 2H<sub>2</sub>O + 2NH<sub>3</sub>↑

### 탄산 나트륨의 성질

1. 흰색 가루로 물에 잘 녹는다. 수용액은 염기성을 나타낸다.
2. 탄산 나트륨을 수용액에서 재결정시키면 탄산 나트륨 십수화물(炭酸ナトリウム十水和物) Na<sub>2</sub>CO<sub>3</sub>·10H<sub>2</sub>O의 무색 결정이 얻어진다. 이를 공기 중에 두면 수화수(결정수)의 일부를 잃고 흰색 가루가 된다(그림 6). 이러한 현상을 풍해(風解)라고 한다.

   Na<sub>2</sub>CO<sub>3</sub>·10H<sub>2</sub>O → Na<sub>2</sub>CO<sub>3</sub>·H<sub>2</sub>O + 9H<sub>2</sub>O

3. 산을 넣으면 분해되어 이산화 탄소를 발생시킨다.

   Na<sub>2</sub>CO<sub>3</sub> + 2HCl → 2NaCl + CO<sub>2</sub>↑ + H<sub>2</sub>O

탄산 나트륨은 유리나 세제 등의 재료로 많이 쓰인다.

### 탄산수소 나트륨 NaHCO<sub>3</sub>의 제법

탄산수소 나트륨(炭酸水素ナトリウム)은 공업적으로 암모니아 소다법으로 만든다.

**주 2** 암모니아 소다법의 b에 해당하는 주반응으로 만들어진다.

### 탄산수소 나트륨의 성질

1. 흰색 가루로 물에 조금 녹는다.
2. 수용액은 약한 염기성을 나타낸다.
3. 가열하거나 산을 넣으면 분해되어 이산화 탄소를 발생시킨다.

   NaHCO<sub>3</sub> + HCl → NaCl + H<sub>2</sub>O + CO<sub>2</sub>↑

탄산수소 나트륨은 중조(重曹)라고도 하며, 베이킹파우더, 위장약, 발포성 입욕제 등에 쓰인다.

![그림: 탄산 나트륨과 탄산수소 나트륨의 성질. 페놀프탈레인 용액을 넣은 물에서 Na2CO3는 진한 빨강, NaHCO3는 연한 빨강을 나타낸다. 묽은 염산을 넣으면 둘 다 CO2를 발생시킨다.](data/textbook/chem/fig/p0158-3.webp)
