그림 4. 이산화 질소 NO<sub>2</sub>의 제법

### 일산화 질소와 이산화 질소의 성질

| 구분 | 일산화 질소(一酸化窒素) NO | 이산화 질소(二酸化窒素) NO<sub>2</sub> |
| --- | --- | --- |
| 상온에서의 상태 | 무색 기체 | 적갈색이며 자극적인 냄새가 나는 기체 |
| 수용성 | 잘 녹지 않는다. | 잘 녹으며 질산이 된다. |
| 산화 반응 | 공기 중에서 쉽게 산화된다. 2NO + O<sub>2</sub> → 2NO<sub>2</sub> | 고온에서 분해하여 산화 작용을 나타낸다. 2NO<sub>2</sub> ⇌ 2NO + O<sub>2</sub> (가열하면 오른쪽, 냉각하면 왼쪽) |

### 질산의 공업적 제법

1. 암모니아 NH<sub>3</sub>를 백금 촉매로 산화시켜 일산화 질소 NO를 만든다(그림 5).

4NH<sub>3</sub> + 5O<sub>2</sub> → 4NO + 6H<sub>2</sub>O

2. 일산화 질소는 쉽게 산화되어 이산화 질소 NO<sub>2</sub>가 된다.

2NO + O<sub>2</sub> → 2NO<sub>2</sub>

3. 이산화 질소를 물에 흡수시키면 질산 HNO<sub>3</sub>가 생성된다. 이때 함께 생성되는 일산화 질소는 2, 3의 과정을 반복하여 모두 질산으로 바꾼다.

3NO<sub>2</sub> + H<sub>2</sub>O → 2HNO<sub>3</sub> + NO

이 질산의 공업적 제법을 오스트발트법(オストワルト法)이라고 한다.

![그림: 오스트발트법의 공정 1. 암모니아와 공기(アンモニアと空気)가 열 교환기(熱交換器)를 거쳐 반응기(反応器)로 들어가고, 800°C의 백금망 촉매(白金網・触媒)에서 NO와 H2O가 된다. 생성 기체는 열 교환기를 지나 NO2 생성 공정으로(NO2生成工程へ) 이동한다. NH3와 O2의 흐름도 표시되어 있다.](data/textbook/chem/fig/p0143-3.webp)

그림 5. 오스트발트법(공정 1)

### 질산의 성질

1. 무색이며 휘발성이 있는 액체이다. 수용액은 강한 산성을 나타낸다.
2. 빛이나 열에 의해 쉽게 분해되어 이산화 질소와 산소를 생성하므로 진한 질산은 갈색 병에 보관한다.

4HNO<sub>3</sub> → 2H<sub>2</sub>O + 4NO<sub>2</sub> + O<sub>2</sub>

3. 산화력이 강하여 금·백금 이외의 이온화 경향이 작은 금속과도 반응하여 녹인다.
4. Fe, Al, Ni 등을 진한 질산에 넣으면 표면에 치밀한 산화 피막이 생겨 반응이 더 진행되지 않는다. 이 상태를 부동태(不動態)라고 한다.
