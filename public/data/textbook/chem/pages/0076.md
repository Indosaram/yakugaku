### 정기 시험 예상 문제

정답 → 308쪽

### 1. 열화학 반응식

다음 (1)~(5)의 내용을 열화학 반응식(熱化学反応式)으로 나타내어라. 화학식량: NaOH = 40

(1) 프로페인 C<sub>3</sub>H<sub>8</sub> 0.1 mol을 완전 연소시키면 222 kJ의 열이 발생한다.

(2) 암모니아 NH<sub>3</sub>의 생성 엔탈피(生成エンタルピー)는 −46 kJ/mol이다.

(3) 수산화 나트륨 NaOH 2.0 g을 다량의 물에 녹이면 2.2 kJ의 열이 발생한다.

(4) 산소 O<sub>2</sub>에서 오존 O<sub>3</sub>이 생성될 때 오존 1 mol당 142 kJ의 열을 흡수한다.

(5) 0.10 mol/L 염산 200 mL와 0.10 mol/L 수산화 나트륨 수용액 200 mL를 혼합하면 1.14 kJ의 열이 발생한다.

### 2. 열화학 반응식의 의미

N<sub>2</sub>(기체) + O<sub>2</sub>(기체) → 2NO(기체)　ΔH = 180 kJ

위 열화학 반응식에 대하여 다음 물음에 답하여라.

(1) 이 반응은 발열 반응과 흡열 반응 중 어느 것인가?

(2) 반응물과 생성물 중 어느 쪽이 더 큰 엔탈피를 가지는가?

(3) ΔH = 180 kJ/mol은 N<sub>2</sub>의 연소 엔탈피(燃焼エンタルピー)를 나타낸다고 할 수 있는가?

(4) ΔH = 90 kJ/mol은 어떤 반응 엔탈피를 나타내는가?

### 3. 연소 엔탈피

다음 열화학 반응식을 참고하여 물음에 답하여라. 원자량: C = 12

C(흑연) + O<sub>2</sub>(기체) → CO<sub>2</sub>(기체)　ΔH = −394 kJ

(1) 흑연 18 g이 완전 연소할 때의 발열량은 몇 kJ인가?

(2) (1)에서 발생한 열을 모두 물 10 kg에 흡수시켰다면 물의 온도는 몇 K 상승하는가? 단, 물의 비열은 4.2 J/(g·K)로 한다.

### 4. 반응 엔탈피의 종류

다음 (1)~(5)의 식은 어떤 반응 엔탈피(反応エンタルピー)를 나타내는가? 아래 보기에서 기호로 골라라.

(1) NaOHaq + HClaq → NaClaq + H<sub>2</sub>O(액체)　ΔH = −56.5 kJ

(2) KNO<sub>3</sub>(고체) + aq → KNO<sub>3</sub>aq　ΔH = 35 kJ

(3) C(흑연) + ½O<sub>2</sub>(기체) → CO(기체)　ΔH = −111 kJ

(4) C(흑연) → C(기체)　ΔH = 715 kJ

(5) CH<sub>4</sub>(기체) + 2O<sub>2</sub>(기체) → CO<sub>2</sub>(기체) + 2H<sub>2</sub>O(액체)　ΔH = −891 kJ

| 기호 | 종류 |
|---|---|
| ア | 연소 엔탈피 |
| イ | 생성 엔탈피 |
| ウ | 용해 엔탈피(溶解エンタルピー) |
| エ | 중화 엔탈피(中和エンタルピー) |
| オ | 기화 엔탈피(蒸発エンタルピー) |
| カ | 승화 엔탈피(昇華エンタルピー) |

### 5. 반응 엔탈피의 계산

(1) 다음 열화학 반응식을 이용하여 이산화 황 SO<sub>2</sub>의 생성 엔탈피를 구하여라.

S(사방황) + (3/2)O<sub>2</sub>(기체) → SO<sub>3</sub>(기체)　ΔH = −396 kJ

SO<sub>2</sub>(기체) + ½O<sub>2</sub>(기체) → SO<sub>3</sub>(기체)　ΔH = −99 kJ

(2) 다음 열화학 반응식을 이용하여 C(흑연) + CO<sub>2</sub>(기체) → 2CO(기체), ΔH = x [kJ]에서 x 값을 구하여라.

C(흑연) + O<sub>2</sub>(기체) → CO<sub>2</sub>(기체)　ΔH = −394 kJ

CO(기체) + ½O<sub>2</sub>(기체) → CO<sub>2</sub>(기체)　ΔH = −283 kJ

(3) 에틸렌(에텐) C<sub>2</sub>H<sub>4</sub>의 연소 엔탈피는 −1411 kJ/mol, 이산화 탄소 CO<sub>2</sub>와 물(액체) H<sub>2</sub>O의 생성 엔탈피는 각각 −394 kJ/mol, −286 kJ/mol이다. 이를 바탕으로 에틸렌의 생성 엔탈피를 구하여라.
