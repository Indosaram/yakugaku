## LIM-01 샌드위치 정리(협공) [패스]
*はさみうち* · 영상 6:52:10
- **발동 신호**: 직접 구할 수 없는 극한
- **핵심**: 직접 구할 수 없는 극한 → 위아래에서 부등식으로 끼운다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 삼각함수 | sin, cos가 들어 있을 때 | \|sin x\| ≤ 1로 끼운다 |
| 형태2 합 | 많은 항의 합 | 각 항을 최대·최소 항으로 평가 |
| 형태3 곱 | 계승·거듭제곱의 곱 | 각 인수를 1 이하 등으로 평가 |
| 형태4 발산 | ∞로 발산함을 보일 때 | 아래에서 큰 식으로 누른다(밀어내기) |

**연습 문제**: 자연수 n에 대해 aₙ = Σ_{k=1}^{n} 1/√(n²+k)라 하자. (1) lim_{n→∞} aₙ을 구하라. (2) lim_{n→∞} n!/nⁿ을 구하라.

**풀이**:
1. n²+1 ≤ n²+k ≤ n²+n ⇒ 1/√(n²+n) ≤ 1/√(n²+k) ≤ 1/√(n²+1)
2. n/√(n²+n) ≤ aₙ ≤ n/√(n²+1)이고 양 끝 → 1 ⇒ lim aₙ = 1
3. n!/nⁿ = (1/n)·(2/n)⋯(n/n)
4. 0 < n!/nⁿ ≤ 1/n → 0 ⇒ lim n!/nⁿ = 0

**답**: (1) 1 (2) 0

**다른 형태 활용**:
- 형태1 삼각함수: 예) sin n / n일 때 → −1/n ≤ sin n / n ≤ 1/n이므로 0으로 수렴
- 형태4 발산: 예) n + sin n일 때 → n + sin n ≥ n − 1 → ∞이므로 ∞로 발산

## LIM-02 구분구적법 [패스]
*区分求積* · 영상 6:55:25
- **발동 신호**: Σ f(k/n)/n
- **핵심**: n개의 합·곱의 극한 → (1/n)Σ f(k/n) → ∫₀¹ f(x)dx

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 그대로 | (1/n)Σ f(k/n)의 꼴 | ∫₀¹ f(x)dx |
| 형태2 꼴 만들기 | 꼴이 조금 어긋나 있을 때 | n을 묶어 내어 1/n과 k/n을 만든다 |
| 형태3 곱·거듭제곱근 | 곱이나 n제곱근의 극한 | 로그를 취해 합으로 바꾼다 |
| 형태4 구간 | 합이 k = n+1 ~ 2n 등일 때 | k/n의 범위로 적분 구간을 정한다 |

**연습 문제**: 극한 lim_{n→∞} (1/n){(2n)!/n!}^(1/n)을 구하라.

**풀이**:
1. aₙ = (1/n){(n+1)(n+2)⋯(2n)}^(1/n) = Π_{k=1}^{n} (1 + k/n)^(1/n)
2. log aₙ = (1/n)Σ_{k=1}^{n} log(1 + k/n) → ∫₀¹ log(1+x) dx
3. ∫₀¹ log(1+x) dx = [(1+x)log(1+x) − (1+x)]₀¹ = 2log2 − 1
4. aₙ → e^(2log2 − 1) = 4/e

**답**: 4/e

**다른 형태 활용**:
- 형태2 꼴 만들기: 예) Σ_{k=1}^{n} n/(n²+k²) → (1/n)Σ 1/(1+(k/n)²) → ∫₀¹ dx/(1+x²) = π/4
- 형태4 구간: 예) Σ_{k=n+1}^{2n} 1/k → k/n은 1부터 2까지 → ∫₁² dx/x = log2

## LIM-03 유명 극한 [패스]
*有名極限* · 영상 6:58:40
- **발동 신호**: sin x/x, (1+1/n)ⁿ, log
- **핵심**: 0/0 꼴 → 유명 극한의 꼴을 만들어 나누어 처리

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 삼각함수 | sin x, cos x가 들어 있을 때 | sin x/x → 1, (1−cos x)/x² → 1/2 |
| 형태2 지수·로그 | eˣ, log x가 들어 있을 때 | (eˣ−1)/x → 1, log(1+x)/x → 1 |
| 형태3 n제곱 꼴 | (1+1/n)ⁿ 꼴 | (1+1/n)ⁿ → e를 만든다 |
| 형태4 치환 | 꼴이 맞지 않을 때 | 문자 치환·미분계수의 정의 |

**연습 문제**: 극한 lim_{x→0} (e^(x²) − cos x)/(x sin x)를 구하라.

**풀이**:
1. (e^(x²) − cos x)/(x sin x) = (e^(x²) − 1)/(x sin x) + (1 − cos x)/(x sin x)
2. (e^(x²) − 1)/x² · x/sin x → 1·1 = 1
3. (1 − cos x)/x² · x/sin x = sin²x/(x²(1+cos x)) · x/sin x → 1/2·1 = 1/2
4. 1 + 1/2 = 3/2

**답**: 3/2

**다른 형태 활용**:
- 형태3 n제곱 꼴: 예) (1+1/n)²ⁿ → {(1+1/n)ⁿ}² → e²
- 형태4 치환: 예) lim_{x→∞} x sin(1/x) → t = 1/x로 둔다 → sin t/t → 1

## LIM-04 무한급수·등비급수 [패스]
*無限級数・等比級数* · 영상 7:01:53
- **발동 신호**: Σ의 극한
- **핵심**: 무한히 더한 합 → 부분합의 극한(등비급수는 a/(1−r))

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 등비급수 | 각 항이 앞 항의 일정 배 | \|r\| < 1일 때 합은 a/(1−r) |
| 형태2 부분합 | 등비가 아닐 때 | 부분분수 분해 등으로 Sₙ을 구해 n → ∞ |
| 형태3 공비에 문자 | 공비에 x가 들어 있을 때 | \|r\| < 1인 범위를 조사. 초항 0은 따로 처리 |
| 형태4 도형 | 넓이·길이가 무한히 이어질 때 | 비가 등비수열이 되는 점을 찾는다 |

**연습 문제**: 실수 x에 대해 무한급수 x + x/(1+x²) + x/(1+x²)² + ⋯ 를 생각하자. (1) 수렴하는 x의 범위와 합 f(x)를 구하라. (2) x → 0에서 f(x)의 극한을 조사하고, x = 0에서 연속인지 답하라.

**풀이**:
1. 초항 x, 공비 r = 1/(1+x²) (0 < r ≤ 1)
2. x ≠ 0: r < 1이므로 수렴, f(x) = x/(1−r) = (1+x²)/x
3. x = 0: 모든 항이 0 ⇒ f(0) = 0 (수렴하는 x는 모든 실수)
4. f(x) = x + 1/x → ∞ (x → +0) ⇒ x = 0에서 연속이 아니다

**답**: (1) 모든 실수, f(x) = (1+x²)/x (x ≠ 0), f(0) = 0 (2) 연속이 아니다

**다른 형태 활용**:
- 형태2 부분합: 예) Σ 1/(n(n+1)) → 1/n − 1/(n+1)로 분해 → 부분합 1 − 1/(N+1) → 1
- 형태4 도형: 예) 정사각형(넓이 S)의 각 변의 중점을 잇는다 → 넓이비 1/2 → 합계 S/(1 − 1/2) = 2S

## LIM-05 방정식의 해의 극한 [패스]
*方程式の解の極限* · 영상 7:05:50
- **발동 신호**: 「해를 aₙ이라 하자」, 「lim aₙ」
- **핵심**: 「해를 aₙ이라 둔다」 → 부호로 평가하여 끼운다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 존재·개수 | 해가 하나 있음을 보일 때 | 단조성 + 중간값 정리 |
| 형태2 범위 평가 | 해의 대략적 위치 | 끝값의 부호로 범위를 누른다 |
| 형태3 극한 | lim aₙ을 구할 때 | 목표 바로 앞에서 부호를 조사해 aₙ을 끼운다 |
| 형태4 단조수열 | aₙ이 단조일 때 | 단조증가 + 위로 유계 → 수렴 |

**연습 문제**: 자연수 n에 대해 xⁿ + x − 1 = 0의 양의 해를 aₙ이라 하자. (1) 양의 해가 오직 하나 존재하고 0 < aₙ < 1임을 보여라. (2) lim_{n→∞} aₙ = 1임을 보여라.

**풀이**:
1. fₙ(x) = xⁿ + x − 1, fₙ′(x) = nxⁿ⁻¹ + 1 > 0 (x > 0)
2. fₙ(0) = −1 < 0, fₙ(1) = 1 > 0 ⇒ 0 < aₙ < 1 (오직 하나)
3. fₙ(1−ε) = (1−ε)ⁿ − ε < 0 (n이 충분히 클 때)
4. 1 − ε < aₙ < 1 ⇒ lim_{n→∞} aₙ = 1

**답**: lim_{n→∞} aₙ = 1

**다른 형태 활용**:
- 형태2 범위 평가: 예) x³ + x − 1 = 0의 양의 해 a → f(0) = −1 < 0, f(1) = 1 > 0이므로 0 < a < 1
- 형태4 단조수열: 예) aₙ이 증가하고 aₙ < 1 → 위로 유계인 단조증가수열 → 수렴한다

## LIM-06 점화식으로 정해지는 수열의 극한 [패스]
*漸化式で定まる数列の極限* · 영상 7:09:36
- **발동 신호**: aₙ₊₁ = f(aₙ)
- **핵심**: 고정점 α를 구하고, |aₙ − α|가 줄어듦을 보여 끼운다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 고정점 | aₙ₊₁ = f(aₙ) | α = f(α)를 푼다 |
| 형태2 차의 평가 | lim aₙ = α를 보이고 싶을 때 | \|aₙ₊₁ − α\| ≤ r\|aₙ − α\| (r < 1)로 끼운다 |
| 형태3 단조·유계 | 단조증가(감소)이고 유계 | 수렴을 보장 → 극한을 α로 두고 푼다 |
| 형태4 주의 | 극한이 존재하는지 불분명 | 수렴을 보이기 전에 극한을 두지 않는다 |

**연습 문제**: a₁ = 1, aₙ₊₁ = √(aₙ + 2). (1) 1 ≤ aₙ < 2임을 보여라. (2) |aₙ₊₁ − 2| ≤ (1/3)|aₙ − 2|임을 보여라. (3) lim aₙ을 구하라.

**풀이**:
1. α = √(α + 2) ⇒ α² − α − 2 = 0, α = 2
2. 1 ≤ aₙ < 2 ⇒ √3 ≤ aₙ₊₁ < 2 (귀납법)
3. aₙ₊₁ − 2 = (aₙ − 2)/(√(aₙ + 2) + 2), √(aₙ + 2) + 2 ≥ √3 + 2 > 3
4. |aₙ − 2| ≤ (1/3)ⁿ⁻¹ |a₁ − 2| → 0 ⇒ lim aₙ = 2

**답**: 2

**다른 형태 활용**:
- 형태3 단조·유계: 예) a₁ = 1, aₙ₊₁ = aₙ/2 + 1 → 증가하고 aₙ < 2 → 수렴 → α = α/2 + 1에서 α = 2
- 형태4 주의: 예) aₙ₊₁ = 2aₙ, a₁ = 1 → α = 2α에서 α = 0은 오류(실제로는 ∞로 발산)

## LIM-07 진동항의 적분은 사라진다 [패스]
*振動項の積分は消える* · 영상 7:13:49
- **발동 신호**: ∫f(x)sin(nx)dx, sin²nx를 포함한 적분의 극한
- **핵심**: 진동항은 1/n으로 사라진다. sin²nx는 평균 1/2

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 1제곱 | sin nx, cos nx가 1제곱 | 부분적분으로 1/n을 끌어낸다 → 0 |
| 형태2 2제곱 | sin²nx, cos²nx | 반각공식 (1 ∓ cos2nx)/2 → 평균 1/2 |
| 형태3 절댓값 | \|sin nx\| 등 | 1주기 평균으로 평가(구간을 주기로 나눈다) |

**연습 문제**: 극한 lim_{n→∞} ∫₀^(π/2) x sin²(nx) dx를 구하라.

**풀이**:
1. sin²nx = (1 − cos2nx)/2 ⇒ Iₙ = (1/2)∫₀^(π/2) x dx − (1/2)Jₙ, Jₙ = ∫₀^(π/2) x cos2nx dx
2. (1/2)∫₀^(π/2) x dx = π²/16
3. Jₙ = [x sin2nx/(2n)]₀^(π/2) − ∫₀^(π/2) sin2nx/(2n) dx = (cos nπ − 1)/(4n²)
4. |Jₙ| ≤ 1/(2n²) → 0 ⇒ lim Iₙ = π²/16

**답**: π²/16

**다른 형태 활용**:
- 형태3 절댓값: 예) ∫₀^π x|sin nx| dx → |sin nx|의 평균은 2/π → (2/π)∫₀^π x dx = π
