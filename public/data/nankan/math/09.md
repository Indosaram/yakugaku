## INT2-01 1/6 공식 계열 [필수]
*1/6公式系* · 영상 4:29:05
- **발동 신호**: 포물선과 직선, 또는 포물선끼리 둘러싸인 넓이
- **핵심**: 포물선과 직선 사이의 넓이는 교점 α, β만으로 결정된다(1/6 공식).

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 포물선과 직선 | 포물선과 직선으로 둘러싸인 넓이 | S = (|a|/6)(β − α)³ (a는 x²의 계수) |
| 형태2 포물선끼리 | 두 포물선으로 둘러싸인 넓이 | 두 식의 차인 2차식의 계수 a를 써서 같은 공식 적용 |
| 형태3 3차함수와 접선 | 3차함수와 그 접선 | S = (|a|/12)(β − α)⁴ (접점이 중근) |
| 형태4 넓이 조건 | 넓이가 주어져 있을 때 | β − α의 값으로 번역해서 사용 |

**연습 문제**: 포물선 y = x² 위에 두 점 A, B를 잡는다. 선분 AB와 포물선으로 둘러싸인 부분의 넓이가 36이 되도록 A, B를 움직일 때, 선분 AB의 중점 M의 자취를 구하여라.

**풀이**:
1. A, B의 x좌표를 α < β라 하면 S = (β − α)³/6 = 36이므로 β − α = 6
2. M(X, Y)라 하면 X = (α + β)/2, Y = (α² + β²)/2
3. α² + β² = {(α + β)² + (β − α)²}/2
4. Y = {(2X)² + 6²}/4 = X² + 9

**답**: 포물선 y = x² + 9

**다른 형태 활용**:
- 형태2 포물선끼리: 예) y = x²와 y = −x² + 2 → 차는 −2(x + 1)(x − 1) → 넓이 (2/6)·2³ = 8/3
- 형태3 3차함수와 접선: 예) y = x³ 위의 점 (1, 1)에서의 접선은 y = 3x − 2 → 교점 x = −2, 1 → 넓이 3⁴/12 = 27/4

## INT2-02 정적분으로 나타낸 함수 [필수]
*定積分で表された関数* · 영상 4:34:08
- **발동 신호**: ∫ₐᵇ f(t)dt가 상수인 경우, 또는 ∫ₐˣ 꼴이 나올 때
- **핵심**: 적분 구간을 본다. 구간이 상수면 "상수로 둔다", 위끝이 x면 "미분한다".

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 구간이 상수 | ∫ₐᵇ f(t) dt를 포함 | x를 포함하지 않는 단순한 수이므로 k로 둔다 |
| 형태2 위끝이 x | ∫ₐˣ f(t) dt를 포함 | 양변을 x로 미분하고, x = a를 대입해 초기 조건을 얻는다 |
| 형태3 x가 섞임 | ∫ₐᵇ (x + t)f(t) dt처럼 피적분함수에 x가 있음 | x를 적분 밖으로 빼고, 나머지를 상수 p, q로 둔다 |
| 형태4 x − t 꼴 | ∫ₐˣ (x − t)f(t) dt | 전개해서 x를 밖으로 빼고 2번 미분 |

**연습 문제**: 함수 f(x)가 f(x) = 6x² + 3x∫₀¹ f(t) dt + ∫₀¹ t f(t) dt를 만족할 때, f(x)를 구하여라.

**풀이**:
1. p = ∫₀¹ f(t)dt, q = ∫₀¹ t f(t)dt로 두면 f(x) = 6x² + 3px + q
2. p = ∫₀¹ (6t² + 3pt + q)dt = 2 + (3/2)p + q
3. q = ∫₀¹ t(6t² + 3pt + q)dt = 3/2 + p + (1/2)q
4. 정리하면 p + 2q = −4, −2p + q = 3이므로 p = −2, q = −1

**답**: f(x) = 6x² − 6x − 1

**다른 형태 활용**:
- 형태2 위끝이 x: 예) ∫₁ˣ f(t) dt = x² − 3x + 2 → 미분하면 f(x) = 2x − 3. x = 1을 대입하면 양변 모두 0이 되어 확인된다.
- 형태4 x − t 꼴: 예) g(x) = ∫₀ˣ (x − t)f(t) dt = x∫₀ˣ f − ∫₀ˣ tf → 2번 미분하면 g″(x) = f(x)

## INT2-03 절댓값이 붙은 적분 [필수]
*絶対値つき積分* · 영상 4:38:48
- **발동 신호**: ∫|f(x)|dx, ∫|x − t|dx
- **핵심**: 적분 안에 절댓값이 있으면 부호가 바뀌는 지점에서 구간을 나눠 절댓값을 벗긴다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 문자를 포함하지 않음 | ∫|f(x)|dx | f(x) = 0의 해로 구간을 나누고, 부호별로 절댓값을 벗긴다 |
| 형태2 문자 t를 포함 | ∫|x − t|dx 등 | 부호가 바뀌는 지점이 구간 안인지 밖인지로 경우를 나눈다 |
| 형태3 t의 함수로 만듦 | 최솟값·최댓값·그래프를 물을 때 | 구간별 적분을 합쳐 I(t)로 만든 뒤 미분 또는 완전제곱 |
| 형태4 넓이로 봄 | 절댓값 적분의 의미를 해석할 때 | 부호를 무시한 넓이의 합으로 생각하고 그림을 그린다 |

**연습 문제**: 0 ≤ t ≤ 1이라 하자. I(t) = ∫₀¹ |x² − t| dx에 대하여 I(t)의 최솟값과 그때의 t의 값을 구하여라.

**풀이**:
1. x² − t = 0에서 x = √t (0 ≤ √t ≤ 1)
2. s = √t로 두면 I = ∫₀ˢ (s² − x²)dx + ∫ₛ¹ (x² − s²)dx
3. 계산하면 I = (4/3)s³ − s² + 1/3 (0 ≤ s ≤ 1)
4. dI/ds = 2s(2s − 1)이므로 s = 1/2에서 최소
5. I = 1/4, t = s² = 1/4

**답**: t = 1/4일 때 최솟값 1/4

**다른 형태 활용**:
- 형태1 문자를 포함하지 않음: 예) ∫₀² |x² − 1| dx → x = 1에서 나눈다 → 2/3 + 4/3 = 2
- 형태4 넓이로 봄: 예) ∫₋₁¹ |x| dx는 밑변 1, 높이 1인 삼각형 2개분 → 1/2 + 1/2 = 1
