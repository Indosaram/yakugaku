## CPX-01 극형식과 드무아브르 [패스]
*極形式とド・モアブル* · 영상 6:08:06
- **발동 신호**: zⁿ, 편각
- **핵심**: 거듭제곱·곱·몫은 극형식으로 바꾸고, 절댓값과 편각으로 계산한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 거듭제곱 계산 | 분수나 곱의 꼴을 거듭제곱할 때 | 극형식으로 바꾼다. 절댓값은 곱하거나 나누고, 편각은 더하거나 뺀다. |
| 형태2 조건에서 n 구하기 | zⁿ이 실수·순허수·1이 될 때 | 편각의 n배를 π의 정수배 등과 비교한다. |
| 형태3 배각 공식 | cos nθ, sin nθ를 구할 때 | 좌변을 이항전개하고 실수부·허수부를 비교한다. |
| 형태4 주기·합 | (1 + i)ⁿ의 합이나 주기를 다룰 때 | 편각이 한 바퀴 도는 주기로 n을 분류한다. |

**연습 문제**: 복소수 z = (√3 + i)/(1 − i)에 대하여 다음을 구하여라.
(1) z의 절댓값과 편각(0 ≤ θ < 2π)
(2) zⁿ이 실수가 되는 최소의 양의 정수 n과, 그때의 zⁿ의 값

**풀이**:
1. √3 + i = 2(cos π/6 + i sin π/6), 1 − i = √2(cos(−π/4) + i sin(−π/4))
2. z = √2(cos 5π/12 + i sin 5π/12)이므로 |z| = √2, arg z = 5π/12
3. zⁿ = (√2)ⁿ(cos 5nπ/12 + i sin 5nπ/12)
4. zⁿ ∈ ℝ ⟺ sin 5nπ/12 = 0 ⟺ 5n = 12k (k ∈ ℤ)
5. 따라서 n = 12이고, z¹² = (√2)¹²(cos 5π + i sin 5π) = −64

**답**: (1) |z| = √2, arg z = 5π/12 (2) n = 12, z¹² = −64

**다른 형태 활용**:
- 형태3 배각 공식: (cos θ + i sin θ)²을 전개하면 실수부에서 cos 2θ = cos²θ − sin²θ, 허수부에서 sin 2θ = 2 sin θ cos θ를 얻는다.
- 형태4 주기·합: 1 + i = √2(cos 45° + i sin 45°)이므로 8제곱하면 한 바퀴를 돈다. (1 + i)⁸ = 16이므로 n을 8로 나눈 나머지로 분류한다.

## CPX-02 회전과 확대 [패스]
*回転と拡大* · 영상 6:12:18
- **발동 신호**: 정삼각형, 직각
- **핵심**: 정삼각형·직각·변의 비가 나오면 한 꼭짓점을 중심으로 회전과 확대를 생각한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 정삼각형 | 정삼각형 ABC | γ − α = (β − α)(cos(±60°) + i sin(±60°)) |
| 형태2 직각 | 직각삼각형, 직각이등변삼각형 | 90° 회전은 ±i배 |
| 형태3 변의 비가 주어짐 | 변의 비나 각도가 주어질 때 | r(cos θ + i sin θ)배로 확대와 회전 |
| 형태4 모양 판정 | 삼각형의 모양을 조사할 때 | (γ − α)/(β − α)의 편각과 절댓값을 읽는다. |

**연습 문제**: 복소수평면 위에 세 점 A(1 + 2i), B(4 + 3i), C(γ)가 있다. △ABC는 ∠A = 90°, AC = 2AB를 만족하고, C는 제2사분면에 있다.
(1) γ를 구하여라.
(2) △ABC의 외심을 나타내는 복소수를 구하여라.

**풀이**:
1. β − α = (4 + 3i) − (1 + 2i) = 3 + i
2. ∠A = 90°, AC = 2AB이므로 γ − α = ±2i(β − α)
3. γ − α = ±2i(3 + i) = ±(−2 + 6i)이므로 γ = −1 + 8i 또는 3 − 4i
4. C는 제2사분면(실수부가 음수)에 있으므로 γ = −1 + 8i
5. 직각삼각형의 외심은 빗변 BC의 중점이므로 (β + γ)/2 = {(4 + 3i) + (−1 + 8i)}/2 = (3 + 11i)/2

**답**: (1) γ = −1 + 8i (2) (3 + 11i)/2

**다른 형태 활용**:
- 형태1 정삼각형: α = 0, β = 2이면 γ = 2(cos 60° + i sin 60°) = 1 + √3 i이다. 다른 하나는 1 − √3 i이다.
- 형태4 모양 판정: (γ − α)/(β − α) = 1 + i이면 절댓값 √2, 편각 45°이므로 B가 직각인 직각이등변삼각형이다.

## CPX-03 |z| = 1이면 z̄ = 1/z [패스]
*|z|=1 なら z̄=1/z* · 영상 6:16:11
- **발동 신호**: 단위원 위의 점
- **핵심**: |z| = 1이면 z̄ = 1/z로 바꿔서 켤레를 없애고 식을 정리한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 켤레를 역수로 | |z| = 1이 나왔을 때 | zz̄ = 1이므로 z̄ = 1/z |
| 형태2 실수·순허수 | w가 실수 또는 순허수일 때 | 실수이면 w = w̄, 순허수이면 w = −w̄ |
| 형태3 절댓값 계산 | 최대·최소, 거리를 구할 때 | |w|² = ww̄로 전개한다. |
| 형태4 두 점의 합 | |α| = |β| = 1이고 α + β가 주어질 때 | 합의 켤레에서 αβ를 구하고 근과 계수의 관계로 넘어간다. |

**연습 문제**: 복소수 α, β는 |α| = |β| = 1을 만족하고, α + β = (7 + 7i)/5이다.
(1) αβ를 구하여라.
(2) α, β를 구하여라.

**풀이**:
1. |α| = |β| = 1이므로 ᾱ = 1/α, β̄ = 1/β
2. α + β의 켤레는 ᾱ + β̄ = 1/α + 1/β = (α + β)/(αβ)
3. 따라서 αβ = (α + β)/(α + β의 켤레) = (7 + 7i)/(7 − 7i) = (1 + i)/(1 − i) = i
4. α, β는 이차방정식 x² − (7 + 7i)/5 · x + i = 0의 두 근이다. 판별식 D = −2i/25 = ((1 − i)/5)²
5. x = {(7 + 7i)/5 ± (1 − i)/5}/2 = (3 + 4i)/5, (4 + 3i)/5

**답**: (1) αβ = i (2) {α, β} = {(3 + 4i)/5, (4 + 3i)/5}

**다른 형태 활용**:
- 형태2 실수·순허수: |z| = 1, w = (z + 1)/(z − 1)이면 w̄ = (1/z + 1)/(1/z − 1) = (1 + z)/(1 − z) = −w이다. 따라서 w는 순허수(또는 0)이다.
- 형태3 절댓값 계산: |z| = 1일 때 |z + 1|² = (z + 1)(z̄ + 1) = 2 + 2Re z이다. 따라서 최댓값은 z = 1일 때 2이다.

## CPX-04 1의 n제곱근 [패스]
*1の n 乗根* · 영상 6:19:56
- **발동 신호**: zⁿ = 1
- **핵심**: zⁿ = 1의 해 ω에 대해 ωⁿ = 1과 1 + ω + ⋯ + ωⁿ⁻¹ = 0을 쓴다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 지수를 나머지로 | ωⁿ = 1을 쓸 수 있을 때 | 지수를 n으로 나눈 나머지로 정리한다. |
| 형태2 합은 0 | 1 + ω + ⋯ + ωⁿ⁻¹ | zⁿ − 1 = (z − 1)(zⁿ⁻¹ + ⋯ + 1)이므로 0이다. |
| 형태3 켤레인 쌍 | ω의 거듭제곱의 합·곱 | 쌍 (α, β)를 만들어 근과 계수의 관계로 넘어간다. |
| 형태4 cos 값 | cos(2π/n)을 구할 때 | ω + ω⁻¹ = 2cos(2π/n)에서 방정식을 세운다. |

**연습 문제**: ω = cos(2π/7) + i sin(2π/7)라 하고, α = ω + ω² + ω⁴, β = ω³ + ω⁵ + ω⁶이라 하자.
(1) α + β와 αβ의 값을 구하여라.
(2) α의 값을 구하여라.

**풀이**:
1. ω⁷ = cos 2π + i sin 2π = 1이므로 ωᵏ⁺⁷ = ωᵏ
2. z⁷ − 1 = (z − 1)(z⁶ + ⋯ + z + 1)이므로 1 + ω + ⋯ + ω⁶ = 0
3. α + β = ω + ω² + ⋯ + ω⁶ = −1
4. αβ = 3 + (ω + ω² + ⋯ + ω⁶) = 3 − 1 = 2
5. α, β는 x² + x + 2 = 0의 두 근이므로 x = (−1 ± √7 i)/2이다. 이때 Im α = sin(2π/7) + sin(4π/7) − sin(π/7) > 0이므로 허수부가 양수인 쪽을 고른다.

**답**: (1) α + β = −1, αβ = 2 (2) α = (−1 + √7 i)/2

**다른 형태 활용**:
- 형태4 cos 값: n = 5이면 ω⁴ + ω³ + ω² + ω + 1 = 0을 ω²으로 나누고 t = ω + ω⁻¹로 놓으면 t² + t − 1 = 0이 된다.

## CPX-05 복소수의 변환과 자취 [패스]
*複素数の変換と軌跡* · 영상 6:24:05
- **발동 신호**: w = f(z)에서 z가 움직일 때
- **핵심**: w = f(z)의 자취는 z = g(w)로 풀어서 z의 조건에 대입한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 거꾸로 풀기 | w = f(z)로 주어질 때 | z = g(w)의 꼴로 고친다. |
| 형태2 대입 | z의 조건이 원·직선일 때 | z를 w로 바꿔 넣어 w의 조건으로 만든다. |
| 형태3 일차변환 | w = az + b | 회전·확대·평행이동이므로 도형의 모양은 변하지 않는다. |
| 형태4 반전 | w = 1/z | 원점을 지나지 않는 원은 원으로, 원점을 지나는 원은 직선으로 옮겨진다. |

**연습 문제**: 복소수평면 위에서 점 z가 원 |z − 2| = 1 위를 움직인다. w = 1/z라 할 때 다음을 구하여라.
(1) 점 w가 그리는 도형
(2) |w|의 최댓값과 최솟값

**풀이**:
1. z = 1/w (w ≠ 0)
2. |z − 2| = 1에 대입하면 |1/w − 2| = 1이므로 |1 − 2w| = |w|
3. 양변을 제곱하면 (1 − 2w)(1 − 2w̄) = ww̄이므로 3ww̄ − 2w − 2w̄ + 1 = 0
4. 정리하면 (w − 2/3)(w̄ − 2/3) = 1/9이므로 |w − 2/3| = 1/3
5. max |w| = 2/3 + 1/3 = 1, min |w| = 2/3 − 1/3 = 1/3

**답**: (1) 원 |w − 2/3| = 1/3 (2) max |w| = 1, min |w| = 1/3

**다른 형태 활용**:
- 형태3 일차변환: w = (1 + i)z + 2는 배율 √2, 45° 회전, 평행이동이다. 따라서 원 |z| = 1은 중심 2, 반지름 √2인 원으로 옮겨진다.
- 형태4 반전: w = 1/z에서 원 |z − 1| = 1(원점을 지남)은 직선 Re w = 1/2로 옮겨진다.
