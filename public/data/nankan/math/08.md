3차함수 그래프 문제는 극값·그래프(DIF2-01)와 대칭성·변곡점(DIF2-03)으로, 접선이 얽힌 문제는 접선의 개수(DIF2-02)와 공통접선·접할 조건(DIF2-04)으로 처리하는 수학Ⅱ 미분법 4패턴 장.

## DIF2-01 3차함수의 극값·그래프 [필수]
*3次関数の極値・グラフ* · 영상 4:06:56
- **발동 신호**: 3차함수
- **핵심**: 3차함수는 f′을 인수분해해 증감표를 만들고, 극값의 부호·차로 처리한다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 그래프 그리기 | 3차함수의 그래프·극값 | f′(x) = 0으로 증감표를 만든 뒤 극댓값·극솟값을 구한다 |
| 형태2 극값을 가질 조건 | 「극값을 가진다」 | f′(x) = 0이 서로 다른 두 실근을 가져야 하므로 판별식 > 0 |
| 형태3 극값의 차 | 극댓값과 극솟값의 차·거리 | f(α) − f(β) = (a/2)(β − α)³ (a는 x³의 계수) |
| 형태4 실근의 개수 | f(x) = 0의 실근 개수 | 극댓값·극솟값의 부호로 판정(하나는 양, 하나는 음이면 3개) |

**연습 문제**: a를 양의 상수라 하고 f(x) = x³ − 3ax² + 4라 하자. (1) 방정식 f(x) = 0이 서로 다른 세 실근을 갖도록 하는 a의 범위를 구하라. (2) f(x)의 극댓값과 극솟값의 차가 108일 때 a의 값을 구하라.

**풀이**:
1. f′(x) = 3x(x − 2a)이다. x = 0에서 극대 f(0) = 4, x = 2a에서 극소 f(2a) = 4 − 4a³이다.
2. (1) 극댓값 4는 양수이므로 극솟값이 음수이면 된다. 4 − 4a³ < 0 ⇒ a > 1
3. (2) f(0) − f(2a) = 3·(2a)³/6 = 4a³
4. 4a³ = 108 ⇒ a = 3

**답**: (1) a > 1 (2) a = 3

**다른 형태 활용**:
- 형태1 그래프 그리기: f(x) = x³ − 3x이면 f′(x) = 3(x + 1)(x − 1)이므로 극대 f(−1) = 2, 극소 f(1) = −2
- 형태2 극값을 가질 조건: f(x) = x³ + ax² + 3x가 극값을 가지려면 f′(x) = 0의 판별식 조건 a² − 9 > 0이 필요하므로 a < −3, 3 < a

## DIF2-02 접선의 개수 [필수]
*接線の本数* · 영상 4:11:55
- **발동 신호**: 「점에서 그을 수 있는 접선의 개수」
- **핵심**: 「점에서 그을 수 있는 접선의 개수」는 접점 t에 관한 방정식의 서로 다른 실근의 개수와 같다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 곡선 위의 점 | 곡선 위의 점 (a, f(a))에서의 접선 | y = f′(a)(x − a) + f(a) |
| 형태2 곡선 밖의 점 | 점 (p, q)에서 긋는 접선 | 접점을 t로 놓고, 접선이 (p, q)를 지나는 조건으로 t의 방정식을 세운다 |
| 형태3 개수 세기 | 「접선의 개수」 | 접점과 접선이 1대1이면 서로 다른 실근 t의 개수가 곧 접선의 개수 |
| 형태4 3차방정식 | t의 3차방정식이 될 때 | 상수 k를 분리해 k = h(t)로 만들고, 수평선 y = k와의 교점 개수를 센다 |

**연습 문제**: 곡선 C: y = x³ − 3x가 있다. 점 P(1, k)에서 C에 그을 수 있는 접선이 정확히 2개가 되도록 하는 k의 값을 모두 구하라. 또 접선을 3개 그을 수 있도록 하는 k의 범위를 구하라.

**풀이**:
1. 접점을 (t, t³ − 3t)로 놓으면 접선은 y = (3t² − 3)x − 2t³이다.
2. 이 접선이 P(1, k)를 지나므로 k = −2t³ + 3t² − 3 = h(t)이다.
3. h′(t) = −6t(t − 1)이므로 t = 0에서 극소 −3, t = 1에서 극대 −2이다.
4. y = k와 y = h(t)의 교점 개수가 곧 접선의 개수이다.
5. −3 < k < −2이면 3개, k = −3, −2이면 2개, 그 외에는 1개이다.

**답**: 2개: k = −3, −2 / 3개: −3 < k < −2

**다른 형태 활용**:
- 형태1 곡선 위의 점: f(x) = x³ − 3x 위의 점 (2, 2)에서 f′(2) = 9이므로 접선은 y = 9(x − 2) + 2 = 9x − 16

## DIF2-03 3차함수의 대칭성·변곡점 [권장]
*3次関数の対称性・変曲点* · 영상 4:16:22
- **발동 신호**: 3차함수의 성질
- **핵심**: 3차함수의 그래프는 변곡점에 대해 점대칭이므로, 변곡점을 원점으로 옮겨 생각한다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 변곡점 구하기 | 3차함수의 변곡점 | f″(x) = 0의 해가 변곡점의 x좌표 |
| 형태2 평행이동 | 3차함수의 대칭성을 쓰고 싶을 때 | X = x − p, Y = y − q로 놓아 기함수 Y = aX³ + cX 꼴로 만든다 |
| 형태3 세 점에서 만나는 직선 | 변곡점을 지나는 직선이 그래프와 세 점에서 만날 때 | 교점들은 변곡점에 대해 대칭이다(중점이 변곡점) |
| 형태4 기울기 최소인 접선 | 접선 기울기의 최솟값 | x³의 계수가 양수이면 변곡점에서의 접선 기울기가 최소 |

**연습 문제**: 곡선 C: y = x³ − 3x² + x의 변곡점을 A라 하자. A를 지나고 기울기가 m인 직선 ℓ이 C와 A 이외의 두 점 P, Q에서 만난다고 하자. (1) m의 범위를 구하라. (2) 선분 PQ의 길이가 4√5일 때 m의 값을 구하라.

**풀이**:
1. f″(x) = 6x − 6 = 0에서 x = 1이므로 A(1, −1)이다.
2. X = x − 1, Y = y + 1로 평행이동하면 C는 Y = X³ − 2X, ℓ은 Y = mX가 된다.
3. 두 식을 연립하면 X(X² − (m + 2)) = 0이므로 X = 0, ±√(m + 2)이다. A 이외의 두 점이 존재하려면 (1) m > −2이다.
4. P, Q의 X좌표는 ±√(m + 2)이고 둘 다 기울기 m인 직선 위에 있으므로 PQ² = 4(m + 2)(1 + m²) = 80이다.
5. 정리하면 (m − 2)(m² + 4m + 9) = 0이다. m² + 4m + 9 > 0이므로 m = 2이다.

**답**: (1) m > −2 (2) m = 2

**다른 형태 활용**:
- 형태4 기울기 최소인 접선: f(x) = x³ − 3x² + x에서 f′(x) = 3(x − 1)² − 2이므로 접선 기울기의 최솟값은 변곡점 x = 1에서의 −2

## DIF2-04 공통접선·두 곡선이 접할 조건 [필수]
*共通接線・2曲線が接する条件* · 영상 4:21:57
- **발동 신호**: 「접한다」
- **핵심**: 「접한다」는 공유점에서 함숫값이 일치하고 기울기도 일치한다는 뜻이다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 두 곡선이 접함 | 두 곡선이 x = t인 점에서 접할 때 | f(t) = g(t) 그리고 f′(t) = g′(t) |
| 형태2 포물선과 직선 | 포물선과 직선이 접할 때 | y를 소거한 2차방정식의 판별식 = 0 |
| 형태3 공통접선 | 두 곡선의 공통접선 | 한쪽 곡선의 접선을 세우고, 그 접선이 다른 곡선에 접할 조건을 건다 |
| 형태4 3차함수와 직선 | 3차함수와 직선이 접할 때 | 두 식의 차를 (x − t)²(x − u) 꼴로 인수분해해 계수를 비교한다 |

**연습 문제**: 곡선 C: y = x³ − x와 포물선 D: y = x² + a가 공유점을 가지고, 그 점에서 공통의 접선을 가진다고 하자. 이러한 a의 값을 모두 구하고, 각각에 대해 공통접선의 방정식을 구하라.

**풀이**:
1. 공유점의 x좌표를 t라 하면, 함숫값 일치에서 t³ − t = t² + a, 기울기 일치에서 3t² − 1 = 2t이다.
2. 기울기 조건을 풀면 (3t + 1)(t − 1) = 0이므로 t = 1, −1/3이다.
3. 함숫값 조건에서 a = t³ − t² − t이다. t = 1이면 a = −1이고, 공통접선은 y = 2x − 2이다.
4. t = −1/3이면 a = 5/27이고, 공통접선은 y = −(2/3)x + 2/27이다.

**답**: a = −1일 때 y = 2x − 2 / a = 5/27일 때 y = −(2/3)x + 2/27

**다른 형태 활용**:
- 형태2 포물선과 직선: y = x²과 y = 2x + k가 접하려면 판별식 4 + 4k = 0이어야 하므로 k = −1
- 형태3 공통접선: y = x²과 y = −(x − 2)²에서, 앞 곡선의 접선 y = 2sx − s²이 다른 곡선에 접할 조건으로 s = 0, 2
- 형태4 3차함수와 직선: x³ − 3x + 2 = (x − 1)²(x + 2)이므로 직선 y = −2는 곡선 y = x³ − 3x와 x = 1에서 접한다
