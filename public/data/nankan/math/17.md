|---|---|---|
| 형태1 특수값 대입 | 「모든 x에 대해 성립」하는 조건 | x = 0, ±1 등 다루기 쉬운 값을 대입해 좁힌다 (필요조건) |
| 형태2 계수 비교 | 다항식 등식이 모든 x에 대해 성립 | 계수를 비교 / (차수+1)개의 값을 대입 |

| 형태4 끝에서 평가 | 큰 x·끝점이 결정적 | 끝에서 성립할 조건을 먼저 구해 범위를 좁힌다 |

**연습 문제**: 실수 a, b, c가 |x| ≤ 1을 만족하는 모든 실수 x에 대해 |ax² + bx + c| ≤ 1을 만족하면서 움직일 때, |a| + |b| + |c|의 최댓값을 구하여라.

**풀이**:
1. f(x) = ax² + bx + c로 두고, p = f(1), q = f(−1), r = f(0) = c로 둔다. (|p|, |q|, |r| ≤ 1 : 필요조건)
2. a = (p + q)/2 − r, b = (p − q)/2
3. |a| + |b| = max(|a + b|, |a − b|) = max(|p − r|, |q − r|) ≤ 2
4. |a| + |b| + |c| ≤ 2 + 1 = 3
5. 등호: f(x) = 2x² − 1은 |x| ≤ 1에서 |f(x)| ≤ 1을 만족한다 (충분성).

**답**: 3

**다른 형태 활용**:
- 형태2 계수 비교: x² + ax + b = (x − 1)(x − 2)가 모든 x에 대해 성립 → a = −3, b = 2
- 형태4 끝에서 평가: 모든 x에 대해 ax² + bx + c ≤ 1 → x를 크게 해서 보면 → a ≤ 0

## CROSS-03 작은 n으로 실험 → 일반화 [필수]

- **핵심**: 규칙이 안 보이면 작은 n으로 실험하고, 예상한 뒤, 귀납법으로 증명한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 수열의 일반항 | 점화식에서 aₙ이 보이지 않음 | n = 1, 2, 3을 계산해서 예상 → 수학적 귀납법 |
| 형태2 정수 | 「모든 n에 대해 ~」인 정수 문제 | 작은 n에서 나머지·약수를 조사해 규칙을 발견 |
| 형태3 경우의 수·도형 | n개의 대상을 센다 | 작은 n에서 세어 보고 → 점화식·일반식을 예상 |
| 형태4 부등식 | n에 대한 성립 범위 | 작은 n으로 시험해 반례·등호 조건을 찾는다 |

**연습 문제**: 수열 {aₙ}이 a₁ = 2, aₙ₊₁ = aₙ² − naₙ + 1을 만족한다. (1) aₙ을 n의 식으로 나타내어라. (2) Sₙ = Σₖ₌₁ⁿ 1/(aₖaₖ₊₁)을 구하여라.

**풀이**:
1. a₁ = 2, a₂ = 3, a₃ = 4, a₄ = 5 ⇒ aₙ = n + 1로 예상한다.
2. n = 1일 때 성립한다. aₖ = k + 1이면 aₖ₊₁ = (k + 1)² − k(k + 1) + 1 = k + 2
3. 따라서 aₙ = n + 1 (귀납법으로 증명)
4. 1/(aₖaₖ₊₁) = 1/((k + 1)(k + 2)) = 1/(k + 1) − 1/(k + 2)
5. Sₙ = 1/2 − 1/(n + 2) = n/(2(n + 2))

**답**: (1) aₙ = n + 1　(2) Sₙ = n/(2(n + 2))

**다른 형태 활용**:
- 형태2 정수: n³ − n은 n = 1, 2, 3에서 0, 6, 24 → 6의 배수로 예상 → (n − 1)n(n + 1)로 증명
- 형태3 경우의 수·도형: n계단을 1계단 또는 2계단씩 오르는 방법 → 1, 2, 3, 5가지 → aₙ₊₂ = aₙ₊₁ + aₙ로 예상
- 형태4 부등식: 2ⁿ > n² → n = 2, 3, 4에서는 불성립(반례), n ≥ 5에서 성립으로 예상

|---|---|---|
| 형태1 치역·최대최소 | 식 f(x, y)가 취할 수 있는 값 | f = k로 두고, 실수해를 가질 조건(판별식) |
| 형태2 통과영역 | 매개변수 t를 포함한 직선·곡선이 지나는 범위 | t에 대한 방정식으로 보고, 실수 t가 존재할 조건 |
| 형태3 자취 | 매개변수로 표현된 점의 자취 | (x, y)에 대응하는 t가 존재할 조건 |
| 형태4 범위가 있는 존재 | 해가 α ≤ t ≤ β 안에 있음 | 끝점의 부호·축의 위치·판별식으로 경우를 나눈다 |

**연습 문제**: 실수 x, y가 x² + 2y² = 4를 만족하면서 움직일 때, x + y가 취할 수 있는 값의 범위를 구하여라. 또한 x + y가 최대가 되는 (x, y)를 구하여라.

**풀이**:
1. x + y = k로 둔다. 「x + y = k가 되는 실수 x, y가 존재한다」는 조건을 구한다.
2. (k − y)² + 2y² = 4 ⟺ 3y² − 2ky + k² − 4 = 0
3. D/4 = k² − 3(k² − 4) = 12 − 2k² ≥ 0 ⟺ −√6 ≤ k ≤ √6
4. k = √6일 때 (중근) y = k/3 = √6/3, x = k − y = 2√6/3

**답**: −√6 ≤ x + y ≤ √6, 최대가 되는 점은 (x, y) = (2√6/3, √6/3)

**다른 형태 활용**:
- 형태2 통과영역: 직선 y = 2tx − t² → t² − 2xt + y = 0이 실수해 t를 가짐 → x² − y ≥ 0 → y ≤ x²
- 형태3 자취: x = t + 1/t, y = t² + 1/t² → y = x² − 2이고, t가 존재할 조건에서 |x| ≥ 2
- 형태4 범위가 있는 존재: x² − kx + 1 = 0이 양의 해를 가짐 → 판별식 k² − 4 ≥ 0 이고 축 k/2 > 0 → k ≥ 2

## CROSS-08 유도식을 견주어 활용하기 [필수]
*誘導の式を見立てて使う* · 영상 9:03:08
- **발동 신호**: (1)(2)의 결과가 (3)과 비슷한 형태
- **핵심**: 유도의 결과와 다음 식의 형태를 비교하고, 문자를 치환해 「견주어」 사용한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 그대로 | 앞 문제의 결과가 그대로 통함 | 특별한 값을 대입해 다음으로 |
| 형태2 문자 치환 | 앞 문제의 식과 같은 구조가 나타남 | 문자를 다른 식·값으로 바꿔 적용한다 |
| 형태3 형태 견주기 | 식의 골격이 비슷함 | 전체를 하나의 문자(cos θ = x 등)로 본다 |
| 형태4 재활용 | 앞 문제의 방법이 다음에도 쓰임 | 증명·계산 절차를 한 번 더 따라간다 |

**연습 문제**: (1) 등식 cos 3θ = 4cos³θ − 3cos θ를 보여라. (2) 3차방정식 8x³ − 6x − 1 = 0의 세 해를 cos을 써서 나타내어라. (3) cos(π/9)·cos(5π/9)·cos(7π/9)의 값을 구하여라.

**풀이**:
1. 8x³ − 6x − 1 = 2(4x³ − 3x) − 1이므로 4x³ − 3x = 1/2
2. x = cos θ로 견주면 cos 3θ = 1/2
3. 0 ≤ θ ≤ π에서 θ = π/9, 5π/9, 7π/9 (세 해)
4. 근과 계수의 관계에서 세 근의 곱 = −(−1)/8 = 1/8

**답**: (2) cos(π/9), cos(5π/9), cos(7π/9)　(3) 1/8

**다른 형태 활용**:
- 형태1 그대로: cos 3θ = 4cos³θ − 3cos θ에 θ = π/3을 대입 → cos π = 4·(1/8) − 3·(1/2) = −1
- 형태4 재활용: (k + 1)³ − k³ = 3k² + 3k + 1을 합하는 절차를 앞 문제의 Σk와 같은 방식으로 써서 Σk²를 구한다
