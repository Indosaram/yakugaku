2차함수 단원: 문자·범위가 붙은 1변수 2차함수는 FUNC-01(축과 정의역)과 FUNC-02(전칭과 존재)로, 2변수의 최대·최소는 제약이 없으면 FUNC-04(한 문자 고정), 등식 제약이 있으면 FUNC-05(=k로 놓기)로 처리한다.

## FUNC-01 축과 정의역의 위치로 경우 나누기 [필수]
*軸と定義域の位置で場合分け* · 영상 0:47:20
- **발동 신호**: 문자를 포함한 2차함수의 최대·최소
- **핵심**: 문자를 포함한 2차함수와 정의역이 주어지면, 축과 구간의 위치 관계로 경우를 나눈다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 축이 움직임 | 정의역은 고정, 축의 위치가 문자로 움직임 | 축이 구간의 왼쪽·안·오른쪽인 3가지로 나눔 (최솟값) |
| 형태2 구간이 움직임 | 축은 고정, 구간의 끝이 문자로 움직임 | 구간이 축의 왼쪽·축을 걸침·오른쪽인 3가지로 나눔 |
| 형태3 최댓값 | 아래로 볼록인데 최댓값을 물음 | 구간의 중앙과 축을 비교해, 축에서 먼 끝점에서 최대 (2가지) |
| 형태4 계수에 문자 | x²의 계수가 문자 | 계수가 양·0·음인 경우로, 그래프 방향에 따라 나눔 |

**연습 문제**: a를 실수라 하자. 0 ≤ x ≤ 2에서 함수 f(x) = x² − 4ax + 1의 최솟값을 m(a), 최댓값을 M(a)라 한다. (1) m(a)를 구하라. (2) M(a)를 구하라.

**풀이**:
1. f(x) = (x − 2a)² − 4a² + 1이므로 축은 x = 2a
2. a < 0일 때: m(a) = f(0) = 1
3. 0 ≤ a ≤ 1일 때: m(a) = f(2a) = 1 − 4a²
4. a > 1일 때: m(a) = f(2) = 5 − 8a
5. a ≤ 1/2일 때: M(a) = f(2) = 5 − 8a
6. a ≥ 1/2일 때: M(a) = f(0) = 1

**답**:
- m(a) = 1 (a < 0), 1 − 4a² (0 ≤ a ≤ 1), 5 − 8a (a > 1)
- M(a) = 5 − 8a (a ≤ 1/2), 1 (a ≥ 1/2)

**다른 형태 활용**:
- 형태2 구간이 움직임: 예) f(x) = x² − 2x, a ≤ x ≤ a + 1이면 축 x = 1에 대해 a < 0, 0 ≤ a ≤ 1, a > 1로 나눈다.
- 형태4 계수에 문자: 예) f(x) = ax² − 2x이면 a > 0(아래로 볼록), a = 0(직선), a < 0(위로 볼록)으로 나눈다.

## FUNC-02 전칭은 최솟값, 존재는 최댓값 [필수]
*全称は最小値、存在は最大値* · 영상 0:51:55
- **발동 신호**: 「모든 x에 대하여」, 「어떤 x에 대하여」
- **핵심**: 「모든 x에 대하여」는 최솟값으로, 「어떤 x에 대하여」는 최댓값으로 판단한다. 부정으로 바꿔 말해도 된다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 전칭 | 모든 x에 대해 f(x) ≥ 0 | 구간에서의 최솟값 ≥ 0 |
| 형태2 존재 | 어떤 x에 대해 f(x) ≥ 0 | 구간에서의 최댓값 ≥ 0 |
| 형태3 부정·여집합 | 「어떤」과 「모든」을 서로 바꿔 말할 때 | 부정해서 반대쪽 형태로 고친 뒤, 전체에서 제외 |
| 형태4 정수(상수) 분리 | a ≥ h(x) 꼴로 만들 수 있음 | 전칭은 a ≥ max h, 존재는 a ≥ min h |

**연습 문제**: a를 실수라 하고 g(x) = x² − 2ax + a + 2라 하자. (1) 0 ≤ x ≤ 2를 만족하는 모든 x에 대하여 g(x) > 0이 성립하는 a의 범위를 구하라. (2) 0 ≤ x ≤ 2를 만족하는 어떤 x에 대하여 g(x) ≤ 0이 성립하는 a의 범위를 구하라.

**풀이**:
1. (1)은 전칭이므로 min g > 0을 조건으로 쓴다. g(x) = (x − a)² − a² + a + 2
2. a < 0일 때: g(0) = a + 2 > 0이므로 −2 < a < 0
3. 0 ≤ a ≤ 2일 때: g(a) = −a² + a + 2 > 0이므로 0 ≤ a < 2
4. a > 2일 때: g(2) = 6 − 3a > 0을 만족하는 a는 없다. 따라서 −2 < a < 2
5. (2)는 (1)의 부정이므로 a ≤ −2, 2 ≤ a

**답**: (1) −2 < a < 2  (2) a ≤ −2, 2 ≤ a

**다른 형태 활용**:
- 형태2 존재: 예) 0 ≤ x ≤ 3인 어떤 x에 대해 −x² + 2x ≥ a이면, 최댓값 f(1) = 1에 대해 1 ≥ a
- 형태4 상수 분리: 예) 1 ≤ x ≤ 2인 모든 x에 대해 x² − 2x ≤ a이면, a ≥ max(x² − 2x) = 0

## FUNC-04 2변수의 최대·최소: 한 문자 고정 (예선·결승) [필수]
*2変数の最大最小：1文字固定（予選決勝）* · 영상 0:56:35
- **발동 신호**: x, y가 독립적으로 움직임
- **핵심**: x, y가 독립적으로 움직이면 한 문자를 고정한다. 예선에서 x로 최소화하고, 결승에서 y로 최소화한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 둘 다 자유 | x, y가 독립적으로 움직임 (등식 제약 없음) | 한 문자로 완전제곱 → 나머지도 완전제곱 (제곱의 합) |
| 형태2 한쪽에 범위 | y ≥ 2처럼 한쪽에만 범위가 있음 | 예선은 자유로운 문자, 결승은 범위가 있는 문자 (경우 나누기) |
| 형태3 고정할 문자 선택 | 어느 쪽을 고정해도 될 때 | 범위가 없고 계수가 간단한 문자를 먼저 움직인다 |
| 형태4 양쪽에 범위 | 0 ≤ x ≤ 1, 0 ≤ y ≤ 1 등 | 예선의 최소가 끝점이 될 수 있으므로 예선에서 경우 나누기 |

**연습 문제**: 실수 x, y가 y ≥ 2를 만족하며 움직일 때, f(x, y) = x² + 2xy + 2y² − 2x − 4y + 5의 최솟값과 그때의 x, y의 값을 구하라.

**풀이**:
1. 예선: y를 고정하고 x로 최소화한다.
2. f = (x + y − 1)² + y² − 2y + 4
3. x = 1 − y일 때 최소이고, 그 값은 h(y) = y² − 2y + 4 = (y − 1)² + 3
4. 결승: y ≥ 2에서 h(y)를 최소화하면 y = 2, h(2) = 4
5. x = 1 − 2 = −1

**답**: 최솟값 4, (x, y) = (−1, 2)

**다른 형태 활용**:
- 형태3 고정할 문자 선택: 예) x² − 2xy + 2y² (y ≥ 1)은 범위가 없는 x를 먼저 움직여 (x − y)² + y²로 만든다.
- 형태4 양쪽에 범위: 예) 0 ≤ x, y ≤ 1에서 (x − 2y)² + y²은 꼭짓점 x = 2y가 구간에 들어가는지에 따라 y ≤ 1/2과 y > 1/2로 나눈다.

## FUNC-05 2변수의 최대·최소: =k로 놓기 (역상법) [권장]
*2変数の最大最小：=k とおく（逆像法）* · 영상 1:00:52
- **발동 신호**: 제약 조건이 붙은 f(x, y)의 치역
- **핵심**: 등식 제약이 있는 상태에서 치역을 물으면, 구하는 식을 k로 놓고 제약 조건과 공유점을 갖는 조건으로 바꾼다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 1차식을 k로 | 등식 제약이 있고 구하는 식이 1차식 | 대입해 2차방정식으로 만든 뒤 판별식 D ≥ 0 |
| 형태2 분수식 (기울기) | y/(x + a)처럼 정점과의 기울기 | y = k(x + a)로 놓고, 직선과 제약 조건의 공유점 조건 |
| 형태3 대칭식 | x + y, xy로 쓸 수 있음 | s = x + y, t = xy로 놓고 s² ≥ 4t |
| 형태4 범위 있음 | x에 범위가 있음 | 그래프로 범위 안에 해를 갖는 조건 |

**연습 문제**: 실수 x, y가 x² + y² = 1을 만족하며 움직일 때, y/(x + 2)의 최댓값과 최솟값을 구하라. 또 최댓값을 가질 때의 x, y의 값을 구하라.

**풀이**:
1. y/(x + 2) = k로 놓으면 y = k(x + 2)
2. x² + k²(x + 2)² = 1이므로 (1 + k²)x² + 4k²x + 4k² − 1 = 0
3. D/4 = 1 − 3k² ≥ 0이므로 −√3/3 ≤ k ≤ √3/3
4. k = √3/3일 때 (x, y) = (−1/2, √3/2)

**답**: 최댓값 √3/3 ((x, y) = (−1/2, √3/2)), 최솟값 −√3/3

**다른 형태 활용**:
- 형태1 1차식을 k로: 예) x² + y² = 1, x + y = k이면 2x² − 2kx + k² − 1 = 0이고, D ≥ 0에서 −√2 ≤ k ≤ √2
- 형태3 대칭식: 예) x + y = s, xy = t로 놓으면 실수 조건은 s² ≥ 4t
- 형태4 범위 있음: 예) x ≥ 0이면 2x² − 2kx + k² − 1 = 0이 x ≥ 0에서 해를 갖는 조건으로 조사한다.
