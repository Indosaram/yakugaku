## DIF3-02 부등식의 증명(미분) [패스]
*不等式の証明（微分）* · 영상 7:21:26
- **발동 신호**: 「x > 0에서 ~임을 보여라」
- **핵심**: 「x > 0에서 ~를 보여라」가 나오면 차를 f(x)로 두고 증감을 조사한다. f(0) = 0이 출발점이다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 단조성 | x > 0에서 부등식을 보일 때 | 차를 f로 두고 f′ > 0과 f(0) = 0에서 f > 0을 얻는다 |
| 형태2 거듭 미분 | f′의 부호를 알 수 없을 때 | f″, f‴까지 미분한 뒤 뒤에서부터 거슬러 올라간다 |
| 형태3 최솟값 | 분수·로그가 얽힐 때 | f의 최솟값 ≥ 0을 보인다 |
| 형태4 비교 | a^b와 b^a 비교 등 | 로그를 취해 함수로 만들고 증감을 본다 |

**연습 문제**: (1) x > 0일 때 eˣ > 1 + x + x²/2 + x³/6임을 보여라. (2) lim(x→∞) x²/eˣ = 0임을 보여라.

**풀이**:
1. g(x) = eˣ − 1 − x − x²/2 − x³/6으로 두면 g(0) = 0이다.
2. g′ = eˣ − 1 − x − x²/2, g″ = eˣ − 1 − x, g‴ = eˣ − 1 > 0 (x > 0)이다.
3. g‴ > 0 ⇒ g″ > 0 ⇒ g′ > 0 ⇒ g > 0이다. (g^(k)(0) = 0이므로 단계마다 성립한다.)
4. (1)에서 eˣ > x³/6이므로 0 < x²/eˣ < 6/x → 0이고, 따라서 lim x²/eˣ = 0이다.

**답**: (1) 증명 완료 (2) 0

**다른 형태 활용**:
- 형태3 최솟값: 예) f = eˣ − 1 − x이면 f′ = eˣ − 1이고, 최솟값 f(0) = 0에서 eˣ ≥ 1 + x를 얻는다.
- 형태4 비교: 예) e^π와 π^e 비교. (log x)/x는 x > e에서 감소하므로 (log e)/e > (log π)/π이고, 따라서 e^π > π^e이다.

**답**: 0 < k < e²/4일 때 1개, k = e²/4일 때 2개, k > e²/4일 때 3개

|---|---|---|

**답**: S = (1 + cos θ)sin θ, θ = π/3일 때 최댓값 3√3/4

## DIF3-05 평균값 정리 [패스]
*平均値の定理* · 영상 7:33:21
- **발동 신호**: |f(a) − f(b)|의 평가, 극한
- **핵심**: 함숫값의 차는 f(b) − f(a) = (b − a)f′(c)로 평가한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 부등식 | f(b) − f(a)를 평가할 때 | c의 범위로부터 f′(c)를 억누른다 |
| 형태2 극한 | f(x + 1) − f(x)의 극한 | f′(c)로 바꾸고 c → ∞를 조사한다 |
| 형태3 롤의 정리 | f(a) = f(b)일 때 | f′(c) = 0인 c의 존재를 보인다 |
| 형태4 차의 평가 | \|f′\| ≤ M일 때 | \|f(b) − f(a)\| ≤ M\|b − a\| |

**연습 문제**: (1) 0 < a < b일 때 (b − a)/b < log b − log a < (b − a)/a임을 보여라. (2) Sₙ = Σ(k=1→n) 1/k일 때 lim(n→∞) Sₙ = ∞임을 보여라.

**풀이**:
1. f(x) = log x에 평균값 정리를 쓰면 log b − log a = (b − a)/c (a < c < b)이다.
2. 1/b < 1/c < 1/a이므로 (b − a)/b < log b − log a < (b − a)/a이다.
3. a = k, b = k + 1로 두면 log(k + 1) − log k < 1/k이다.
4. k = 1부터 n까지 합하면 log(n + 1) < Sₙ이고, log(n + 1) → ∞이므로 Sₙ → ∞이다.

**답**: (1) 증명 완료 (2) Sₙ > log(n + 1) → ∞

**다른 형태 활용**:
- 형태2 극한: 예) √(x + 1) − √x = 1/(2√c) (x < c < x + 1)이므로 x → ∞일 때 0이다.
- 형태3 롤의 정리: 예) f = x³ − 3x는 f(0) = f(√3) = 0이므로 그 사이에 f′(c) = 0인 점이 있다(c = 1).
- 형태4 차의 평가: 예) |cos x| ≤ 1이므로 |sin b − sin a| ≤ |b − a|이다.

## DIF3-06 역함수·음함수의 미분 [패스]
*逆関数・陰関数の微分* · 영상 7:37:19
- **발동 신호**: x = g(y), F(x, y) = 0
- **핵심**: 식을 그대로 미분한다. 역함수는 기울기가 역수가 되고, 음함수는 양변을 x로 미분한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 역함수 | y = g(x)가 x = f(y)의 역함수일 때 | g′(x) = 1/f′(g(x)) |
| 형태2 음함수 | F(x, y) = 0 | 양변을 x로 미분한다(y는 합성함수로 취급) |
| 형태3 매개변수 | x = x(t), y = y(t) | dy/dx = (dy/dt)/(dx/dt) |
| 형태4 로그미분 | 곱·거듭제곱 꼴 | 양변에 로그를 취한 뒤 미분한다 |

**연습 문제**: (1) f(x) = xeˣ (x > −1)의 역함수 g에 대하여 g′(e)를 구하여라. (2) 곡선 x³ + y³ = 3xy 위의 점 (3/2, 3/2)에서의 접선의 기울기를 구하여라.

**풀이**:
1. f′(x) = (1 + x)eˣ > 0이므로 역함수 g가 존재한다. f(1) = e이므로 g(e) = 1이다.
2. g′(e) = 1/f′(g(e)) = 1/f′(1) = 1/(2e)이다.
3. 양변을 x로 미분하면 3x² + 3y²y′ = 3y + 3xy′이므로 y′ = (y − x²)/(y² − x)이다.
4. (3/2, 3/2)를 대입하면 (3/2 − 9/4)/(9/4 − 3/2) = −1이다.

**답**: (1) 1/(2e) (2) −1

**다른 형태 활용**:
- 형태3 매개변수: 예) x = t², y = t³이면 dy/dx = 3t²/(2t) = (3/2)t이다.
- 형태4 로그미분: 예) y = xˣ이면 log y = x log x이므로 y′ = xˣ(log x + 1)이다.

## DIF3-07 접선·법선과 곡선이 둘러싼 도형 [패스]
*接線・法線と曲線の囲む図形* · 영상 7:41:34
- **발동 신호**: 접선의 방정식
- **핵심**: 접선은 접점을 t로 두고 y − f(t) = f′(t)(x − t)로 세운다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 접선 | 곡선 위의 점에서의 접선 | y − f(t) = f′(t)(x − t) |
| 형태2 외부의 점에서 | 곡선 밖의 점에서 긋는 접선 | 접점을 t로 두고, 그 점을 지난다는 조건으로 t를 정한다 |
| 형태3 법선 | 접선에 수직인 직선 | 기울기 −1/f′(t) |
| 형태4 공통접선 | 두 곡선이 접할 때 | 함숫값과 미분계수를 일치시킨다 |

**연습 문제**: 원점 O에서 곡선 C : y = log x에 그은 접선을 ℓ이라 하자. (1) ℓ의 방정식과 접점의 좌표를 구하여라. (2) C, ℓ, x축으로 둘러싸인 도형의 넓이 S를 구하여라.

**풀이**:
1. 접점을 (t, log t)로 두면 접선은 y − log t = (1/t)(x − t)이다.
2. 원점을 지나므로 −log t = −1, 즉 t = e이다. 따라서 ℓ : y = x/e, 접점은 (e, 1)이다.
3. S = △ − ∫₁^e log x dx = e/2 − [x log x − x]₁^e이다.
4. S = e/2 − 1이다.

**답**: (1) y = x/e, 접점 (e, 1) (2) S = e/2 − 1

**다른 형태 활용**:
- 형태3 법선: 예) y = log x의 x = 1에서 접선의 기울기는 1이다. 따라서 법선의 기울기는 −1이고, 법선은 y = −x + 1이다.
- 형태4 공통접선: 예) y = ax²와 y = log x가 접하면 at² = log t, 2at = 1/t이므로 t = √e, a = 1/(2e)이다.
