## TRI-01 사인·코사인 법칙으로 변각 변환 [필수]
*正弦・余弦定理で辺角変換* · 영상 1:06:39
- **발동 신호**: 삼각형의 변과 각 사이의 관계
- **핵심**: 변과 각이 섞여 있으면 사인·코사인 법칙으로 각만 또는 변만 남도록 통일한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 변 → 각 | 세 변을 알 때 / 변의 비를 알 때 | 코사인 법칙 cos A = (b² + c² − a²)/(2bc) |
| 형태2 각 → 변 | sin의 비, 외접원의 반지름 | a/sin A = 2R 이므로 sin A : sin B : sin C = a : b : c |
| 형태3 혼재 등식 | 변과 각이 섞인 등식 | 어느 한쪽으로 통일해 인수분해 (이등변인지 직각인지 판정) |
| 형태4 중선·이등분선 | 중선이나 각의 이등분선이 있을 때 | 두 삼각형에서 각각 코사인 법칙 |

**연습 문제**: 삼각형 ABC의 변 BC, CA, AB의 길이를 a, b, c, 외접원의 반지름을 R이라 하자. (sin B + sin C) : (sin C + sin A) : (sin A + sin B) = 4 : 5 : 6 이고 R = 7√3/3 일 때, (1) ∠A를 구하여라. (2) a, b, c와 삼각형 ABC의 넓이를 구하여라.

**풀이**:
1. sin A : sin B : sin C = a : b : c 이므로 (b + c) : (c + a) : (a + b) = 4 : 5 : 6
2. b + c = 4k, c + a = 5k, a + b = 6k로 두면 a : b : c = 7 : 5 : 3
3. cos A = (25 + 9 − 49)/30 = −1/2 이므로 A = 120°
4. a = 2R sin A = 2 · (7√3/3) · (√3/2) = 7 이므로 a, b, c = 7, 5, 3
5. S = (1/2)bc sin A = 15√3/4

**답**: A = 120°, (a, b, c) = (7, 5, 3), S = 15√3/4

**다른 형태 활용**:
- 형태3 혼재 등식: 예) sin A = 2 sin B cos C → 변으로 통일해 정리 → b = c (이등변삼각형)
- 형태4 중선·이등분선: 예) BC의 중점을 M이라 하면 △ABM, △ACM에서 코사인 법칙 → AB² + AC² = 2(AM² + BM²)

## TRI-02 합성해서 하나의 삼각함수로 [필수]
*合成して1つの三角関数へ* · 영상 1:10:48
- **발동 신호**: a sin θ + b cos θ
- **핵심**: 사인과 코사인이 덧셈으로 섞여 있으면 합성해서 하나의 삼각함수로 만든다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 직접 합성 | a sin θ + b cos θ 꼴 | √(a² + b²) sin(θ + α) |
| 형태2 차수 낮추기 → 합성 | sin²θ, sin θ cos θ가 섞여 있을 때 | 2배각 공식으로 2θ로 맞춘 뒤 합성 |
| 형태3 범위 처리 | 범위가 있는 최대·최소, 방정식 | 합성한 각의 범위를 먼저 부등식으로 쓴다 |
| 형태4 α가 특수각이 아닐 때 | tan α = b/a 가 특수각이 아닐 때 | cos α, sin α 값을 남겨 두고 범위를 부등식으로 다룬다 |

**연습 문제**: 0 ≤ θ ≤ π 라 하자. 함수 f(θ) = 2√3 sin θ cos θ + 2 sin²θ 에 대하여 (1) f(θ)의 최댓값, 최솟값과 그때의 θ 값을 구하여라. (2) 방정식 f(θ) = 2를 풀어라.

**풀이**:
1. f = √3 sin 2θ + 1 − cos 2θ
2. f = 2 sin(2θ − π/6) + 1
3. −π/6 ≤ 2θ − π/6 ≤ 11π/6
4. 최대 3 (θ = π/3), 최소 −1 (θ = 5π/6)
5. sin(2θ − π/6) = 1/2 이므로 θ = π/6, π/2

**답**: (1) 최대 3 (θ = π/3), 최소 −1 (θ = 5π/6) (2) θ = π/6, π/2

**다른 형태 활용**:
- 형태1 직접 합성: 예) sin θ + cos θ = √2 sin(θ + π/4)
- 형태4 α가 특수각이 아닐 때: 예) 2 sin θ + cos θ = √5 sin(θ + α), cos α = 2/√5, sin α = 1/√5

## TRI-03 t = sin θ + cos θ 치환 [필수]
*t=sinθ+cosθ 置換* · 영상 1:15:10
- **발동 신호**: sin θ cos θ 와 sin θ + cos θ 가 섞여 있음
- **핵심**: sin θ cos θ 와 sin θ + cos θ 가 섞여 있으면 t = sin θ + cos θ 로 치환한다 (범위 −√2 ≤ t ≤ √2).

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 곱과 합의 혼재 | sin θ cos θ 와 sin θ + cos θ | t² = 1 + 2 sin θ cos θ 로 곱을 t로 나타냄 |
| 형태2 차의 경우 | sin θ − cos θ 가 나올 때 | t² = 1 − 2 sin θ cos θ |
| 형태3 t의 범위 | t에 대한 최대·최소, 방정식 | 합성해서 −√2 ≤ t ≤ √2 (θ의 범위에 주의) |
| 형태4 해의 개수 | 방정식의 해의 개수 | t 값 하나에 θ가 몇 개 대응하는지 확인 |

**연습 문제**: 0 ≤ θ < 2π 라 하자. 함수 f(θ) = sin θ cos θ + sin θ + cos θ 에 대하여 (1) f(θ)의 최댓값, 최솟값과 그때의 θ 값을 구하여라. (2) 방정식 f(θ) = 1을 풀어라.

**풀이**:
1. t = sin θ + cos θ 로 두면 sin θ cos θ = (t² − 1)/2
2. f = (1/2)(t + 1)² − 1, −√2 ≤ t ≤ √2
3. 최소 −1 (t = −1, θ = π, 3π/2), 최대 1/2 + √2 (t = √2, θ = π/4)
4. f = 1 이면 (t − 1)(t + 3) = 0 이므로 t = 1
5. √2 sin(θ + π/4) = 1 이므로 θ = 0, π/2

**답**: (1) 최대 1/2 + √2 (θ = π/4), 최소 −1 (θ = π, 3π/2) (2) θ = 0, π/2

**다른 형태 활용**:
- 형태2 차의 경우: 예) t = sin θ − cos θ → t² = 1 − 2 sin θ cos θ → sin θ cos θ = (1 − t²)/2
- 형태4 해의 개수: 예) 0 ≤ θ < 2π 일 때 t = 1에는 θ가 2개, t = √2에는 θ가 1개 대응

## TRI-04 2배각·반각으로 차수 낮추기 / x = cos θ 다항식화 [필수]
*2倍角・半角で次数下げ／t=cosθ の多項式化* · 영상 1:19:51
- **발동 신호**: cos 2θ, cos 3θ 가 섞여 있음
- **핵심**: cos 2θ, cos 3θ 가 섞여 있으면 x = cos θ 의 다항식으로 맞춘 뒤 미분한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 2배각·3배각 | cos 2θ, cos 3θ 가 섞여 있을 때 | 2x² − 1, 4x³ − 3x 로 바꿔 넣는다 |
| 형태2 반각으로 차수 낮추기 | cos²θ 같은 제곱 | cos²θ = (1 + cos 2θ)/2 |
| 형태3 sin이 섞여 있음 | sin²θ 가 나올 때 | sin²θ = 1 − cos²θ 로 cos로 통일 |
| 형태4 범위·해의 개수 | x = cos θ 의 범위, 방정식의 해 | −1 ≤ x ≤ 1, θ와의 대응 (1대1인지 2대1인지) |

**연습 문제**: 0 ≤ θ ≤ π 라 하자. 함수 f(θ) = 2 cos 3θ + 3 cos 2θ − 6 cos θ 에 대하여 (1) f(θ)의 최댓값, 최솟값과 그때의 θ 값을 구하여라. (2) 방정식 f(θ) = 0의 서로 다른 해의 개수를 구하여라.

**풀이**:
1. x = cos θ (−1 ≤ x ≤ 1) 로 두면 cos 3θ = 4x³ − 3x, cos 2θ = 2x² − 1
2. f = g(x) = 8x³ + 6x² − 12x − 3
3. g′(x) = 12(2x − 1)(x + 1) 이므로 x = −1에서 1/2까지 감소, 1/2에서 1까지 증가
4. g(−1) = 7, g(1/2) = −13/2, g(1) = −1
5. g(−1) > 0, g(1/2) < 0, g(1) < 0 이므로 g(x) = 0의 해는 1개 (x와 θ는 1대1 대응)

**답**: (1) 최대 7 (θ = π), 최소 −13/2 (θ = π/3) (2) 1개

**다른 형태 활용**:
- 형태2 반각으로 차수 낮추기: 예) cos²(π/8) = (1 + cos(π/4))/2 = (2 + √2)/4
- 형태3 sin이 섞여 있음: 예) sin²θ + cos θ = 1 − cos²θ + cos θ = −x² + x + 1 (x = cos θ)

## TRI-05 삼각함수의 합→곱·곱→합 [권장]
*三角関数の和積・積和* · 영상 1:24:50
- **발동 신호**: sin A + sin B 등
- **핵심**: 삼각함수의 합은 합→곱 공식으로 곱(인수분해) 형태로 바꾼다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 합 → 곱 | sin A + sin B 같은 합 | 2 sin((A + B)/2) cos((A − B)/2) |
| 형태2 곱 → 합 | sin A cos B 같은 곱 (적분·차수 낮추기) | (1/2){sin(A + B) + sin(A − B)} |
| 형태3 등간격 각의 합 | sin θ + sin 2θ + sin 3θ | 양 끝을 합→곱 → 가운데 항으로 묶는다 |
| 형태4 삼각형의 각 | A + B + C = π 를 쓸 수 있을 때 | 두 개의 합을 곱으로 바꾸고 나머지 각과 연결 |

**연습 문제**: 0 ≤ θ ≤ π 라 하자. f(θ) = sin θ + sin 2θ + sin 3θ 에 대하여 (1) 방정식 f(θ) = 0을 풀어라. (2) 부등식 f(θ) > 0을 풀어라.

**풀이**:
1. sin θ + sin 3θ = 2 sin 2θ cos θ
2. f = sin 2θ (2 cos θ + 1)
3. f = 0: sin 2θ = 0 (θ = 0, π/2, π), cos θ = −1/2 (θ = 2π/3)
4. 부호: (0, π/2)에서 +, (π/2, 2π/3)에서 −, (2π/3, π)에서 +

**답**: (1) θ = 0, π/2, 2π/3, π (2) 0 < θ < π/2, 2π/3 < θ < π

**다른 형태 활용**:
- 형태2 곱 → 합: 예) sin 3θ cos θ = (1/2)(sin 4θ + sin 2θ)
- 형태4 삼각형의 각: 예) A + B + C = π 이면 sin A + sin B = 2 cos(C/2) cos((A − B)/2)

## TRI-06 삼각형의 넓이·내접원·외접원 [필수]
*三角形の面積・内接円・外接円* · 영상 1:29:15
- **발동 신호**: 넓이 최대 / r, R
- **핵심**: 넓이 S를 축으로 S = (1/2)bc sin A, S = rs, a/sin A = 2R 을 연결한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 두 변과 끼인각 | 두 변과 그 끼인각을 알 때 | S = (1/2)bc sin A (cos는 코사인 법칙으로) |
| 형태2 내접원 | 내접원의 반지름 r | S = rs, s = (a + b + c)/2 (헤론 공식과 병용) |
| 형태3 외접원 | 외접원의 반지름 R | a/sin A = 2R, 또는 R = abc/(4S) |
| 형태4 넓이의 최대 | 넓이가 최대인 삼각형 | 두 변 고정이면 끼인각을 움직인다 / 둘레 고정이면 모양을 정한다 |

**연습 문제**: 삼각형 ABC에서 BC = 7, CA = 8, AB = 9 이다. (1) cos A의 값과 삼각형 ABC의 넓이 S를 구하여라. (2) 내접원의 반지름 r과 외접원의 반지름 R을 구하여라.

**풀이**:
1. cos A = (8² + 9² − 7²)/(2·8·9) = 2/3, sin A = √5/3
2. S = (1/2) · 8 · 9 · (√5/3) = 12√5
3. s = 12, S = rs 이므로 r = √5
4. 7/sin A = 2R 이므로 R = 21√5/10

**답**: cos A = 2/3, S = 12√5, r = √5, R = 21√5/10

**다른 형태 활용**:
- 형태4 넓이의 최대: 예) 두 변 3, 4 고정 → S = (1/2) · 3 · 4 sin C = 6 sin C → C = 90°일 때 최대 6
