## EXP-01 치환해서 2차·3차로 [필수]
*置換して2次・3次へ* · 영상 3:52:40
- **발동 신호**: 4ˣ와 2ˣ가 함께 나옴, log의 제곱
- **핵심**: 지수·로그 식에서 같은 형태가 반복되면 한 문자로 치환해 다항식 문제로 바꾼다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 밑이 같은 지수 | 4ˣ와 2ˣ가 함께 있음 | t = 2ˣ (t > 0)로 놓고 2차·3차 방정식으로 |
| 형태2 로그의 반복 | (log x)²와 log x가 함께 있음 | t = log x로 놓는다. 진수 조건으로 x의 범위 확인 |
| 형태3 역수의 합 | 2ˣ + 2⁻ˣ와 4ˣ + 4⁻ˣ가 함께 있음 | t = 2ˣ + 2⁻ˣ (t ≥ 2), 4ˣ + 4⁻ˣ = t² − 2 |
| 형태4 해의 개수 | 해의 개수·범위를 물을 때 | t의 범위에 주의하고, t의 해와 x의 해의 대응을 조사 |

**연습 문제**: a를 실수인 상수라 하자. x에 대한 방정식 4ˣ − a·2ˣ⁺¹ + 3a + 4 = 0에 대하여, (1) 서로 다른 두 실근을 갖도록 하는 a의 범위, (2) 단 하나의 실근을 갖도록 하는 a의 범위를 구하여라.

**풀이**:
1. t = 2ˣ (t > 0)로 놓으면 g(t) = t² − 2at + 3a + 4 = 0
2. x의 해의 개수 = t > 0인 해의 개수 (1대1 대응)
3. (1) 서로 다른 두 양의 해: D/4 = a² − 3a − 4 > 0, 축 a > 0, g(0) = 3a + 4 > 0 ⇒ a > 4
4. (2) 중근 (D = 0, a > 0)에서 a = 4
5. (2) 양의 해 하나와 양이 아닌 해 하나: g(0) < 0에서 a < −4/3

**답**: (1) a > 4  (2) a = 4, a < −4/3

**다른 형태 활용**:
- 형태2 로그의 반복: 예) (log₂x)² − 3log₂x + 2 = 0 → t = log₂x → t = 1, 2 → x = 2, 4
- 형태3 역수의 합: 예) 4ˣ + 4⁻ˣ − 3(2ˣ + 2⁻ˣ) + 4 = 0 → t = 2ˣ + 2⁻ˣ (t ≥ 2) → t² − 3t + 2 = 0 → t = 2, x = 0

## EXP-02 자릿수·최고 자리의 숫자 [필수]
*桁数・最高位の数字* · 영상 3:57:45
- **발동 신호**: 「몇 자리인가」, 「최고 자리」
- **핵심**: 「자릿수」「최고 자리」「소수 몇째 자리」가 나오면 상용로그를 취해 정수 부분과 소수 부분으로 나눈다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 자릿수 | N은 몇 자리인가 | k − 1 ≤ log₁₀N < k이면 k자리 |
| 형태2 최고 자리의 숫자 | 최고 자리 숫자는 무엇인가 | 소수 부분이 log m 이상 log(m + 1) 미만 → 최고 자리 m |
| 형태3 1보다 작은 수 | 소수 몇째 자리에서 처음으로 0이 아닌 숫자가 나오나 | log N = −k + r (0 ≤ r < 1)로 고친다 → 소수 제k자리 |
| 형태4 조건에서 n 구하기 | 몇 자리 이상이 되는 최소의 n | log 부등식을 n에 대해 푼다 |

**연습 문제**: log₁₀2 = 0.3010, log₁₀3 = 0.4771로 한다. (1) 12³⁰의 자릿수와 최고 자리의 숫자를 구하여라. (2) (1/12)³⁰을 소수로 나타낼 때, 소수 몇째 자리에서 처음으로 0이 아닌 숫자가 나타나는가? 또 그 숫자를 구하여라.

**풀이**:
1. log₁₀12³⁰ = 30(2log₁₀2 + log₁₀3) = 30 × 1.0791 = 32.373
2. 32 ≤ log₁₀12³⁰ < 33 ⇒ 33자리
3. 소수 부분 0.373은 log₁₀2 = 0.301과 log₁₀3 = 0.477 사이 ⇒ 최고 자리 2
4. log₁₀(1/12)³⁰ = −32.373 = −33 + 0.627
5. log₁₀4 = 0.602 ≤ 0.627 < log₁₀5 = 0.699 ⇒ 10⁻³³ × 4.⋯ ⇒ 소수 제33자리에 4

**답**: (1) 33자리, 최고 자리는 2  (2) 소수 제33자리, 숫자는 4

**다른 형태 활용**:
- 형태4 조건에서 n 구하기: 예) 2ⁿ이 10자리 이상이 되는 최소의 n → n log₁₀2 ≥ 9 → n ≥ 9/0.3010 = 29.9⋯ → n = 30

## EXP-03 밑의 통일과 진수 조건 [필수]
*底の統一と真数条件* · 영상 4:02:02
- **발동 신호**: 밑이 서로 다른 log
- **핵심**: 밑이 다른 로그 → 밑을 맞춘다. 진수 조건·밑 조건을 맨 처음에 쓴다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 밑이 다름 | log₄x와 logₓ8처럼 밑이 제각각 | 밑변환 공식 logₐb = log꜀b / log꜀a로 밑을 맞춘다 |
| 형태2 조건 확인 | 진수·밑에 문자가 포함됨 | 진수 > 0, 밑 > 0 그리고 ≠ 1을 맨 처음에 쓴다 |
| 형태3 밑과 진수 바꾸기 | logₐb와 log_b a가 함께 있음 | logₐb = t이면 log_b a = 1/t |
| 형태4 부등식 | 밑이 문자인 부등식 | 밑 > 1이면 부등호 방향 그대로, 0 < 밑 < 1이면 방향이 반대 |

**연습 문제**: (1) 방정식 log₄x + logₓ8 = 5/2를 풀어라. (2) 부등식 log₄x + logₓ8 < 5/2를 풀어라.

**풀이**:
1. 조건: x > 0 그리고 x ≠ 1
2. t = log₂x (t ≠ 0)로 놓으면 log₄x = t/2, logₓ8 = 3/t
3. (1) t/2 + 3/t = 5/2 ⇒ t² − 5t + 6 = 0 ⇒ t = 2, 3 ⇒ x = 4, 8
4. (2) (t − 2)(t − 3)/(2t) < 0 ⇒ t < 0, 2 < t < 3
5. x로 되돌린다 (밑 2 > 1): 0 < x < 1, 4 < x < 8

**답**: (1) x = 4, 8  (2) 0 < x < 1, 4 < x < 8

**다른 형태 활용**:
- 형태4 밑이 1보다 작은 부등식: 예) log₁/₂ x > 1 → 밑이 0 < 1/2 < 1이므로 방향이 반대 → 0 < x < 1/2
