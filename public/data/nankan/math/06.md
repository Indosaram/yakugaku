- **핵심**: 「초등기하」 → 직각·대칭을 살려 좌표를 놓고 계산으로 바꾼다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 직각 도형 | 정사각형·직사각형·직각삼각형일 때 | 직각인 꼭짓점을 원점, 두 변을 좌표축으로 |
| 형태2 대칭 도형 | 이등변삼각형·정삼각형·원일 때 | 대칭축을 y축, 밑변을 x축으로 |
| 형태3 동점 | 점이 변 위를 움직일 때 | 동점을 문자 하나로 나타내 거리·넓이를 식으로 |
| 형태4 각 조건 | ∠PAQ = 45° 같은 조건이 있을 때 | 기울기의 tan과 덧셈정리, 내적 |

**연습 문제**: 한 변의 길이가 2인 정사각형 ABCD의 변 BC 위에 점 P, 변 CD 위에 점 Q를 ∠PAQ = 45°가 되도록 잡는다. 단, P, Q는 꼭짓점이 아니다. BP = p, DQ = q로 놓는다. (1) p, q가 만족하는 관계식을 구하라. (2) △CPQ의 둘레의 길이를 구하라.

**풀이**:
1. A(0, 0), B(2, 0), D(0, 2)로 놓으면 P(2, p), Q(q, 2)이다.
2. tan∠BAP = p/2, tan∠BAQ = 2/q이고, 두 각의 차가 45°이다.
3. 탄젠트 덧셈정리에서 (2/q − p/2) / (1 + p/q) = 1 ⇒ pq + 2p + 2q = 4
4. CP = u = 2 − p, CQ = v = 2 − q로 놓으면 uv = 4u + 4v − 8이다.
5. PQ² = u² + v² = (u + v − 4)²이므로 PQ = 4 − u − v이다. 따라서 둘레 = u + v + PQ = 4이다.

**답**: (1) pq + 2p + 2q = 4 (2) 4

**다른 형태 활용**:
- 형태2 대칭 도형: 한 변이 2인 정삼각형 → A(−1, 0), B(1, 0), C(0, √3)
- 형태3 동점: A(0, 0), B(2, 0), C(0, 2), P(t, 0) → PA² + PB² + PC² = 3t² − 4t + 8

## GEO-09 대칭점으로 꺾은선의 최단 거리 [필수]
*対称点で折れ線の最短* · 영상 3:47:35
- **발동 신호**: AP + PB의 최소, 평면·직선 위의 점 P
- **핵심**: 「꺾은선의 최단」 → 대칭이동으로 꺾은선을 직선으로 편다 (두 점이 같은 쪽에 있는지 꼭 확인)

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 AP + PB | 직선 위의 점 P를 거치는 경로의 최소 | 같은 쪽이면 대칭이동해 AB′, 반대쪽이면 그대로 AB |
| 형태2 |AP − PB| | 차의 최대 | 같은 쪽이면 직선 AB 위에서 P를 잡는다, 반대쪽이면 대칭이동 |
| 형태3 두 직선 | 두 직선 위의 점을 차례로 지나는 꺾은선 | A, B를 각각 대칭이동해 두 상을 잇는다 |
| 형태4 원·포물선 | 원 위 등의 점을 지날 때 | 중심까지의 거리로 평가 + 대칭이동 |

**연습 문제**: 좌표평면 위에 두 점 A(2, 3), B(6, 1)이 있다. 점 P를 y축 위에, 점 Q를 x축 위에 잡을 때, 꺾은선 A → P → Q → B의 길이 AP + PQ + QB의 최솟값을 구하라. 또 그때의 P, Q의 좌표를 구하라.

**풀이**:
1. A, B는 모두 제1사분면에 있다. 즉 두 축에 대해 같은 쪽이다.
2. A를 y축에 대해 대칭이동하면 A′(−2, 3), B를 x축에 대해 대칭이동하면 B′(6, −1)이다.
3. AP + PQ + QB = A′P + PQ + QB′ ≥ A′B′
4. A′B′ = √(8² + 4²) = 4√5
5. 등호는 P, Q가 선분 A′B′ 위에 있을 때 성립한다. 이때 P(0, 2), Q(4, 0)이다(A′, P, Q, B′ 순서).

**답**: 최솟값 4√5, P(0, 2), Q(4, 0)

**다른 형태 활용**:
- 형태2 |AP − PB|: A(1, 2), B(3, 1)(같은 쪽) → 직선 AB와 x축의 교점 P(5, 0)에서 최대 √5
- 형태4 원·포물선: 점 A(5, 0)과 원 x² + y² = 1 위의 점 P → AP의 최소는 5 − 1 = 4
