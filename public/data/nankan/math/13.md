## CURV-01 2차곡선의 표준형과 성질 [패스]
*2次曲線の標準形と性質* · 영상 6:28:49
- **발동 신호**: 타원·쌍곡선·포물선
- **핵심**: 2차곡선 → 표준형에서 a, b, c를 읽고, 초점·정의·접선 공식을 쓴다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 표준형과 초점 | 표준형이 주어질 때 | 타원 c² = a² − b², 쌍곡선 c² = a² + b² |
| 형태2 정의로 돌아가기 | 초점으로부터의 거리가 나올 때 | 거리의 합 일정·차 일정·초점과 준선에서 같은 거리 |
| 형태3 접선 공식 | 곡선 위의 점에서의 접선 | 타원 x₀x/a² + y₀y/b² = 1 |
| 형태4 평행이동 | 중심이 어긋난 식 | 완전제곱식으로 고쳐 표준형으로 바꾼다 |

**연습 문제**: 타원 E : x²/25 + y²/9 = 1의 초점 중 x좌표가 양수인 것을 F라 한다. E 위의 점 P에서의 접선에 F에서 내린 수선의 발을 H라 한다. P가 E 위를 움직일 때, 점 H의 자취를 구하여라.

**풀이**:
1. a = 5, b = 3, c = √(25 − 9) = 4 ⇒ F(4, 0)
2. P(x₀, y₀), u = x₀/25, v = y₀/9로 두면 접선 l : ux + vy = 1이고, 25u² + 9v² = 1이다.
3. H = (4 + tu, tv) ∈ l ⇒ t = (1 − 4u)/(u² + v²)
4. OH² = 16 + 8tu + t²(u² + v²) = 16 + t(1 + 4u) = 16 + (1 − 16u²)/(u² + v²)
5. 1 − 16u² = 9(u² + v²) ⇒ OH² = 25

**답**: x² + y² = 25

**다른 형태 활용**:
- 형태2 정의로 돌아가기: 예) 초점 (±3, 0), 거리의 합 10 → a = 5, c = 3, b² = 16 → x²/25 + y²/16 = 1
- 형태4 평행이동: 예) x² + 4y² − 4x + 8y − 8 = 0 → (x−2)²/16 + (y+1)²/4 = 1, 중심 (2, −1)

## CURV-02 매개변수 표시 [패스]
*媒介変数表示* · 영상 6:33:37
- **발동 신호**: x = f(t), y = g(t)
- **핵심**: x = f(t), y = g(t) → t인 채로 미분·적분한다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 접선·기울기 | 접선의 방정식, 기울기 | dy/dx = g′(t)/f′(t) |
| 형태2 넓이 | 곡선으로 둘러싸인 넓이 | ∫ y dx = ∫ g(t)f′(t) dt (방향에 주의) |
| 형태3 곡선의 길이 | 길이를 구할 때 | ∫ √(f′(t)² + g′(t)²) dt |
| 형태4 t의 소거 | 자취의 식을 구할 때 | cos² + sin² = 1 등으로 소거, 범위도 확인 |

**연습 문제**: t가 −1 ≤ t ≤ 1에서 움직일 때, x = t² − 1, y = t³ − t로 나타나는 곡선을 C라 한다. (1) C는 원점을 지난다. 원점에서 C의 접선의 방정식을 모두 구하여라. (2) C로 둘러싸인 부분의 넓이를 구하여라.

**풀이**:
1. dx/dt = 2t, dy/dt = 3t² − 1 ⇒ dy/dx = (3t² − 1)/(2t)
2. x = y = 0 ⟺ t = ±1 ⇒ 기울기 = ±1 ⇒ y = x, y = −x
3. C는 x축에 대해 대칭이다. 위쪽 절반은 −1 ≤ t ≤ 0에 해당한다.
4. S = 2∫(x=−1→0) y dx = 2∫(0→−1) (t³ − t)·2t dt
5. = 2[(2/5)t⁵ − (2/3)t³](0→−1) = 2(−2/5 + 2/3) = 8/15

**답**: (1) y = x, y = −x (2) 8/15

**다른 형태 활용**:
- 형태3 곡선의 길이: 예) x = t²/2, y = t³/3 (0 ≤ t ≤ 1) → ∫₀¹ t√(1 + t²) dt = (2√2 − 1)/3
- 형태4 t의 소거: 예) x = 3cos t, y = 2sin t → cos²t + sin²t = 1에서 x²/9 + y²/4 = 1

## CURV-03 극좌표·극방정식 [패스]
*極座標・極方程式* · 영상 6:38:13
- **발동 신호**: r = f(θ)
- **핵심**: r = f(θ) → x = r cos θ, y = r sin θ로 보고, 넓이는 (1/2)∫ r² dθ

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 좌표 변환 | 직교좌표와 극좌표를 오갈 때 | x = r cos θ, y = r sin θ, r² = x² + y² |
| 형태2 넓이 | 둘러싸인 부분의 넓이 | S = (1/2)∫(α→β) r² dθ |
| 형태3 극방정식 만들기 | 직선·원·2차곡선을 나타낼 때 | 원점을 중심·초점으로 잡고 그림에서 r = f(θ) |
| 형태4 θ로 미분 | 최대·최소, 접선 | x, y를 θ의 식으로 하여 매개변수로서 미분 |

**연습 문제**: 극방정식 r = 1 + cos θ (0 ≤ θ ≤ 2π)로 나타나는 곡선을 C라 한다. (1) C 위의 점의 y좌표의 최댓값을 구하여라. (2) C로 둘러싸인 부분의 넓이를 구하여라.

**풀이**:
1. y = r sin θ = (1 + cos θ) sin θ
2. dy/dθ = cos θ + cos 2θ = (2cos θ − 1)(cos θ + 1)
3. 0 ≤ θ ≤ π에서 θ = π/3일 때 최대 ⇒ y_max = (3/2)·(√3/2) = 3√3/4
4. S = (1/2)∫₀^(2π) (1 + cos θ)² dθ = (1/2)∫₀^(2π) (3/2 + 2cos θ + (1/2)cos 2θ) dθ
5. = (1/2)·(3/2)·2π = 3π/2

**답**: (1) 3√3/4 (2) 3π/2

**다른 형태 활용**:
- 형태1 좌표 변환: 예) r = 2cos θ → 양변에 r을 곱하면 x² + y² = 2x → 중심 (1, 0), 반지름 1인 원
- 형태3 극방정식 만들기: 예) 중심 (a, 0)이고 원점을 지나는 원 → 그림에서 r = 2a cos θ

## CURV-04 타원은 원의 축소 [패스]
*楕円は円の縮小* · 영상 6:42:39
- **발동 신호**: 타원 안 삼각형의 넓이 최대
- **핵심**: 타원 → X = x/a, Y = y/b로 원으로 바꾸고, 넓이는 ab배

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 원으로 귀착 | 타원 위 도형의 넓이·최대 | X = x/a, Y = y/b로 단위원으로 바꾼다. 넓이는 ab배 |
| 형태2 원에서 최대 | 원에 내접하는 도형 | 삼각형은 정삼각형, 사각형은 정사각형일 때 최대 |
| 형태3 매개변수 | 계산으로 밀어붙일 때 | (a cos θ, b sin θ)로 둔다 |
| 형태4 내부의 넓이 | 타원 내부의 넓이 | πab (원 넓이의 ab배) |

**연습 문제**: 타원 E : x²/9 + y²/4 = 1 위에 점 A(3, 0)이 있다. E 위에 두 점 B, C를 잡아 △ABC를 만든다. (1) △ABC의 넓이의 최댓값을 구하여라. (2) 최대가 될 때 B, C의 좌표를 구하여라.

**풀이**:
1. X = x/3, Y = y/2 ⇒ X² + Y² = 1, A′(1, 0)
2. 넓이는 3 × 2 = 6배이므로 S = 6S′이다.
3. 단위원에 내접하는 삼각형은 정삼각형일 때 최대이므로 S′_max = 3√3/4이다. (A′을 꼭짓점으로 잡을 수 있다)
4. S_max = 6·(3√3/4) = 9√3/2
5. B′, C′ = (−1/2, ±√3/2) ⇒ B, C = (−3/2, ±√3)

**답**: (1) 9√3/2 (2) (−3/2, √3), (−3/2, −√3)

**다른 형태 활용**:
- 형태3 매개변수: 예) x²/9 + y²/4 = 1 위의 점을 (3cos θ, 2sin θ)로 둔다 → x + y의 최댓값은 √13
- 형태4 내부의 넓이: 예) x²/9 + y²/4 = 1의 내부 넓이 → π·3·2 = 6π

## CURV-05 굴러가는 도형의 자취 [패스]
*転がる図形の軌跡* · 영상 6:47:06
- **발동 신호**: 원·선분이 미끄러지지 않고 구른다
- **핵심**: 미끄러지지 않고 구른다 → 호의 길이 = 굴러간 거리. 점 = 중심 + 회전벡터

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 직선 위를 구르는 원 | 원이 미끄러지지 않고 직선 위를 구를 때 | 중심 (rt, r), 점 = 중심 + 회전벡터 |
| 형태2 원周 위를 구르는 원 | 원의 바깥쪽·안쪽을 구를 때 | 호의 길이가 같다는 것에서 자전각을 중심각으로 나타낸다 |
| 형태3 미끄러지는 선분 | 양 끝이 벽·바닥을 따라 미끄러질 때 | 기울기 θ로 끝점·선분 위의 점을 나타낸다 |
| 형태4 길이·넓이 | 자취의 길이·넓이 | ∫ √(x′² + y′²) dt, 반각 공식으로 근호를 없앤다 |

**연습 문제**: 반지름 1인 원이 x축 위를 미끄러지지 않고 구른다. 처음에 원주 위의 정점 P는 원점 O에 있다. 원이 t라디안 회전했을 때 P의 위치를 (x, y)라 한다. (1) x, y를 t로 나타내어라. (2) 0 ≤ t ≤ 2π 동안 P가 그리는 곡선의 길이를 구하여라.

**풀이**:
1. 굴러간 거리 = 호의 길이 = t이므로 원의 중심은 (t, 1)이다.
2. 중심에서 P로 가는 벡터는 (0, −1)을 시계방향으로 t 회전한 것이므로 (−sin t, −cos t)이다.
3. x = t − sin t, y = 1 − cos t
4. (dx/dt)² + (dy/dt)² = (1 − cos t)² + sin²t = 2 − 2cos t = 4sin²(t/2)
5. L = ∫₀^(2π) 2sin(t/2) dt = [−4cos(t/2)]₀^(2π) = 8

**답**: (1) x = t − sin t, y = 1 − cos t (2) 8

**다른 형태 활용**:
- 형태2 원주 위를 구르는 원: 예) 반지름 1인 원이 반지름 3인 원의 바깥쪽을 중심각 θ만큼 나아감 → 호의 길이 3θ → 자전각은 3θ + θ = 4θ
- 형태3 미끄러지는 선분: 예) 길이 2인 선분 → 끝점 (2cos θ, 0), (0, 2sin θ), 중점 (cos θ, sin θ)는 원 x² + y² = 1 위에 있다
