| 형태4 주기성 | 합·격자점의 개수 | [x + 1] = [x] + 1을 이용 |

## NUM-11 소인수 p의 지수(p진 부치)로 평가 [권장]
*素因数 p の指数（p進付値）で評価* · 영상 3:07:08
- **발동 신호**: 「2로 몇 번 나누어떨어지는가」, 분수 합의 분모
- **핵심**: 분수의 합이 정수가 아님 → 분모의 p의 지수가 최대인 항이 하나뿐이 되는 소수 p를 찾는다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 몇 번 나누어떨어지는가 | n!이나 곱이 p로 몇 번 나누어떨어짐 | ⌊n/p⌋ + ⌊n/p²⌋ + ⋯ |
| 형태2 분모로 평가 | 분수의 합이 정수가 아님 | 분모의 p의 지수가 최대인 항이 하나 → 합은 정수가 아니다 |
| 형태3 합의 지수 | 두 수의 합의 지수 | 지수가 다르면 작은 쪽, 같으면 그 이상 |
| 형태4 거듭제곱의 차 | aⁿ − bⁿ의 지수 | 인수분해해서 각 인수의 지수를 조사 |

**연습 문제**: n ≥ 2일 때, S = 1 + 1/3 + 1/5 + ⋯ + 1/(2n − 1)은 정수가 되지 않음을 보여라.

**풀이**:
1. 3ᵏ ≤ 2n − 1 < 3ᵏ⁺¹ (k ≥ 1). 3ᵏ으로 나누어떨어지는 홀수 분모는 3ᵏ뿐
2. 다른 항의 합 = B/(3ᵏ⁻¹M) (3 ∤ M)
3. S = 1/3ᵏ + B/(3ᵏ⁻¹M) = (M + 3B)/(3ᵏM)
4. 3 ∤ M + 3B → 분모에 3ᵏ이 남는다 → S는 정수가 아니다

**답**: S는 정수가 되지 않는다

**다른 형태 활용**:
- 형태1 몇 번 나누어떨어지는가: 예) 10!에 포함된 3의 개수 → ⌊10/3⌋ + ⌊10/9⌋ = 3 + 1 = 4개
- 형태4 거듭제곱의 차: 예) 2⁶ − 1 = (2³ − 1)(2³ + 1) = 7·9 → 3의 지수는 2

## NUM-12 소인수별로 독립적으로 생각한다(곱셈성) [필수]
*素因数ごとに独立に考える（乗法性）* · 영상 3:10:57
- **발동 신호**: 약수의 개수·총합, 곱의 최대화, n의 소인수분해
- **핵심**: 약수·배수·최대공약수 → 소인수분해하고, 소인수별 지수 선택으로 나눠 곱으로 센다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 개수·총합 | 약수의 개수·총합 | n = ∏pᵉ: 개수 ∏(e + 1), 총합 ∏(1 + p + ⋯ + pᵉ) |
| 형태2 조건부 | 배수·제곱수인 약수 | 조건을 각 소인수의 지수 범위로 바꾼다 |
| 형태3 gcd·lcm | 최대공약수·최소공배수 | 소인수별로 지수의 min / max |
| 형태4 곱의 최대화 | 약수의 곱, 조합 세기 | 소인수별로 선택 방법을 세고 곱한다 |

**연습 문제**: N = 2⁴·3³·5²이라 하자. (1) N의 양의 약수의 개수를 구하라. (2) N의 양의 약수 중 12의 배수인 것의 총합을 구하라.

**풀이**:
1. 약수는 2ᵃ3ᵇ5ᶜ (0 ≤ a ≤ 4, 0 ≤ b ≤ 3, 0 ≤ c ≤ 2)
2. (1) 5 × 4 × 3 = 60
3. (2) 12 = 2²·3의 배수 → a ≥ 2, b ≥ 1
4. (2² + 2³ + 2⁴)(3 + 3² + 3³)(1 + 5 + 5²) = 28·39·31 = 33852

**답**: (1) 60개 (2) 33852

**다른 형태 활용**:
- 형태3 gcd·lcm: 예) 2³·3²과 2·3⁴ → 지수가 작은 쪽으로 gcd = 2·3² = 18, 큰 쪽으로 lcm = 2³·3⁴ = 648
- 형태4 곱의 최대화: 예) 12의 약수 전부의 곱 → 2의 지수 (0 + 1 + 2) × 2 = 6, 3의 지수 1 × 3 = 3 → 2⁶·3³ = 1728
