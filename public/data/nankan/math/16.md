- **핵심**: 지수×삼각 → 2회 부분적분으로 같은 꼴이 출현 → 방정식으로 푼다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 다항식형 | xⁿeˣ, xⁿ sin x | 다항식을 미분하는 쪽에 둔다(n회로 차수가 내려감) |
| 형태2 같은 꼴 출현 | e^(ax) sin bx, e^(ax) cos bx | 2회 부분적분 → 원래 적분이 나타남 → 이항해서 푼다 |
| 형태3 log·역삼각 | log x, tan⁻¹x의 적분 | 1을 곱해서 log x 쪽을 미분 |
| 형태4 sin과 cos의 쌍 | I, J가 서로 얽힘 | 연립방정식으로 푼다 |

1. I = [−e^(−x) sin2x]₀^π + 2J = 2J
2. J = [−e^(−x) cos2x]₀^π − 2I = 1 − e^(−π) − 2I
3. J = 1 − e^(−π) − 4J ⇒ 5J = 1 − e^(−π)
4. J = (1−e^(−π))/5, I = 2(1−e^(−π))/5

**답**: I = 2(1−e^(−π))/5, J = (1−e^(−π))/5

**다른 형태 활용**:

- 형태3 log·역삼각: ∫₁^e log x dx = [x log x − x]₁^e = 1

## INT3-03 정적분의 점화식 [패스]
*定積分の漸化式* · 영상 7:53:53
- **발동 신호**: Iₙ = ∫ sinⁿx dx 등
- **핵심**: 거듭제곱의 정적분 → Iₙ과 Iₙ₋₂ 등의 점화식 → 극한은 샌드위치(はさみうち)

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 부분적분 | sinⁿx, xⁿeˣ, (log x)ⁿ | 1개분을 떼어 부분적분 → Iₙ과 Iₙ₋₁(Iₙ₋₂)의 관계 |
| 형태2 tan의 n제곱 | tanⁿx | 1 + tan²x = 1/cos²x로 Iₙ + Iₙ₊₂를 만든다 |
| 형태3 베타형 | x^p(1−x)^q | 부분적분으로 q를 1씩 낮춘다 |
| 형태4 극한·부등식 | lim nIₙ, 대소 평가 | 단조성과 점화식으로 Iₙ을 위아래에서 끼운다 |

**연습 문제**: Jₙ = ∫₀^(π/4) tanⁿx dx라 하자. (1) Jₙ + Jₙ₊₂를 n으로 나타내라. (2) J₄를 구하라. (3) lim(n→∞) nJₙ을 구하라.

**풀이**:
1. Jₙ + Jₙ₊₂ = ∫₀^(π/4) tanⁿx (1+tan²x) dx = [tanⁿ⁺¹x/(n+1)]₀^(π/4) = 1/(n+1)
2. J₀ = π/4, J₂ = 1 − π/4, J₄ = 1/3 − J₂ = π/4 − 2/3
3. 0 ≤ tan x ≤ 1 ⇒ Jₙ₊₂ ≤ Jₙ이므로 2Jₙ₊₂ ≤ 1/(n+1) ≤ 2Jₙ
4. n/(2(n+1)) ≤ nJₙ ≤ n/(2(n−1)) → 샌드위치로 1/2

**답**: (1) 1/(n+1) (2) π/4 − 2/3 (3) 1/2

**다른 형태 활용**:
- 형태1 부분적분: Iₙ = ∫₀^(π/2) sinⁿx dx → Iₙ = ((n−1)/n)·Iₙ₋₂
- 형태3 베타형: ∫₀¹ x^p(1−x)^q dx = (q/(p+1))·∫₀¹ x^(p+1)(1−x)^(q−1) dx

## INT3-04 대칭성·King property [패스]
*対称性・King property* · 영상 7:58:16
- **발동 신호**: ∫₀^a f(x)dx = ∫₀^a f(a−x)dx
- **핵심**: 구간의 양끝을 맞바꾸는 치환 → 원래 식과 더해서 2I

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 기본형 | 구간 [0, a]의 정적분 | x → a−x로 원래 식과 더해 2I |
| 형태2 sin↔cos | sin과 cos가 대칭으로 들어간 분수식 | x → π/2 − x로 맞바꾸고, 더하면 1 |
| 형태3 x f(sin x) | x f(sin x)의 꼴(구간 0 → π) | x → π−x로 x가 사라지고, π/2배의 적분으로 |
| 형태4 우기(偶奇) | 구간이 [−a, a] | 기함수는 0, 우함수는 0 → a의 2배 |

**연습 문제**: 다음 정적분을 구하라. (1) ∫₀^π x sin x/(1+cos²x) dx (2) ∫₀^(π/2) sin³x/(sin³x+cos³x) dx

**풀이**:
1. (1) x → π−x로부터 I = ∫₀^π (π−x) sin x/(1+cos²x) dx
2. 더해서 2I = π∫₀^π sin x/(1+cos²x) dx = π∫₋₁¹ dt/(1+t²) = π²/2
3. I = π²/4
4. (2) x → π/2 − x로부터 K = ∫₀^(π/2) cos³x/(sin³x+cos³x) dx. 더하면 2K = π/2

**답**: (1) π²/4 (2) π/4

**다른 형태 활용**:
- 형태1 기본형: I = ∫₀² x²/(x²+(2−x)²) dx → x → 2−x와 더해 2I = 2이므로 I = 1
- 형태4 우기: ∫₋₁¹ x³ dx = 0(기함수), ∫₋₁¹ x² dx = 2∫₀¹ x² dx = 2/3(우함수)

## INT3-05 정적분과 부등식 [패스]
*定積分と不等式* · 영상 8:02:10
- **발동 신호**: Σ1/k와 log n의 비교
- **핵심**: 합과 적분의 비교 → 직사각형 넓이로 끼운다 → 극한은 샌드위치

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 합과 log | Σ1/k와 log n의 비교 | 단조감소 → 직사각형이 곡선의 위아래에 → 넓이로 비교 |
| 형태2 계승의 평가 | n!, Σlog k | ∫log x dx와 비교해 평가 |
| 형태3 대소 비교 | 적분값의 평가 | 구간 전체에서 f ≤ g를 보이고, 적분해서 비교 |
| 형태4 합의 극한 | lim Σ | 위아래에서 끼워 같은 값으로(샌드위치) |

**연습 문제**: Sₙ = Σ(k=1→n) 1/k (n ≥ 2). (1) log(n+1) < Sₙ < 1 + log n을 보여라. (2) lim(n→∞) Sₙ/log n을 구하라.

**풀이**:
1. k ≤ x ≤ k+1에서 1/(k+1) < 1/x < 1/k → 1/(k+1) < ∫ₖ^(k+1) dx/x < 1/k
2. 오른쪽 부등식을 k = 1..n으로 합하면 log(n+1) < Sₙ
3. 왼쪽 부등식을 k = 1..n−1로 합하면 Sₙ − 1 < log n
4. log(n+1)/log n < Sₙ/log n < 1 + 1/log n → 샌드위치로 1

**답**: (2) 1

**다른 형태 활용**:
- 형태2 계승의 평가: ∫₁ⁿ log x dx = n log n − n + 1 < log n!과 비교해 n!을 평가
- 형태3 대소 비교: 0 ≤ x ≤ 1에서 1/(1+x²) ≥ 1/2 → ∫₀¹ dx/(1+x²) ≥ 1/2

## INT3-06 면적(곡선·매개변수) [패스]
*面積（曲線・媒介変数）* · 영상 8:06:14
- **발동 신호**: 둘러싸인 부분의 넓이
- **핵심**: 둘러싸인 넓이 → 위아래(좌우)를 정리 → 「위 − 아래」를 적분, 매개변수는 ∫y x′(t)dt

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 y=f(x)끼리 | y = f(x)와 y = g(x)로 둘러쌈 | 교점 → 위아래 확인 → 「위 − 아래」를 x로 적분 |
| 형태2 매개변수 | x = x(t), y = y(t) | S = ∫y dx = ∫y(t)x′(t)dt(범위와 방향에 주의) |
| 형태3 가로로 자르기 | x = g(y) 쪽이 편함 | 「오른쪽 − 왼쪽」을 y로 적분 |
| 형태4 대칭성 | 축대칭·원점대칭 | 1/4(1/2)만 계산해서 배수 |

**연습 문제**: 곡선 C: x = 2cos t, y = sin2t (0 ≤ t ≤ 2π)로 둘러싸인 부분의 넓이 S를 구하라.

**풀이**:
1. x축·y축 대칭 → 제1사분면(0 ≤ t ≤ π/2)의 4배
2. S = 4∫₀² y dx, dx = −2sin t dt, x: 0 → 2 ⇔ t: π/2 → 0
3. S = 4∫₀^(π/2) sin2t·2sin t dt = 16∫₀^(π/2) sin²t cos t dt
4. = 16[sin³t/3]₀^(π/2) = 16/3

**답**: S = 16/3

**다른 형태 활용**:
- 형태1 y=f(x)끼리: y = x와 y = x² → 교점 x = 0, 1 → ∫₀¹ (x − x²) dx = 1/6
- 형태3 가로로 자르기: x = y²와 x = y + 2 → 오른쪽−왼쪽을 y로 적분 → ∫₋₁² (y + 2 − y²) dy = 9/2

| 형태3 바움쿠헨형 | 역함수를 구하기 어려움/축에서 떨어진 도형 | V = 2π∫r h dx(r 반지름, h 높이) |

2. V = 2π∫₀^π (x+1) sin x dx
3. ∫₀^π x sin x dx = π, ∫₀^π sin x dx = 2
4. V = 2π(π + 2) = 2π² + 4π

- 형태2 y축 둘레: y = x² (0 ≤ y ≤ 1)를 y축 둘레로 → x² = y → π∫₀¹ y dy = π/2

## INT3-09 곡선의 길이 [패스]
*曲線の長さ* · 영상 8:17:32
- **발동 신호**: 「곡선의 길이」
- **핵심**: 곡선의 길이 → 공식에 대입 → 근호 안을 완전제곱으로 고쳐 벗긴다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 y=f(x) | y = f(x) | L = ∫ₐᵇ √(1+(y′)²) dx |
| 형태2 매개변수 | x = x(t), y = y(t) | L = ∫√((x′)² + (y′)²) dt |
| 형태3 완전제곱 | 근호 안이 제곱 꼴이 됨 | (⋯)²로 고치고, 부호를 확인해 근호를 벗긴다 |
| 형태4 이동 거리 | 점의 운동에서 이동 거리를 물음 | 이동 거리 = ∫|v⃗| dt |

**연습 문제**: 다음 곡선의 길이를 구하라. (1) y = x²/4 − (1/2)log x (1 ≤ x ≤ e) (2) x = t − sin t, y = 1 − cos t (0 ≤ t ≤ 2π)

**풀이**:
1. (1) y′ = x/2 − 1/(2x), 1 + y′² = (x/2 + 1/(2x))²
2. L = ∫₁^e (x/2 + 1/(2x)) dx = [x²/4 + (1/2)log x]₁^e = (e²+1)/4
3. (2) x′² + y′² = 2 − 2cos t = 4sin²(t/2)
4. L = ∫₀^(2π) 2sin(t/2) dt = [−4cos(t/2)]₀^(2π) = 8

## INT3-11 미분방정식을 세워서 풀기 [패스]
*微分方程式を立てて解く* · 영상 8:25:25
- **발동 신호**: 함수방정식, 길이·넓이가 함수로 주어지는 조건
- **핵심**: 도형·넓이의 조건 → 식으로 고쳐 미분 → f′의 관계식을 푼다(변수분리·(f/x)′)

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 변수분리 | f′ = g(x)h(f)의 꼴 | f 쪽과 x 쪽으로 나눠 적분(log f의 꼴) |
| 형태2 적분 조건 | 넓이·길이가 x의 함수로 주어짐 | 양변을 x로 미분해 f′의 식으로 |
| 형태3 접선의 절편 | f − xf′가 나타남 | (f/x)′ = (xf′ − f)/x²를 이용 |
| 형태4 함수방정식 | f(x+y) = f(x)f(y) | y로 미분해 f′(x) = f′(0)f(x) |

**연습 문제**: x > 0에서 미분가능한 양의 함수 f(x)가 f(1) = 1을 만족한다. 곡선 y = f(x) 위의 임의의 점 P(t, f(t))에서의 접선의 y절편이 tf(t)와 같을 때, f(x)를 구하라.

**풀이**:
1. 접선 Y − f(t) = f′(t)(X − t)의 y절편 = f(t) − tf′(t)
2. 조건: f − tf′ = tf → tf′ = (1−t)f → f′/f = 1/t − 1
3. log f = log t − t + C, f(1) = 1이므로 f(x) = xe^(1−x)

**답**: f(x) = xe^(1−x)

**다른 형태 활용**:

- 형태4 함수방정식: f(x+y) = f(x)f(y) → y로 미분하고 y = 0 → f′(x) = f′(0)f(x) → f(x) = e^(ax)

## INT3-12 통과(소과) 영역의 넓이·부피 [패스]
*通過（掃過）領域の面積・体積* · 영상 8:29:44
- **발동 신호**: 선분·도형이 회전·이동하며 지나가는 부분
- **핵심**: 통과 영역 → 움직임에 맞춰 자른다 → 각 단면에서 통과 범위를 구해 적분

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 평행이동·변형 | 선분·도형이 어긋나며 움직임 | x를 고정하고, 통과하는 y의 범위를 구한다 |
| 형태2 원점 중심 회전 | 원점 둘레로 회전 | 극좌표: 각 r에서 각도의 범위 → 폭×r을 적분 |
| 형태3 입체의 통과 | 회전·이동으로 생기는 입체 | 각 단면에서 바깥 반지름·안쪽 반지름 → 원환의 넓이를 적분 |
| 형태4 매개변수 직선 | 직선이 t에 따라 움직임 | t의 방정식이 실수해를 가질 조건 |

**연습 문제**: 점 A(1, −1), B(1, 1)을 잇는 선분 AB를 원점 O 둘레로 반시계 방향으로 0에서 π/2까지 회전시킨다. 선분 AB가 통과하는 영역의 넓이를 구하라.

**풀이**:
1. 원점으로부터의 거리 r: 1 ≤ r ≤ √2
2. 반지름 r인 원과 선분의 교점의 편각은 ±α (cosα = 1/r, 0 ≤ α ≤ π/4)
3. 통과하는 각도의 범위는 [−α, α + π/2], 폭은 π/2 + 2α
4. S = ∫₁^√2 (π/2 + 2cos⁻¹(1/r)) r dr = π/4 + 2(π/4 − 1/2) = 3π/4 − 1

**답**: S = 3π/4 − 1

**다른 형태 활용**:
- 형태1 평행이동·변형: y = x² + t (0 ≤ t ≤ 1) → x를 고정 → x² ≤ y ≤ x² + 1
- 형태3 입체의 통과: 직각삼각형을 z축 둘레로 회전 → 바깥 반지름 1·안쪽 반지름 z인 원환 → π∫₀¹ (1 − z²) dz = 2π/3
- 형태4 매개변수 직선: y = tx − t² → t² − xt + y = 0이 실수해를 가짐 → x² − 4y ≥ 0 → y ≤ x²/4
