## VEC-01 교점의 위치벡터(계수 비교) [필수]

- **발동 신호**: 두 직선의 교점
- **핵심**: 「두 직선의 교점」이 나오면 같은 점을 두 가지로 나타내고 계수를 비교한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 두 직선의 교점 | 두 직선(AD와 BC 등)의 교점 P | 같은 점을 두 가지로 나타내고 a⃗, b⃗의 계수를 비교 |
| 형태2 직선 위의 조건 | 점 P가 직선 AB 위에 있음 | OP = sOA + tOB에서 s + t = 1 |
| 형태3 연장선 위의 비 | 직선 OP와 변 AB의 교점 Q | OQ = kOP로 두고, 계수의 합 = 1로 k를 결정 |

**연습 문제**: 삼각형 OAB에서 변 OA를 2 : 1로 내분하는 점을 C, 변 OB를 3 : 2로 내분하는 점을 D라 하자. 선분 AD와 선분 BC의 교점을 P라 하고 OA = a⃗, OB = b⃗라 할 때, (1) OP를 a⃗, b⃗로 나타내어라. (2) 직선 OP와 변 AB의 교점을 Q라 할 때, AQ : QB를 구하여라.

**풀이**:
1. OC = (2/3)a⃗, OD = (3/5)b⃗
2. P는 AD 위의 점이므로 OP = (1 − s)a⃗ + (3/5)s b⃗
3. P는 BC 위의 점이므로 OP = (2/3)t a⃗ + (1 − t)b⃗
4. 계수 비교: 1 − s = (2/3)t, (3/5)s = 1 − t ⇒ s = 5/9, t = 2/3
5. OP = (4/9)a⃗ + (1/3)b⃗
6. OQ = kOP로 두면 (4/9)k + (1/3)k = 1 ⇒ k = 9/7, OQ = (4/7)a⃗ + (3/7)b⃗

**답**: OP = (4/9)a⃗ + (1/3)b⃗, AQ : QB = 3 : 4

**다른 형태 활용**:
- 형태2 직선 위의 조건: 예) OP = (1/3)a⃗ + k b⃗가 직선 AB 위에 있으면 1/3 + k = 1이므로 k = 2/3

**연습 문제**: 실수 x, y에 대해 u = 2x + y, v = x + 3y라 하고, 점 (x, y)에 점 (u, v)를 대응시킨다. (1) 원판 x² + y² ≤ 1의 점들의 상이 만드는 도형의 넓이를 구하여라. (2) 정사각형 0 ≤ x ≤ 1, 0 ≤ y ≤ 1의 상인 평행사변형의 내부에 포함되는 격자점의 개수를 구하여라.

**풀이**:
1. det(2 1 / 1 3) = 2·3 − 1·1 = 5
2. (1) 넓이는 π·5 = 5π
3. (2) 상의 꼭짓점은 (0, 0), (2, 1), (3, 4), (1, 3)이고 S = 5
4. 둘레 위의 격자점은 B = 4(gcd(2, 1) = gcd(1, 3) = 1이므로 꼭짓점 외에는 없음)
5. 픽의 정리 5 = I + 4/2 − 1 ⇒ I = 4

**답**: (1) 5π (2) 4
