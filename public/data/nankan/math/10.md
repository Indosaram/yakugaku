## SEQ-01 인접 2항 간 점화식 [필수]
*隣接2項間漸化式* · 영상 4:44:39
- **발동 신호**: aₙ₊₁ = paₙ + q
- **핵심**: 「aₙ₊₁ = paₙ + q」 → 형태를 맞춰 등비수열로 만든다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 상수가 더해짐 | aₙ₊₁ = paₙ + q 꼴 | 특성방정식으로 등비수열로 |
| 형태2 계차 | aₙ₊₁ = aₙ + f(n) 꼴 | 계차수열의 합을 구한다 |
| 형태3 지수가 더해짐 | rⁿ 같은 지수항이 더해짐 | 양변을 rⁿ⁺¹로 나눈다 |
| 형태4 1차식이 더해짐 | n의 1차식이 더해짐 | 계수를 정해 등비 꼴로 |

**연습 문제**: 수열 {aₙ}은 a₁ = 3, aₙ₊₁ = 3aₙ − 2ⁿ⁺¹을 만족한다. (1) bₙ = aₙ/2ⁿ으로 둘 때 bₙ₊₁을 bₙ으로 나타내라. (2) aₙ을 구하라.

**풀이**:
1. aₙ₊₁/2ⁿ⁺¹ = (3/2)·aₙ/2ⁿ − 1 (양변을 2ⁿ⁺¹로 나눔)
2. bₙ₊₁ = (3/2)bₙ − 1 … (1)
3. α = (3/2)α − 1 ⇒ α = 2, bₙ₊₁ − 2 = (3/2)(bₙ − 2)
4. bₙ − 2 = −(1/2)(3/2)ⁿ⁻¹
5. aₙ = 2ⁿbₙ = 2ⁿ⁺¹ − 3ⁿ⁻¹

**답**: (1) bₙ₊₁ = (3/2)bₙ − 1 (2) aₙ = 2ⁿ⁺¹ − 3ⁿ⁻¹

**다른 형태 활용**:
- 형태2 계차: a₁ = 1, aₙ₊₁ = aₙ + 2n일 때 → aₙ = 1 + Σₖ₌₁ⁿ⁻¹ 2k = n² − n + 1
- 형태4 1차식이 더해짐: aₙ₊₁ = 2aₙ + n일 때 → aₙ₊₁ + (n+1) + 1 = 2(aₙ + n + 1)로 변형할 수 있다

## SEQ-02 인접 3항 간 점화식 [필수]
*隣接3項間漸化式* · 영상 4:48:20
- **발동 신호**: aₙ₊₂ = paₙ₊₁ + qaₙ
- **핵심**: 3항 간 → 특성방정식 t² = pt + q의 해로 경우를 나눈다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 서로 다른 두 해 | 특성방정식이 서로 다른 두 해 α, β | 등비 꼴을 두 가지로 만들어 연립 |
| 형태2 중근 | 특성방정식이 중근 α | 양변을 αⁿ⁺¹로 나눠 계차로 |
| 형태3 상수 포함 | 상수가 더해져 있음 | 상수를 빼서 동차 꼴로 |
| 형태4 무리수·허수 해 | 해가 무리수나 허수 | 해를 문자 그대로 두고 처리 |

**연습 문제**: 수열 {aₙ}은 a₁ = 1, a₂ = 4, aₙ₊₂ = 6aₙ₊₁ − 9aₙ을 만족한다. (1) bₙ = aₙ₊₁ − 3aₙ으로 둘 때 bₙ을 n으로 나타내라. (2) aₙ을 구하라.

**풀이**:
1. t² = 6t − 9 ⇒ (t − 3)² = 0 ⇒ t = 3 (중근)
2. aₙ₊₂ − 3aₙ₊₁ = 3(aₙ₊₁ − 3aₙ) ⇒ bₙ₊₁ = 3bₙ
3. b₁ = a₂ − 3a₁ = 1 ⇒ bₙ = 3ⁿ⁻¹ … (1)
4. aₙ₊₁ = 3aₙ + 3ⁿ⁻¹ →(÷3ⁿ⁺¹) aₙ₊₁/3ⁿ⁺¹ = aₙ/3ⁿ + 1/9
5. aₙ/3ⁿ = (n+2)/9 ⇒ aₙ = (n + 2)3ⁿ⁻²

**답**: (1) bₙ = 3ⁿ⁻¹ (2) aₙ = (n + 2)·3ⁿ⁻²

**다른 형태 활용**:
- 형태1 서로 다른 두 해: aₙ₊₂ = 5aₙ₊₁ − 6aₙ → 해 2, 3 → aₙ₊₂ − 2aₙ₊₁ = 3(aₙ₊₁ − 2aₙ)
- 형태3 상수 포함: aₙ₊₂ = 2aₙ₊₁ + 3aₙ + 8 → bₙ = aₙ + 2로 두면 bₙ₊₂ = 2bₙ₊₁ + 3bₙ
- 형태4 무리수 해: aₙ₊₂ = aₙ₊₁ + aₙ → 해 α, β = (1±√5)/2를 문자 그대로 → aₙ₊₂ − αaₙ₊₁ = β(aₙ₊₁ − αaₙ)

## SEQ-03 분수형·연립 점화식 [필수]

- **핵심**: 분수형·연립 → 부동점 / 합과 차로 「등비·등차」로 고친다

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 부동점이 2개 | 분수형에서 부동점이 서로 다른 2개 | 부동점과의 차의 비가 등비수열 |
| 형태2 부동점이 1개 | 분수형에서 부동점이 중근 | 1/(aₙ − α)가 등차수열 |
| 형태3 연립 | 두 수열이 얽혀 있음 | 합·차의 조합으로 분리 |
| 형태4 역수형 | 분모에 제n항만 있음 | 역수를 취해 2항 간 점화식으로 |

**연습 문제**: 수열 {aₙ}은 a₁ = 2, aₙ₊₁ = (3aₙ − 1)/(aₙ + 1)을 만족하고, 모든 n에서 aₙ > 1이다. (1) 방정식 x = (3x − 1)/(x + 1)을 풀어라. (2) bₙ = 1/(aₙ − 1)로 둘 때 bₙ₊₁을 bₙ으로 나타내라. (3) aₙ을 구하라.

**풀이**:
1. x(x + 1) = 3x − 1 ⇒ (x − 1)² = 0 ⇒ x = 1 (중근) … (1)
2. aₙ₊₁ − 1 = 2(aₙ − 1)/(aₙ + 1)
3. 1/(aₙ₊₁ − 1) = (aₙ + 1)/(2(aₙ − 1)) = 1/2 + 1/(aₙ − 1) ⇒ bₙ₊₁ = bₙ + 1/2 … (2)
4. b₁ = 1 ⇒ bₙ = (n + 1)/2
5. aₙ = 1 + 1/bₙ = (n + 3)/(n + 1)

**답**: (1) x = 1 (2) bₙ₊₁ = bₙ + 1/2 (3) aₙ = (n + 3)/(n + 1)

**다른 형태 활용**:
- 형태1 부동점이 2개: aₙ₊₁ = (4aₙ − 2)/(aₙ + 1) → 부동점 1, 2 → (aₙ₊₁ − 1)/(aₙ₊₁ − 2) = (3/2)·(aₙ − 1)/(aₙ − 2)
- 형태3 연립: aₙ₊₁ = 2aₙ + bₙ, bₙ₊₁ = aₙ + 2bₙ → 합은 3배씩, 차 aₙ − bₙ은 일정
- 형태4 역수형: aₙ₊₁ = aₙ/(2aₙ + 1) → 역수를 취하면 1/aₙ₊₁ = 1/aₙ + 2 (등차수열)

## SEQ-06 Σ 계산(부분분수·차분) [필수]

- **핵심**: 합의 내용을 f(k) − f(k+1) 꼴로 → 망원경 합(연쇄 소거)

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 연속 2정수의 곱 | 분모가 k(k + 1) | 1/k − 1/(k + 1)로 나눈다 |
| 형태2 연속 3정수의 곱 | 분모가 k(k + 1)(k + 2) | 2항 곱의 차로 만들고 1/2을 앞에 |
| 형태3 근호가 있는 분모 | 분모가 √k + √(k+1) | 유리화해서 차의 꼴로 |
| 형태4 계승·로그 등 | k·k!, 로그 등 | f(k + 1) − f(k) 꼴을 찾는다 |

**풀이**:
1. 1/(k(k+1)(k+2)) = (1/2){1/(k(k+1)) − 1/((k+1)(k+2))}
2. Sₙ = (1/2){1/(1·2) − 1/((n+1)(n+2))}
3. Sₙ = 1/4 − 1/(2(n+1)(n+2)) = n(n+3)/(4(n+1)(n+2)) … (1)
4. Sₙ > 49/200 ⟺ (n + 1)(n + 2) > 100
5. n = 8: 90, n = 9: 110 ⇒ n = 9 … (2)

**답**: (1) Sₙ = n(n+3)/(4(n+1)(n+2)) (2) n = 9

**다른 형태 활용**:
- 형태3 근호가 있는 분모: 1/(√k + √(k+1)) = √(k+1) − √k → 합은 √(n+1) − 1
- 형태4 계승·로그 등: k·k! = (k + 1)! − k! → Σₖ₌₁ⁿ k·k! = (n + 1)! − 1

## SEQ-07 수학적 귀납법 [권장]
*数学的帰納法* · 영상 5:08:53
- **발동 신호**: 「모든 자연수 n에 대해 ~를 보여라」
- **핵심**: 「모든 자연수 n에서」 → 수학적 귀납법 (토대 + 가정 → 다음)

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 보통 | n = k에서 n = k + 1이 나옴 | n = 1 확인 → k를 가정하고 k + 1 |
| 형태2 2단계 | 3항 간 점화식 등 | n = 1, 2 확인 → k, k + 1을 가정 |
| 형태3 강한 귀납법 | 앞의 모든 항을 사용 | 1부터 k까지를 가정하고 k + 1 |
| 형태4 부등식·나누어떨어짐 | 부등식·정수의 성질 | 가정으로 평가 / 배수 꼴로 고친다 |

**연습 문제**: a₁ = 1, a₂ = 2, aₙ₊₂ = aₙ₊₁ + aₙ으로 정해지는 수열에 대해, 모든 자연수 n에서 (3/2)ⁿ⁻¹ ≤ aₙ ≤ 2ⁿ⁻¹임을 수학적 귀납법으로 보여라.

**풀이**:
1. n = 1: 1 ≤ 1 ≤ 1, n = 2: 3/2 ≤ 2 ≤ 2
2. n = k, k + 1에서 성립한다고 가정
3. aₖ₊₂ = aₖ₊₁ + aₖ ≤ 2ᵏ + 2ᵏ⁻¹ = 3·2ᵏ⁻¹ ≤ 2ᵏ⁺¹
4. aₖ₊₂ ≥ (3/2)ᵏ + (3/2)ᵏ⁻¹ = (5/2)(3/2)ᵏ⁻¹ ≥ (9/4)(3/2)ᵏ⁻¹ = (3/2)ᵏ⁺¹
5. n = k + 2에서도 성립 → 모든 n에서 성립

**답**: (증명) 2단계 수학적 귀납법

**다른 형태 활용**:
- 형태1 보통: 1 + 2 + ⋯ + n = n(n+1)/2 → n = 1 확인, n = k를 가정하고 양변에 k + 1을 더한다
- 형태3 강한 귀납법: 2 이상의 정수는 소수의 곱으로 나타낼 수 있다 → k + 1이 합성수이면 k + 1 = ab (a, b ≤ k)로 놓고 가정을 사용

## SEQ-08 점화식의 평가(부등식으로 끼우기) [패스]
*漸化式の評価（不等式で挟む）* · 영상 5:13:12
- **발동 신호**: 일반항을 구할 수 없는 점화식
- **핵심**: 일반항이 안 나온다 → 부동점 α와의 차를 |aₙ₊₁ − α| ≤ r|aₙ − α|로 평가

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 차가 줄어듦 | 극한 α를 예상할 수 있음 | |aₙ₊₁ − α| ≤ r|aₙ − α| |
| 형태2 비율이 항에 의존 | 비율이 aₙ을 포함 | aₙ의 범위에서 비율의 상한을 낸다 |
| 형태3 단조 유계 | 증가하면서 위로 억제됨 | 수렴 → 극한의 방정식을 푼다 |
| 형태4 발산 | aₙ → ∞를 보이고 싶음 | aₙ₊₁ ≥ raₙ (r > 1)로 아래에서 억제 |

**연습 문제**: a₁ = 1, aₙ₊₁ = (aₙ + 2)/(aₙ + 1)에 대해 (1) 모든 n에서 aₙ ≥ 1임을 보여라. (2) |aₙ₊₁ − √2| ≤ (1/2)|aₙ − √2|임을 보여라. (3) lim(n→∞) aₙ을 구하라.

**풀이**:
1. x = (x + 2)/(x + 1) ⇒ x² = 2, α = √2
2. aₙ ≥ 1 ⇒ aₙ₊₁ = 1 + 1/(aₙ + 1) > 1 … (1)
3. aₙ₊₁ − √2 = (1 − √2)(aₙ − √2)/(aₙ + 1)
4. |(1 − √2)/(aₙ + 1)| ≤ (√2 − 1)/2 < 1/2 … (2)
5. |aₙ − √2| ≤ (√2 − 1)(1/2)ⁿ⁻¹ → 0 ⇒ lim aₙ = √2 … (3)

**답**: lim(n→∞) aₙ = √2

**다른 형태 활용**:
- 형태3 단조 유계: a₁ = 1, aₙ₊₁ = √(aₙ + 2) → 증가하고 aₙ < 2 → 수렴 → α = √(α + 2)에서 α = 2
- 형태4 발산: a₁ = 1, aₙ₊₁ = 2aₙ + 1 → aₙ₊₁ ≥ 2aₙ에서 aₙ ≥ 2ⁿ⁻¹ → ∞

## SEQ-09 등차×등비의 합은 S − rS [필수]
*等差×等比の和は S−rS* · 영상 5:17:10
- **발동 신호**: Σ k rᵏ
- **핵심**: (등차)×(등비)의 합 → S − rS로 등비수열의 합으로

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 k×등비 | k rᵏ의 합 | S − rS로 등비수열의 합으로 |
| 형태2 1차식×등비 | (ak + b)rᵏ⁻¹의 합 | S − rS, 남는 등비합의 항수에 주의 |
| 형태3 2차식×등비 | k²rᵏ의 합 | S − rS를 2번 반복 |
| 형태4 차의 꼴 | (αk + β)rᵏ의 합 | f(k + 1) − f(k)가 되도록 계수를 정한다 |

**연습 문제**: Sₙ = Σₖ₌₁ⁿ (2k − 1)3ᵏ⁻¹이라 하자. (1) Sₙ을 n의 식으로 나타내라. (2) Sₙ > 1000이 되는 최소의 자연수 n을 구하라.

**풀이**:
1. S = 1 + 3·3 + 5·3² + ⋯ + (2n − 1)3ⁿ⁻¹, 3S = 1·3 + 3·3² + ⋯ + (2n − 1)3ⁿ
2. S − 3S = 1 + 2(3 + 3² + ⋯ + 3ⁿ⁻¹) − (2n − 1)3ⁿ
3. −2S = 1 + (3ⁿ − 3) − (2n − 1)3ⁿ = −2 − 2(n − 1)3ⁿ
4. Sₙ = (n − 1)3ⁿ + 1 … (1)
5. S₅ = 973, S₆ = 3646 ⇒ n = 6 … (2)

**답**: (1) Sₙ = (n − 1)3ⁿ + 1 (2) n = 6

**다른 형태 활용**:
- 형태1 k×등비: Σₖ₌₁ⁿ k·2ᵏ → S − 2S로 등비합으로 → (n − 1)2ⁿ⁺¹ + 2
- 형태3 2차식×등비: Σ k²2ᵏ → S − 2S로 (1차식)×2ᵏ의 합으로 귀착 → 한 번 더 S − 2S
- 형태4 차의 꼴: f(k) = (k − 2)2ᵏ로 두면 f(k + 1) − f(k) = k·2ᵏ → 합은 f(n + 1) − f(1)

## SEQ-10 도형의 개수를 점화식으로 세기 [권장]
*図形の個数を漸化式で数える* · 영상 5:21:08
- **발동 신호**: n개의 직선·n장의 평면에 의한 분할 수
- **핵심**: 도형의 개수 → 「n + 1번째를 더했을 때의 증가분」으로 점화식

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 직선으로 평면 분할 | n개의 직선(일반적인 위치) | n + 1번째 직선은 영역을 n + 1개 늘린다 |
| 형태2 원으로 평면 분할 | n개의 원(어느 두 개도 2점에서 만남) | n + 1번째 원은 2n개 늘린다 |
| 형태3 평면으로 공간 분할 | n장의 평면(일반적인 위치) | 새 평면 위의 직선 문제로 귀착 |
| 형태4 꺾은선·특수한 도형 | V자·꺾은선 등 | 교점의 수에서 증가분을 낸다 |

**연습 문제**: (1) 평면 위에 어느 두 개도 평행하지 않고 어느 세 개도 한 점에서 만나지 않는 n개의 직선이 있을 때, 평면은 aₙ개의 부분으로 나뉜다. aₙ을 구하라. (2) 공간에 어느 두 장도 평행하지 않고, 어느 세 장도 한 직선을 공유하지 않으며, 어느 네 장도 한 점을 공유하지 않는 n장의 평면이 있을 때, 공간은 cₙ개의 부분으로 나뉜다. cₙ을 구하라.

**풀이**:
1. aₙ₊₁ = aₙ + (n + 1), a₁ = 2 ⇒ aₙ = (n² + n + 2)/2 … (1)
2. 새 평면 위에 n개의 직선 → 공간은 aₙ개 늘어난다
3. cₙ₊₁ = cₙ + aₙ = cₙ + (n² + n + 2)/2, c₁ = 2
4. cₙ = 2 + Σₖ₌₁ⁿ⁻¹ (k² + k + 2)/2
5. cₙ = (n³ + 5n + 6)/6 … (2)

**답**: (1) aₙ = (n² + n + 2)/2 (2) cₙ = (n³ + 5n + 6)/6

**다른 형태 활용**:
- 형태2 원으로 평면 분할: n개의 원 → 새 원은 2n개 점에서 만나 2n개 늘어난다 → aₙ₊₁ = aₙ + 2n, aₙ = n² − n + 2
- 형태4 꺾은선(V자): n개의 V자 → 새 V자는 4n개 점에서 만나 4n + 1개 늘어난다 → aₙ = 2n² − n + 1

## SEQ-11 모함수·다항식의 곱으로 계수 추적 [권장]
*母関数・多項式の積で係数を追う* · 영상 5:25:27
- **발동 신호**: Π(1 + aₖx)의 계수, 확률의 합을 p의 함수로
- **핵심**: 확률의 합 → 모함수 (px + q)ⁿ을 미분해서 x = 1을 대입
- 참고: (px + q)ⁿ의 미분은 합성함수 미분(수학Ⅲ)에 가깝다. 마크시트에서는 k·ₙCₖ = n·ₙ₋₁Cₖ₋₁로 처리해도 같은 결과가 나온다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 곱 꼴의 다항식 | Π(1 + aₖx)의 계수 | 인수를 하나 늘려 점화식으로 |
| 형태2 모함수를 미분 | 이항계수의 합에 k가 곱해짐 | (px + q)ⁿ을 미분해서 x = 1 |
| 형태3 특별한 값 대입 | 계수의 합·짝수 번째의 합 | x = 1, −1 등을 대입해 더하고 뺀다 |
| 형태4 곱의 계수 비교 | (1 + x)ᵐ(1 + x)ⁿ 등 | 같은 xᵏ의 계수를 비교 |

**연습 문제**: 0 < p < 1, q = 1 − p, n은 2 이상의 자연수라 하자. (1) A = Σₖ₌₀ⁿ k·ₙCₖ pᵏqⁿ⁻ᵏ을 구하라. (2) B = Σₖ₌₀ⁿ k²·ₙCₖ pᵏqⁿ⁻ᵏ을 구하라.

**풀이**:
1. f(x) = (px + q)ⁿ = Σₖ₌₀ⁿ ₙCₖ pᵏqⁿ⁻ᵏxᵏ
2. f′(x) = np(px + q)ⁿ⁻¹ = Σ k·ₙCₖ pᵏqⁿ⁻ᵏxᵏ⁻¹
3. x = 1: A = np(p + q)ⁿ⁻¹ = np … (1)
4. f″(x) = n(n − 1)p²(px + q)ⁿ⁻² ⇒ Σ k(k − 1)·ₙCₖ pᵏqⁿ⁻ᵏ = n(n − 1)p²
5. B = n(n − 1)p² + np … (2)

**답**: (1) A = np (2) B = n(n − 1)p² + np

**다른 형태 활용**:
- 형태1 곱 꼴의 다항식: fₙ(x) = Πₖ₌₁ⁿ (1 + kx) → fₙ₊₁ = fₙ·(1 + (n + 1)x) → 계수의 점화식 cₙ₊₁,ⱼ = cₙ,ⱼ + (n + 1)cₙ,ⱼ₋₁
- 형태4 곱의 계수 비교: (1 + x)ᵐ(1 + x)ⁿ = (1 + x)ᵐ⁺ⁿ의 xᵏ의 계수 → Σᵢ ₘCᵢ·ₙCₖ₋ᵢ = ₘ₊ₙCₖ
