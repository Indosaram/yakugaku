## ALG-01 대칭식은 기본대칭식으로 [필수]
*対称式は基本対称式へ* · 영상 0:02:22
- **발동 신호**: x+y, xy가 나온다 / xⁿ+yⁿ
- **핵심**: 대칭식은 기본대칭식 s = x + y, t = xy로 나타내고, 실수 조건 s² − 4t ≥ 0을 붙인다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 값 구하기 | x² + y², x³ + y³ 등 대칭식의 값 | s, t로 나타내 대입 (x² + y² = s² − 2t, x³ + y³ = s³ − 3st) |
| 형태2 범위·최대최소 | 실수 x, y의 조건식에서 범위를 묻는다 | s, t의 관계식 + 실수 조건 s² − 4t ≥ 0 |
| 형태3 n제곱의 합 | xⁿ + yⁿ을 구한다 | Sₙ₊₂ = sSₙ₊₁ − tSₙ으로 차례로 만든다 |

**연습 문제**: 실수 x, y가 x² + xy + y² = 3을 만족할 때, (1) x + y가 취할 수 있는 값의 범위를 구하라. (2) x³ + y³의 최댓값과 최솟값을 구하라.

**풀이**:
1. s = x + y, t = xy로 두면 s² − t = 3이므로 t = s² − 3
2. x, y가 실수 ⇔ s² − 4t ≥ 0 ⇒ s² ≤ 4, 따라서 −2 ≤ x + y ≤ 2
3. x³ + y³ = s³ − 3st = −2s³ + 9s (−2 ≤ s ≤ 2)
4. f′(s) = −6s² + 9 = 0 ⇒ s = ±√(3/2)이고, f(±√(3/2)) = ±3√6, f(±2) = ±2
5. 최댓값 3√6, 최솟값 −3√6 (s = ±√(3/2)일 때 t = −3/2이고 s² − 4t > 0이므로 실제로 존재)

**답**: (1) −2 ≤ x + y ≤ 2 (2) 최댓값 3√6, 최솟값 −3√6

**다른 형태 활용**:
- 형태3 n제곱의 합: 예) s = 3, t = 1일 때 Sₙ₊₂ = 3Sₙ₊₁ − Sₙ → S₂ = 7, S₃ = 18, S₄ = 47

## ALG-02 근과 계수의 관계로 통째로 처리 [필수]
*解と係数の関係で丸ごと処理* · 영상 0:05:54
- **발동 신호**: 근을 α, β, γ로 둔다 / 근의 대칭식
- **핵심**: 근을 구하지 않고 근과 계수의 관계와 거듭제곱 합의 점화식으로 처리한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 대칭식의 값 | α² + β² 등 근의 대칭식 | 기본대칭식(합·곱)으로 나타내 근과 계수의 관계를 대입 |
| 형태2 거듭제곱 합 | αⁿ + βⁿ + γⁿ (3제곱 이상) | αⁿ⁺³ = ⋯를 세 근에 대해 더해 점화식 pₙ₊₃ = ⋯ |
| 형태3 근의 변환 | α + 1, 1/α 등을 근으로 갖는 방정식 | 새 근을 y로 두고 x를 y로 나타내 대입 |

**연습 문제**: 3차방정식 x³ − x² − 2x + 1 = 0의 세 근을 α, β, γ라 하자. (1) α² + β² + γ²의 값을 구하라. (2) α⁴ + β⁴ + γ⁴의 값을 구하라.

**풀이**:
1. α + β + γ = 1, αβ + βγ + γα = −2, αβγ = −1
2. p₂ = (α + β + γ)² − 2(αβ + βγ + γα) = 1 + 4 = 5
3. α³ = α² + 2α − 1 ⇒ α⁴ = α³ + 2α² − α
4. 세 근에 대해 더하면 p₃ = p₂ + 2p₁ − 3, p₄ = p₃ + 2p₂ − p₁
5. p₃ = 5 + 2 − 3 = 4, p₄ = 4 + 10 − 1 = 13

**답**: (1) 5 (2) 13

**다른 형태 활용**:
- 형태3 근의 변환: 예) 근을 1씩 크게 한다 → x = y − 1을 대입 → y³ − 4y² + 3y + 1 = 0

## ALG-03 나머지정리와 차수 낮추기 [필수]
*剰余の定理と次数下げ* · 영상 0:09:19
- **발동 신호**: "~로 나눈 나머지" / 고차식의 값
- **핵심**: "나눈 나머지"는 P(x) = Q(x)D(x) + R(x)로 두고, D = 0의 근을 대입한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 1차식으로 나누기 | x − a로 나눈 나머지 | 나머지정리 R = P(a) |
| 형태2 2차 이상으로 나누기 | (x − a)(x − b)나 (x − a)²로 나눈 나머지 | 나머지를 px + q 등으로 두고, P(a), P(b)(중근이면 P′(a))로 계수 결정 |
| 형태3 차수 낮추기 | 고차식의 값, x² = x + 1 등 | D(x) = 0을 이용해 xⁿ을 낮은 차수로 고쳐 쓴다 |

**연습 문제**: 정식 x¹⁰에 대해, (1) x + 1로 나눈 나머지를 구하라. (2) (x − 1)²(x + 1)로 나눈 나머지를 구하라.

**풀이**:
1. (1) P(−1) = (−1)¹⁰ = 1
2. x¹⁰ = (x − 1)²(x + 1)Q(x) + ax² + bx + c로 둔다
3. x = 1을 대입하면 a + b + c = 1, x = −1을 대입하면 a − b + c = 1
4. 양변을 미분하고 x = 1을 대입하면 10 = 2a + b
5. b = 0, a = 5, c = −4

**답**: (1) 1 (2) 5x² − 4

**다른 형태 활용**:
- 형태3 차수 낮추기: 예) x² = x + 1일 때 x³ = x(x + 1) = x² + x = 2x + 1

## ALG-04 근의 분리(배치) [필수]
*解の配置* · 영상 0:12:40
- **발동 신호**: "~의 범위에 근을 2개 갖는다"
- **핵심**: "범위에 근"이 나오면 풀지 말고 f(x)의 그래프 조건(판별식·축·끝점)으로 바꾼다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 범위에 2근 | p < x < q에 서로 다른 두 근 | 판별식·축·끝점의 3조건 |
| 형태2 1근·끼우기 | 범위에 근이 1개, 범위를 사이에 끼운다 | 끝점의 부호 f(p)f(q) < 0으로 결정 |
| 형태3 0 기준 | 두 양근, 부호가 다른 근 | D ≥ 0과 합·곱의 부호 |

**연습 문제**: 2차방정식 x² − 2ax + a + 2 = 0이 −1 < x < 3의 범위에서 서로 다른 두 실근을 갖도록 하는 상수 a의 값의 범위를 구하라.

**풀이**:
1. f(x) = x² − 2ax + a + 2로 둔다 (아래로 볼록)
2. (i) D/4 = a² − a − 2 = (a − 2)(a + 1) > 0 ⇒ a < −1 또는 a > 2
3. (ii) 축 x = a에 대해 −1 < a < 3
4. (iii) f(−1) = 3a + 3 > 0, f(3) = 11 − 5a > 0 ⇒ a > −1, a < 11/5
5. 공통 부분은 2 < a < 11/5

**답**: 2 < a < 11/5

**다른 형태 활용**:
- 형태2 1근·끼우기: 예) x² − 2x − 3 = 0이 0 < x < 5에 근을 1개 가짐 → f(0)f(5) = (−3)·12 < 0
- 형태3 0 기준: 예) x² − 5x + 6 = 0은 합 5 > 0, 곱 6 > 0 → 두 근 모두 양수 (x = 2, 3)

## ALG-05 정수(상수) 분리 [필수]
*定数分離* · 영상 0:16:17
- **발동 신호**: 문자 상수를 포함한 방정식의 근의 개수
- **핵심**: 문자 상수 a를 분리해 a = f(x)로 만들고, 곡선 y = f(x)와 수평선 y = a의 공유점으로 생각한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 1차 상수 분리 | a가 1차로 들어 있는 방정식 | a = f(x)로 만들어 공유점의 개수를 센다 |
| 형태2 범위 조건 | 양의 근, x > 1인 근 등 | 그래프도 그 범위만 본다 (끝점 포함 여부 주의) |
| 형태3 나눠서 분리 | x로 나누면 a를 분리할 수 있다 | x = 0이 근인지 확인한 뒤 나눈다 |

**연습 문제**: 3차방정식 x³ − 3x² − 9x + a = 0에 대해, (1) 서로 다른 실근의 개수를 a의 값에 따라 답하라. (2) 양의 근을 정확히 2개 갖는 a의 범위를 구하라.

**풀이**:
1. a = −x³ + 3x² + 9x = f(x)로 분리한다
2. f′(x) = −3(x − 3)(x + 1)이므로 극소 f(−1) = −5, 극대 f(3) = 27
3. (1) a < −5 또는 27 < a일 때 1개, a = −5 또는 27일 때 2개, −5 < a < 27일 때 3개
4. (2) x > 0에서는 f(0) = 0에서 f(3) = 27까지 증가하고 그 뒤로 감소한다
5. 따라서 0 < a < 27

**답**: (1) a < −5 또는 27 < a일 때 1개, a = −5 또는 27일 때 2개, −5 < a < 27일 때 3개 (2) 0 < a < 27

**다른 형태 활용**:
- 형태3 나눠서 분리: 예) x² + 1 = ax → x = 0은 근이 아님 → x로 나눠 a = x + 1/x

## ALG-06 산술·기하평균, 코시-슈바르츠 [필수]
*相加相乗・コーシーシュワルツ* · 영상 0:20:04
- **발동 신호**: 양수의 합과 곱 / 최솟값
- **핵심**: 양수의 최솟값은 산술·기하평균(등호 성립 확인까지) 또는 코시-슈바르츠로 구한다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 합·곱이 일정 | 합이나 곱이 상수, x + 1/x 등 | a + b ≥ 2√(ab) (등호는 a = b) |
| 형태2 조건의 1을 곱하기 | 1/x + 4/y = 1 같은 조건이 있을 때 | 구하는 식에 조건식을 곱해 전개 → 곱이 상수인 쌍을 만든다 |
| 형태3 코시-슈바르츠 | 제곱의 합과 1차식의 관계 | (a² + b²)(x² + y²) ≥ (ax + by)², 등호는 a : b = x : y |

**연습 문제**: x > 0, y > 0이고 1/x + 4/y = 1을 만족할 때, x + y의 최솟값과 그때의 x, y의 값을 구하라.

**풀이**:
1. x + y = (x + y)(1/x + 4/y) = 5 + 4x/y + y/x
2. 산술·기하평균에 의해 ≥ 5 + 2√((4x/y)·(y/x)) = 9
3. 등호는 4x/y = y/x일 때이므로 y = 2x
4. 조건에 대입하면 1/x + 4/(2x) = 3/x = 1 ⇒ x = 3, y = 6
5. (형태3으로 풀면) (x + y)(1/x + 4/y) ≥ (1 + 2)² = 9

**답**: 최솟값 9 (x = 3, y = 6일 때)

**다른 형태 활용**:
- 형태1 합·곱이 일정: 예) x > 0일 때 x + 4/x ≥ 2√(x·4/x) = 4 (등호는 x = 2)

## ALG-07 부등식 증명은 차를 취한다 / 주인공을 정한다 [권장]
*不等式証明は差をとる／主役を決める* · 영상 0:23:11
- **발동 신호**: "~를 보여라" 형태의 부등식
- **핵심**: 부등식의 증명은 차를 취한다. 문자가 여러 개면 주인공(기준 문자)을 정해 완전제곱식으로 만든다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 차를 취한다 | "A ≥ B를 보여라" | A − B를 인수분해하거나 제곱의 합으로 만들어 부호를 조사 |
| 형태2 주인공을 정한다 | 문자가 여러 개 | 한 문자에 대해 정리 → 완전제곱식 or 판별식 D ≤ 0 |
| 형태3 제곱의 차 | 양변이 양수, 절댓값 포함 | A² − B²의 부호를 조사 |

**연습 문제**: (1) a > 0, b > 0일 때 a³ + b³ ≥ a²b + ab²를 보여라. (2) 실수 x, y에 대해 x² − xy + y² − x − y + 1 ≥ 0을 보이고, 등호가 성립하는 x, y를 구하라.

**풀이**:
1. a³ + b³ − (a²b + ab²) = (a − b)(a² − b²) = (a + b)(a − b)² ≥ 0
2. x를 주인공으로 정리하면 F = x² − (y + 1)x + y² − y + 1
3. F = (x − (y + 1)/2)² + (3/4)(y − 1)² ≥ 0
4. 등호 ⇔ y = 1, x = 1

**답**: (1) 증명 생략 (등호는 a = b) (2) 증명 생략, 등호는 x = y = 1

**다른 형태 활용**:
- 형태3 제곱의 차: 예) |a + b| ≤ |a| + |b| → (|a| + |b|)² − |a + b|² = 2(|ab| − ab) ≥ 0

## ALG-08 절댓값·경우 나누기 정리 [필수]
*絶対値・場合分けの整理* · 영상 0:26:49
- **발동 신호**: |x − a|가 여러 개
- **핵심**: 절댓값이 여러 개면 0이 되는 점에서 구간을 나눠 벗기거나, 그래프(꺾은선)로 만들어 읽는다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 구간별로 벗기기 | |x − a| + |x − b| 등 여러 개 | 안이 0이 되는 점에서 나누고, 각 구간에서 부호를 정해 벗긴다 |
| 형태2 그래프화 | 근의 개수·부등식의 범위 | 꺾은선 y = g(x)와 직선의 교점·위아래 관계로 읽는다 |
| 형태3 거리의 의미 | |x − a| < r 등 1개 | a − r < x < a + r, 수직선 위의 거리로 생각 |

**연습 문제**: (1) 부등식 |x − 1| + |x − 3| ≤ x + 1을 풀어라. (2) 방정식 |x − 1| + |x − 3| = x + a가 서로 다른 두 실근을 갖도록 하는 상수 a의 값의 범위를 구하라.

**풀이**:
1. g(x) = |x − 1| + |x − 3|은 x < 1일 때 −2x + 4, 1 ≤ x ≤ 3일 때 2, x > 3일 때 2x − 4
2. y = g(x)와 y = x + 1의 교점은 x = 1, 5 ⇒ 1 ≤ x ≤ 5
3. y = x + a는 기울기 1인 직선이고, 점 (3, 2)를 지날 때 a = −1
4. a > −1일 때 두 점에서 만난다

**답**: (1) 1 ≤ x ≤ 5 (2) a > −1

**다른 형태 활용**:
- 형태3 거리의 의미: 예) |x − 2| < 3 → 2로부터의 거리가 3 미만 → −1 < x < 5

## ALG-09 복소수 근과 켤레 [필수]
*複素数解と共役* · 영상 0:30:26
- **발동 신호**: 실수 계수인데 허근이 나온다
- **핵심**: 실수 계수 방정식의 허근은 켤레근과 세트다. ω³ = 1, ω² + ω + 1 = 0으로 차수를 낮춘다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 켤레근 추가 | 실수 계수 방정식에서 허근이 주어진다 | 켤레근도 근이다. 근과 계수의 관계나 인수분해로 나머지 근을 정한다 |
| 형태2 1의 세제곱근 ω | x³ = 1의 허근, ωⁿ의 합 | ω² + ω + 1 = 0, ω³ = 1로 차수 낮추기 |
| 형태3 실수부·허수부로 나누기 | 복소수를 대입한다 | a + bi = 0 ⇔ a = b = 0 (a, b는 실수) |

**연습 문제**: (1) 실수 a, b를 계수로 하는 방정식 x³ + ax² + bx + 5 = 0이 1 + 2i를 근으로 가질 때, a, b의 값과 나머지 근을 구하라. (2) x² + x + 1 = 0의 한 근을 ω라 할 때, ω¹⁰⁰ + ω²⁰⁰의 값을 구하라.

**풀이**:
1. 1 + 2i가 근이면 1 − 2i도 근이다. 나머지 근을 r로 둔다
2. 곱: (1 + 2i)(1 − 2i)r = 5r = −5 ⇒ r = −1
3. 합: 2 + r = −a ⇒ a = −1, b = 5 + 2r = 3
4. ω³ = 1이므로 ω¹⁰⁰ = ω, ω²⁰⁰ = ω²
5. ω¹⁰⁰ + ω²⁰⁰ = ω + ω² = −1

**답**: (1) a = −1, b = 3, 나머지 근 1 − 2i, −1 (2) −1

**다른 형태 활용**:
- 형태3 실수부·허수부로 나누기: 예) x² + ax + b = 0에 x = 1 + i를 대입 → 실수부 a + b = 0, 허수부 2 + a = 0 → a = −2, b = 2

## ALG-10 변변 빼서 인수분해 [권장]
*辺々を引いて因数分解* · 영상 0:34:27
- **발동 신호**: 비슷한 형태의 연립방정식·대칭인 연립
- **핵심**: 대칭이거나 비슷한 형태의 연립방정식은 변변 빼서 (x − y)(⋯) = 0을 만든 뒤 경우를 나눈다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 2원 대칭형 | x, y를 바꿔도 형태가 같다 | 변변 빼서 (x − y)(⋯) = 0, x = y와 다른 식으로 나눈다 |
| 형태2 3원 순환형 | x → y → z → x로 도는 형태 | 변변 빼서, 모두 같은 경우 / 그렇지 않은 경우로 나눈다 |
| 형태3 동차 연립 | 상수항이 맞춰진 연립 | 상수항을 없애는 조합으로 x = ky의 관계를 끄집어낸다 |

**연습 문제**: 연립방정식 x² = 2y + 4, y² = 2x + 4의 실수해를 모두 구하라.

**풀이**:
1. 변변 빼면 x² − y² = 2(y − x) ⇒ (x − y)(x + y + 2) = 0
2. (i) x = y일 때: x² − 2x − 4 = 0 ⇒ x = 1 ± √5
3. (ii) y = −x − 2일 때: x² = −2x ⇒ x = 0, −2
4. (x, y) = (1 ± √5, 1 ± √5) (복부호 동순), (0, −2), (−2, 0)

**답**: (x, y) = (1 + √5, 1 + √5), (1 − √5, 1 − √5), (0, −2), (−2, 0)

**다른 형태 활용**:
- 형태2 3원 순환형: 예) x² = y + 1, y² = z + 1, z² = x + 1 → 변변 뺀다 (x² − y² = y − z 등) → 먼저 x = y = z인 경우
- 형태3 동차 연립: 예) x² + xy = 6, xy + y² = 3 → ① − ②×2 → (x − 2y)(x + y) = 0

## ALG-11 정식의 결정: 차수를 좁혀 계수 비교 [권장]
*整式の決定：次数を絞って係数比較* · 영상 0:38:36
- **발동 신호**: "f(x)를 구하라"에서 함수 등식·차분 조건
- **핵심**: 정식 f(x)를 구할 때는 차수 비교로 차수를 정하고, 계수를 두어 비교한다(대입도 병용).

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 차수를 정한다 | 차수가 불명인 함수 등식·차분 조건 | 양변의 최고차 차수를 비교해 n을 확정 |
| 형태2 계수 비교 | 차수가 정해졌을 때 | f = axⁿ + ⋯로 두고 항등식으로서 계수를 비교 |
| 형태3 특수값 대입 | f(0), f(1) 등을 쓸 수 있다 | x = 0, 1을 대입해 조건·값을 끌어낸다 |

**연습 문제**: 정식 f(x)가 f(0) = 1 및 f(x + 1) − f(x − 1) = 6x² + 4x + 4를 만족할 때, f(x)를 구하라.

**풀이**:
1. f를 n차식 (n ≥ 1)이라 하면 f(x + 1) − f(x − 1)은 n − 1차
2. n − 1 = 2 ⇒ n = 3
3. f = ax³ + bx² + cx + d로 두면 f(x + 1) − f(x − 1) = a(6x² + 2) + 4bx + 2c
4. 계수 비교: 6a = 6, 4b = 4, 2a + 2c = 4 ⇒ a = b = c = 1
5. f(0) = d = 1 ⇒ f(x) = x³ + x² + x + 1

**답**: f(x) = x³ + x² + x + 1

**다른 형태 활용**:
- 형태3 특수값 대입: 예) f(x + 1) = f(x) + 2x에 x = 0, 1을 대입 → f(1) = f(0), f(2) = f(1) + 2

## ALG-12 4차식은 제곱의 차로 인수분해 [권장]
*4次式は平方の差で因数分解* · 영상 0:42:43
- **발동 신호**: x⁴ + ax² + b 형태, 복이차식
- **핵심**: 4차식 x⁴ + ax² + b는 제곱식을 만들어 (x² + c)² − (kx)²의 제곱의 차로 바꾼다.

**형태별 정리**
| 형태 | 언제 | 어떻게 |
|---|---|---|
| 형태1 제곱 만들기 | x⁴ + ax² + b에서 t² + at + b가 인수분해되지 않는다 | (x² + √b)² − (⋯)x²로 변형해 합과 차의 곱으로 |
| 형태2 더하고 빼기 | x⁴ + 4, x⁴ + 1 등 가운데 항이 없다 | 4x² 등을 더하고 빼서 (x² + 2)² − 4x² |
| 형태3 t로 치환 | x² = t로 둔 식이 인수분해된다 | t의 2차식으로 인수분해 |

**연습 문제**: (1) x⁴ − 2x² + 9를 실수 계수 범위에서 인수분해하라. (2) 방정식 x⁴ − 2x² + 9 = 0을 풀어라.

**풀이**:
1. x⁴ − 2x² + 9 = (x² + 3)² − 8x²
2. = (x² + 3)² − (2√2 x)² = (x² + 2√2x + 3)(x² − 2√2x + 3)
3. x² − 2√2x + 3 = 0 ⇒ x = √2 ± i
4. x² + 2√2x + 3 = 0 ⇒ x = −√2 ± i

**답**: (1) (x² + 2√2x + 3)(x² − 2√2x + 3) (2) x = ±√2 ± i (4개)

**다른 형태 활용**:
- 형태2 더하고 빼기: 예) x⁴ + 4 = (x² + 2)² − 4x² = (x² + 2x + 2)(x² − 2x + 2)
- 형태3 t로 치환: 예) x⁴ − 5x² + 4 → t² − 5t + 4 = (t − 1)(t − 4) → (x² − 1)(x² − 4)
