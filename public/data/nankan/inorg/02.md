## 이 장의 요점
- 금속 산화물 = 이온 결합·염기성, 비금속 산화물 = 공유 결합·산성
- **양쪽성(両性): Al₂O₃·ZnO·SnO·PbO (NaOH와 반응하여 [Al(OH)₄]⁻·[Zn(OH)₄]²⁻)**
- 중성: CO·NO·N₂O / SiO₂는 물에 녹지 않지만 산성 산화물이다
- 산무수물(酸無水物): SO₃→H₂SO₄, P₄O₁₀→H₃PO₄, Cl₂O₇→HClO₄ (산화수는 그대로)
- **제3주기: 오른쪽일수록 산성 (중심 원자의 전기음성도 때문)**
- **HClO < HClO₂ < HClO₃ < HClO₄ (산화력은 반대 순서), H₂SO₃ < H₂SO₄**
- 물: HCl에 대해서는 염기, NH₃에 대해서는 산
- NaHSO₄·NaH₂PO₄는 산성 쪽, NaHCO₃·Na₂HPO₄는 염기성 쪽

## 외울 지식
- ★ 금속 산화물은 이온 결합, 비금속 산화물은 공유 결합이다. ★ 산성 산화물 + 물 → 옥소산(オキソ酸)
- ★ 양쪽성 산화물(両性酸化物)은 Al₂O₃·ZnO (SnO·PbO)이다.
  - Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄]
  - ZnO + 2NaOH + H₂O → Na₂[Zn(OH)₄]
  - Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O
- ★ MgO·CaO는 염기성 산화물, SiO₂는 산성 산화물이다.
- ★ 산성 산화물과 물의 반응:
  - SO₂ + H₂O → H₂SO₃
  - SO₃ + H₂O → H₂SO₄
  - P₄O₁₀ + 6H₂O → 4H₃PO₄
  - Cl₂O₇ + H₂O → 2HClO₄
- ★ 염소 옥소산의 세기는 HClO < HClO₂ < HClO₃ < HClO₄이고, 과염소산(過塩素酸)이 가장 강하다. ★ H₂SO₃의 S는 +4, H₂SO₄의 S는 +6이다.
- ★ 산화수:
  - HNO₂의 N = +3
  - H₃PO₄의 P = +5
  - H₂SO₄의 S = +6
  - HClO₄의 Cl = +7
  - NaClO의 Cl = +1
  - KClO₃의 Cl = +5
- ★ Mn₂O₃의 Mn = +3, K₂MnO₄의 Mn = +6
- ★ 금속 산화물 관련 정오(正誤) 문제: Na의 보존, Ca와 물, Al₂O₃와 염산
- ★ HCl + H₂O에서 H₂O는 염기, NH₃ + H₂O에서 H₂O는 산이다 (브뢴스테드(ブレンステッド) 정의).
- 중성 산화물(中性酸化物) CO·NO·N₂O는 물과도 염기와도 반응하지 않는다.
- 옥소산의 명명: 과~산(過〜酸)·~산(〜酸)·아~산(亜〜酸)·차아~산(次亜〜酸)
- 염의 액성(液性):
  - ★ NaHSO₄·NH₄Cl은 산성, Na₂CO₃·NaHCO₃는 염기성, NaCl·Na₂SO₄는 중성이다.
  - ★ NaH₂PO₄는 약산성, Na₂HPO₄는 약염기성이다.

## 호시약대 관점
[필수] 무기 원소·화합물 성질 단원은 9회 전부 출제됐고, 그 핵심 중 하나가 양쪽성(Al·Zn)이다. 산화수(4회)와 산염기·염의 액성(3회)도 이 장 내용과 직결되며, 정오 조합형 문제에서 바로 득점할 수 있는 영역이다.
