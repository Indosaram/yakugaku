## 이 장의 요점
- 구리: HCl·묽은 H₂SO₄에는 녹지 않는다 / HNO₃·뜨거운 진한 H₂SO₄·왕수(王水)에는 녹는다
- Cu²⁺(청색) → 소량의 염기로 Cu(OH)₂(청백색) → 가열하면 CuO(흑색)
- **NH₃ 과량이면 [Cu(NH₃)₄]²⁺(심청색·정사각형), NaOH를 가하면 Cu(OH)₂로 되돌아간다**
- H₂S: 산성에서도 CuS(흑색)
- 산화물: CuO(흑색)와 Cu₂O(적색, 1000℃ 이상·펠링액(フェーリング液))
- **요오드 적정(ヨウ素滴定): 2Cu²⁺ + 4I⁻ → 2CuI + I₂, Cu²⁺ : S₂O₃²⁻ = 1 : 1**
- CuSO₄·5H₂O(청색) → 무수물(백색), 녹청(緑青), 황동·청동·백동

## 외울 지식
- ★ Cu: 적색(赤色), Ag 다음으로 전기전도성이 크다. 불꽃반응(炎色反応)은 청록색(青緑色)이고 11족이다.
  - ★ 염산·묽은 황산에는 녹지 않는다.
  - 진한 질산·묽은 질산·뜨거운 진한 황산에는 녹는다(★ Cu + 2H₂SO₄ → CuSO₄ + SO₂ + 2H₂O).
- ★ Cu²⁺에 NH₃ 수용액을 넣을 때
  - 소량이면 청백색(青白色) Cu(OH)₂가 생긴다(Cu²⁺ + 2OH⁻ → Cu(OH)₂).
  - 과량이면 심청색(深青色) [Cu(NH₃)₄]²⁺가 된다(정사각형, 테트라아민구리(II) 이온(テトラアンミン銅(II)イオン)).
  - ★ [Cu(NH₃)₄]²⁺에 NaOH를 가하면 다시 Cu(OH)₂가 침전한다([Cu(NH₃)₄]²⁺ + 2OH⁻ → Cu(OH)₂ + 4NH₃).
  - Cu(OH)₂는 과량의 NaOH에 녹지 않는다.
- ★ Cu²⁺는 H₂S에 의해 산성에서도 CuS(흑색)로 침전한다(Cu²⁺ + H₂S → CuS + 2H⁺).
- ★ Cu의 산화물
  - Cu(적색)를 공기 중에서 가열하면 CuO(흑색)가 된다(2Cu + O₂ → 2CuO).
  - 1000℃ 이상에서는 Cu₂O(적색)가 된다(4CuO → 2Cu₂O + O₂).
  - ★ Cu(OH)₂를 가열하면 CuO가 된다.
  - ★ 펠링액이 환원되면 Cu₂O(적색 침전(赤色沈殿))가 생긴다.
- ★ Cu²⁺와 I⁻에서 CuI(백색 침전(白色沈殿))와 I₂가 생긴다(2Cu²⁺ + 4I⁻ → 2CuI + I₂). 이 I₂를 티오황산나트륨(チオ硫酸ナトリウム)으로 적정해 Cu를 정량한다.
  - ★ CuO는 I⁻를 산화한다(2CuO + 4I⁻ + 4H⁺ → 2CuI + I₂ + 2H₂O). Cu₂O는 요오드를 생성하지 않는다.
  - ★ 고온에서 급랭한 고체의 주성분(Cu₂O)과 그 이유.
- ★ CuSO₄·5H₂O(청색)를 가열하면 CuSO₄(백색, 무수염(無水塩))가 된다. 이 변화로 물을 검출한다.
- ★ 녹청(緑青): 습한 공기 중에서 구리 표면에 생기는 녹색(緑色) 녹(CuCO₃·Cu(OH)₂).
- ★ 합금
  - 황동(黄銅, 真ちゅう) = Cu + Zn
  - 청동(青銅) = Cu + Sn
  - 백동(白銅) = Cu + Ni ☆
- ★ 아연판을 CuSO₄ 수용액에 담그면 Cu가 석출된다(Zn + Cu²⁺ → Zn²⁺ + Cu).
  - ★ 이온화 에너지 사이클로 Cu와 Zn의 이온화 경향(イオン化傾向)을 비교한다(阪大).
- ★ 구리(II) 글리신 착물 [Cu(NH₂CH₂COO)₂]: 평면사각형이며 cis/trans 이성질체가 있다.
  - trans: 극성이 작고 비늘 모양(りん片状)
  - cis: 극성이 크고 바늘 모양(針状)
- ★ 다니엘 전지(ダニエル電池)의 양극.
- ★ 전해정련(電解精錬)(→ID-08).
- ★ 황동광(黄銅鉱) CuFeS₂: Cu²⁺·Fe²⁺·S²⁻의 이온결정으로 취급한다 ☆. 섬아연광형(閃亜鉛鉱型) 구조.
- ☆ 슈바이처 시약(シュバイツァー試薬)([Cu(NH₃)₄](OH)₂)으로 셀룰로스를 녹여 구리암모니아레이온(銅アンモニアレーヨン)을 만든다.
- ☆ CuCl(백색).
- ☆ 보르도액(ボルドー液)(CuSO₄ + Ca(OH)₂).

## 호시약대 관점
[필수] 무기 원소·화합물 성질은 9회 모두 출제되었고, 착이온은 공부 우선순위 3번에 해당한다. 요오드 적정은 산화환원 단원(4회 출제)의 비고에도 명시되어 있다. 「동전」 같은 실생활 소재 지문에서 Cu의 색 변화, 착이온, 합금이 그대로 출제되기 쉽다.
