## 이 장의 요점
- Ag: 전기전도성·반사율이 최대이다. 질산·뜨거운 진한 황산에 녹고, 왕수(王水)에는 잘 녹지 않는다.
- H₂S와 반응하면 흑색(黒) Ag₂S가 생긴다(변색). AgNO₃는 빛에 분해되므로 갈색병(褐色瓶)에 보관한다.
- **Ag⁺ + 염기 → Ag₂O(갈색(褐色)). NH₃를 과량 넣으면 → [Ag(NH₃)₂]⁺(무색(無色)·직선형)**
- **AgCl 백색(白)·AgBr 담황색(淡黄)·AgI 황색(黄)(AgF는 가용성). NH₃수에 녹는 것은 AgCl**
- Na₂S₂O₃ → [Ag(S₂O₃)₂]³⁻(정착(定着)), KCN → [Ag(CN)₂]⁻
- 감광성(感光性): 2AgBr → 2Ag + Br₂. 은거울 반응(銀鏡反応). 은나무(銀樹): Cu + 2Ag⁺ → Cu²⁺ + 2Ag
- Ag₂CrO₄ 적갈색(赤褐)(모르법(モール法): 중성∼약염기성), Ag₂S 흑색(黒), Ag₂SO₄ 약간 난용성

## 외울 지식
- ★ Ag(11족)는 금속 중에서 전기전도성·열전도성·빛의 반사율이 최대이다.
- ★ 염산·묽은 황산에는 녹지 않고, 질산·뜨거운 진한 황산에 녹는다.
  - Ag + 2HNO₃(진한) → AgNO₃ + NO₂ + H₂O
  - 3Ag + 4HNO₃(묽은) → 3AgNO₃ + NO + 2H₂O
- ★ Ag⁺에 NaOH 또는 소량의 NH₃수를 넣으면 갈색(褐色) Ag₂O가 침전한다(2Ag⁺ + 2OH⁻ → Ag₂O + H₂O).
  - NH₃수를 과량 넣으면 무색(無色)의 [Ag(NH₃)₂]⁺가 된다. 이름은 디암민은(I) 이온(ジアンミン銀(I)イオン)이고 직선형이다.
  - Ag₂O + 4NH₃ + H₂O → 2[Ag(NH₃)₂]⁺ + 2OH⁻
- ★ Ag₂O는 NaOH를 과량 넣어도 녹지 않는다.
- ★ 할로겐화은(ハロゲン化銀): AgCl 백색(白), AgBr 담황색(淡黄), AgI 황색(黄)(AgF는 가용성).
- ★ NH₃수에 대한 용해성: AgCl은 녹는다. AgBr은 잘 녹지 않는다(일부 녹음). AgI는 녹지 않는다.
- ★ AgBr(고) + 2NH₃ ⇄ [Ag(NH₃)₂]⁺ + Br⁻
  - 용해도는 Ksp와 Kf의 곱으로 구한다.
  - Ksp(AgBr) ≈ 5×10⁻¹³, Kf ≈ 1.6×10⁷
- ★ [Ag(NH₃)]⁺·[Ag(NH₃)₂]⁺의 축차평형(逐次平衡)과 존재 비율(存在割合) 그래프
- ★ 할로겐화은의 감광성(感光性): 빛을 받으면 Ag가 유리되어 검게 변한다. 사진 필름에 이용된다.
  - 2AgCl → 2Ag + Cl₂
  - 2AgBr → 2Ag + Br₂
- ★ 정착(定着): AgBr + 2Na₂S₂O₃ → Na₃[Ag(S₂O₃)₂] + NaBr
- ★ Ag는 H₂S와 반응하여 흑색(黒色) Ag₂S가 된다. 이것이 은의 변색이다.
  - 2Ag + H₂S + ½O₂ → Ag₂S + H₂O
- ★ Ag₂CrO₄: 적갈색(赤褐色), Ksp ≈ 1∼4×10⁻¹²
- ★ 모르법(モール法): K₂CrO₄를 지시약으로 쓰고, 중성∼약염기성(pH 6.5∼10)에서 행한다.
  - 산성에서는 Cr₂O₇²⁻가 되고, 염기성에서는 Ag₂O가 생기기 때문이다.
- ★ 염화은 침전을 홑원소물질로 환원하는 방법
- ★ 은거울 반응(銀鏡反応): 포르밀기(ホルミル基)·개미산(ギ酸)
- AgNO₃는 빛에 분해되므로 갈색병(褐色瓶)에 보관한다.
- ★ 은 농담전지(銀濃淡電池)(이론)
- ★ Ag·Au는 면심입방(面心立方) 구조이다(단위격자에 4개).
- ★ 왕수 속에서 Ag는 AgCl로 침전한다.
- ☆ [Ag(CN)₂]⁻: 은도금(銀めっき)·청화법(青化法)
