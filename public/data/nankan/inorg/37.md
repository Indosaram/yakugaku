## 이 장의 요점
- 불꽃 반응(炎色反応) 색: Li 빨간색(赤) · Na 노란색(黄) · K 적자색(赤紫) · Cu 청록색(青緑) · Ca 등적색(橙赤) · Sr 진홍색(紅) · Ba 황록색(黄緑). Be · Mg는 불꽃 반응 없음
- **Fe²⁺ + K₃[Fe(CN)₆], Fe³⁺ + K₄[Fe(CN)₆] → 짙은 청색(濃青), Fe³⁺ + KSCN → 혈적색(血赤)**
- NH₄⁺: NaOH를 넣고 가열 → NH₃
- Pb²⁺: K₂CrO₄ → 노란색(黄)
- Ba²⁺: H₂SO₄ → 흰색(白)
- **AgCl 흰색(白) · AgBr 담황색(淡黄) · AgI 노란색(黄) → NH₃수에 각각 잘 녹는다 / 조금 녹는다 / 녹지 않는다**
- **BaSO₄는 염산에 녹지 않는다. BaCO₃는 CO₂를 내며 녹는다**
- S²⁻: 아세트산납(II)(酢酸鉛(II)) → 검은색(黒)
- ☆NO₃⁻: 갈색고리 반응(褐輪反応)
- ☆PO₄³⁻: 몰리브덴산암모늄(モリブデン酸アンモニウム) → 노란색(黄)
- 물: 무수 CuSO₄ 흰색(白) → 청색(青), 염화코발트지(塩化コバルト紙) 청색(青) → 담적색(淡赤)
- O₃ · Cl₂: 아이오딘화칼륨 녹말 종이(KIデンプン紙) → 청자색(青紫)

## 외울 지식
- ★ 불꽃 반응
  - Li 빨간색(赤), Na 노란색(黄), K 적자색(赤紫)
  - Ca 등적색(橙赤), Sr 진홍색(紅, 심홍색(深赤)), Ba 황록색(黄緑), Cu 청록색(青緑)
  - ☆ Rb 심홍색(深赤), Cs 청자색(青紫), B 황록색(黄緑)
- ★ NH₄⁺ 확인: NaOH를 넣고 가열 → NH₃
- ★ Fe²⁺: K₃[Fe(CN)₆] → 짙은 청색(濃青)
- Fe³⁺: K₄[Fe(CN)₆] → 짙은 청색(濃青), KSCN → 혈적색(血赤)
- ★ Pb²⁺: K₂CrO₄ → 노란색(黄)
- ★ Ag⁺: Cl⁻ → 흰색(白) 침전 → NH₃수에 녹음
- ★ Ba²⁺: 묽은 황산(希硫酸) → 흰색(白)
- 음이온
  - Cl⁻: AgNO₃ → 흰색(白), NH₃수에 녹음
  - Br⁻: 담황색(淡黄)
  - I⁻: 노란색(黄). 또는 녹말 + Cl₂수 → 청색(青)
  - SO₄²⁻: BaCl₂ → 흰색(白), 염산에 녹지 않음
  - CO₃²⁻: 염산 → CO₂ 발생
  - ☆ NO₃⁻: 갈색고리 반응(褐輪反応), FeSO₄ + 진한 황산(濃硫酸)
  - S²⁻: Pb(CH₃COO)₂ → 검은색(黒)
  - ☆ PO₄³⁻: 몰리브덴산암모늄 → 노란색(黄)
- ★ 물의 검출: 무수 CuSO₄ 흰색(白) → 청색(青), 염화코발트지 청색(青) → 적색(赤)
- ★ 오존 · Cl₂의 검출: KI 녹말 종이(KIデンプン紙)

## 호시약대 관점
[필수] 무기 원소·화합물 성질은 9회분 모두 출제되었고, Fe 화합물이 공부 우선순위 3에 들어 있다. Fe 이온 검출, 불꽃 반응, 할로젠화은 침전 성질은 정오 조합형에서 바로 득점할 수 있으니 ★ 항목은 반드시 외운다. ☆ 항목(NO₃⁻ · PO₄³⁻ 검출, Rb · Cs)과 계통분리 전체 과정은 출제 흔적이 적어 후순위로 둔다.
