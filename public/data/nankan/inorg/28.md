## 이 장의 요점
- 크롬: 6족, 은백색(銀白色), 단단함, 부동태(不動態). 용도는 도금(めっき), 스테인리스강(ステンレス鋼), 니크롬(ニクロム, Ni-Cr)
- **2CrO₄²⁻(황색(黄)) + 2H⁺ ⇄ Cr₂O₇²⁻(적등색(赤橙)) + H₂O : 산화수는 +6 그대로**
- **Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺(녹색(緑)) + 7H₂O**
- Cr(OH)₃(회녹색(灰緑), ☆양쪽성(両性)), Cr₂O₃(녹색(緑)), CrO₃(암적색(暗赤)), 루비(ルビー)
- PbCrO₄·BaCrO₄(황색(黄)), Ag₂CrO₄(적갈색(赤褐)) → 모르법(モール法)은 중성∼약염기성에서 시행
- 크롬철석(クロム鉄鉱) FeCr₂O₄ → Na₂CrO₄. 6가 크롬은 환원한 뒤 Cr(OH)₃로 침전시켜 제거

## 외울 지식
- ★ 크롬은 6족, 은백색(銀白色) 금속이며 표면에 치밀한 산화 피막(부동태(不動態))이 생긴다.
- ★ 크롬 도금(クロムめっき): 6가 크롬 욕(六価クロム浴) CrO₃에서 전해한다. 음극에서 Cr⁶⁺→Cr³⁺→Cr로 환원되고 H₂도 발생한다.
- ★ 니크롬선(ニクロム線, Ni-Cr 합금)
- ★ 스테인리스강(ステンレス鋼)
- ★ 주요 크롬 광석은 크롬철석(クロム鉄鉱) FeCr₂O₄이다.
- ★ 알칼리 산화 배소(アルカリ酸化焙焼): 4FeCr₂O₄ + 8Na₂CO₃ + 7O₂ → 8Na₂CrO₄ + 2Fe₂O₃ + 8CO₂
- ★ CrO₄²⁻(황색(黄色)) ⇄ Cr₂O₇²⁻(적등색(赤橙色)): 2CrO₄²⁻ + 2H⁺ ⇄ Cr₂O₇²⁻ + H₂O
 - 산성에서는 Cr₂O₇²⁻, 염기성에서는 CrO₄²⁻가 된다.
 - 산화환원 반응이 아니다.
- ★ H₂CrO₄의 제1단계는 완전 전리한다.
 - HCrO₄⁻ ⇄ H⁺ + CrO₄²⁻ (K₁ = 1.25×10⁻⁶)
 - 2HCrO₄⁻ ⇄ Cr₂O₇²⁻ + H₂O (K₂ = 60)
 - pH−log[Cr]total 우세영역도(優勢領域図)
- ★ Cr₂O₇²⁻는 황산 산성에서 강한 산화제이다: Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O (Cr³⁺는 녹색(緑)·암녹색(暗緑))
- ★ Cr₂O₇²⁻ + 3H₂O₂ + 8H⁺ → 2Cr³⁺ + 3O₂ + 7H₂O (H₂O₂의 정량)
- ★ Sn²⁺·Fe²⁺와의 반응
- ★ 6가 크롬(六価クロム)은 독성이 강하다.
- ★ 폐수 처리(排水処理):
 - 2H₂Cr₂O₇ + 6NaHSO₃ + 3H₂SO₄ → 2Cr₂(SO₄)₃ + 3Na₂SO₄ + 8H₂O
 - Cr₂(SO₄)₃ + 6NaOH → 2Cr(OH)₃ + 3Na₂SO₄
 - Ksp = [Cr³⁺][OH⁻]³ 로 농도 하한을 구한다.
- ★ Cr(OH)₃는 회녹색(灰緑色)이다.
 - 생성: Cr³⁺ + 3NH₃ + 3H₂O → Cr(OH)₃ + 3NH₄⁺
 - 계통분리(系統分離)에서 Fe(OH)₃·Al(OH)₃와 함께 침전한다.
 - 양쪽성☆: NaOH 과량이면 [Cr(OH)₄]⁻가 된다.
- ★ PbCrO₄(황색(黄)), BaCrO₄(황색(黄)☆), Ag₂CrO₄(적갈색(赤褐), 모르법(モール法))
- ★ K₂CrO₄는 황색(黄)이다(Cr +6).
- ★ H₂Cr₂O₇의 식량은 218이다.
- ☆ Cr₂O₃: 녹색(緑), 안료(顔料)·연마제(研磨剤)
- ☆ CrO₃: 암적색(暗赤色)
- ☆ 루비의 붉은색은 Cr³⁺ 때문이다.
- ☆ 다이크롬산칼륨(二クロム酸カリウム)을 이용한 알코올 검지, 제1급 알코올(第一級アルコール)의 산화

## 호시약대 관점
[권장] — 출제 빈도표의 무기 핵심(Fe·Al·Zn)에 Cr은 직접 들어 있지 않다. 다만 공장 폐수 소재의 지문, 산화환원·산화수, 수산화물 용해도곱(Ksp)은 출제 경향과 겹친다. 따라서 CrO₄²⁻⇄Cr₂O₇²⁻ 평형, 산화제 반응식, 폐수 처리 흐름, 침전의 색까지만 확실히 잡아 두자.
