## 이 장의 요점
- 동소체: 사방황(斜方硫黄, 상온·덩어리 모양)·단사황(単斜硫黄, 95.5℃ 이상·바늘 모양) = 고리형 S₈의 분자결정(分子結晶)
- 고무상 황(ゴム状硫黄): 사슬 모양·탄성·불안정(약 250℃의 액체를 물로 급랭)
- 가황(加硫): 황 수 %로 탄성 고무, 30∼40%로 에보나이트(エボナイト) / 황은 석유의 탈황(脱硫)으로 얻는다
- **H₂S: 무색·썩은 달걀 냄새(腐卵臭)·유독·약산·환원제·굽은형(折れ線形), FeS + 산, 하방치환(下方置換), 아세트산납(II) 종이(酢酸鉛(II)紙)가 검게 변함**
- **2H₂S + SO₂ → 3S + 2H₂O (SO₂가 산화제)**
- Fe³⁺를 Fe²⁺로 환원(계통분리(系統分離)에서 끓이기·질산), I₂를 환원(요오드 적정(ヨウ素滴定))
- 황화 광물: FeS₂·CuFeS₂·ZnS·PbS·HgS

## 외울 지식
- ★ 동소체: 사방황(상온에서 안정·황색(黄色)·S₈ 고리형), 단사황(95.5℃ 이상·바늘 모양·S₈), 고무상 황(사슬형 Sₓ·탄성·불안정·암갈색(暗褐色)∼황색(黄色)). ★ 고리형 분자의 화학식은 S₈. ★ 사방황·단사황은 분자결정이며, 상태도(状態図)의 상경계가 출제된다(名大).
- ★ 황은 석유 정제(탈황)로 얻는다. 화산 지대에서는 천연 황이 난다.
- ★ 가황: 천연고무(폴리이소프렌)에 황 수 %를 넣으면 탄성 고무(S–S 가교), 30∼40%를 넣으면 에보나이트(흑색(黒色)·경질)가 된다.
- ★ H₂S: 무색·썩은 달걀 냄새·유독·약산(2단 전리, K₁≈1×10⁻⁷, K₂≈1×10⁻¹⁴, K=K₁K₂≈1.2×10⁻²¹)·환원제·굽은형 분자·화산가스·온천. ★ 제법: FeS + H₂SO₄ → FeSO₄ + H₂S(킵 장치(キップの装置)), FeS + 2HCl → FeCl₂ + H₂S, 하방치환으로 포집. ★ 검출: 아세트산납(II) 종이가 검게 변함(PbS).
- ★ H₂S + SO₂: 2H₂S + SO₂ → 3S + 2H₂O(SO₂가 산화제, H₂S가 환원제, 백탁). ★ Fe³⁺ + H₂S → Fe²⁺ + S + 2H⁺(계통분리에서 Fe²⁺가 되는 이유).
- ★ 황철석(黄鉄鉱) FeS₂는 Fe²⁺와 S₂²⁻로 이루어진다(NaCl형 배치). 묽은 황산을 가하면 H₂S가 발생한다(FeS₂ + 2H⁺ → Fe²⁺ + H₂S + S). ★ FeS₂의 연소: 4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂.
- ★ 황화 광물: 방연석(方鉛鉱) PbS·황철석 FeS₂·섬아연석(閃亜鉛鉱) ZnS·진사(辰砂) HgS·황동석(黄銅鉱) CuFeS₂.
- ★ 화산가스 성분: H₂O·CO₂·SO₂·H₂S·HCl·H₂. ★ SO₂ + 3H₂ ⇄ H₂S + 2H₂O의 평형(東大 이론).
- 황의 연소: 파란 불꽃을 내며 SO₂가 생긴다. 황은 물에 녹지 않고 CS₂에 녹는다(사방황·단사황). 고무상 황은 CS₂에도 녹지 않는다☆.

## 호시약대 관점
[필수] 기체 발생(H₂S 제법·포집·검출)은 9회 전부 나온 무기 단골이고, 동소체(7회)와 요오드 적정(산화환원)도 정오 문제로 직결된다. 반면 계통분리 전체 흐름과 가황(합성고무 관련)은 출제 흔적이 거의 없으니 가볍게 넘긴다.
