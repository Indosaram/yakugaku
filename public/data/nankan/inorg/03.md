## 이 장의 요점
- H₂: 우주에서 가장 많음·밀도 최소·물에 난용(수상치환(水上置換))·끓는점은 He보다 높음
- 동위체(同位体) ¹H·D·T (T는 방사성, β붕괴(β壊変), 반감기(半減期) 약 12년)
- **제법: Zn + 묽은 산, Al + NaOH, 전기분해**
- **공업: CH₄ + H₂O → CO + 3H₂, 시프트 반응(シフト反応)**
- NaH·LiH는 이온결합(H⁻), NaH + H₂O → NaOH + H₂ / PH₃는 공유결합
- **끓는점 CH₄ < NH₃ < HF < H₂O (수소결합), 수소흡장합금(水素吸蔵合金) LaNi₅·TiFe**
- **물: 4℃에서 밀도 최대, 가압하면 녹는점 저하, 감압하면 끓는점 저하**
- 물과 반응: K·Na·Ca는 상온 / Mg는 뜨거운 물(熱水) / Al·Zn·Fe는 고온 수증기
- 2F₂ + 2H₂O → 4HF + O₂, 3NO₂ + H₂O → 2HNO₃ + NO
- Cl₂ + H₂O ⇄ HCl + HClO (물은 산화제도 환원제도 아님)

## 외울 지식
- ★ 수소: 우주에서 가장 많은 원소, 무색·무취, 모든 기체 중 밀도 최소, 물에 대한 용해도 작음, 끓는점은 He보다 높음. ★ 동위체 ¹H·²H(D)·³H(T) (³H는 β붕괴, 반감기 약 12년☆).
- ★ H₂ 발생: 금속 + 산(Zn + 2HCl → ZnCl₂ + H₂), 양쪽성 금속(両性金属) + 강염기(2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂), 물의 전기분해. ★ 공업: CH₄ + H₂O → CO + 3H₂ (Ni 촉매·흡열), CO + H₂O → CO₂ + H₂, 2CH₄ + O₂ → 2CO + 4H₂.
- ★ PH₃는 공유결합, LiH·NaH는 이온결합(H⁻). ★ NaH + H₂O → NaOH + H₂.
- ★ 수소흡장합금(Ti·TiFe·LaNi₅, TiH₂). 연료전지 자동차(燃料電池自動車).
- ★ 물: 극성분자, 4℃에서 밀도 최대, 얼음의 녹는점은 가압하면 저하, 감압하면 끓는점 저하. ★ 분자간력(分子間力) = 반데르발스 힘(ファンデルワールス力)과 수소결합 (이온결합·금속결합·공유결합은 분자간력이 아님).
- ★ 물과의 반응: Ca + 2H₂O → Ca(OH)₂ + H₂, 3NO₂ + H₂O → 2HNO₃ + NO (불균화(不均化)), Cl₂ + H₂O ⇄ HCl + HClO, 2F₂ + 2H₂O → 4HF + O₂, SO₂ + H₂O → H₂SO₃, CaO + H₂O → Ca(OH)₂. ★ 적열(赤熱)한 철과 수증기: 3Fe + 4H₂O → Fe₃O₄ + 4H₂. ★ Mg는 찬물과 거의 반응하지 않고 뜨거운 물과 반응: Mg + 2H₂O → Mg(OH)₂ + H₂. ★ Ti는 고온 수증기와 반응해 TiO₂ + 2H₂.
- ★ 제2주기 수소화물의 끓는점 CH₄ < NH₃ < HF < H₂O. H₂O₂ (산화제·환원제 양면으로 작용, 3% 수용액은 옥시돌(オキシドール)).

## 호시약대 관점
[필수] 9회 모두 나온 무기 단골인 '기체 발생·양쪽성'(Zn + 산, Al + NaOH)과 매년 B방식에 나오는 전기분해가 이 장의 H₂ 제법과 직결된다. 수소결합에 따른 끓는점 순서도 1번 결합 정오 문제의 기본 지식이다. 다만 T의 반감기나 Ti 반응 같은 세부 내용은 가볍게 확인만 하면 된다.
