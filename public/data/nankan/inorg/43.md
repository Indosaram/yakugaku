## 이 장의 요점
- 제1단계: 4NH₃ + 5O₂ → 4NO + 6H₂O (Pt 그물(Pt網)·약 800℃·발열)
- 제2단계: 2NO + O₂ → 2NO₂ (무색(無色) → 적갈색(赤褐色), 냉각)
- 제3단계: 3NO₂ + H₂O → 2HNO₃ + NO (불균등화(不均化), NO는 재이용)
- **전체: NH₃ + 2O₂ → HNO₃ + H₂O, NH₃ : HNO₃ = 1 : 1**
- **촉매는 평형을 이동시키지 않는다. NO가 생기는 반응을 골라서 빠르게 한다(선택성(選択性)).**
- 용도: 질산암모늄(硝安, NH₃의 절반을 HNO₃로 바꿔 만든다)·화약·염료 / 예전에는 NaNO₃ + 진한 H₂SO₄로 제조

## 외울 지식
- ★ 4NH₃ + 5O₂ → 4NO + 6H₂O (Pt 촉매, 약 800℃), 2NO + O₂ → 2NO₂, 3NO₂ + H₂O → 2HNO₃ + NO (온수와 반응, NO는 재이용)
- ★ 3단계를 하나의 식으로 합치면: NH₃ + 2O₂ → HNO₃ + H₂O
- ★ 물의 전기분해(5.0 A·1930초) → 하버·보슈법(ハーバー・ボッシュ法) → 오스트발트법(オストワルト法)으로 얻어지는 HNO₃의 양 (九大 2025)
- ★ Pt 촉매로 NH₃ 산화 (각종 촉매의 조합: 名大 2024)
- 질산의 용도: 비료(질산암모늄(硝安))·화약·염료·니트로화(ニトロ化)

## 호시약대 관점
[필수] 공부 우선순위 3번 '공업 제법'에 질산이 직접 명시되어 있다. 또한 B방식에서 매년 나오는 전기분해와 연결한 계산이 가능하다(NH₃ : HNO₃ = 1 : 1). 그래서 반응식 3단계와 전체식은 확실히 외워 두어야 한다.
