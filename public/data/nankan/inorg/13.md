## 이 장의 요점
- 황린(黄リン) P₄: 정사면체, 맹독, 자연발화(自然発火) → 수중 보존(水中保存), CS₂에 녹는다
- 적린(赤リン): 독성이 작고 자연발화하지 않는다. 성냥갑의 측약(側薬)으로 쓰인다(황린을 공기를 차단하고 가열해 만든다)
- **제법(製法): 2Ca₃(PO₄)₂ + 6SiO₂ + 10C → P₄ + 6CaSiO₃ + 10CO (전기로(電気炉))**
- P₄O₁₀: 강한 건조제(乾燥剤)지만 NH₃에는 사용 불가(×). P₄O₁₀ + 6H₂O → 4H₃PO₄. 다리 걸친 O(橋かけO) 6개 + 말단 O(末端O) 4개
- **H₃PO₄: 3가 산(3価の酸)이며 중간 정도 세기의 산. H₂PO₄⁻/HPO₄²⁻로 완충액(緩衝液)을 만든다(pH ≈ 7.2)**
- 과인산석회(過リン酸石灰) = Ca(H₂PO₄)₂ + CaSO₄ (혼합물). 부영양화(富栄養化), 연료전지·촉매

## 외울 지식
- ★ 인의 동소체(同素体)
  - 황린: P₄, 정사면체, 맹독, 자연발화, 수중 보존, 담황색(淡黄色) 밀랍 모양(ろう状), CS₂에 녹는다
  - 적린: Pₙ, 적갈색(赤褐色) 분말, 독성이 작다, 성냥갑의 측약
- ★ 인 원자는 원자가전자 5개, 홀전자(不対電子) 3개
- ★ 황린의 제법: 인광석(リン鉱石) Ca₃(PO₄)₂에 규사(ケイ砂)와 코크스(コークス)를 섞어 전기로에서 가열한다
  - 2Ca₃(PO₄)₂ + 6SiO₂ + 10C → P₄ + 6CaSiO₃ + 10CO
- ★ 2단계로 쓰면
  - 2Ca₃(PO₄)₂ → P₄O₁₀ + 6CaO
  - P₄O₁₀ + 10C → P₄ + 10CO
- ★ P₄ + 5O₂ → P₄O₁₀ (백색(白色))
  - P₄O₁₀은 흡습성과 탈수 작용이 강하다(건조제·탈수제(脱水剤))
  - P₄O₁₀ + 6H₂O → 4H₃PO₄
- ★ P₄O₁₀의 분자 구조 그리기: P₄의 각 변에 O, 각 P에 말단 O가 붙는다. 무극성
- ★ H₃PO₄: 3가 산(중간 정도 세기)이며 3단계로 전리한다
  - H₃PO₄ ⇄ H⁺ + H₂PO₄⁻ ⇄ H⁺ + HPO₄²⁻ ⇄ H⁺ + PO₄³⁻
- ★ NaH₂PO₄는 약산성, Na₂HPO₄는 약염기성이다. H₂PO₄⁻/HPO₄²⁻는 완충액을 만든다
- ★ [A⁻] = [HA]일 때 pH = pKa
- ★ 인광석은 Ca₃(PO₄)₂이고, 과인산석회는 Ca(H₂PO₄)₂와 CaSO₄의 혼합물이다
  - Ca₃(PO₄)₂ + 2H₂SO₄ → Ca(H₂PO₄)₂ + 2CaSO₄
  - 중과인산석회(重過リン酸石灰)는 Ca(H₂PO₄)₂ ☆
- ★ 질소와 인은 부영양화(적조(赤潮)·녹조(アオコ))의 원인
- ★ 인산형 연료전지(リン酸形燃料電池): 전해질이 H₃PO₄
- ★ 에틸렌 수화 반응의 촉매는 H₃PO₄
- ☆ PH₃(포스핀(ホスフィン), 유독)
- ☆ 성냥의 원리: 두약(頭薬)은 KClO₃, 측약은 적린
- 뼈와 치아의 성분은 하이드록시아파타이트(ヒドロキシアパタイト) Ca₁₀(PO₄)₆(OH)₂

## 호시약대 관점
[권장] 인은 빈출 무기 원소(Fe·Al·Zn·기체)에 들지 않지만, 동소체(결합·결정 단원, 7회)와 인산 완충·pH(2024년에 집중)는 정오 문제와 계산 문제로 나올 수 있다. 황린·적린 비교와 H₂PO₄⁻/HPO₄²⁻ 완충, P₄O₁₀ 건조제(NH₃에는 ×)를 우선 확인해 두자.
