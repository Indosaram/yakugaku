## 이 장의 요점
- HClO(+1) < HClO₂(+3) < HClO₃(+5) < HClO₄(+7): O가 많을수록 강한 산이다 (옥소산(オキソ酸)의 산의 세기)
- **Cl₂ + 2NaOH → NaCl + NaClO + H₂O (냉(冷)), 3Cl₂ + 6KOH → 5KCl + KClO₃ + 3H₂O (열(熱))**
- **섞으면 위험(まぜるな危険): NaClO + 2HCl → NaCl + H₂O + Cl₂ (ClO⁻ + Cl⁻ + 2H⁺ → Cl₂ + H₂O)**
- 표백분(さらし粉) CaCl(ClO)·H₂O, 고도표백분(高度さらし粉) Ca(ClO)₂·2H₂O + 4HCl → 2Cl₂
- 2KClO₃ → 2KCl + 3O₂ (MnO₂ 촉매(触媒)), 성냥·불꽃놀이(マッチ・花火)
- Cl₂O₇ + H₂O → 2HClO₄. HClO₄·H₂O는 H₃O⁺와 ClO₄⁻로 이루어진 이온결정(イオン結晶)이다.

## 외울 지식
- ★ 차아염소산나트륨(次亜塩素酸ナトリウム) NaClO: 염소계 표백제(塩素系漂白剤)·살균제(殺菌剤)로 쓰인다. Cl의 산화수는 +1이며 강한 산화 작용을 한다.
- ★ NaClO의 제법: Cl₂ + 2NaOH → NaCl + NaClO + H₂O. 이온교환막(イオン交換膜)을 없애고 전기분해하면 생성된다.
- ★ 염소계와 산성(염산계) 세제(酸性（塩酸系）洗剤)를 섞으면 위험하다: NaClO + 2HCl → NaCl + H₂O + Cl₂
- ★ 표백분 CaCl(ClO)·H₂O, 고도표백분 Ca(ClO)₂·2H₂O
  - 고도표백분 + 염산: Ca(ClO)₂·2H₂O + 4HCl → CaCl₂ + 2Cl₂ + 4H₂O
  - 표백분 + 염산: CaCl(ClO)·H₂O + 2HCl → CaCl₂ + 2H₂O + Cl₂ (가열이 필요 없음(加熱不要))
- ★ KClO₃: MnO₂ 촉매로 2KClO₃ → 2KCl + 3O₂ (O₂의 실험실적 제법(実験室的製法))
- ★ KClO₃는 불꽃놀이의 조연제(助燃剤)와 성냥의 머리약(頭薬)으로 쓰인다(강한 산화제).
- ★ Cl₂와 뜨거운 KOH 수용액을 반응시키면 KClO₃가 생긴다 (3Cl₂ + 6KOH → 5KCl + KClO₃ + 3H₂O ☆)
- ★ Cl₂O₇(칠산화이염소(七酸化二塩素))은 과염소산(過塩素酸)의 산무수물(酸無水物)이다. HClO₄의 분자량은 100.5이다.
- ★ 과염소산 일수화물(過塩素酸一水和物) HClO₄·H₂O는 H₃O⁺와 ClO₄⁻로 이루어진 이온결정이다.
- ★ 옥소산의 산의 세기: HClO < HClO₂ < HClO₃ < HClO₄. 산화수는 각각 +1, +3, +5, +7이다.
- ☆ 산화력은 HClO가 가장 강하다(표백(漂白)에 이용).
- ☆ 아염소산나트륨(亜塩素酸ナトリウム) NaClO₂도 표백제로 쓰인다.

## 호시약대 관점
[필수] 무기 단원은 9회 전부 출제되었고, 그중 기체 발생(표백분·NaClO + 염산 → Cl₂, KClO₃ → O₂)이 중심이다. 이온교환막법도 우선순위 목록에 명시되어 있고, 「섞으면 위험」 같은 실생활 소재 지문 형식과 직결되므로 ★ 항목의 반응식과 산화수는 확실히 외워 두어야 한다.
