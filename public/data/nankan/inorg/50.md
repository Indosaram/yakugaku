## 이 장의 요점
- **용융염 전해(溶融塩電解): Li·Na·Mg·Ca·Al (수용액에서는 H₂) ☆다운스법(ダウンズ法)**
- **크롤법(クロール法): TiO₂ + C + 2Cl₂ → TiCl₄ + CO₂ → 증류(蒸留)**
- TiCl₄ + 2Mg → Ti + 2MgCl₂ (Ar 중)
- 전기로(電気炉): SiO₂ + 2C → Si + 2CO
- 황린(黄リン): 2Ca₃(PO₄)₂ + 6SiO₂ + 10C → P₄ + 6CaSiO₃ + 10CO
- 크로뮴철석(クロム鉄鉱) → Na₂CrO₄ → Na₂Cr₂O₇, Cr·Mn은 테르밋(テルミット)
- 브로민(臭素): Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂
- 아이오딘(ヨウ素): 간수(かん水)의 I⁻를 Cl₂로 산화 / 칠레초석(チリ硝石)의 IO₃⁻를 환원
- 과인산석회(過リン酸石灰): Ca₃(PO₄)₂ + 2H₂SO₄ → Ca(H₂PO₄)₂ + 2CaSO₄

## 외울 지식
- ★ 크롤법: TiO₂+C+2Cl₂→TiCl₄+CO₂ (TiCl₄는 증류로 정제), TiCl₄+2Mg→Ti+2MgCl₂, MgCl₂→Mg+Cl₂ (용융염 전해로 재이용), 전체 반응 TiO₂+C→Ti+CO₂
- ★ Si: SiO₂+2C→Si+2CO (전기로)
- ★ 황린: Ca₃(PO₄)₂+SiO₂+C (전기로)
- ★ Na₂CrO₄: 크로뮴철석의 알칼리 산화 배소(アルカリ酸化焙焼)
- ★ Br₂: Cl₂에 의한 산화
- ★ I₂: 칠레초석의 IO₃⁻ 환원
- ★ Li의 용융염 전해 (阪大 이론)
- ☆ 다운스법: NaCl+CaCl₂를 융해 전해해서 Na를 얻음
- ★ 과인산석회: Ca₃(PO₄)₂+2H₂SO₄→Ca(H₂PO₄)₂+2CaSO₄
- ★ KClO₃의 제조와 분해의 열화학 (名大 이론)
- ★ Si·Al·Fe·Cr·Mn의 제련 비교 (東北大 2025: 용광로(溶鉱炉)·용융염 전해·탄소 환원·테르밋☆)
- ☆ 시멘트(セメント): 로터리 킬른(ロータリーキルン)
- ☆ 유리(ガラス): 규사(ケイ砂)+소다회(ソーダ灰)+석회석(石灰石)
- ☆ 도자기(陶磁器): 점토의 소성(焼成)

## 호시약대 관점
[권장] 공업 제법·제련은 무기 우선순위(3순위)에 들어가고, 전기분해는 B방식에서 매년 출제된다. 따라서 용융염 전해(Al·Na)와 Si·Al·Fe 제련 비교는 확실히 챙겨 둔다. 크롤법·황린·크로뮴 제법은 출제 흔적이 적으므로 반응식을 한 번 훑어보는 정도면 충분하다.
