## 이 장의 요점
- 원료: 철광석(鉄鉱石)(Fe₂O₃·Fe₃O₄)·코크스(コークス)·석회석(石灰石). 아래에서 열풍(熱風)을 불어넣음
- C + O₂ → CO₂, CO₂ + C → 2CO (흡열)
- **Fe₂O₃ → Fe₃O₄ → FeO → Fe (CO로 단계적으로 환원)**
- 전체: Fe₂O₃ + 3CO → 2Fe + 3CO₂
- CaO + SiO₂ → CaSiO₃ (슬래그(スラグ). 위에 뜨며 시멘트 원료)
- **선철(銑鉄)(C 약 4%, 무름(もろい)) → 전로(転炉)에서 O₂ 주입 → 강(鋼)(C 0.02∼2%, 끈기가 있음(粘り強い))**
- 수소 환원: CO₂는 나오지 않지만 흡열 / 테르밋(テルミット): 2Al + Fe₂O₃ → Al₂O₃ + 2Fe

## 외울 지식
- ★ 용광로(溶鉱炉)에 철광석(적철광(赤鉄鉱) Fe₂O₃, 자철광(磁鉄鉱) Fe₃O₄), 코크스, 석회석을 넣는다.
- ★ C + O₂ → CO₂, CO₂ + C → 2CO
- ★ CO에 의한 단계적 환원
  - 3Fe₂O₃ + CO → 2Fe₃O₄ + CO₂
  - Fe₃O₄ + CO → 3FeO + CO₂
  - FeO + CO → Fe + CO₂
  - 전체: Fe₂O₃ + 3CO → 2Fe + 3CO₂
- ★ CO/CO₂의 압평형 조건(京大 이론)
- ★ 석회석 CaCO₃ → CaO, CaO + SiO₂ → CaSiO₃ (슬래그. 선철보다 가벼워 상층으로 분리되며 시멘트 원료가 됨)
- ★ 선철은 탄소를 약 4% 포함해 단단하지만 무르다(硬くて脆い). 전로에서 산소를 불어넣으면 강(C 0.02∼2%)이 된다.
- ★ 수소 환원 제철(水素還元製鉄): Fe₂O₃ + 3H₂ → 2Fe + 3H₂O (흡열, CO₂ 삭감)
  - FeO + H₂ → Fe + H₂O
  - Fe₃O₄ + 4H₂ → 3Fe + 4H₂O
- ★ FeO의 CO/H₂ 환원 엔탈피(東北大)
- ★ 4Fe₂O₃ + 3CH₄ → 8Fe + 3CO₂ + 6H₂O (東大)
- ★ 고로법(高炉法)의 CO₂ 배출량(東大 이론)
- ★ 테르밋 반응(テルミット反応)
- ★ H₂로 환원해 Fe를 얻는 계산(名大 2021)

## 호시약대 관점
[필수] 무기 원소·화합물(Fe 포함)은 9회 모두 출제되었고, 제련은 무기와 산화환원 단원 양쪽에서 명시적으로 다뤄진다. 단계적 환원식, 슬래그, 선철과 강의 차이는 정오 조합형으로, 환원 질량 계산은 계산기 없는 유효숫자 2자리 문제로 대비해 두자.
