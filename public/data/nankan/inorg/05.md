## 이 장의 요점
- F₂ 담황색(淡黄)·기체 / Cl₂ 황록색(黄緑)·기체 / Br₂ 적갈색(赤褐)·액체 / I₂ 흑자색(黒紫)·고체 (승화(昇華)하며, 증기는 자색(紫))
- **끓는점 F₂ < Cl₂ < Br₂ < I₂, 산화력 F₂ > Cl₂ > Br₂ > I₂ (추가로 F₂ > O₂ > I₂ > S)**
- 2F₂ + 2H₂O → 4HF + O₂, Cl₂ + H₂O ⇄ HCl + HClO (살균·표백)
- H₂와의 반응: F₂는 냉암소(冷暗所)에서, Cl₂는 빛으로 폭발한다. Br₂는 가열이 필요하고, I₂는 평형을 이룬다.
- **I₂ + I⁻ ⇄ I₃⁻ (갈색(褐色)), 요오드-녹말 반응(ヨウ素デンプン反応)은 청자색(青紫), KI 녹말 종이(KIデンプン紙)는 산화제에 의해 청색(青)**
- MnO₂ + 4HCl → MnCl₂ + Cl₂ + 2H₂O 로 발생시킨 뒤 물 → 진한 황산(濃硫酸) 순으로 통과시키고 하방치환(下方置換)으로 포집한다.
- Br₂: Br⁻를 Cl₂로 산화해 얻는다. I₂: IO₃⁻의 환원 또는 I⁻의 산화로 얻는다 (일본은 세계 2위).

## 외울 지식
- ★17족, 원자가전자 7개, 이원자 분자(단일결합 1쌍·비공유 전자쌍 6쌍). ★단체의 산화력 F₂ > Cl₂ > Br₂ > I₂. ★산화력 순서를 O₂, S, F₂, I₂로 비교하면 F₂ > O₂ > I₂ > S ☆.
- 상태와 색: F₂ 담황색(淡黄色) 기체, Cl₂ 황록색(黄緑色) 기체, Br₂ 적갈색(赤褐色) 액체, I₂ 흑자색(黒紫色) 고체(승화하여 자색(紫色) 기체가 됨). ★끓는점 F₂ < Cl₂ < Br₂ < I₂ (분자량이 클수록 분자간력이 커지기 때문).
- ★Cl₂: 황록색(黄緑色)·자극취·유독하다. 물에 녹아 HCl과 HClO를 만든다(Cl₂ + H₂O ⇄ HCl + HClO). HClO가 산화·표백·살균 작용을 하며, pH가 내려간다. ★HClO + H⁺ + 2e⁻ → Cl⁻ + H₂O.
- ★2F₂ + 2H₂O → 4HF + O₂ (F₂는 물과 격렬하게 반응).
- ★F₂·Cl₂는 H₂와 폭발적으로 반응한다. F₂는 저온·암소에서도, Cl₂는 빛을 받으면 반응한다: H₂ + Cl₂ → 2HCl (광화학 반응). Br₂는 가열이 필요하고, I₂는 가열해도 평형 상태다 (2HI ⇄ H₂ + I₂ ★).
- ★Cl₂ + 2KI → 2KCl + I₂, Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂. ★KI 녹말 종이(KIデンプン紙)는 O₃·Cl₂·Br₂ 등의 산화제에 의해 청자색(青紫)이 된다.
- ★I₂는 물에 잘 녹지 않지만 KI 수용액에는 I₃⁻(갈색(褐色))로 녹는다: I₂ + I⁻ ⇄ I₃⁻. ★요오드-녹말 반응(ヨウ素デンプン反応)은 청자색(青紫)이다. I₂가 녹말의 나선 구조에 끼어 들어가 생기며, 가열하면 색이 사라진다 ☆.
- ★I₂ 결정은 분자결정(分子結晶)이다(면심직방격자(面心直方格子), 단위격자당 분자 4개). 승화성이 있다. ★고압에서는 I₂가 해리되어 원자의 면심입방격자(面心立方格子)가 된다(금속적) ☆.
- ★Br₂는 공업적으로 산성 용액에서 Br⁻를 Cl₂로 산화해 얻는다(해수·함수(かん水)가 원료). ★4Br⁻ + O₂ + 4H⁺ → 2Br₂ + 2H₂O.
- ★I₂는 요오드산 이온을 포함한 광석(칠레초석(チリ硝石))이나 함수(かん水)의 I⁻로부터 제조한다. IO₃⁻ + 6H⁺ + 6e⁻ → I⁻ + 3H₂O. ★일본은 요오드 생산 세계 2위다(지바현(千葉県)).
- ★브롬수의 첨가 반응으로 불포화도(不飽和度)를 결정한다(유기와 융합 출제). ★칼피셔 적정(カールフィッシャー滴定): I₂ + SO₂ + CH₃OH + H₂O → 2HI + CH₃OSO₃H (수분 정량) ☆.
- ★요오드 화합물(포비돈요오드(ポビドンヨード))은 소독약·가글약으로 쓰인다.
- ★요오드 적정(ヨウ素滴定): I₂ + 2S₂O₃²⁻ → 2I⁻ + S₄O₆²⁻. 종말점은 녹말의 청자색(青紫色)이 사라지는 때다. 종말점 근처에서 담황색(淡黄色)이 되면 녹말을 넣는다.
- ★Br의 원자량 79.9는 ⁷⁹Br과 ⁸¹Br이 약 1:1로 섞인 결과다(평균 중성자수 계산에 출제). ★염소의 동위체 비는 ³⁵Cl : ³⁷Cl = 3 : 1.
- Cl₂의 용도: 수돗물 살균, 염화비닐(塩化ビニル) 원료, 표백분(さらし粉). Br₂는 상온에서 액체인 유일한 비금속 단체다.

## 호시약대 관점
[필수] 무기 '기체 발생'(9회 전부 출제)에 해당하는 Cl₂ 제법·포집과, 산화환원 단원(4회)에 명시된 요오드 적정(S₂O₃²⁻·녹말 종말점)은 반드시 잡아야 한다. 칼피셔 적정, 고압 I₂ 결정 같은 ☆ 항목은 후순위로 미뤄도 된다.
