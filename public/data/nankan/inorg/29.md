## 이 장의 요점
- 산화수: Mn²⁺(담도색(淡桃)) · MnO₂(흑색(黒)) · K₂MnO₄(진녹색(濃緑)) · KMnO₄(적자색(赤紫))
- **산성: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O (적자색(赤紫) → 거의 무색(ほぼ無色))**
- 중성·염기성: MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻ (흑갈색(黒褐色) 침전)
- 적정: 황산으로 산성화한다(HCl·HNO₃는 ×). 자기지시약(自己指示薬)이며 Mn²⁺의 자기촉매작용(自触媒作用)이 있다. COD와 연결된다.
- **MnO₂: 산화제(진한 염산 → Cl₂) · 촉매(H₂O₂·KClO₃) · 전지의 양극(正極)**
- Mn(OH)₂(백색(白) → 갈색(褐色))와 MnS(담도색(淡桃))는 중성∼염기성에서 침전한다.

## 외울 지식
- ★ Mn은 제4주기 7족이고 산화수는 +2∼+7이다.
  - MnO(+2), Mn₂O₃(+3)
  - MnO₂(+4, 흑색(黒色)∼흑갈색(黒褐色))
  - K₂MnO₄(+6, 진녹색(濃緑色))
  - KMnO₄(+7, 적자색(赤紫色))
  - ★ Mn²⁺는 거의 무색(담도색(淡桃色))이다.
  - ★ Mn²⁺의 전자배치는 [Ar]3d⁵이다.
- ★ KMnO₄는 황산 산성에서 강한 산화제다.
  - MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O (적자색 → 거의 무색)
  - 중성∼염기성에서는 MnO₂(흑갈색(黒褐色) 침전)로 환원된다.
  - ★ 2KMnO₄ + 3H₂O₂ → 2MnO₂ + 3O₂ + 2KOH + 2H₂O (중성). 산성에서는 O₂가 발생하고 Mn²⁺가 된다.
  - ★ 2KMnO₄ + 5H₂C₂O₄ + 3H₂SO₄ → 2MnSO₄ + 10CO₂ + 8H₂O + K₂SO₄
  - ★ 2MnO₄⁻ + 10I⁻ + 16H⁺ → 2Mn²⁺ + 5I₂ + 8H₂O
- ★ KMnO₄ 적정에서는 Mn²⁺가 자기촉매(自触媒)로 작용한다. 처음에 색이 잘 사라지지 않는 이유가 이것이다.
  - 종점에서는 옅은 적자색(赤紫色)이 남는다.
  - ★ COD(화학적 산소요구량(化学的酸素要求量))
- ★ MnO₂의 세 가지 역할
  - 알칼리 망간 건전지·망간 건전지의 양극 활물질(正極活物質): MnO₂ + H₂O + e⁻ → MnO(OH) + OH⁻
  - ★ 진한 염산에서 Cl₂를 발생시킬 때는 산화제: MnO₂ + 4HCl → MnCl₂ + Cl₂ + 2H₂O
  - ★ H₂O₂·KClO₃ 분해에서는 촉매
- ★ Mn(OH)₂는 백색(白色) 침전이며, 공기 중에서 산화되어 갈색(褐色)이 된다. Ksp와 pH의 관계를 확인한다.
  - ★ MnS(담도색(淡桃色)=살색(肉色))는 중성∼염기성에서 침전하고, 산성에서는 침전하지 않는다.
  - Mn²⁺ + H₂S + 2NH₃ → MnS + 2NH₄⁺
  - ★ NH₄Cl을 넣으면 Mn(OH)₂가 침전하지 않는다(공통이온효과(共通イオン効果)).
- ★ Mn²⁺를 강한 산화제로 MnO₄⁻로 바꾸면 적자색(赤紫色)이 되어 정량할 수 있다.
  - 산화제: H₅IO₆, 퍼옥소이황산염(ペルオキソ二硫酸塩), NaBiO₃
  - 2Mn²⁺ + 5H₅IO₆ → 2MnO₄⁻ + 5IO₃⁻ + 11H⁺ + 7H₂O
- ★ 망간 노듈(マンガンノジュール, 망간 단괴(マンガン団塊))은 Co·Ni를 포함한 해저 자원이다.
- ☆ KMnO₄는 빛에 분해되므로 갈색병(褐色瓶)에 보관한다.
- ☆ 염산 산성으로 쓸 수 없는 이유는 KMnO₄가 Cl⁻를 산화하기 때문이다. 질산 산성으로 쓸 수 없는 이유는 HNO₃ 자체가 산화제이기 때문이다.

## 호시약대 관점
[권장] 산화환원·산화수(요오드 적정 포함, 4회)와 기체 발생, 유기 구조결정의 KMnO₄ 산화가 꾸준히 출제되므로 KMnO₄ 반쪽반응식, 적정 반응식, MnO₂+HCl→Cl₂는 확실히 익혀 둔다. 반면 Mn 단독 출제는 빈도표에 없고 전지 세부 구조도 출제 흔적이 거의 없으므로, 건전지 반응식과 ☆ 항목은 후순위로 둔다.
