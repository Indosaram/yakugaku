## 이 장의 요점
- 용광로(溶鉱炉): 2CuFeS₂ + O₂ → Cu₂S + 2FeS + SO₂ (매트(マット)), Fe는 슬래그(スラグ)로 제거
- **전로(転炉): 2Cu₂S + 3O₂ → 2Cu₂O + 2SO₂, Cu₂S + 2Cu₂O → 6Cu + SO₂**
- 전체: Cu₂S + O₂ → 2Cu + SO₂
- 전해정련(電解精錬): 양극(陽極) 조동(粗銅), 음극(陰極) 순동(純銅), 황산 산성 CuSO₄ 수용액, 0.2∼0.4 V
- **Zn·Fe·Ni는 용액에 남음 / Ag·Au·Pt는 양극 찌꺼기(陽極泥) / Pb는 PbSO₄**
- 음극에서 석출되는 Cu = 녹아 나온 Cu + 녹아 나온 불순물(2가)의 몫 → 양극의 감소량 ≠ 음극의 증가량
- [Cu²⁺]는 감소 / Zn: 배소(焙焼) → 용해 → 전해채취(電解採取), Pb: 배소 → C·CO로 환원

## 외울 지식
- ★ 황동석(黄銅鉱) CuFeS₂를 규사(ケイ砂, SiO₂)·석회석(石灰石)과 함께 용광로에서 가열한다(용련(溶錬)).
  - 반응: 2CuFeS₂ + O₂ → Cu₂S + 2FeS + SO₂
  - Fe는 FeSiO₃ 등의 슬래그가 되고, Cu₂S + FeS는 매트가 된다.
- ★ 전로에서 Cu₂S에 공기를 불어넣는다.
  - 반응: 2Cu₂S + 3O₂ → 2Cu₂O + 2SO₂, Cu₂S + 2Cu₂O → 6Cu + SO₂ (전체 Cu₂S + O₂ → 2Cu + SO₂)
  - 생성물은 조동(순도 약 99%)이다.
  - SO₂는 회수하여 황산으로 만든다.
- ★ Cu₂O의 Cu는 +1이다(Cu₂S와 같음).
- ★ 전해정련의 구성
  - 양극(전원의 양극(正極)에 연결): 조동
  - 음극: 순동(얇은 판)
  - 전해액: 황산 산성 CuSO₄ 수용액
  - 전압: 저전압 0.2∼0.4 V
- ★ 전극 반응
  - 양극: Cu → Cu²⁺ + 2e⁻
  - 음극: Cu²⁺ + 2e⁻ → Cu
- ★ 얻어지는 구리의 순도는 99.99% 이상이다.
- ★ 불순물의 행방
  - Zn·Fe·Ni: Cu보다 이온화 경향(イオン化傾向)이 커서 이온으로 녹아 나온 뒤 용액 중에 남는다(음극에서 환원되지 않음).
  - Ag·Au·Pt: 양극 찌꺼기가 된다.
- ★ 조동 중의 Pb는 PbSO₄로 침전한다(九大 2024).
- ★ 양극 찌꺼기에 포함될 가능성이 있는 금속을 고르는 문제(北大 2025)
- ★ 1.50 A·7720 s로 석출되는 Cu의 양(패러데이 법칙(ファラデーの法則) Q = It = nF)
- ★ Ni·Au를 포함한 조동의 전해(東大 2019)
- ★ Cu²⁺만 환원할 수 있는 금속 중 부적절한 것과 그 이유(東大 논술)
- ★ Zn의 제련(製錬): 섬아연석(閃亜鉛鉱) → ZnO → 묽은 황산 → 전해채취
- ★ Pb의 제련: 방연석(方鉛鉱) → PbO → C·CO 환원(九大 2024)

## 호시약대 관점
[필수] 전기분해·패러데이는 B방식에서 매년 출제되고, 제련도 무기·산화환원 단골 소재다. 그래서 전극 반응, 불순물의 행방, Q = It = nF 계산(계산기 불가)은 반드시 연습해 두자.
