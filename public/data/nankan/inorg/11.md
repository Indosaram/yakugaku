## 이 장의 요점
- N₂: 공기의 78%이고 삼중결합 때문에 불활성(不活性)이다. NH₄NO₂ → N₂ + 2H₂O로 얻으며, 공업적으로는 액체 공기의 분별증류(分留)로 얻는다.
- **NH₃: 무색, 자극취(刺激臭), 공기보다 가볍다, 물에 매우 잘 녹는다, 약염기(弱塩基), 삼각뿔형(三角錐形), 수소결합(水素結合)**
- **제법: 2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2NH₃ + 2H₂O(시험관 입구를 아래로 기울인다), 상방치환(上方置換)으로 포집**
- 건조는 소다석회(ソーダ石灰)·CaO로 한다. 진한 황산·P₄O₁₀·CaCl₂는 사용할 수 없다(×).
- 검출: HCl을 대면 흰 연기(白煙)가 생기고, 젖은 적색(赤色) 리트머스 종이가 청색(青)으로 변한다.
- NH₄⁺는 약한 산이다(NH₄Cl 수용액은 약산성). NH₄Cl은 가열하면 분해되고, 식으면 다시 결합한다.
- 황안(硫安)과 소석회(消石灰)를 섞으면 NH₃가 빠져나간다. 초안(硝安)·요소(尿素)의 용해는 흡열이다.
- 요소: 2NH₃ + CO₂ → CO(NH₂)₂ + H₂O. 가수분해하면 NH₃가 생긴다(요소 SCR). NH₃는 연료로도 쓰인다.

## 외울 지식
- ★ 공기 중 N₂는 78%이고, 삼중결합 때문에 화학적으로 불활성이다.
- ★ 아질산암모늄(亜硝酸アンモニウム) NH₄NO₂ → N₂ + 2H₂O (실험실적 제법)
- ★ NH₃의 성질
  - 무색이고 자극취가 있다.
  - 물에 매우 잘 녹는다. 그래서 헨리 법칙(ヘンリーの法則)을 따르지 않는다.
  - 약염기다: NH₃ + H₂O ⇄ NH₄⁺ + OH⁻
  - 삼각뿔형이다(비공유 전자쌍(非共有電子対) 1개).
  - 수소결합 때문에 끓는점이 높고 액화하기 쉽다(냉매(冷媒)로 사용).
  - 상방치환으로 포집한다.
- ★ NH₃는 실재 기체(実在気体)로서 이상 기체와의 차이가 크다(Z<1).
- ★ 제법
  - 2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2NH₃ + 2H₂O (가열, 시험관 입구를 아래로 기울인다)
  - (NH₄)₂SO₄ + 2NaOH → Na₂SO₄ + 2NH₃ + 2H₂O
  - (NH₄)₂SO₄ + Ca(OH)₂ → CaSO₄ + 2NH₃ + 2H₂O
- 건조는 소다석회·CaO로 한다(CaCl₂·진한 황산·P₄O₁₀은 불가).
- 검출
  - 진한 염산을 대면 흰 연기(NH₄Cl)가 생긴다.
  - 젖은 적색 리트머스 종이가 청색으로 변한다.
- ★ NH₄⁺의 전리: NH₄⁺ ⇄ NH₃ + H⁺
- ★ NH₄Cl 수용액은 산성이다.
- ★ 완충액(緩衝液): NH₃ + NH₄Cl
- ★ NH₄Cl의 결정 구조는 고온에서 NaCl형, 실온에서 CsCl형이다.
- ★ 질소 비료(窒素肥料): 황산암모늄, 요소, 질산암모늄, 염화암모늄
- ★ (NH₄)₂SO₄를 소석회와 섞으면 NH₃가 발생해서 비료 효과(肥効)가 떨어진다.
- ★ 질산암모늄과 요소의 용해는 흡열이다(냉각팩(冷却パック)에 이용).
- ★ 요소
  - 뵐러(ウェーラー)의 합성(1828): NH₄OCN → 요소
  - 공업적 제법: 2NH₃ + CO₂ → CO(NH₂)₂ + H₂O (고온·고압)
  - 가수분해: CO(NH₂)₂ + H₂O → CO₂ + 2NH₃
  - 분자량 60, 요소수지(尿素樹脂)의 원료
- ★ 암모니아 연료
  - 4NH₃ + 3O₂ → 2N₂ + 6H₂O (CO₂를 배출하지 않는다)
  - 액체 암모니아는 액체 수소보다 부피당 에너지 밀도가 높다.
- ★ NO₃⁻의 전해 환원: NO₃⁻ + 9H⁺ + 8e⁻ → NH₃ + 3H₂O
- ☆ 히드라진(ヒドラジン) N₂H₄: 로켓 연료로 쓰이고, N의 산화수는 −2다.
- ☆ 네슬러 시약(ネスラー試薬)으로 NH₄⁺를 검출한다. 황색(黄)~적갈색(赤褐色)을 띤다.

## 호시약대 관점
[필수] 무기 문제는 9회분 전부에서 출제되었고, 기체 발생(NH₃ 제법·건조제·포집법)이 핵심입니다. 암모니아 공업 제법은 공부 우선순위 3에 명시되어 있습니다. NH₃–NH₄Cl 완충액과 실재 기체 문제는 이론 계산(완충, 기체 법칙)과도 바로 연결됩니다.
