## 이 장의 요점
- **바이어법(バイヤー法): Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄] (Fe₂O₃는 적니(赤泥))**
- Na[Al(OH)₄] → Al(OH)₃ + NaOH (NaOH 재이용) → 소성(焼成)으로 Al₂O₃
- **홀-에루법(ホール・エルー法): 빙정석(氷晶石) Na₃AlF₆에 녹여 약 1000℃에서 용융염전해(溶融塩電解)**
- 음극 Al³⁺ + 3e⁻ → Al / 양극 C + 2O²⁻ → CO₂ + 4e⁻ (탄소가 소모됨)
- Al³⁺ 수용액을 전기분해하면 H₂만 발생한다
- **Al 1 mol에 e⁻ 3 mol, 1 kg에 약 13 kWh, 재생(리사이클)은 약 3%**

## 외울 지식
- ★ 보크사이트(ボーキサイト)(주성분 Al₂O₃ + Fe₂O₃·SiO₂) → 바이어법: 진한 NaOH 수용액에 용해(Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄], SiO₂도 녹는다). Fe₂O₃는 적니로 여과해 분리한다. 용액의 pH를 낮추어(또는 희석·종결정(種結晶) 첨가) Al(OH)₃를 석출시키고, 가열하여 Al₂O₃를 얻는다.
- ★ 홀-에루법: 빙정석 Na₃AlF₆을 융해하고 Al₂O₃를 조금씩 녹여 용융염전해한다(약 1000℃, 융점을 낮춘다). 전극은 탄소 전극이다.
  - 음극(탄소로 덮은 전해조): Al³⁺ + 3e⁻ → Al
  - 양극(탄소봉): C + O²⁻ → CO + 2e⁻, C + 2O²⁻ → CO₂ + 4e⁻ (양극의 탄소가 소모됨)
  - 전체: 2Al₂O₃ → 4Al + 3O₂ (형식상)
- ★ Al³⁺ 수용액을 전기분해하면 H₂가 발생하고 홑원소 물질(Al)은 얻을 수 없다.
- ★ Mg의 용융염전해(수용액에서는 H₂ 발생).
- ★ Al의 리사이클.
- ★ 용융염전해의 양적 계산(Al 1 mol에 e⁻ 3 mol).

## 호시약대 관점
[필수] 무기 원소(Al·양쪽성·제련)는 9회 모두 출제되었고, 전기분해·패러데이 계산은 B방식에서 매년 나온다. 바이어법 반응식과 「Al 1 mol = e⁻ 3 mol」 계산은 계산기 없이 확실히 풀 수 있게 해 두자.
