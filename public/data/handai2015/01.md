# 大阪大学 2015년 전기 第1問 — 크롬의 산화환원과 침전

## 한눈에 보기
- 第1問은 **크롬(Ⅵ) 화합물의 평형·산화환원·침전**을 한 번에 묻는 문제다. 問1은 크롬산칼륨↔이크롬산칼륨의 평형식, 問2는 산화환원 후의 농도, 問3은 침전 생성 여부, 問4는 침전 순서와 그래프, 問5는 눈에 보이는 침전의 변화다.
- 問1의 열쇠는 **Cr을 2개로 맞추면 O가 8개 → 7개로 하나 남는다**는 것. 남은 O 하나가 H⁺ 2개와 붙어 H₂O가 된다.
- 問2의 열쇠는 **전자 수를 맞춘 뒤 "부족한 쪽"을 찾는 것**이다. Cr₂O₇²⁻ : Fe²⁺ = 1 : 6으로 반응하므로, 1.5×10⁻³ mol과 3.0×10⁻³ mol을 견주면 **Fe²⁺가 먼저 바닥난다**.
- 問3·問4의 열쇠는 **혼합 직후의 농도로 이온곱을 만들어 Ksp와 비교**하는 것이다. 침전 여부는 "될까?"가 아니라 **숫자 비교**로 끝난다.
- 問5는 問4의 결과를 그림으로 확인하는 문제다. **AgCl이 먼저 다 침전하고, 그 다음에 Ag₂CrO₄**가 나오므로 색은 **흰색 → 적갈색** 순서다. 이것이 모어법(モール法)의 원리다.

## 이 大問의 발상(패턴)
| 발동 사인 | 쓰는 형 |
|---|---|
| 산화제와 환원제를 섞었다 | 반반응식 → **전자 수 맞추기** → 몰비로 한계 반응물 판정 |
| 반응 후의 이온 농도 | 몰수 표(はじめ/반응/반응 후) → **전체 부피로 나누기** |
| 용해도곱이 주어지고 "침전되는가" | 혼합 직후 농도로 **이온곱** 계산 → Ksp와 대소 비교 |
| "어느 침전이 먼저" | 각 침전이 **시작되는 [Ag⁺]** 를 계산 → 작은 쪽이 먼저 |
| 이온 농도 그래프에서 선 고르기 | 1 : 1로 소비되는 이온은 **직선**, 먼저 끝나는 이온이 꺾이는 자리 |
| 침전의 색이 순서대로 바뀐다 | 먼저 침전하는 염의 색 → 그다음 염의 색 |

## 문제 요약 <a href="https://youtu.be/p98nUjz1axs?t=39">▶ 00:39</a>

![第1問 문제: 크롬(Ⅵ) 화합물의 성질과 용해도곱](data/handai2015/fig/01-problem.webp)

크롬에는 산화수 +6의 화합물 **K₂CrO₄, K₂Cr₂O₇**이 있다.

- 산성 수용액에서 **Cr₂O₇²⁻는 Fe²⁺와 반응**해, 크롬은 전자를 받아 **Cr³⁺**, 철은 전자를 잃어 Fe³⁺가 된다.
- **CrO₄²⁻는 Ag⁺와 적갈색 Ag₂CrO₄ 침전**, **Cl⁻는 Ag⁺와 흰색 AgCl 침전**을 만든다.
- 용해도곱(25 ℃): **Ag₂CrO₄ 3.6×10⁻¹² mol³/L³, AgCl 1.8×10⁻¹⁰ mol²/L²**

設問은 5개다. 問1은 평형의 이온반응식, 問2는 반응 후 Cr³⁺·Fe³⁺의 농도, 問3은 Ag₂CrO₄ 침전의 유무, 問4는 그래프에서 세 이온의 곡선 선택, 問5는 관찰되는 침전의 모습이다.

### 問1 — 크롬산과 이크롬산의 평형 <a href="https://youtu.be/p98nUjz1axs?t=122">▶ 02:02</a>

**문제 요약**: K₂CrO₄와 K₂Cr₂O₇은 수용액의 pH로 구성비가 변하는 평형 관계에 있다. 이 평형을 나타내는 이온반응식을 쓴다.

**발상의 이유(패턴)**: 두 화합물은 **Cr의 개수가 2 : 1로 다르다**. 평형식은 원자 수를 먼저 맞추고, 남는 O를 H⁺와 H₂O로 처리하면 기계적으로 완성된다. 색(황색 ↔ 적등색)이 어느 쪽이 산성에서 우세한지를 알려 주는 검산 장치다.

**풀이**

1. **Cr을 2개로 맞춘다** — CrO₄²⁻ 2개 → Cr₂O₇²⁻ 1개. Cr은 2 : 2로 맞는다.
2. **O의 수를 센다** — 왼쪽 2×4 = 8개, 오른쪽 7개. **1개가 남는다**.
3. **남은 O 하나를 처리** — O 1개는 **H⁺ 2개**와 결합해 **H₂O**가 된다. 그래서 왼쪽에 H⁺ 2개, 오른쪽에 H₂O 1개를 놓는다.
4. **전하 검산** — 왼쪽 2×(−2) + 2×(+1) = −2, 오른쪽 −2. 맞는다.
5. **색과 방향 검산** — 산성에서 Cr₂O₇²⁻(적등색)이 많아지므로, H⁺가 왼쪽에 있는 이 식은 **산성에서 오른쪽으로 이동**한다. 문제문의 색 변화와 일치한다.

![問1 풀이: Cr을 2개로 맞추면 O가 하나 남고, 그 O가 H⁺ 2개와 물이 된다](data/handai2015/fig/01-q1.webp)

> **정답** **2CrO₄²⁻ + 2H⁺ ⇌ Cr₂O₇²⁻ + H₂O**
>
> (적등색 Cr₂O₇²⁻는 산성에서, 황색 CrO₄²⁻는 염기성에서 많아진다.)

### 問2 — 반응 후의 Cr³⁺·Fe³⁺ 농도 <a href="https://youtu.be/p98nUjz1axs?t=169">▶ 02:49</a>

**문제 요약**: 황산산성 6.0×10⁻² mol/L FeSO₄ 수용액 50.0 mL와, 황산산성 3.0×10⁻² mol/L K₂Cr₂O₇ 수용액 50.0 mL를 혼합했다. 반응이 끝난 뒤 **Cr³⁺와 Fe³⁺의 농도**를 구한다.

**발상의 이유(패턴)**: 산화환원의 양 계산은 **"전자 수를 맞춘 계수"가 곧 몰비**라는 점으로 끝난다. 두 이온의 몰수를 내고 1 : 6 비율에 견주면 어느 쪽이 한계인지 즉시 보인다. 농도는 마지막에 **혼합 후 전체 부피**로 나눠야 한다.

**풀이**

1. **반반응식 두 개** — Cr₂O₇²⁻는 H⁺ 14개와 전자 6개를 받아 Cr³⁺ 2개와 H₂O 7개가 된다. Fe²⁺는 전자 1개를 내놓고 Fe³⁺가 된다.
2. **전자 수 맞추기** — Fe²⁺ 쪽을 6배 하면 전자가 6개로 맞는다. 합치면 **Cr₂O₇²⁻ 1 + Fe²⁺ 6 → Cr³⁺ 2 + Fe³⁺ 6**.
3. **몰수 계산**
   - Fe²⁺: 6.0×10⁻² × 0.0500 = **3.0×10⁻³ mol**
   - Cr₂O₇²⁻: 3.0×10⁻² × 0.0500 = **1.5×10⁻³ mol**
4. **한계 판정** — 1 : 6으로 반응하므로 Fe²⁺ 3.0×10⁻³ mol이 소비할 수 있는 Cr₂O₇²⁻는 그 1/6인 **5.0×10⁻⁴ mol**. 실제로는 1.5×10⁻³ mol 있으므로 **Cr₂O₇²⁻가 남고 Fe²⁺가 전부 없어진다**.
5. **생성량** — Cr³⁺는 소비된 Cr₂O₇²⁻의 2배인 **1.0×10⁻³ mol**, Fe³⁺는 Fe²⁺와 같은 **3.0×10⁻³ mol**.
6. **농도로 환산** — 전체 부피 50.0 + 50.0 = 100 mL = **0.100 L**.
   - [Cr³⁺] = 1.0×10⁻³ ÷ 0.100 = **1.0×10⁻² mol/L**
   - [Fe³⁺] = 3.0×10⁻³ ÷ 0.100 = **3.0×10⁻² mol/L**

![問2 몰수 표: Fe²⁺가 먼저 바닥나고 Cr₂O₇²⁻가 남는다](data/handai2015/fig/01-q2-table.webp)

![問2 농도 환산: 전체 부피 0.100 L로 나눈다](data/handai2015/fig/01-q2-result.webp)

> **정답** **[Cr³⁺] = 1.0×10⁻² mol/L, [Fe³⁺] = 3.0×10⁻² mol/L**

### 問3 — Ag₂CrO₄ 침전은 생기는가 <a href="https://youtu.be/p98nUjz1axs?t=281">▶ 04:41</a>

**문제 요약**: 1.0×10⁻² mol/L K₂CrO₄ 수용액 49.8 mL에 1.0×10⁻² mol/L AgNO₃ 수용액 0.2 mL를 가했다. **Ag₂CrO₄ 침전이 생기는지 이유와 함께** 답한다.

**발상의 이유(패턴)**: 용해도곱이 주어지고 "침전되는가"를 물으면 **혼합 직후 농도로 이온곱을 만들어 Ksp와 비교**하는 한 가지 길뿐이다. 이온곱 > Ksp면 침전, 이온곱 < Ksp면 전부 녹은 채로 남는다.

**풀이**

1. **부피 확인** — 49.8 + 0.2 = **50.0 mL**. 두 용액 모두 이 부피로 희석된다.
2. **혼합 직후 농도**
   - [Ag⁺] = 1.0×10⁻² × 0.2/50.0 = **4.0×10⁻⁵ mol/L**
   - [CrO₄²⁻] = 1.0×10⁻² × 49.8/50.0 = **9.96×10⁻³ mol/L**
3. **이온곱 계산** — Ag₂CrO₄는 Ag⁺ 2개와 CrO₄²⁻ 1개로 이루어지므로 **이온곱 = [Ag⁺]²[CrO₄²⁻]**.
   - (4.0×10⁻⁵)² × 9.96×10⁻³ = 1.6×10⁻⁹ × 9.96×10⁻³ = **1.6×10⁻¹¹**
4. **Ksp와 비교** — 1.6×10⁻¹¹ > 3.6×10⁻¹². 이온곱이 용해도곱을 넘으므로 **침전이 생긴다**.

![問3 풀이: 혼합 직후 농도로 이온곱을 만들어 Ksp와 비교](data/handai2015/fig/01-q3.webp)

> **정답** **침전이 생긴다.** 혼합 직후의 이온곱 [Ag⁺]²[CrO₄²⁻] = 1.6×10⁻¹¹이 용해도곱 3.6×10⁻¹²보다 크기 때문이다.

### 問4 — 어느 침전이 먼저인가, 그래프 읽기 <a href="https://youtu.be/p98nUjz1axs?t=370">▶ 06:10</a>

**문제 요약**: K₂CrO₄와 NaCl을 모두 1.0×10⁻² mol/L로 포함한 수용액 50.0 mL에 1.0×10⁻² mol/L AgNO₃를 조금씩 가한다(0–70 mL). 그림의 **ア~エ 중 Ag⁺, CrO₄²⁻, Cl⁻의 농도 변화**를 각각 고른다.

**발상의 이유(패턴)**: "먼저 침전하는 쪽"은 **침전이 시작되는 [Ag⁺]가 작은 쪽**이다. 각 염의 Ksp 식을 [Ag⁺]에 대해 풀어 두 값을 비교하면 순서가 정해지고, 순서를 알면 그래프의 모양(직선인지 꺾이는지)이 자동으로 따라온다.

**풀이**

1. **AgCl이 시작되는 [Ag⁺]** — [Ag⁺][Cl⁻] = 1.8×10⁻¹⁰, [Cl⁻] = 1.0×10⁻²
   - [Ag⁺] = 1.8×10⁻¹⁰ ÷ 1.0×10⁻² = **1.8×10⁻⁸ mol/L**
2. **Ag₂CrO₄가 시작되는 [Ag⁺]** — [Ag⁺]²[CrO₄²⁻] = 3.6×10⁻¹², [CrO₄²⁻] = 1.0×10⁻²
   - [Ag⁺]² = 3.6×10⁻¹⁰ → [Ag⁺] = **1.9×10⁻⁵ mol/L**
3. **순서 결정** — 1.8×10⁻⁸ ≪ 1.9×10⁻⁵이므로 **AgCl(흰색)이 먼저** 침전한다.
4. **그래프 읽기**
   - **Cl⁻**: Ag⁺와 1 : 1로 반응하므로 **직선으로 감소**하고, AgNO₃ 50 mL에서 0이 된다 → **(ウ)**
   - **CrO₄²⁻**: AgCl이 끝날 때까지는 **희석되기만** 하므로 완만히 감소해 50 mL에서 0.005(= 0.010 × 50/100). 그 뒤 Ag₂CrO₄로 소비되어 더 줄어든다 → **(イ)**
   - **Ag⁺**: 가한 즉시 침전에 소비되어 **거의 0** → **(エ)**
   - 남는 (ア)는 침전하지 않는 NO₃⁻다.

![問4 순서 판정: 침전이 시작되는 [Ag⁺]를 각각 계산해 비교](data/handai2015/fig/01-q4-order.webp)

![問4 그래프: Cl⁻는 직선으로 0, CrO₄²⁻는 완만히 감소, Ag⁺는 거의 0](data/handai2015/fig/01-q4-graph.webp)

> **정답** **Ag⁺ = (エ), CrO₄²⁻ = (イ), Cl⁻ = (ウ)**
>
> (ア는 침전하지 않는 NO₃⁻)

### 問5 — 관찰되는 침전의 모습 <a href="https://youtu.be/p98nUjz1axs?t=435">▶ 07:15</a>

**문제 요약**: 問4의 조작에서 관찰되는 침전의 모습을 (あ)–(お) 중에서 고른다.

**발상의 이유(패턴)**: 問4에서 순서가 정해졌으므로 **색의 순서**도 자동으로 정해진다. Ag₂CrO₄가 나오기 시작하는 순간 남은 Cl⁻가 얼마인지를 보면 "동시에"가 아님을 숫자로 말할 수 있다.

**풀이**

1. **0–50 mL** — AgCl만 침전하므로 **흰색 침전**만 보인다.
2. **Ag₂CrO₄가 시작되는 지점의 [Cl⁻]** — 그때의 [Ag⁺]는 1.9×10⁻⁵이므로
   - [Cl⁻] = 1.8×10⁻¹⁰ ÷ 1.9×10⁻⁵ ≈ **9×10⁻⁶ mol/L** (영상 표기는 7×10⁻⁶)
   - 처음 1.0×10⁻²의 1000분의 1 수준으로 **거의 전부 침전해 있다**.
3. 따라서 **흰색 → 적갈색**의 순서이고, 두 침전이 처음부터 동시에 생기지는 않는다.

![問5 풀이: Ag₂CrO₄가 시작될 때 Cl⁻는 이미 거의 남아 있지 않다](data/handai2015/fig/01-q5.webp)

> **정답** **(え) 처음에 흰색 침전, 다음에 적갈색 침전**
>
> 적갈색이 보이기 시작한 지점이 Cl⁻의 침전이 끝난 지점이므로, 이 원리로 Cl⁻를 정량할 수 있다(**모어법 モール法**).

## 꼭 외울 것
- **2CrO₄²⁻ + 2H⁺ ⇌ Cr₂O₇²⁻ + H₂O** — Cr 2개로 맞추면 O가 1개 남고, 그 O가 H⁺ 2개와 물이 된다.
- 산성 → **Cr₂O₇²⁻(적등색)** 이 많고, 염기성 → **CrO₄²⁻(황색)** 이 많다.
- 산화환원 양 계산은 **전자 수를 맞춘 계수 = 몰비**. Cr₂O₇²⁻ : Fe²⁺ = **1 : 6**.
- **한계 반응물은 "필요량이 더 많은 쪽이 아니라, 실제로 모자라는 쪽"** 이다.
- 침전 판정: **이온곱 > Ksp → 침전**, 이온곱 < Ksp → 녹은 채로.
- 먼저 침전하는 쪽은 **필요한 [Ag⁺]가 작은 쪽**. AgCl 1.8×10⁻⁸ < Ag₂CrO₄ 1.9×10⁻⁵.
- AgCl은 **흰색**, Ag₂CrO₄는 **적갈색**. 모어법은 이 색 변화로 Cl⁻를 정량한다.

## 자주 틀리는 함정
- 問1에서 전하만 맞추고 **O의 개수를 세지 않는** 실수가 가장 흔하다. 왼쪽 O 8개, 오른쪽 O 7개를 반드시 세야 H⁺ 2개가 나온다.
- 問1의 평형식을 **일방향 화살표(→)** 로 쓰면 감점이다. pH로 비율이 변하는 **가역 평형**이므로 ⇌를 쓴다.
- 問2에서 "Cr₂O₇²⁻가 1.5×10⁻³이니 Cr³⁺는 그 2배"라고 하면 틀린다. **Fe²⁺가 한계**이므로 소비된 5.0×10⁻⁴의 2배다.
- 問2의 농도를 **가하기 전 부피(50 mL)** 로 나누면 틀린다. 혼합 후 **0.100 L**로 나눈다.
- 問3에서 [Ag⁺]를 2배로 하거나, 이온곱을 [Ag⁺][CrO₄²⁻]로 쓰면 안 된다. Ag₂CrO₄는 **Ag⁺의 2제곱**이다.
- 問3의 Ksp 단위가 **mol³/L³**이라는 점도 확인용이다. 2제곱이 들어가는 염이라는 신호다.
- 問4에서 "Ag₂CrO₄가 Ksp가 작으니 먼저 침전한다"고 판단하면 틀린다. Ksp의 크기가 아니라 **실제로 필요한 [Ag⁺]** 를 비교해야 한다.
- 問5에서 "흰색과 적갈색이 동시에"라고 답하면 틀린다. 적갈색이 보이는 순간 Cl⁻는 **10⁻⁶ mol/L 수준(계산값 9×10⁻⁶, 영상 7×10⁻⁶)** 으로 이미 거의 없다.
