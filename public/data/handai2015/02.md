# 大阪大学 2015년 전기 第2問 — 메탄하이드레이트와 이산화탄소의 상태도

## 한눈에 보기
- 第2問은 **기체 + 물이 같은 용기에 있는 상황**과 **CO₂ 상태도**를 이어 붙인 문제다. 問1은 메탄 연소식, 問2는 용기 A의 CO₂ 분압, 問3–問5는 용기 B 안의 CO₂ 상태와 비즈의 위치다.
- 問2의 열쇠는 **기체로 남은 양 + 물에 녹은 양 = 전체 1.0 mol**이라는 물질량 보존이다. 헨리 법칙만으로는 P를 못 구하고, 이 보존식이 있어야 방정식이 닫힌다.
- 問2에서 가장 많이 틀리는 지점은 **기체의 부피**다. 용기 1.14 L에서 **액체 물 139.5 mL를 빼야** 하고, 그 값이 1.00 L다.
- 問3–問5의 열쇠는 **상태도에서 지금 어느 영역에 있는지 읽는 것**이다. 217 K은 삼중점, 280 K은 액체+기체, 310 K은 임계점 너머(초임계유체)다.
- 問4·問5의 비즈는 **주변 유체의 밀도와 비교**해서 뜨고 가라앉는다. 그래서 밀도를 먼저 구하는 것이 순서다.

## 이 大問의 발상(패턴)
| 발동 사인 | 쓰는 형 |
|---|---|
| 기체와 물이 같은 용기 | **기체량 + 용해량 = 전체량** (물질량 보존) |
| 헨리 법칙 상수와 압력이 주어짐 | 녹는 양 = k × (P/P₀) × **물의 부피** |
| 밀도·질량이 주어지고 부피를 물음 | 액체 부피를 구해 **용기 부피에서 뺀다** |
| 삼중점과 같은 온도 | 고·액·기 **3상이 공존** |
| 액체가 절반 | 기체부/액체부 **부피가 같다** → 밀도 계산 |
| 임계점보다 온도·압력이 모두 높다 | **초임계유체** — 액면이 없다 |
| 밀도가 다른 비즈 | 주변보다 **가벼우면 위, 무거우면 아래** |

### 問1 — 메탄의 완전연소 반응식 <a href="https://youtu.be/p98nUjz1axs?t=619">▶ 10:19</a>

**문제 요약**: 메탄의 완전연소의 화학반응식을 쓴다.

**발상의 이유(패턴)**: 연소식은 **C → CO₂, H → H₂O로 개수를 그대로 옮기고, O는 오른쪽에서 세어 왼쪽 O₂로 되돌리는** 순서로 만들면 계수가 저절로 나온다.

**풀이**

1. **C 1개** → CO₂ **1개**
2. **H 4개** → H₂O **2개**
3. **오른쪽 O 세기** — CO₂의 2개 + H₂O의 2개 = **4개**. 왼쪽은 O₂이므로 **2개**.

![問1 메탄 연소식: C 1개, H 4개, O 4개를 세어 계수를 정한다](data/handai2015/fig/02-q1.webp)

> **정답** **CH₄ + 2O₂ → CO₂ + 2H₂O**

### 問2 — 조작1 후 용기 A의 CO₂ 분압 <a href="https://youtu.be/p98nUjz1axs?t=635">▶ 10:35</a>

**문제 요약**: 조작1이 끝난 뒤 용기 A 안의 CO₂ 분압은 몇 Pa인가. (300 K, 1.0×10⁵ Pa에서 CO₂는 물 1 L에 0.040 mol 녹는다. 물의 밀도 1.0 g/cm³, 물의 증기압은 무시)

**발상의 이유(패턴)**: CO₂는 **기체로도 있고 물에 녹아도 있다**. 헨리 법칙은 "녹은 양"만 알려 주므로, **기체 + 용해 = 전체 1.0 mol**이라는 보존식을 세워야 P가 하나로 정해진다. 또 기체가 쓰는 부피는 용기 전체가 아니라 **물을 뺀 공간**이다.

**풀이**

1. **몰수 계산**
   - CH₄·5.75H₂O의 식량 = 16 + 5.75×18 = **119.5** → 119.5 g은 **1.00 mol**. 따라서 CH₄ **1.00 mol**, 물 **5.75 mol**.
   - O₂ = 96 ÷ 32 = **3.0 mol**
2. **연소 전후 표**

   | | CH₄ | O₂ | CO₂ | H₂O |
   |---|---|---|---|---|
   | 처음 | 1.0 | 3.0 | 0 | 5.75 |
   | 반응 | −1.0 | −2.0 | +1.0 | +2.0 |
   | 반응 후 | 0 | 1.0 | **1.0** | **7.75** |

3. **물의 부피** — 7.75 × 18 = 139.5 g, 300 K에서 **액체**이고 밀도 1.0이므로 **139.5 mL**.
4. **기체가 쓰는 부피** — 1.14 L − 0.1395 L = **1.00 L**. 여기가 핵심이다.
5. **분압을 P로 놓고 두 몫을 더한다**
   - 기체: P × 1.00 ÷ (8.31×10³ × 300) = **4.01×10⁻⁷ P**
   - 용해: 0.040 × P/(1.0×10⁵) × 0.1395 = **5.58×10⁻⁸ P**
6. **보존식** — 기체 + 용해 = 1.0 mol
   - (4.01×10⁻⁷ + 5.58×10⁻⁸)P = 4.57×10⁻⁷ P = 1.0
   - P = 2.19×10⁶ Pa → 유효숫자 2자리로 **2.2×10⁶ Pa**

![問2 연소 전후의 몰수 표와 액체 물 139.5 mL](data/handai2015/fig/02-q2-table.webp)

![問2 기체와 용해의 합이 1.0 mol이라는 보존식으로 P를 푼다](data/handai2015/fig/02-q2-p.webp)

> **정답** **2.2×10⁶ Pa**

### 問3 — 217 K에서 보이는 CO₂의 모습 <a href="https://youtu.be/p98nUjz1axs?t=782">▶ 13:02</a>

**문제 요약**: 조작3 후 용기 B에서 보이는 CO₂의 모습을 50자 이내로 설명한다.

**발상의 이유(패턴)**: 217 K은 주어진 상태도의 **삼중점 온도 그 자체**다. 삼중점에서는 세 상이 공존할 수 있고, **1.0 mol을 94 mL에 가두면 기체만으로는 담을 수 없어** 고체가 남는다.

**풀이**

1. **온도 확인** — 217 K = **삼중점의 온도**(압력 0.52×10⁶ Pa).
2. **양 확인** — CO₂ 1.0 mol을 **94 mL**에 넣었다. 기체나 액체만으로는 이 부피에 다 들어가지 못하므로 **고체가 남는다**.
3. **결론** — 삼중점이므로 **고체·액체·기체가 동시에 존재**하고, 창으로는 세 상태가 공존하는 모습이 보인다.

![問3 217 K은 삼중점의 온도: 1.0 mol을 94 mL에 가두면 고체가 남고, 고·액·기가 공존한다](data/handai2015/fig/02-q3.webp)

> **정답** **삼중점의 온도이므로 고체·액체·기체의 3가지 상태가 공존해 관찰된다.**

### 問4 — 280 K에서 청·적 비즈의 위치 <a href="https://youtu.be/p98nUjz1axs?t=814">▶ 13:34</a>

**문제 요약**: 조작4 후 용기 B 안은 7.0×10⁶ Pa이고, **정확히 절반의 높이까지 액체**가 되었으며 흰 비즈는 그림 3의 위치에 있었다. **청·적 비즈의 위치**를 나타낸다.

**발상의 이유(패턴)**: 비즈의 뜨고 가라앉음은 **주변 유체의 밀도와의 대소**로만 결정된다. 그래서 먼저 기체와 액체의 밀도를 구한다. 흰 비즈가 기체 속에 떠 있다는 것은 **기체 밀도 = 흰 비즈 밀도**라는 뜻이므로, 이것이 밀도를 알아내는 열쇠다.

**풀이**

1. **기체 밀도** — 흰 비즈(0.28)가 기체 한가운데서 멈춰 있으므로 **기체의 밀도 = 0.28 g/cm³**.
2. **액체 밀도** — 절반이 액체이므로 기체부 47 mL, 액체부 47 mL.
   - 기체의 질량 = 0.28 × 47 = **13.2 g**
   - 액체의 질량 = 44 − 13.2 = **30.8 g** → 밀도 = 30.8 ÷ 47 = **0.66 g/cm³**
3. **비즈와 비교**
   - 청 0.40, 적 0.60은 모두 **기체 0.28보다 크고 액체 0.66보다 작다**.
   - 따라서 기체 속에서는 가라앉고, 액체 속에서는 뜬다 → **둘 다 액면에 뜬다**.
   - 적은 0.60으로 액체 0.66에 가까워 **액면 바로 아래에 거의 잠긴 상태**로 뜬다.

![問4 흰 비즈가 기체에 떠 있다 → 기체 밀도 0.28, 액체 밀도 0.66](data/handai2015/fig/02-q4-density.webp)

![問4 답: 청·적 모두 액면에 뜨고, 적은 거의 잠긴 상태](data/handai2015/fig/02-q4-float.webp)

> **정답** **청·적 비즈 모두 액면(기체와 액체의 경계)에 뜬다.** 적 비즈는 액체의 밀도에 가까워 액면 바로 아래에 거의 잠긴 상태로 뜬다.

### 問5 — 310 K에서 세 비즈의 위치와 이유 <a href="https://youtu.be/p98nUjz1axs?t=905">▶ 15:05</a>

**문제 요약**: 조작5에서 용기 B 안의 모습이 크게 바뀌고 압력이 **7.4×10⁶ Pa**이 되었다. **3색 비즈의 위치를 나타내고 그 이유를 설명**한다.

**발상의 이유(패턴)**: 온도와 압력을 **임계점(304 K, 7.38×10⁶ Pa)과 비교**하면 상태가 결정된다. 둘 다 넘으면 **초임계유체**가 되어 액면이 사라지고, 용기 전체가 하나의 균일한 유체가 된다. 그 균일 밀도와 비즈를 비교하면 위치가 정해진다.

**풀이**

1. **상태 판정** — 310 K > 304 K, 7.4×10⁶ Pa > 7.38×10⁶ Pa. **둘 다 임계점을 넘었으므로 초임계유체**다.
2. **모습** — 액면이 없어져 **용기 전체에 균일하게 퍼진다**.
3. **밀도** — 44 g ÷ 94 mL = **0.47 g/cm³**
4. **비즈와 비교**
   - 흰 0.28, 청 0.40 < 0.47 → **위로 떠올라 윗면에 모인다**
   - 적 0.60 > 0.47 → **바닥으로 가라앉는다**

![問5 답: 흰·청은 위, 적은 아래](data/handai2015/fig/02-q5-beads.webp)

> **정답**
> - **흰·청 비즈: 위쪽(윗면)에 모인다.** 310 K, 7.4×10⁶ Pa는 임계점보다 온도도 압력도 높아 **초임계유체**가 되고 액면이 사라진다. 유체의 밀도는 44/94 = **0.47 g/cm³**로, 0.28과 0.40보다 크므로 두 비즈는 뜬다.
> - **적 비즈: 바닥에 가라앉는다.** 0.60 > 0.47이기 때문이다.

## 꼭 외울 것
- **CH₄ + 2O₂ → CO₂ + 2H₂O**
- 기체와 물이 함께 있으면 **기체량 + 용해량 = 전체량**으로 방정식을 세운다.
- 헨리 법칙: 녹는 양 = **k × (P/P₀) × 물의 부피**. 여기서는 0.040 × P/(1.0×10⁵) × 0.1395.
- 기체의 부피는 **용기 부피 − 액체 부피**. 1.14 L − 0.1395 L = 1.00 L.
- 기체 상태방정식은 **P·V = n·R·T**, R = 8.31×10³ Pa·L/(K·mol).
- CO₂ 상태도: **삼중점 217 K, 0.52×10⁶ Pa / 임계점 304 K, 7.38×10⁶ Pa**.
- 임계점보다 온도·압력이 모두 높으면 **초임계유체**(액면 없음).
- 비즈의 부침은 **주변 유체의 밀도와의 대소**로만 판단한다.

## 자주 틀리는 함정
- 기체 부피를 **용기 전체 1.14 L로 두는** 실수가 가장 흔하다. 물 139.5 mL를 빼서 **1.00 L**로 해야 한다.
- 물의 양을 **5.75 mol만** 쓰는 실수. 연소로 **2.0 mol이 더 생겨 7.75 mol**이 된다.
- 問2에서 헨리 법칙 항을 **빠뜨리면** P가 2.49×10⁶으로 나와 틀린다. 녹은 양까지 더해야 2.2×10⁶이다.
- 問3을 "기체만 있다"거나 "액체가 된다"고 쓰면 틀린다. 217 K은 **삼중점**이므로 세 상이 공존하고, 94 mL에 1.0 mol은 다 들어가지 않아 **고체가 남는다**.
- 問4에서 "청은 가라앉고 적은 뜬다"고 뒤집는 실수. **기체 0.28 < 청 0.40 < 적 0.60 < 액체 0.66**이므로 둘 다 액면에 뜬다.
- 問4의 액체 밀도를 44/47 = 0.94로 계산하면 틀린다. 액체 질량은 **44 − 13.2 = 30.8 g**이다.
- 問5에서 "임계점을 넘었으니 기체"라고만 쓰면 부족하다. **초임계유체**라서 액면이 없다는 점, 밀도 0.47과의 비교까지 써야 이유가 된다.
- 問5에서 흰 비즈를 "가운데"에 둔 채로 두면 틀린다. 균일한 초임계유체에서는 **밀도 차이만으로** 위·아래가 갈린다.
