# 大阪大学 2015년 전기 第4問 — 펩티드의 구조 결정

## 한눈에 보기
- 분자량 270 전후의 **펩티드 A**를, 원소분석(실험1~3)과 검출 반응(실험4~7)만으로 구조까지 결정하는 문제다.
- 問1은 **원소분석으로 분자식**, 問2는 **니히드린 반응의 시약 이름**, 問3은 **황 검출의 검은 침전 화학식**, 問4는 **아미노산 배열 순서의 가짓수**, 問5는 **구조식 1개**를 쓰는 문제다.
- 원소분석의 핵심은 **O를 나머지에서 빼서 구하는 것**이다. C·H·N·S를 각각 질량으로 구한 뒤 53.0 mg에서 빼면 O가 남는다.
- 아미노산 결정의 핵심은 **"S를 포함 → 시스테인", "부제 탄소 없음 → 글리신"**, 그리고 **분자량 차이로 세 번째 아미노산(세린)**을 잡는 것이다.
- 배열 순서는 **부분 가수분해 결과**로 정한다. 두 종류의 디펩티드 **양쪽 모두에 시스테인이 들어 있으면 시스테인은 반드시 가운데**다.

## 이 大問의 발상(패턴)
| 발동 사인 | 쓰는 형 |
|---|---|
| 원소분석(연소 → CO₂·H₂O, N₂ 부피, S 질량) | 질량 → 원자 수의 비. **O는 빼서 구한다** |
| 분자량 270 전후 | 실험식량을 계산해 그대로 분자식인지 확인 |
| 닌히드린으로 자주~청자색 | 니히드린 반응 = 아미노산 검출 |
| NaOH로 가열 후 (CH₃COO)₂Pb → 검은 침전 | 황 함유 아미노산 → S²⁻ → PbS |
| 부분 가수분해로 디펩티드 2종 | 양쪽에 공통으로 들어가는 아미노산이 **가운데** |

### 問1 — 펩티드 A의 분자식 <a href="https://youtu.be/p98nUjz1axs?t=1544">▶ 25:44</a>

**문제 요약**: 실험1~3의 결과로 펩티드 A의 분자식을 구한다.

**발상의 이유(패턴)**: 연소 분석은 **"생성물의 질량 → 그 안의 원소 질량"**으로 되돌리는 작업이다. CO₂의 12/44가 탄소, H₂O의 2/18이 수소다. **산소는 직접 측정값이 없으므로 전체 질량에서 나머지를 빼서** 구한다.

**풀이**

1. **각 원소의 질량**
   - C: 70.4 × 12/44 = **19.2 mg**
   - H: 27.0 × 2/18 = **3.0 mg**
   - N: 6.72 mL ÷ 22.4 L = 3.0×10⁻⁴ mol N₂ → N 원자는 그 2배인 6.0×10⁻⁴ mol → 6.0×10⁻⁴ × 14 = **8.4 mg**
   - S: 주어진 값 그대로 **6.4 mg**
   - O: 53.0 − (19.2 + 3.0 + 8.4 + 6.4) = **16.0 mg**
2. **원자량으로 나눠 몰비로**
   - C 19.2/12 = 1.6, H 3.0/1 = 3.0, N 8.4/14 = 0.6, O 16.0/16 = 1.0, S 6.4/32 = 0.2
3. **가장 작은 값 0.2로 나누기** → C 8, H 15, N 3, O 5, S 1
4. **실험식 C₈H₁₅N₃O₅S**의 식량 = 96 + 15 + 42 + 80 + 32 = **265**. 문제의 분자량이 270 전후이므로 **실험식이 곧 분자식**이다.

![問1 분자식: 질량 → 원자량으로 나누기 → 0.2로 나누기](data/handai2015/fig/04-element-table.webp)

> **정답** **C₈H₁₅N₃O₅S** (분자량 265)

### 問2 — [아]에 해당하는 화합물 이름 <a href="https://youtu.be/p98nUjz1axs?t=1617">▶ 26:57</a>

**문제 요약**: 크로마토그래피에 분무해 가온하면 자주~청자색 반점이 나타나는 시약 [아]의 이름을 쓴다.

**발상의 이유(패턴)**: **아미노산 + 시약 → 가온 → 자주~청자색**은 니히드린 반응 하나로 정해져 있다. 색 변화의 방향(자주 → 청자)까지 그대로 외워 둔다.

**풀이**

1. 아미노산(아미노기)은 **니히드린(ニンヒドリン)**과 반응해 **루헤만 퍼플** 색을 낸다. 이것이 니히드린 반응이다.
2. 실제 색은 **자주~청자색**으로 표현되며, 0.1 ㎍ 수준의 아미노산도 검출할 수 있을 만큼 감도가 높다.
3. 실험4에서 반점이 3개였다는 것은 **아미노산이 3종류**라는 뜻이다.

![問2·問3 검출 반응: 니히드린 반응과 황 검출(PbS)](data/handai2015/fig/04-detection.webp)

> **정답** **니히드린(ニンヒドリン)**

### 問3 — 밑줄부 ①의 검은 침전의 화학식 <a href="https://youtu.be/p98nUjz1axs?t=1617">▶ 26:57</a>

**문제 요약**: 황을 포함한 아미노산을 NaOH로 가열한 뒤 (CH₃COO)₂Pb를 가하면 생기는 검은 침전의 화학식을 쓴다.

**발상의 이유(패턴)**: **S를 포함한 아미노산 + NaOH 가열 → S²⁻**, 그리고 **Pb²⁺ + S²⁻ → 검은 침전**이다. 검은 침전의 정체는 황화납 하나뿐이다.

**풀이**

1. 시스테인의 –SH가 NaOH로 가열되면 수소가 떨어져 **S²⁻(황화 이온)**가 된다.
2. (CH₃COO)₂Pb가 주는 **Pb²⁺**와 결합해 **PbS**의 검은 침전이 생긴다.
3. 실험6에서 **디펩티드에서는 침전이 생기고 아미노산 2종류에서는 생기지 않았다**는 점이 중요하다. 부분 가수분해로 유리된 아미노산 2종류는 **글리신과 세린**이라 황이 없고, 디펩티드 2종류는 **둘 다 시스테인을 포함**하기 때문이다. 이 사실이 問4에서 시스테인을 가운데에 고정하는 근거가 된다.

![問3 황 검출의 경로: S 함유 아미노산 + NaOH 가열 → S²⁻ → Pb²⁺로 검은 침전](data/handai2015/fig/04-answer-q3.webp)

> **정답** **PbS**

### 問4 — 아미노산의 배열 순서는 몇 가지인가 <a href="https://youtu.be/p98nUjz1axs?t=1642">▶ 27:22</a>

**문제 요약**: A를 이루는 3종류의 아미노산을 정하고, 가능한 배열 순서의 가짓수를 구한다.

**발상의 이유(패턴)**: 세 아미노산의 정체는 **"S 포함 / 부제 탄소 없음"**이라는 두 단서와 **분자량 계산**으로 결정된다. 배열은 **부분 가수분해로 나온 두 디펩티드의 공통 성분**을 찾으면 자동으로 정해진다.

**풀이**

1. **아미노산 3종 결정**
   - S를 포함 → **시스테인(システイン), 분자량 121**
   - 부제 탄소가 없음 → **글리신(グリシン), 분자량 75**
   - 세 번째: 트리펩티드는 아미노산 3분자에서 물 2분자가 빠진 것이므로, 세 아미노산 분자량의 합 = 265 + 2×18 = **301**
   - 301 − 121 − 75 = **105**, 메틸기가 없으므로 **세린(セリン, 측쇄 –CH₂OH)**이다. (알라닌은 89이고 메틸기를 가지므로 해당 없음)
2. **배열 결정**
   - 부분 가수분해로 나온 **아미노산 2종류**는 S 반응이 없으므로 **글리신과 세린**이다.
   - **디펩티드 2종류는 둘 다 S 반응이 있으므로 양쪽 모두 시스테인을 포함**한다.
   - 시스테인이 두 디펩티드 **양쪽에 들어가려면 가운데 자리**에 있을 수밖에 없다.
3. 따라서 배열은 **Gly–Cys–Ser** 또는 **Ser–Cys–Gly**의 **2가지**다.

![問4 배열 결정: 아미노산 2종은 S 반응 없음 → 글리신과 세린, 디펩티드 2종은 둘 다 S 반응 → 시스테인이 가운데](data/handai2015/fig/04-order.webp)

![問4 세 아미노산: 글리신(75)·시스테인(121)·세린(105)](data/handai2015/fig/04-amino-acids.webp)

> **정답** **2가지** (Gly–Cys–Ser, Ser–Cys–Gly)

### 問5 — 펩티드 A의 구조식의 예 <a href="https://youtu.be/p98nUjz1axs?t=1716">▶ 28:36</a>

**문제 요약**: 問4에서 구한 배열로 펩티드 A의 구조식 1개를 쓴다.

**발상의 이유(패턴)**: 펩티드 사슬은 **왼쪽이 아미노기 말단(N 말단), 오른쪽이 카르복시기 말단(C 말단)**이다. 아미노산끼리는 **카르복시기와 아미노기가 물을 빼고 이어진 펩티드 결합**으로 연결된다.

**풀이**

1. **Gly–Cys–Ser** 순으로 놓는다. 왼쪽 끝은 H₂N–, 오른쪽 끝은 –COOH.
2. 결합은 **–C(=O)–NH–**를 두 번 넣는다.
3. 측쇄를 붙인다. 가운데 시스테인의 측쇄는 **–CH₂SH**, 오른쪽 세린의 측쇄는 **–CH₂OH**.
4. 완성된 사슬: H₂N–CH₂–CO–NH–CH(CH₂SH)–CO–NH–CH(CH₂OH)–COOH

![問5 펩티드 A의 구조식 예: Gly–Cys–Ser](data/handai2015/fig/04-answer-q5.webp)

> **정답** **H₂N–CH₂–CO–NH–CH(CH₂SH)–CO–NH–CH(CH₂OH)–COOH** (Gly–Cys–Ser)
>
> 반대 배열 Ser–Cys–Gly도 정답이 된다(문제는 "예를 1개" 쓰는 것).

## 꼭 외울 것
- 원소분석: **C = CO₂×12/44, H = H₂O×2/18, N = N₂ 부피÷22.4×2×14, O = 전체 − 나머지**.
- 아미노산 검출은 **니히드린 → 자주~청자색**. 황 검출은 **NaOH 가열 → Pb²⁺ → PbS 검은 침전**.
- 시스테인 분자량 **121**, 글리신 **75**, 세린 **105**, 알라닌 **89**.
- 트리펩티드의 아미노산 분자량 합 = **펩티드 분자량 + 18×2**.
- 두 디펩티드 양쪽에 공통으로 들어가는 아미노산은 **가운데**에 있다.

## 자주 틀리는 함정
- 산소를 "전체 − (C+H+N)"로 계산해 **S를 빼먹는** 실수가 가장 흔하다. S의 6.4 mg까지 반드시 빼야 O가 16.0 mg으로 떨어진다.
- N₂ 6.72 mL를 **N 원자 몰수로 착각**하기 쉽다. 6.72 mL는 **N₂ 분자**이므로 원자는 2배다.
- 실험식 C₈H₁₅N₃O₅S의 식량 265를 "분자량 270과 다르다"며 2배로 늘리면 틀린다. 270 **전후**라는 표현이므로 265가 그대로 분자식이다.
- 세 번째 아미노산을 알라닌(89)으로 쓰면 안 된다. 105이고 **메틸기가 없다**는 조건에 맞는 것은 **세린**이다.
- 배열을 3! = 6가지로 세면 틀린다. **시스테인이 가운데로 고정**되므로 2가지다.
- 問3에서 PbS를 "PbS₂"나 "PbSO₄"로 쓰지 않는다. 검은 침전은 **PbS**다.
