# 大阪大学 2015년 전기 第3問 — 의약품 합성 경로와 브롬 첨가의 입체

## 한눈에 보기
- 第3問은 성격이 완전히 다른 두 파트로 나뉜다. **[I]는 벤젠·에틸렌에서 아세트아미노펜을 합성하는 경로 추적(問1~問4)**, **[II]는 브롬 첨가의 입체화학(問5~問6)**이다.
- [I]의 열쇠는 **목표 구조에서 한 단계씩 거꾸로 되짚는 것**이다. 목표의 N–C 결합이 아미드 결합이므로, 그 양쪽이 "아미노기 쪽"과 "아실기 쪽"으로 갈라진다.
- [I]의 벤젠 쪽 3단계는 **쿠멘법(クメン法)**이다. 벤젠 + 프로펜 → 쿠멘 → 쿠멘히드로퍼옥시드 → 페놀 + **아세톤**.
- [II]의 열쇠는 **Br₂가 이중결합 평면의 위·아래에 하나씩 붙는 안티 첨가(アンチ付加)**이다. 평면을 옆에서 보면 위·아래만 비교하면 되므로 판단이 쉬워진다.
- 問6은 그 결과를 응용하는 문제다. **트랜스형에서만 메소체(メソ体)가 나와 생성물이 1종류**가 된다.

### 問1 — 화합물 A~F의 구조식 <a href="https://youtu.be/p98nUjz1axs?t=1064">▶ 17:44</a>

**문제 요약**: 아세트아미노펜 합성 경로에 등장하는 A~F의 구조식을 쓴다.

**발상의 이유(패턴)**: 목표 분자의 **N–C 결합이 아미드 결합**이다. 아미드 결합은 **아미노기 + 카르복시산 유도체(무수물)**의 탈수 축합으로 생긴다. 그러므로 목표를 N 쪽과 C=O 쪽으로 자르면 A와 B가 바로 정해진다.

**풀이**

1. **목표에서 자르기** — N–C 결합을 끊으면 N 쪽은 **p-아미노페놀**, C=O 쪽은 **아세틸기**다. 아세틸기를 주는 쪽은 무수아세트산이므로 **B = (CH₃CO)₂O**.
2. **에틸렌 쪽(3단계)** — 에틸렌을 산화하면 먼저 **아세트알데히드**, 더 산화하면 **아세트산**이 된다. 무수아세트산은 아세트산 2분자에서 물 1분자가 빠진 것이므로 **B = E 2분자 − H₂O → E는 아세트산**.
   - 강의 설명: **F = CH₃CHO(아세트알데히드)** — 페일링액을 환원하는 것은 알데히드라는 단서와 일치한다.
   - 이 산화법(염화팔라듐 + 염화구리 촉매)을 **바커 산화(ワッカー酸化)**라고 한다.
3. **벤젠 쪽(5단계)** — A는 C를 **Sn·HCl로 환원한 뒤 NaOH로 처리**해 얻으므로, **C는 p-니트로페놀**, **A는 p-아미노페놀**이다. C는 D를 질산화한 것이므로 **D는 페놀**.
4. D는 벤젠 + 프로펜 3단계(쿠멘법)의 생성물이므로 앞뒤가 맞는다.

![問1 에틸렌 쪽: 에틸렌 → 아세트알데히드 → 아세트산 → 무수아세트산](data/handai2015/fig/03-ethylene.webp)

> **정답**
> - **A** = p-아미노페놀 HO–C₆H₄–NH₂ (파라)
> - **B** = 무수아세트산 (CH₃CO)₂O
> - **C** = p-니트로페놀 HO–C₆H₄–NO₂ (파라)
> - **D** = 페놀 C₆H₅OH
> - **E** = 아세트산 CH₃COOH
> - **F** = 아세트알데히드 CH₃CHO

### 問2 — 이성질체 X의 구조식 <a href="https://youtu.be/p98nUjz1axs?t=1123">▶ 18:43</a>

**문제 요약**: D에 질산을 반응시킬 때 C와 함께 생기는 이성질체 X의 구조식을 쓴다.

**발상의 이유(패턴)**: 페놀의 **–OH는 오르토·파라 배향성**이다. 질산화는 –OH에 대해 오르토와 파라에 들어가므로, 파라체가 C라면 **오르토체가 X**다.

**풀이**

1. 페놀의 –OH는 벤젠 고리에 전자를 밀어 넣어 **오르토·파라 위치를 활성화**한다.
2. 파라 위치에 –NO₂가 들어간 것이 **C(p-니트로페놀)**.
3. 같은 이유로 오르토 위치에도 –NO₂가 들어간 **o-니트로페놀이 함께 생긴다** → 이것이 X.

![問2 벤젠 쪽: D 페놀 → C p-니트로페놀, 그리고 오르토체 X](data/handai2015/fig/03-benzene.webp)

> **정답** **X = o-니트로페놀** (2-니트로페놀)

### 問3 — 밑줄부 ①의 합성법 이름 <a href="https://youtu.be/p98nUjz1axs?t=1142">▶ 19:02</a>

**문제 요약**: 벤젠 + 프로펜에서 시작하는 3단계 페놀 합성법의 명칭을 쓴다.

**발상의 이유(패턴)**: "벤젠 + 프로펜 → 산화 → 산분해"라는 3단계 조합은 **쿠멘법** 하나뿐이다. 페놀의 공업적 제법은 이 이름으로 외워 둔다.

3. 묽은 산으로 분해 → **페놀 + 아세톤**

### 問5 — 아래에서 접근했을 때의 생성물 3·4 <a href="https://youtu.be/p98nUjz1axs?t=1244">▶ 20:44</a>

**문제 요약**: Br₂가 평면의 **아래**에서 접근한 경우를 생각해, R¹R² 쪽 탄소를 공격한 것을 생성물 3, R³R⁴ 쪽 탄소를 공격한 것을 생성물 4로 할 때 두 구조를 쓴다.

**발상의 이유(패턴)**: 위에서 접근한 경우(생성물 1·2)와 **위·아래가 전부 뒤집힌다**. 그래서 새로 그리지 않고, 이미 나온 생성물 1·2와 대조해 **같은 배열을 찾으면** 답이 된다.

**풀이**

![생성물 1·2의 구조: 왼쪽 C를 공격한 것이 생성물 1, 오른쪽 C를 공격한 것이 생성물 2](data/handai2015/fig/03-stereo-products.webp)

1. **평면을 옆에서 본다** — C=C 평면을 옆에서 보면 **한 줄**이 된다. 왼쪽 탄소가 R¹R² 쪽, 오른쪽 탄소가 R³R⁴ 쪽이다.
2. **위에서 접근한 경우 확인** — Br⁺가 위에 있으므로 Br⁻는 **아래에서 공격**한다.
   - 왼쪽 C를 공격 → 왼쪽 Br 아래, 오른쪽 Br 위 = **생성물 1**
   - 오른쪽 C를 공격 → 오른쪽 Br 아래, 왼쪽 Br 위 = **생성물 2**
3. **아래에서 접근한 경우** — Br⁺가 아래에 있으므로 Br⁻는 **위에서 공격**한다. 위·아래가 전부 반전된다.
   - 왼쪽 C를 공격한 **생성물 3** → 왼쪽 Br 위, 오른쪽 Br 아래 → **생성물 2와 완전히 같은 배열**
   - 오른쪽 C를 공격한 **생성물 4** → 오른쪽 Br 위, 왼쪽 Br 아래 → **생성물 1과 완전히 같은 배열**

![問5 풀이: 평면을 옆에서 보면 생성물 1은 왼쪽 Br 아래·오른쪽 Br 위](data/handai2015/fig/03-side-view.webp)

![問5 답: 생성물 3은 생성물 2와, 생성물 4는 생성물 1과 같은 구조](data/handai2015/fig/03-answer-q5.webp)

> **정답**
> - **생성물 3 = 생성물 2와 같은 구조식** (오른쪽 Br 아래, 왼쪽 Br 위)
> - **생성물 4 = 생성물 1과 같은 구조식** (왼쪽 Br 아래, 오른쪽 Br 위)
>
> 즉 아래에서 접근해도 **실제로 새로 생기는 입체는 2종류뿐**이고, 위에서 접근한 경우와 같은 화합물이 나온다.

### 問6 — C₄H₈의 시스·트랜스 이성질체 H와 생성물 5 <a href="https://youtu.be/p98nUjz1axs?t=1333">▶ 22:13</a>

**문제 요약**: 분자식 C₄H₈이며 서로 시스·트랜스 이성질체 관계인 화합물 G, H가 있다. Br₂를 첨가하면 **G에서는 거울상 이성질체의 혼합물**이, **H에서는 1종류만** 생겼다. H와 생성물 5의 구조식을 쓴다.

**발상의 이유(패턴)**: C₄H₈에 시스·트랜스가 있으면 **2-뷰텐**이다. 첨가 생성물은 **2,3-디브로모뷰테인**이고, C2·C3이 둘 다 **부제 탄소**가 되므로 **메소체인지 아닌지**가 생성물 개수를 결정한다.

**풀이**

1. **탄화수소 결정** — C₄H₈에서 시스·트랜스 이성질체가 존재하는 것은 **2-뷰텐**뿐이다(1-뷰텐·2-메틸프로펜은 시스·트랜스가 없다).
2. **생성물 확인** — 2-뷰텐에 Br₂가 첨가되면 **2,3-디브로모뷰테인**. C2와 C3에는 각각 Br, H, CH₃, 그리고 상대 탄소가 붙어 **둘 다 부제 탄소**다.
3. **트랜스형을 생성물 1의 틀에 대입** — 트랜스형은 R¹·R⁴ = CH₃, R²·R³ = H로 놓을 수 있다. 이때 두 부제 탄소 주변이 **거울에 비친 것처럼 반대 방향**이 되어, 분자 안에 **대칭면**이 생긴다. 부제 탄소가 있어도 거울상 이성질체가 없는 이런 분자를 **메소체(メソ体)**라 한다.
4. **생성물 개수로 역확인** — 트랜스형에서는 생성물 1과 2가 **모두 같은 메소체**가 되므로 **1종류**. 시스형에서는 생성물 1과 2가 **거울상 쌍**이 되어 2종류(라세미 혼합물)가 된다. 문제의 "H에서 1종류"와 일치하므로 **H = 트랜스형**이다.

![問6 시스·트랜스 2-뷰텐의 구조](data/handai2015/fig/03-butene.webp)

> **정답**
> - **H = 트랜스-2-뷰텐** (CH₃가 이중결합을 사이에 두고 반대쪽)
> - **생성물 5 = 메소-2,3-디브로모뷰테인** — C2·C3의 Br이 서로 반대쪽(안티)에 있고, 분자 안에 대칭면이 있어 거울상 이성질체가 없다 → **1종류**

## 꼭 외울 것
- 아미드 결합 N–C는 **아미노기 + 무수아세트산(아실화)**. 아세트아미노펜 = p-아미노페놀 + 무수아세트산.
- **–NH₂는 니트로기의 환원(Sn·HCl → NaOH)**으로 만든다. 페놀의 질산화는 **오르토·파라** 두 자리에 들어간다.
- **페놀 = 쿠멘법**. 벤젠 + 프로펜 → 쿠멘 → 쿠멘히드로퍼옥시드 → 페놀 + **아세톤**.
- 에틸렌 → 아세트알데히드 → 아세트산은 **바커법**. 무수아세트산 = 아세트산 2분자 − H₂O.
- Br₂ 첨가는 **안티 첨가**. 평면을 옆에서 보면 "위·아래"만 비교하면 된다.
- **트랜스형 → 메소체 1종류**, **시스형 → 거울상 쌍 2종류**.

## 자주 틀리는 함정
- A를 **p-아미노페놀**이 아니라 아닐린으로 쓰면 안 된다. 목표에 –OH가 남아 있으므로 벤젠 고리에 **–OH와 –NH₂가 둘 다** 있어야 한다.
- 쿠멘법의 부생물을 **페놀**이나 **프로펜**으로 쓰는 실수가 많다. 정답은 **아세톤**이다.
- 問5에서 "아래에서 접근하면 새로운 생성물이 생긴다"고 착각하기 쉽다. 위·아래를 반전시켜 보면 **생성물 3 = 생성물 2, 생성물 4 = 생성물 1**이다.
- 메소체는 "부제 탄소가 없다"는 뜻이 아니다. **부제 탄소가 있는데도 분자 내 대칭면 때문에 거울상이 겹치는** 경우다.
- 시스형에서 생성물이 1종류라고 답하면 틀린다. 시스형은 **거울상 쌍(2종류)**이고, 1종류가 되는 것은 **트랜스형**이다.
