# #004 4차방정식이 서로 다른 양의 근 4개를 가질 조건 (근의 분리)

**문제**: 4차방정식 x⁴ + ax³ + bx² + ax + 1 = 0 이 서로 다른 4개의 양의 근을 갖도록 하는 점 (a, b)의 범위를 도시하라.

**발동 신호**: "양의 근"처럼 근의 범위가 지정되어 있음 → 근의 분리(解の配置). 계수가 좌우대칭(1, a, b, a, 1)이면 x²으로 나누고 t = x + 1/x로 치환한다.

**핵심 아이디어**: t = x + 1/x로 치환하면 4차방정식이 t에 대한 2차방정식이 된다. x > 0에서 t > 2인 t 하나에 서로 다른 양의 x가 정확히 2개 대응하므로, 조건은 "t의 2차방정식이 2보다 큰 서로 다른 두 실근을 가질 것"이 된다.

**풀이**:
1. x = 0은 근이 아니다(상수항이 1). 따라서 양변을 x²으로 나눌 수 있다.
   x² + ax + b + a/x + 1/x² = 0 → (x² + 1/x²) + a(x + 1/x) + b = 0
2. t = x + 1/x로 놓으면 x² + 1/x² = t² − 2 이므로
   t² − 2 + at + b = 0, 즉 g(t) = t² + at + b − 2 = 0
3. x와 t의 대응을 확인한다. x > 0일 때 산술·기하평균 부등식에 의해 t = x + 1/x ≥ 2이고, 등호는 x = 1일 때 성립한다.
   - t를 고정하면 x² − tx + 1 = 0이다. 이 방정식의 판별식은 t² − 4이고, 두 근의 합은 t > 0, 곱은 1 > 0이다.
   - t > 2이면 서로 다른 양의 x가 2개 나온다.
   - t = 2이면 x = 1 하나(중근)만 나온다.
   - t < 2이면 양의 실근 x가 없다.
   - 서로 다른 t에서 나온 x는 서로 다르다(x가 t를 하나로 결정하므로).
   따라서 "서로 다른 양의 근 4개"는 "g(t) = 0이 t > 2인 서로 다른 두 실근을 가짐"과 동치이다.
4. 포물선 g(t)는 아래로 볼록하므로 근의 분리 조건 3가지를 세운다.
   - ① 판별식: D = a² − 4(b − 2) = a² − 4b + 8 > 0 → b < a²/4 + 2
   - ② 축: −a/2 > 2 → a < −4
   - ③ 경계값: g(2) = 4 + 2a + b − 2 = 2a + b + 2 > 0 → b > −2a − 2
5. 그래프 관계를 확인한다. (a²/4 + 2) − (−2a − 2) = (a² + 8a + 16)/4 = (a + 4)²/4 ≥ 0 이므로, 직선 b = −2a − 2는 a = −4, 점 (−4, 6)에서 포물선 b = a²/4 + 2에 접한다. 접선의 기울기는 (a²/4 + 2)′ = a/2 = −2로 일치한다.
   따라서 a < −4 쪽에서 포물선과 접선 사이에 낀 띠 모양 영역이 답이다.
6. 검산: a = −6, b = 10.5를 대입하면 g(t) = t² − 6t + 8.5 = 0이고, t = 3 ± √0.5 ≈ 3.71, 2.29로 둘 다 2보다 크다. 조건을 만족한다.

**답**: a < −4 이고 −2a − 2 < b < a²/4 + 2
→ 포물선 b = a²/4 + 2와 그 접선 b = −2a − 2(접점 (−4, 6)) 사이에 낀 부분 중 a < −4인 영역. 경계는 포함하지 않는다.

**일본어 용어**:
- `解の配置(かいのはいち) — 근의 분리(근의 위치 조건)`
- `判別式(はんべつしき) — 판별식`
- `軸(じく) — (포물선의) 축`
- `置き換え(おきかえ) — 치환`
- `接線(せっせん) — 접선`
- `境界(きょうかい)は含まない — 경계는 포함하지 않음`

**난이도/호시 관련성**: [권장] 근의 분리(판별식·축·경계값)는 수학Ⅰ 2차함수의 핵심으로 마크시트에서도 자주 나온다. 다만 상반방정식 치환과 영역 도시까지 결합한 이 문제는 2차 시험 수준이므로, 기본 3조건을 익히는 연습용으로 권장한다.
