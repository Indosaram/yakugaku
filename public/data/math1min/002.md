# #002 최대 실근의 5제곱, 정수 부분은? — 근과 계수의 관계로 한꺼번에 처리

**문제**: 방정식 x³ − 5x² + 1 = 0의 가장 큰 실근을 α라 하자. α⁵의 정수 부분을 구하여라.
(方程式 x³ − 5x² + 1 = 0 の最大の実数解を α とする。α⁵ の整数部分を求めよ。)

**발동 신호**: 방정식의 근 하나의 거듭제곱(αⁿ)이 나오는데, 그 근을 직접 구할 수 없다. → 나머지 근(β, γ)까지 불러서 대칭식 αⁿ + βⁿ + γⁿ으로 만든다.

**핵심 아이디어**: pₙ = αⁿ + βⁿ + γⁿ은 근과 계수의 관계와 점화식으로 계산하면 항상 정수가 된다(영상의 "보이지 않는 짝꿍을 부르면 정수가 나타난다"). α⁵ = p₅ − (β⁵ + γ⁵)이고, β⁵ + γ⁵가 0과 1 사이에 있음만 보이면 된다.

**풀이**:

1. 세 근을 α, β, γ(α가 최대)라 하면 근과 계수의 관계에서
   α + β + γ = 5, αβ + βγ + γα = 0, αβγ = −1

2. pₙ = αⁿ + βⁿ + γⁿ으로 두고 점화식을 만든다.
   각 근 x는 x³ = 5x² − 1을 만족하므로 양변에 xⁿ을 곱하면 x^(n+3) = 5x^(n+2) − xⁿ이다.
   이것을 x = α, β, γ에 대해 더하면
   **p(n+3) = 5·p(n+2) − pₙ**

3. 초기값을 구한다.
   - p₀ = 1 + 1 + 1 = 3
   - p₁ = α + β + γ = 5
   - p₂ = (α + β + γ)² − 2(αβ + βγ + γα) = 25 − 0 = 25

4. 점화식으로 차례대로 계산한다.
   - p₃ = 5·p₂ − p₀ = 125 − 3 = 122
     (검산: 뉴턴 항등식 p₃ = 5·p₂ − 0·p₁ + 3·(−1) = 122 ✓)
   - p₄ = 5·p₃ − p₁ = 610 − 5 = 605
   - p₅ = 5·p₄ − p₂ = 3025 − 25 = **3000**

   따라서 α⁵ = 3000 − (β⁵ + γ⁵)이다.

5. f(x) = x³ − 5x² + 1의 부호를 조사해 근의 위치를 잡는다.
   - f(−1/2) = −1/8 − 5/4 + 1 = −3/8 < 0
   - f(0) = 1 > 0
   - f(1/2) = 1/8 − 5/4 + 1 = −1/8 < 0
   - f(4) = 64 − 80 + 1 = −15 < 0
   - f(5) = 125 − 125 + 1 = 1 > 0

   부호가 바뀌는 구간마다 근이 하나씩 있고, 3차방정식이므로 근은 이것이 전부다.
   −1/2 < γ < 0 < β < 1/2, 4 < α < 5

6. β⁵ + γ⁵의 범위를 구한다.
   - α < 5이므로 β + γ = 5 − α > 0이다. 즉 β > −γ = |γ|이다.
   - 따라서 β⁵ > |γ|⁵이고, β⁵ + γ⁵ = β⁵ − |γ|⁵ > 0이다.
   - 또 γ⁵ < 0이므로 β⁵ + γ⁵ < β⁵ < (1/2)⁵ = 1/32 < 1이다.
   - 정리하면 0 < β⁵ + γ⁵ < 1이다.

7. α⁵ = 3000 − (β⁵ + γ⁵)이므로 2999 < α⁵ < 3000이다.
   따라서 α⁵의 정수 부분은 2999이다.
   (참고: α ≈ 4.96, α⁵ ≈ 2999.99이다.)

**답**: 2999

**일본어 용어**:
- `解と係数の関係(かいとけいすうのかんけい)` — 근과 계수의 관계
- `実数解(じっすうかい)` — 실근
- `整数部分(せいすうぶぶん)` — 정수 부분
- `漸化式(ぜんかしき)` — 점화식 (자막의 "全科式"은 오인식)
- `累乗(るいじょう)` — 거듭제곱
- `符号(ふごう)` — 부호 (자막의 "符合"은 오인식)

**난이도/호시 관련성**: [권장] 문제 전체는 2차 시험형 난문이라 호시약대 마크시트에는 그대로 나오기 어렵다. 다만 근과 계수의 관계로 α² + β² 같은 대칭식을 계산하는 부분(수학Ⅱ)과 pₙ 점화식(수학B)은 단골 소재이므로 3~4번 단계는 익혀 둘 것.
