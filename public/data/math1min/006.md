# #006 삼각형 내부의 점에서 세 변까지 거리의 제곱합 최솟값 (코시-슈바르츠 부등식)

**문제**: AB = 3, BC = 4, CA = 5인 삼각형 ABC의 내부의 점 P에서 변 AB, BC, CA까지의 거리를 각각 x, y, z라 한다. x² + y² + z²의 최솟값을 구하여라.

**발동 신호**: "제곱합(x² + y² + z²)의 최솟값"이 나오고 x, y, z 사이에 **1차식 조건**이 있거나 만들 수 있으면 코시-슈바르츠 부등식을 쓴다.

**핵심 아이디어**: 삼각형을 점 P로 세 조각으로 나눠 넓이를 더하면 숨은 1차 조건 3x + 4y + 5z = 12가 나온다. 이 조건에 계수 (3, 4, 5)와 (x, y, z)를 짝지어 코시-슈바르츠를 쓰면 한 줄로 끝난다.

**풀이**:

1. **삼각형의 모양 확인**
   3² + 4² = 9 + 16 = 25 = 5²이므로 CA가 빗변이고, ∠B = 90°인 직각삼각형이다.
   넓이는 S = (1/2) × 3 × 4 = 6이다.

2. **숨은 조건 만들기 (넓이 분할)**
   점 P와 세 꼭짓점을 이으면 △PAB, △PBC, △PCA로 나뉜다. 각 삼각형의 높이가 x, y, z이므로
   (1/2)·3·x + (1/2)·4·y + (1/2)·5·z = 6
   ∴ **3x + 4y + 5z = 12** (단, x, y, z > 0)

3. **코시-슈바르츠 부등식 적용**
   (a² + b² + c²)(x² + y² + z²) ≥ (ax + by + cz)²에 (a, b, c) = (3, 4, 5)를 넣으면
   (3² + 4² + 5²)(x² + y² + z²) ≥ (3x + 4y + 5z)² = 12² = 144
   3² + 4² + 5² = 9 + 16 + 25 = 50이므로
   x² + y² + z² ≥ 144/50 = **72/25**

4. **등호 성립 조건**
   등호는 x : y : z = 3 : 4 : 5일 때 성립한다. x = 3k, y = 4k, z = 5k로 두고 조건식에 대입하면
   9k + 16k + 25k = 50k = 12 → k = 6/25
   ∴ (x, y, z) = (18/25, 24/25, 30/25) = (18/25, 24/25, 6/5)
   검산: x² + y² + z² = (324 + 576 + 900)/625 = 1800/625 = 72/25 ✓

5. **그런 점 P가 실제로 내부에 있는지 확인** (영상은 결론만 제시)
   좌표를 B(0, 0), C(4, 0), A(0, 3)으로 잡는다.
   - AB는 직선 X = 0이므로, P까지의 거리 x = 18/25이면 P의 X좌표는 18/25이다.
   - BC는 직선 Y = 0이므로, y = 24/25이면 P의 Y좌표는 24/25이다.
   - 따라서 P(18/25, 24/25)이다.
   - CA는 직선 3X + 4Y = 12이다. 3·(18/25) + 4·(24/25) = 54/25 + 96/25 = 6 < 12이므로 P는 이 직선의 B 쪽에 있다.
   - 즉 P는 삼각형 내부에 있다. CA까지의 거리는 (12 − 6)/5 = 6/5 = z로 일치한다 ✓
   - 일반적으로도 x, y, z > 0이고 3x + 4y + 5z = 12를 만족하면, 그런 내부의 점 P가 반드시 하나 존재한다.

6. **참고 (별해 감각)**
   - 공간에서 원점과 평면 3x + 4y + 5z = 12 사이의 거리는 12/√50이다. 그 제곱 144/50 = 72/25가 바로 최솟값이다.
   - 코시-슈바르츠를 쓰기 어려우면 (x − 3k)² + (y − 4k)² + (z − 5k)² ≥ 0을 전개해도 같은 결과가 나온다.
   - 덧붙여, 세 변까지의 거리가 변의 길이에 비례하는 이 점은 르무안 점(symmedian point)이라 불린다.

※ 자막 오타 정정: 公子の不等式 → コーシーの不等式, 一時の条件 → 一次の条件, 統合 → 等号, 変 → 辺. 또 자막의 "最小値72"는 **72/25**가 맞다.

**답**: 최솟값 **72/25** (x : y : z = 3 : 4 : 5, 즉 (x, y, z) = (18/25, 24/25, 6/5)일 때)

**일본어 용어**:
- `コーシー・シュワルツの不等式(こーしー・しゅわるつのふとうしき) — 코시-슈바르츠 부등식`
- `相加相乗平均(そうかそうじょうへいきん) — 산술-기하 평균`
- `等号成立(とうごうせいりつ) — 등호 성립`
- `一次式(いちじしき) — 1차식`
- `辺(へん) — 변`
- `最小値(さいしょうち) — 최솟값`

**난이도/호시 관련성**: [권장] 넓이 분할(수학Ⅰ)과 코시-슈바르츠(수학Ⅱ 式と証明의 단골 증명)만으로 짧게 풀리는 전형적인 패턴이다. 마크시트로도 출제될 수 있는 수준이라 한 번 익혀 둘 가치가 충분하다.
