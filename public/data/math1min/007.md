# #007 세 문자 부등식, k는 얼마까지 커질 수 있나? (차를 잡고 주인공 문자를 정한다)

**문제**: 모든 실수 x, y, z에 대하여

x² + y² + z² ≥ k(xy + yz)

가 성립하도록 하는 실수 k의 최댓값을 구하여라.

**발동 신호**: "모든 실수 x, y, z에 대해 성립하는 부등식"이고 각 문자에 대해 2차식이면, 차를 잡고 한 문자를 주인공으로 하는 2차식으로 보고 판별식을 쓴다.

**핵심 아이디어**: f = (좌변) − (우변)을 먼저 y의 2차식으로 보고 D₁ ≤ 0 조건을 얻는다. 그 조건을 다시 x의 2차식으로 보고 D₂ ≤ 0을 적용한다. 판별식을 두 번 쓰는 구조다.

**풀이**:
1. 차를 잡는다.
   f = x² + y² + z² − k(xy + yz)
   모든 실수 x, y, z에 대해 f ≥ 0이 되는 조건을 구하면 된다.

2. y를 주인공으로 정리한다. y는 xy와 yz 양쪽에 나오므로 y를 고르는 것이 자연스럽다. xy + yz = y(x + z)이므로
   f = y² − k(x + z)·y + (x² + z²)

3. y² 계수가 1 > 0이므로 f는 y에 대해 아래로 볼록이다. 따라서 모든 y에 대해 f ≥ 0일 조건은 D₁ ≤ 0이다.
   D₁ = k²(x + z)² − 4(x² + z²) ≤ 0 (모든 x, z에 대해)

4. D₁을 전개해서 x에 대해 정리한다.
   k²(x² + 2xz + z²) − 4x² − 4z²
   = (k² − 4)x² + 2k²z·x + (k² − 4)z² ≤ 0 (모든 x에 대해)

5. 이 식이 모든 x에서 0 이하가 되려면 x에 대해 위로 볼록이어야 한다.
   - k² − 4 > 0이면 x → ∞일 때 양수가 되므로 불성립이다.
   - k² − 4 = 0이면 식은 2·4·zx = 8zx (부호까지 쓰면 ±8zx) ≤ 0이 된다. 예를 들어 z = 1, x = 1이면 8 > 0이므로 불성립이다.
   - 따라서 k² − 4 < 0, 즉 k² < 4이다.

6. 위로 볼록일 때 모든 x에서 0 이하가 될 조건은 D₂ ≤ 0이다.
   D₂/4 = (k²z)² − (k² − 4)·(k² − 4)z²
   = k⁴z² − (k⁴ − 8k² + 16)z²
   = (8k² − 16)z²
   = 8(k² − 2)z² ≤ 0 (모든 z에 대해)
   z² ≥ 0이고 z ≠ 0인 경우도 있으므로 k² − 2 ≤ 0, 즉 k² ≤ 2이다.

7. 두 조건 k² < 4와 k² ≤ 2를 합치면 k² ≤ 2이다.
   −√2 ≤ k ≤ √2

8. 검산 (등호 성립):
   - k = √2, x = z = 1, y = √2를 대입한다. 좌변은 1 + 2 + 1 = 4이고, 우변은 √2·(√2 + √2) = √2·2√2 = 4이다. 등호가 성립한다.
   - 이 점에서 k > √2이면 우변이 2√2·k > 4가 되어 부등식이 깨진다. 따라서 √2보다 큰 k는 불가능하다.
   - k = √2일 때는 완전제곱으로 바로 확인할 수 있다.
     x² + y² + z² − √2·y(x + z) = (x − y/√2)² + (z − y/√2)² ≥ 0
     전개하면 x² − √2xy + y²/2 + z² − √2yz + y²/2가 되어 일치한다.

**답**: k의 최댓값은 √2 (등호는 x = z = 1, y = √2일 때)

**일본어 용어**:
- `判別式(はんべつしき) — 판별식`
- `主役(しゅやく) — 주인공 (주 변수로 삼는 문자)`
- `下に凸(したにとつ) — 아래로 볼록`
- `上に凸(うえにとつ) — 위로 볼록`
- `係数(けいすう) — 계수`
- `等号(とうごう) — 등호`

**난이도/호시 관련성**: [권장] 2차함수와 판별식(수학Ⅰ), 부등식 증명(수학Ⅱ) 범위 안의 기술이지만, 판별식을 두 번 쓰는 구조는 호시약대 마크시트에서는 드문 난이도다. 판별식을 쓰기 전에 최고차 계수의 부호와 계수가 0인 경우를 확인하는 습관을 익히는 용도로 보면 된다.
