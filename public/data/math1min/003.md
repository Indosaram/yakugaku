# #003 x²⁰²⁵를 (x²+x+1)²로 나눈 나머지: 나머지 정리와 차수 낮추기

**문제**: 정식 x²⁰²⁵를 (x² + x + 1)²으로 나눈 나머지를 구하여라.

**발동 신호**: 큰 거듭제곱을 (2차식)² 같은 식으로 나눈 나머지를 묻는다. 나누는 식과 잘 맞는 식(여기서는 x³ − 1)을 찾는다.

**핵심 아이디어**: x³ − 1 = (x − 1)(x² + x + 1)이므로 t = x³ − 1로 두면 t²은 (x² + x + 1)²으로 나누어떨어진다. x²⁰²⁵ = (1 + t)⁶⁷⁵를 이항정리로 전개하면 t² 이상의 항이 전부 사라진다.

**풀이**:
1. 나누는 식이 4차식이므로 나머지 R(x)는 3차 이하이다. 즉 x²⁰²⁵ = (x² + x + 1)²·Q(x) + R(x), deg R ≤ 3이다.
2. t = x³ − 1로 둔다. 인수분해하면 t = (x − 1)(x² + x + 1)이다. 따라서 t² = (x − 1)²(x² + x + 1)²이 되어 t²은 (x² + x + 1)²으로 나누어떨어진다.
3. 2025 = 3 × 675이므로 x²⁰²⁵ = (x³)⁶⁷⁵ = (1 + t)⁶⁷⁵이다.
4. 이항정리로 전개한다.
   (1 + t)⁶⁷⁵ = 1 + ₆₇₅C₁·t + ₆₇₅C₂·t² + … + t⁶⁷⁵
   = 1 + 675t + t²·(₆₇₅C₂ + ₆₇₅C₃·t + … + t⁶⁷³)
5. t²·(…) 부분은 (x² + x + 1)²의 배수이므로 나머지에 영향이 없다. 남는 것은 1 + 675t이다.
6. t를 되돌린다.
   1 + 675(x³ − 1) = 675x³ − 675 + 1 = 675x³ − 674
   이 식은 3차식으로, 차수가 4보다 작다. 따라서 이것이 그대로 나머지이다.
7. 검산 ① (값 일치): ω를 x² + x + 1 = 0의 근으로 두면 ω³ = 1이다.
   - 좌변: ω²⁰²⁵ = (ω³)⁶⁷⁵ = 1
   - 우변: 675ω³ − 674 = 675 − 674 = 1
   - 두 값이 일치한다.
8. 검산 ② (영상에서 생략된 부분): 나누는 식이 제곱 형태라서 ω는 중근이다. 따라서 도함수 값도 일치해야 완전한 검산이 된다.
   - (x²⁰²⁵)′ = 2025x²⁰²⁴이다. 2024 = 3·674 + 2이므로 x = ω에서 2025ω²이다.
   - (675x³ − 674)′ = 2025x²이므로 x = ω에서 2025ω²이다.
   - 두 값이 일치한다. ω 대신 ω²(다른 근)를 넣어도 같은 방식으로 일치한다.

**답**: 675x³ − 674

**일본어 용어**:
- `整式(せいしき) — 정식(다항식)`
- `余り(あまり) — 나머지`
- `剰余の定理(じょうよのていり) — 나머지 정리`
- `次数下げ(じすうさげ) — 차수 낮추기`
- `割り切れる(わりきれる) — 나누어떨어지다`
- `二項定理(にこうていり) — 이항정리`

**난이도/호시 관련성**: [권장] 수학Ⅱ(나머지 정리·이항정리·ω) 범위 안의 문제이다. 호시약대 마크시트에 (2차식)²으로 나누는 형태가 그대로 나올 일은 드물다. 다만 "x³ = 1 + t로 두고 전개" 및 "ω³ = 1로 차수 낮추기"는 빈출 도구이므로 익혀 둘 가치가 있다.
