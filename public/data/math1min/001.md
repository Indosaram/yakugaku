# #001 x⁵+y⁵+z⁵의 최댓값: 대칭식은 기본대칭식으로 바꿔라

**문제**: 세 실수 x, y, z가 x + y + z = 0, x² + y² + z² = 6을 만족할 때, x⁵ + y⁵ + z⁵의 최댓값을 구하라.

**발동 신호**: 조건과 구하는 식이 모두 x, y, z를 서로 바꿔도 변하지 않는 **대칭식**이다.

**핵심 아이디어**: 기본대칭식 (합, 두 개씩 곱의 합, 세 개의 곱 = k)으로 바꾸면 x, y, z는 3차방정식 u³ − 3u − k = 0의 세 근이 된다. 이 식으로 u⁵의 차수를 낮춰 합을 k의 1차식으로 만든다. 그다음 "세 근이 모두 실수"라는 조건으로 k의 범위를 구한다.

**풀이**:

1. **기본대칭식 구하기**
   - x + y + z = 0
   - xy + yz + zx = {(x+y+z)² − (x²+y²+z²)} / 2 = (0² − 6) / 2 = −3
   - xyz = k로 둔다.

2. **3차방정식 만들기** (근과 계수의 관계)
   - x, y, z를 근으로 하는 3차방정식은 u³ − (합)u² + (두 개씩 곱의 합)u − (세 개의 곱) = 0이다.
   - 값을 넣으면 u³ − 0·u² − 3u − k = 0, 즉 **u³ − 3u − k = 0**이다.
   - 따라서 u = x, y, z 각각에 대해 **u³ = 3u + k**가 성립한다.

3. **차수 낮추기** (u⁵를 2차식으로)
   - u⁵ = u²·u³ = u²(3u + k) = 3u³ + ku²
   - 여기에 u³ = 3u + k를 다시 대입하면 3(3u + k) + ku² = **ku² + 9u + 3k**이다.

4. **x, y, z에 대해 더하기**
   - x⁵ + y⁵ + z⁵ = k(x² + y² + z²) + 9(x + y + z) + 3k × 3
   - 값을 넣으면 k·6 + 9·0 + 9k = **15k**이다.
   - 이제 k의 범위만 알면 된다.

5. **k의 범위** (세 근이 모두 실수일 조건)
   - u³ − 3u = k로 바꿔 쓴다. 곡선 y = u³ − 3u와 수평선 y = k가 (중근 포함) 3번 만나야 한다.
   - f(u) = u³ − 3u이면 f′(u) = 3u² − 3 = 3(u + 1)(u − 1)이다.
   - u = −1일 때 극댓값 f(−1) = −1 + 3 = 2이다.
   - u = 1일 때 극솟값 f(1) = 1 − 3 = −2이다.
   - 따라서 **−2 ≤ k ≤ 2**이다.
   - 역으로 이 범위의 k에 대해 세 실근 x, y, z를 잡으면 근과 계수의 관계로 두 조건이 그대로 성립하므로, k는 이 범위 전체를 실제로 취할 수 있다.

6. **최댓값과 등호 확인**
   - 15k ≤ 15 × 2 = 30이다.
   - k = 2일 때 u³ − 3u − 2 = (u + 1)²(u − 2) = 0이므로 (x, y, z) = (2, −1, −1)과 그 순서를 바꾼 것들이다.
   - 조건 검산: 2 − 1 − 1 = 0, 4 + 1 + 1 = 6으로 둘 다 성립한다.
   - 값 검산: 2⁵ + (−1)⁵ + (−1)⁵ = 32 − 1 − 1 = 30이다.
   - (참고: 최솟값은 k = −2일 때 −30이다.)

**답**: 최댓값 30 ((x, y, z) = (2, −1, −1) 및 그 순서를 바꾼 것일 때)
