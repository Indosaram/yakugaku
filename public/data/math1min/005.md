# #005 xᵃ = aˣ의 양의 해는 몇 개? (상수 분리)

**문제**: a를 양의 상수로 한다. x에 관한 방정식 xᵃ = aˣ 의 양의 해의 개수를 구하여라.

**발동 신호**: "상수 a를 포함한 방정식의 해의 개수"를 묻는다 → 상수를 한쪽으로 모으고 그래프와 가로선의 교점을 센다.

**핵심 아이디어**: 양변에 로그를 취하고 ax로 나누면 좌우가 완전히 같은 꼴 (log x)/x = (log a)/a 가 된다. f(x) = (log x)/x 로 두면 f(x) = f(a)이다. 따라서 y = f(x)와 가로선 y = f(a)의 교점 개수를 세면 된다. (log는 자연로그 ln)

**풀이**:
1. x > 0, a > 0이므로 양변이 모두 양수이다. 따라서 양변에 자연로그를 취할 수 있다.
   a·log x = x·log a
2. 양변을 ax (> 0)로 나누면 다음과 같다.
   (log x)/x = (log a)/a
   f(x) = (log x)/x (x > 0)로 두면 방정식은 f(x) = f(a)이다. 즉 곡선 y = f(x)와 가로선 y = f(a)의 교점 개수가 곧 해의 개수이다.
3. 미분한다.
   f′(x) = { (1/x)·x − log x·1 } / x² = (1 − log x)/x²
   - 0 < x < e 이면 log x < 1이므로 f′ > 0이고, f는 증가한다.
   - x > e 이면 f′ < 0이고, f는 감소한다.
   - 따라서 최댓값은 f(e) = 1/e 이다.
4. 그래프의 주요 값과 극한을 확인한다.
   - f(1) = 0 이다. 0 < x < 1이면 f < 0이고, x > 1이면 f > 0이다.
   - x → +0 일 때 log x → −∞이고 1/x → +∞이므로 f(x) → −∞이다.
   - x → ∞ 일 때 (log x)/x → 0이다. 이때 f는 항상 양수이므로 0에 위에서 접근한다.
   - 정리하면 그래프는 (0, e)에서 −∞부터 1/e까지 증가하고, (e, ∞)에서 1/e부터 0을 향해 감소한다. 이 구간에서 f는 양수를 유지한다.
5. 가로선의 높이 f(a)에 따라 경우를 나눈다. x = a는 항상 해이다.
   - **0 < a ≤ 1**: f(a) ≤ 0이다. (0, e)의 증가 구간에서 교점이 1개 생긴다. (e, ∞)에서는 f > 0이므로 교점이 없다. 따라서 **1개**(x = a)이다.
   - **a = e**: f(a) = 1/e 로 최댓값이다. 가로선이 꼭짓점에서 접하므로 **1개**(x = e)이다.
   - **1 < a < e 또는 a > e**: 0 < f(a) < 1/e 이다. 교점은 (1, e)에서 1개, (e, ∞)에서 1개 생긴다. 따라서 **2개**이다.
6. 검산 예시로 a = 2를 넣어 본다.
   - f(2) = (log 2)/2 이다.
   - f(4) = (log 4)/4 = (2 log 2)/4 = (log 2)/2 이다.
   - 따라서 x = 2, 4가 해이다. 실제로 2⁴ = 4² = 16 이다.

**답**:
- 0 < a ≤ 1 또는 a = e 일 때: 1개
- 1 < a < e 또는 a > e 일 때: 2개

**일본어 용어**:
- `定数分離(ていすうぶんり) — 상수 분리`
- `対数(たいすう) — 로그`
- `両辺(りょうへん) — 양변`
- `交点(こうてん) — 교점`
- `最大値(さいだいち) — 최댓값`
- `場合分け(ばあいわけ) — 경우 나누기`

**난이도/호시 관련성**: (log x)/x의 미분과 극한은 수학Ⅲ 내용이라 호시약대 범위(수학Ⅰ·A·Ⅱ·B) 밖이다. 다만 "상수 분리 → 가로선 교점" 발상은 수학Ⅱ의 삼차함수 문제에서도 쓰인다. [패스]
