# 제5문 (20점, 석유 분류·나일론 6 합성·바나듐 화합물: 산화수·나프탈렌 산화·헤스 법칙·EDTA 정량)
원유(原油) 분류(分留)로 얻는 유출물을 소재로 한 융합형 대문항이다. 석유 분류 순서, 벤젠에서 나일론 6까지의 합성 경로, 원유 속 바나듐(V)의 산화수·촉매 반응·생성 엔탈피 계산·EDTA 정량을 묻는다.

## 問1 — 원유 분류탑의 유출물 순서 `[권장]`
- 호시 기출에서 석유 분류가 직접 나온 흔적은 거의 없다. 하지만 끓는점과 탄소 수의 관계를 아는 기초 상식이라 30초 안에 풀 수 있어야 한다.

**문제 요약**: 분류탑(分留塔/精留塔)에서 원유를 분류하면 석유가스(〜30 ℃)와 중유(重油, 残油, 350 ℃〜) 외에 유출물 A(30〜180 ℃), B(180〜250 ℃), C(250〜350 ℃)가 얻어진다. A〜C의 올바른 조합을 고르는 문제다.

| 번호 | A | B | C |
|---|---|---|---|
| ① | 등유(灯油) | 나프타(ナフサ, 粗製ガソリン) | 경유(軽油) |
| ② | 등유 | 경유 | 나프타 |
| ③ | 나프타 | 등유 | 경유 |
| ④ | 나프타 | 경유 | 등유 |
| ⑤ | 경유 | 나프타 | 등유 |
| ⑥ | 경유 | 등유 | 나프타 |

**정답**: 해답번호 29 = ③

**풀이**:
1. 탄소 수가 많을수록 분자간력(반데르발스 힘)이 커져서 끓는점이 높아진다.
2. 탄소 수 순서는 석유가스(C₁〜C₄) < 나프타(C₅〜C₁₀ 정도) < 등유(C₁₀〜C₁₅ 정도) < 경유(C₁₅〜C₂₀ 정도) < 중유다.
3. 따라서 A(30〜180 ℃)는 나프타, B(180〜250 ℃)는 등유, C(250〜350 ℃)는 경유이므로 ③이다.

**포인트**: 끓는점이 낮은 순서는 **석유가스 → 나프타(가솔린) → 등유 → 경유 → 중유**다. 분류탑에서는 위로 갈수록 끓는점이 낮은 성분이 나온다.

## 問2 — 벤젠 → 시클로헥산 → … → 나일론 6 `[권장]`
- 합성고분자는 호시 기출에 2회 나온 저빈도 단원이다. 다만 나일론 6과 나일론 66의 구별은 고분자 기본 중의 기본이다.

**문제 요약**: 벤젠에 Pt 또는 Ni 촉매로 고온·고압에서 H₂를 반응시키면 화합물 D가 된다. D를 산화하면 시클로헥사논, 여기에 히드록실아민(ヒドロキシルアミン)과 산 촉매를 쓰면 ε-카프로락탐이 된다. 이를 물과 함께 가열해 개환중합(開環重合)하면 화합물 E가 된다. D와 E의 조합을 고르는 문제다.
- ①〜③: D는 C=C가 2개 남은 시클로헥사디엔, ④〜⑥: D는 시클로헥산이다.
- E 후보: ①④는 –[CO–(CH₂)₅–NH]ₙ–, ②⑤는 –[CO–(CH₂)₄–CO–NH–(CH₂)₆–NH]ₙ– (나일론 66), ③⑥은 –[CO–(CH₂)₆–NH]ₙ–이다.

**정답**: 해답번호 30 = ④

**풀이**:
1. 벤젠에 Pt/Ni 촉매로 고온·고압에서 H₂를 첨가하면 3분자가 완전히 부가된다. C₆H₆ + 3H₂ → C₆H₁₂(시클로헥산)이므로 D는 시클로헥산이다. 시클로헥사디엔(①〜③)은 산화 후 시클로헥사논(포화 고리)으로 이어지지 않는다.
2. ε-카프로락탐은 고리 안에 C=O 탄소 1개, CH₂ 5개, N 1개를 가진 7원환 아미드다.
3. 개환하면 –CO–(CH₂)₅–NH– 단위가 반복되는 나일론 6이 된다.
4. (CH₂)₆인 ③⑥은 탄소 수가 맞지 않는다. ②⑤는 아디프산과 헥사메틸렌디아민의 축합중합으로 만드는 나일론 66이다.
5. 따라서 답은 ④(시클로헥산 + 나일론 6)이다.

**포인트**: 나일론 6은 ε-카프로락탐의 **개환중합**으로 만들고 반복단위는 –CO(CH₂)₅NH–다. 나일론 66은 아디프산 + 헥사메틸렌디아민의 **축합중합**으로 만든다.

## 問3a — VO²⁺ 중 V의 산화수 `[필수]`
- 산화수 계산은 산화환원 단원의 기본으로, 호시 1번·산화환원 문제의 단골이다.

**문제 요약**: 원유 속 V는 주로 옥시도바나듐 이온(オキシドバナジウムイオン) VO²⁺로 존재한다. V의 산화수를 고르는 문제다. ① +1 ② +2 ③ +3 ④ +4 ⑤ +5 ⑥ 0

**정답**: 해답번호 31 = ④

**풀이**: V의 산화수를 x로 두면 x + (−2) = +2이므로 x = **+4**다.

**포인트**: 이온 전체 전하는 각 원자 산화수의 합과 같다. 참고로 V₂O₅의 V는 +5, V₂O₃의 V는 +3이다.

## 問3b — V₂O₅ 촉매로 나프탈렌 산화 `[필수]`
- 방향족 단원(호시 7회)에서 무수프탈산 제법은 교과서 수준의 반응이다. 살리실산·프탈산 계열과 함께 반드시 알아둬야 한다.

**문제 요약**: V₂O₅를 촉매로 나프탈렌을 산화했을 때의 생성물을 고르는 문제다.
- ① 무수프탈산(無水フタル酸)
- ② 쿠마린(벤젠고리 + 락톤 고리)
- ③ 카테콜(o-디히드록시벤젠)
- ④ 히드로퀴논(p-디히드록시벤젠)
- ⑤ 무수말레산(無水マレイン酸)

**정답**: 해답번호 32 = ①

**풀이**:
1. 나프탈렌을 V₂O₅ 촉매로 공기 산화하면 한쪽 벤젠고리가 끊어진다.
2. 끊어진 고리의 두 탄소가 카르복시기가 되고, 이것이 곧바로 탈수되어 **무수프탈산**이 된다.
3. 나머지 선택지는 이 반응의 생성물이 아니다.
   - ②: 쿠마린 골격으로, 이 반응에서 생기지 않는다.
   - ③④: 고리가 끊어지지 않고 OH만 붙은 페놀류라서 틀리다.
   - ⑤: 무수말레산은 **벤젠**(또는 부탄)을 V₂O₅로 산화할 때 생기는 생성물이다.

**포인트**: V₂O₅ 촉매 산화는 두 가지를 짝으로 외운다. **나프탈렌 → 무수프탈산**, **벤젠 → 무수말레산**. o-자일렌을 산화해도 프탈산(무수프탈산)이 된다.

## 問3c — 헤스 법칙으로 두 경로의 반응 엔탈피 비교 `[권장]`
- 엔탈피는 호시 저빈도 단원이다. 다만 생성 엔탈피로 반응 엔탈피를 구하는 계산은 기본이고, 계산기 없이도 쉬운 숫자다.

**문제 요약**: V₂O₅ 1 mol을 기준으로 두 경로를 비교한다.
- 경로 Ⅰ: (1) V₂O₅ + 5Ca → 2V + 5CaO
- 경로 Ⅱ: (2) V₂O₅ + 2H₂ → V₂O₃ + 2H₂O(액)를 거친 뒤 (3) V₂O₃ + 3Ca → 2V + 3CaO

경로 Ⅰ의 반응 엔탈피 ΔH_Ⅰ과, 경로 Ⅱ의 두 반응 엔탈피 합 ΔH_Ⅱ의 대소 관계를 고르는 문제다(①〜⑨). 단체의 생성 엔탈피는 0이다.

| 물질 | 생성 엔탈피(kJ/mol) |
|---|---|
| V₂O₅(고) | −1550 |
| V₂O₃(고) | −1220 |
| CaO(고) | −636 |
| H₂O(액) | −286 |

선택지: ① ΔH_Ⅰ < ΔH_Ⅱ < 0 ② ΔH_Ⅰ < 0 < ΔH_Ⅱ ③ 0 < ΔH_Ⅰ < ΔH_Ⅱ ④ ΔH_Ⅱ < ΔH_Ⅰ < 0 ⑤ ΔH_Ⅱ < 0 < ΔH_Ⅰ ⑥ 0 < ΔH_Ⅱ < ΔH_Ⅰ ⑦ ΔH_Ⅰ = ΔH_Ⅱ < 0 ⑧ 0 < ΔH_Ⅰ = ΔH_Ⅱ ⑨ 0 = ΔH_Ⅰ = ΔH_Ⅱ

**정답**: 해답번호 33 = ①

**풀이**: 반응 엔탈피 = (생성물의 생성 엔탈피 합) − (반응물의 생성 엔탈피 합)
1. 경로 Ⅰ: ΔH_Ⅰ = 5(−636) − (−1550) = −3180 + 1550 = **−1630 kJ**
2. 경로 Ⅱ의 각 반응:
   - 식(2): (−1220) + 2(−286) − (−1550) = −1220 − 572 + 1550 = −242 kJ
   - 식(3): 3(−636) − (−1220) = −1908 + 1220 = −688 kJ
3. 합하면 ΔH_Ⅱ = −242 + (−688) = **−930 kJ**
4. 따라서 −1630 < −930 < 0, 즉 ΔH_Ⅰ < ΔH_Ⅱ < 0이므로 ①이다.

※ 출발 물질과 최종 생성물이 같은데 ΔH가 다른 이유는 부생성물이 다르기 때문이다. 경로 Ⅱ는 CaO 2 mol 대신 H₂O 2 mol을 만든다. 실제로 ΔH_Ⅰ − ΔH_Ⅱ = 2(−636) − 2(−286) = −700 kJ로 계산 결과와 일치한다. 그래서 "헤스 법칙이니 같다"(⑦)는 함정이다.

**포인트**: 헤스 법칙은 **처음과 끝 상태(부생성물 포함)가 완전히 같을 때만** 경로에 무관하다. 계산은 ΔH = Σ(생성물 ΔfH) − Σ(반응물 ΔfH)이고, 단체의 ΔfH는 0이다.

## 問3d — EDTA 1:1 적정으로 V 정량 `[권장]`
- EDTA 킬레이트 적정 자체는 호시 범위 밖이다. 하지만 1:1 몰비, 분취(10/250) 환산, 질량 계산은 중화·산화환원 적정과 같은 구조라서 연습 가치가 있다.

**문제 요약**: VO²⁺와 EDTA는 1:1로 반응해 VO–EDTA를 만든다. 연소재 1.00 g 속의 V를 모두 VO²⁺로 바꿔 250 mL 수용액을 만들었다. 그중 10.0 mL에 1.00×10⁻² mol/L EDTA 4.00 mL를 넣으니 과부족 없이 반응했다. 연소재 1.00 g 속 V의 질량(g)을 구하는 문제다.
- 선택지: ① 8.16×10⁻⁵ ② 2.04×10⁻³ ③ 5.10×10⁻² ④ 8.16×10⁻² ⑤ 2.04×10⁻¹ ⑥ 5.10×10⁻¹

**정답**: 해답번호 34 = ③

**풀이**:
1. 반응한 EDTA의 몰수: 1.00×10⁻² mol/L × 4.00×10⁻³ L = 4.00×10⁻⁵ mol. 1:1 반응이므로 10.0 mL 속 VO²⁺도 4.00×10⁻⁵ mol이다.
2. 전체 250 mL로 환산: 4.00×10⁻⁵ × (250 / 10.0) = 1.00×10⁻³ mol
3. V의 질량(V = 51): 1.00×10⁻³ × 51 = **5.10×10⁻² g**

**포인트**: 적정 계산의 기본 흐름은 **적정 몰수 → 몰비 → 분취 비율로 전체 환산 → 몰질량을 곱함**이다. ①은 분취 환산을 빼먹은 값(4.00×10⁻⁵ × 51 = 2.04×10⁻³은 ②)처럼 실수를 노린 선택지가 섞여 있으니 단계를 빠짐없이 밟자.
