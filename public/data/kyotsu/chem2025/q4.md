# 제4문 (20점, 산소 포함 유기화합물·질소 유기화합물·천연고분자·합성고분자)
알코올·페놀·케톤의 기본 반응, 구조 추론(아크릴산메틸 + 아닐린), 당·아미노산·단백질 정오, 아세틸렌의 성질과 비닐론·폴리비닐부티랄 합성을 묻는다. 후반부에는 아세탈화 비율 계산이 있다.

## 問1 — 산소를 포함한 유기화합물의 반응 정오 `[필수]`
- 이유: Na 반응, 요오드포름 반응, 페놀의 산성, 에스테르화는 호시 유기 구조결정에서 매회 쓰는 판단 도구다.

**문제 요약**: 산소를 포함한 유기화합물의 반응에 관한 설명 중 **틀린 것(誤りを含むもの)**을 고른다.
- ① 에틸렌글리콜(1,2-에탄디올)에 나트륨을 넣으면 수소가 발생한다.
- ② 묽은 페놀 수용액에 소량의 탄산수소나트륨(炭酸水素ナトリウム) 수용액을 넣으면 이산화탄소가 발생한다.
- ③ 에탄올의 분자간 탈수 반응(分子間の脱水反応)으로 디에틸에테르가 생성된다.
- ④ 아세톤에 요오드와 NaOH 수용액을 넣어 반응시키면 요오드포름(ヨードホルム)이 생성된다.
- ⑤ 무수아세트산과 페놀을 반응시키면 아세트산페닐(酢酸フェニル)이 생성된다.

**정답**: 해답번호 21 = ②

**풀이**:
- ① 옳다. –OH를 가진 화합물은 Na과 반응해 H₂를 낸다. HOCH₂CH₂OH + 2Na → NaOCH₂CH₂ONa + H₂
- ② **틀렸다.** 산의 세기는 카르복실산 > 탄산(H₂O + CO₂) > 페놀 순이다. 페놀은 탄산보다 약한 산이라 NaHCO₃에서 CO₂를 빼앗지 못하므로 CO₂가 발생하지 않는다. NaHCO₃와 반응해 CO₂를 내는 것은 카르복실산이다.
- ③ 옳다. 진한 황산과 함께 약 130∼140 ℃로 가열하면 분자간 탈수가 일어난다. 2C₂H₅OH → C₂H₅OC₂H₅ + H₂O. 참고로 160∼170 ℃에서는 분자내 탈수로 에틸렌이 생긴다.
- ④ 옳다. 아세톤은 CH₃CO– 구조를 가지므로 요오드포름 반응 양성이다. CHI₃가 노란색 침전으로 생긴다.
- ⑤ 옳다. 페놀은 아세트산과는 직접 잘 에스테르화되지 않는다. 대신 무수아세트산으로 아세틸화하면 아세트산페닐 C₆H₅OCOCH₃이 생긴다.

**포인트**:
- 산의 세기는 술폰산 > 카르복실산 > 탄산 > 페놀 순이다. NaHCO₃로 CO₂가 나오면 카르복실산이다(추출 분리의 핵심).
- 요오드포름 반응 양성은 CH₃CO– 또는 CH₃CH(OH)– 구조다.
- 에탄올 탈수는 130∼140 ℃에서 에테르, 160∼170 ℃에서 에틸렌이 생긴다.

## 問2 — 아크릴산메틸 + 아닐린 생성물의 구조 추론 `[권장]`
- 이유: 반응 자체(마이클 부가)는 교과서 밖이지만, 조건(작용기·부제탄소·분자량)으로 소거하는 방식은 호시 구조결정과 같다.

**문제 요약**: 아크릴산메틸(분자량 86.0)과 아닐린(분자량 93.0)이 촉매 아래 반응해 화합물 A가 생성되었다. A는 다음 조건을 모두 만족한다. A의 구조를 ①∼⑥에서 고른다.
- Ⅰ. 에스테르 결합(エステル結合)을 가진다.
- Ⅱ. 부제탄소 원자(不斉炭素原子)를 가지지 않는다.
- Ⅲ. 분자량이 179.0이다.

**정답**: 해답번호 22 = ⑤

**풀이**:
1. 분자량을 먼저 본다. 86.0 + 93.0 = 179.0이므로 A는 두 분자가 **그대로 합쳐진 부가 생성물**이다. 탈수나 메탄올 이탈은 없다.
2. 선택지를 조건으로 확인한다.

| 선택지 | 구조 | 분자식 / 분자량 | 판정 |
|---|---|---|---|
| ① | C₆H₅NH–CH=CH–COOCH₃ | C₁₀H₁₁NO₂ = 177 | Ⅲ 불충족 |
| ② | CH₂=C(NHC₆H₅)–COOCH₃ | C₁₀H₁₁NO₂ = 177 | Ⅲ 불충족 |
| ③ | CH₃CH₂CH(NHC₆H₅)COOH | 카르복실산 | 에스테르 없음, Ⅰ 불충족 (부제탄소도 있음) |
| ④ | CH₃CH₂CONHC₆H₅ | C₉H₁₁NO = 149, 아미드 | Ⅰ·Ⅲ 불충족 |
| ⑤ | C₆H₅NH–CH₂CH₂–COOCH₃ | C₁₀H₁₃NO₂ = 179 | **Ⅰ·Ⅱ·Ⅲ 모두 충족** |
| ⑥ | CH₃CH(NHC₆H₅)COOCH₃ | C₁₀H₁₃NO₂ = 179 | 부제탄소 있음, Ⅱ 불충족 |

3. 분자량 확인: ⑤ C₁₀H₁₃NO₂ = 12×10 + 1×13 + 14 + 16×2 = 179
4. 해석: 아닐린의 N–H가 C=C에 부가했다. N이 말단 CH₂ 쪽에 붙으면 ⑤, 가운데 CH 쪽에 붙으면 ⑥이다. 조건 Ⅱ가 이 둘을 구별해 준다.

**포인트**:
- 생성물 분자량이 반응물 분자량의 합과 같으면 부가 반응이고, 18 작으면 탈수 축합이다.
- 부제탄소는 서로 다른 4개의 원자·원자단이 결합한 탄소다. 위치 이성체를 구분할 때 자주 쓰인다.

## 問3 — 천연 화합물(단백질·아미노산·당) 정오 `[필수]`
- 이유: 아미노산(5회)과 당류(4회)는 호시의 반복 출제 단원이다. 단당류의 이성질 관계는 기본 지식이다.

**문제 요약**: 천연 화합물에 관한 설명 중 **틀린 것**을 고른다.
- ① 단백질의 폴리펩타이드 사슬은 펩타이드 결합끼리의 수소결합으로 2차 구조(二次構造)를 만든다.
- ② 아미노산은 결정 속에서 쌍성이온(双性イオン)으로 존재한다.
- ③ 글루코스는 수용액 속에서 고리형 2종과 사슬형 1종, 합계 3종이 평형으로 존재한다.
- ④ 프럭토스는 글루코스의 입체이성체(立体異性体)이다.

**정답**: 해답번호 23 = ④

**풀이**:
- ① 옳다. 펩타이드 결합의 C=O와 N–H 사이의 수소결합으로 α-나선과 β-시트(2차 구조)가 만들어진다.
- ② 옳다. 결정 속에서는 H₃N⁺–CHR–COO⁻ 형태다. 그래서 이온 결정처럼 녹는점이 높고 물에 잘 녹는다.
- ③ 옳다. α-글루코스, β-글루코스(고리형 2종)와 사슬형(알데히드기 –CHO 보유)이 평형을 이룬다. 사슬형 때문에 환원성을 보인다.
- ④ **틀렸다.** 둘 다 C₆H₁₂O₆이지만, 글루코스는 알도스(–CHO)이고 프럭토스는 케토스(C=O)다. 원자의 결합 순서가 다르므로 **구조이성체(構造異性体)**다. 입체이성체는 결합 순서는 같고 공간 배치만 다른 것이다.

**포인트**:
- 글루코스와 프럭토스는 구조이성체, 글루코스와 갈락토스는 입체이성체다.
- 단백질 구조: 1차는 아미노산 배열, 2차는 펩타이드 결합 간 수소결합(α-나선, β-시트), 3차는 S–S 결합 등이 관여한다.

## 問4a — 아세틸렌의 성질 정오 `[권장]`
- 이유: 알킨 반응은 유기 기초로 알아둘 가치가 있다. 다만 호시에서는 구조결정 속 보조 지식 수준으로만 나온다.

**문제 요약**: 아세틸렌에 관한 설명 중 **틀린 것**을 고른다.
- ① 탄화칼슘(칼슘카바이드)에 물을 가하면 발생한다.
- ② 산소를 충분히 공급해 완전연소시킨 불꽃은 금속의 절단·용접에 쓰일 만큼 고온이다.
- ③ 물을 부가시키면 아세트알데히드가 생성된다.
- ④ 시안화수소 HCN을 부가시키면 섬유 원료인 단량체(モノマー)가 얻어진다.
- ⑤ 아세틸렌이 중합한 폴리아세틸렌은 삼중결합과 단일결합이 교대로 탄소를 연결한 고분자다.

**정답**: 해답번호 24 = ⑤

**풀이**:
- ① 옳다. CaC₂ + 2H₂O → Ca(OH)₂ + C₂H₂
- ② 옳다. 산소-아세틸렌 불꽃은 약 3000 ℃에 이르며 용접·절단에 쓰인다.
- ③ 옳다. HC≡CH + H₂O → [CH₂=CH–OH(비닐알코올)] → CH₃CHO. 비닐알코올은 불안정해서 곧바로 아세트알데히드로 이성화한다.
- ④ 옳다. HC≡CH + HCN → CH₂=CH–CN(아크릴로니트릴). 아크릴 섬유의 원료다.
- ⑤ **틀렸다.** 삼중결합 하나가 중합에 쓰이므로 폴리아세틸렌은 –CH=CH–CH=CH–처럼 **이중결합과 단일결합이 교대**하는 구조다. 이 공액 구조에 요오드 등을 첨가하면 전기가 통한다(시라카와 히데키, 도전성 고분자).

**포인트**:
- 아세틸렌 부가 생성물: H₂O는 아세트알데히드, HCl은 염화비닐, CH₃COOH는 아세트산비닐, HCN은 아크릴로니트릴이다.
- 폴리아세틸렌은 이중결합과 단일결합이 교대하는 도전성 고분자다.

## 問4b — 비닐론 합성 경로 `[권장]`
- 이유: 합성고분자는 저빈도(2회)지만 비닐론은 호시 기출에 실제로 나온 소재다. 합성 경로는 통째로 암기한다.

**문제 요약**: 아세틸렌에 아세트산을 부가해 아세트산비닐을 만들고, 반응 ア로 화합물 B를 만든 뒤, 반응 イ로 폴리비닐알코올(PVA)을 얻는다. PVA를 HCHO로 아세탈화(アセタール化)하면 비닐론이 된다. 반응 ア, 반응 イ, 화합물 B를 고른다.
- 반응 선택지: ① 가수분해(加水分解), ② 산화, ③ 환원, ④ 공중합(共重合), ⑤ 축합중합(縮合重合), ⑥ 부가중합(付加重合)
- 구조 선택지: ⑦ [–CH=C(OH)–]ₙ, ⑧ [–CH=C(OCOCH₃)–]ₙ, ⑨ [–CH₂–CH(OCOCH₃)–]ₙ, ⓪ CH₂=CH–OH

**정답**: 해답번호 25 = ⑥, 26 = ①, 27 = ⑨

**풀이**:
1. **반응 ア = 부가중합(⑥)**: 아세트산비닐 CH₂=CH–OCOCH₃의 C=C가 열리면서 이어져 폴리아세트산비닐이 된다.
2. **화합물 B = 폴리아세트산비닐(⑨)**: [–CH₂–CH(OCOCH₃)–]ₙ. 주쇄에 이중결합이 남는 ⑦·⑧은 틀린 구조다.
3. **반응 イ = 가수분해(①)**: NaOH로 에스테르를 비누화(けん化)하여 –OCOCH₃를 –OH로 바꾸면 PVA가 된다.
   [–CH₂–CH(OCOCH₃)–]ₙ + nNaOH → [–CH₂–CH(OH)–]ₙ + nCH₃COONa
4. ⓪ 비닐알코올은 불안정해서 곧 아세트알데히드로 변한다. 따라서 비닐알코올을 직접 중합해 PVA를 만들 수는 없고, 이 우회 경로를 거치는 것이다.

**포인트**:
- 비닐론 합성 경로: 아세트산비닐 → (부가중합) → 폴리아세트산비닐 → (비누화) → PVA → (HCHO 아세탈화) → 비닐론
- PVA는 수용성이다. 일부 –OH를 아세탈화해 물에 녹지 않게 하되, 남은 –OH 덕분에 비닐론은 흡습성이 있다.

## 問4c — 폴리비닐부티랄의 아세탈화 비율 계산 `[권장]`
- 이유: 질량 증가량으로 반응량을 구하는 계산은 호시의 이론 계산과 같은 감각이다. 비닐론 아세탈화율 계산의 응용형이다.

**문제 요약**: PVA(반복단위 식량 44.0)에 HCHO 대신 부틸알데히드 CH₃CH₂CH₂CHO(분자량 72.0)를 반응시키면 폴리비닐부티랄이 된다. PVA 88.0 g을 아세탈화했더니 폴리비닐부티랄 120.4 g이 얻어졌다. PVA의 히드록시기 중 아세탈화된 비율(%)은? 선택지는 ① 30, ② 45, ③ 60, ④ 67, ⑤ 82, ⑥ 85이다.

**정답**: 해답번호 28 = ③ (60 %)

**풀이**:
1. 반응식(아세탈 1단위당): 2(–CH₂–CH(OH)–) + C₃H₇CHO → 아세탈 고리 + H₂O
   - –OH 2개와 알데히드 1분자가 반응하고 H₂O 1분자가 빠진다.
2. 아세탈 1 mol이 생길 때 질량 증가량 = 72.0 − 18.0 = 54.0 g
3. 실제 질량 증가량 = 120.4 − 88.0 = 32.4 g
4. 생성된 아세탈 구조 = 32.4 ÷ 54.0 = 0.600 mol
5. 아세탈화된 –OH = 0.600 × 2 = 1.20 mol
6. PVA 전체의 –OH = 반복단위 수 = 88.0 ÷ 44.0 = 2.00 mol
7. 아세탈화 비율 = 1.20 ÷ 2.00 × 100 = **60 %**

**포인트**:
- 아세탈화 1단위는 "–OH 2개 + 알데히드 1분자 − H₂O"이고, 질량 증가는 (알데히드 분자량 − 18)이다. 비닐론(HCHO)이면 30 − 18 = 12다.
- 아세탈 몰수에 2를 곱하는 것을 잊지 말 것. 이것을 빠뜨리면 30 %(①)로 틀린다.
