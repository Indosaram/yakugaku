# 제3문 (20점, 무기화학: 전이원소·규소·기체 발생·할로젠(아이오딘)과 산화환원·화학량론)
전이원소 화합물, 규산나트륨과 물유리, 실험실 기체 제법의 정오를 판단한다. 이어서 아이오딘(I₂) 제조를 소재로 산화환원 판단, 반응식 계수 맞추기, 농도 계산을 묻는다.

## 問1 — 전이원소 화합물의 성질 정오 `[필수]`
- Fe 화합물 검출 반응과 착이온은 호시 무기에서 매회 다루는 핵심이다.

**문제 요약**: 전이원소(遷移元素) 화합물에 관한 서술 중 **틀린 것**을 고른다.
1. CuSO₄ 수용액에 NaOH 수용액을 넣으면 침전이 생긴다.
2. Fe³⁺를 포함한 수용액에 K₃[Fe(CN)₆](헥사시아니도철(Ⅲ)산칼륨) 수용액을 넣으면 청백색 침전(青白色沈殿)이 생긴다.
3. KMnO₄가 염기성 수용액에서 산화제로 작용하면 MnO₂가 된다.
4. Ag₂O에 과량의 암모니아수를 넣으면 착이온(錯イオン)이 생긴다.

**정답**: 해답번호 13 = ②

**풀이**:
- ① 옳다. Cu²⁺ + 2OH⁻ → Cu(OH)₂가 되어 청백색 침전이 생긴다.
- ② **틀렸다.** Fe³⁺에 K₃[Fe(CN)₆]를 넣으면 침전이 생기지 않고 갈색 용액이 될 뿐이다.
  - K₃[Fe(CN)₆]로 짙은 청색 침전이 생기는 쪽은 **Fe²⁺**이다.
  - Fe³⁺의 검출에는 K₄[Fe(CN)₆](짙은 청색 침전)나 KSCN(혈적색 용액)을 쓴다.
- ③ 옳다. 산성에서는 MnO₄⁻ → Mn²⁺(5e⁻)가 되고, 중성·염기성에서는 MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻가 된다.
- ④ 옳다. Ag₂O + 4NH₃ + H₂O → 2[Ag(NH₃)₂]⁺ + 2OH⁻ 반응으로 디암민은(Ⅰ) 이온이 생긴다.

**포인트**:

| 시약 | Fe²⁺ | Fe³⁺ |
|---|---|---|
| K₃[Fe(CN)₆] | 짙은 청색 침전 | 갈색 용액(침전 없음) |
| K₄[Fe(CN)₆] | 청백색 침전 | 짙은 청색 침전 |
| KSCN | 변화 거의 없음 | 혈적색 용액 |

- KMnO₄의 생성물은 산성이면 Mn²⁺, 중성·염기성이면 MnO₂이다.

## 問2 — 규산나트륨·물유리·실리카겔 `[필수]`
- 실리카겔은 호시 무기의 실생활 소재로 출제된 이력이 있다.

**문제 요약**: SiO₂ + Na₂CO₃ → Na₂SiO₃ + CO₂ 반응으로 규산나트륨을 만들고, 여기에 물을 넣고 가열하면 물유리(水ガラス)가 된다. 다음 중 **틀린 것**을 고른다.
1. SiO₂에 NaOH 분말을 섞어 고온에서 반응시켜도 Na₂SiO₃가 생긴다.
2. Na₂SiO₃에서 Si의 산화수는 +4이다.
3. 물유리를 건조시킨 것을 실리카겔(シリカゲル)이라 한다.
4. 물유리에 염산을 넣으면 규산(ケイ酸)이 생긴다.

**정답**: 해답번호 14 = ③

**풀이**:
- ① 옳다. SiO₂는 산성 산화물이므로 염기와 반응한다. SiO₂ + 2NaOH → Na₂SiO₃ + H₂O
- ② 옳다. 산화수를 x로 두면 2(+1) + x + 3(−2) = 0이므로 x = +4이다.
- ③ **틀렸다.** 실리카겔은 물유리를 바로 말린 것이 아니다.
  - 물유리에 산을 넣어 얻은 **규산(H₂SiO₃)을 가열·건조**한 것이 실리카겔이다.
- ④ 옳다. Na₂SiO₃ + 2HCl → H₂SiO₃ + 2NaCl 반응이 일어난다. 약산의 염에 강산을 넣으면 약산이 유리된다.

**포인트**:
- 제조 흐름은 SiO₂ → (Na₂CO₃ 또는 NaOH) → Na₂SiO₃ → (물+가열) 물유리 → (HCl) 규산 → (가열·건조) 실리카겔이다.
- 실리카겔은 다공질이고 표면의 –OH가 물을 흡착하므로 건조제로 쓰인다.

## 問3 — 기체 발생 반응과 기체의 성질 `[필수]`
- 기체 발생과 포집법은 호시 무기의 단골 문제다.

**문제 요약**: 다음 반응식의 ア〜エ(생성 기체)에 관한 서술 중 **틀린 것**을 고른다.
- (2) Cu + 4HNO₃(진한 질산) → Cu(NO₃)₂ + 2H₂O + 2 ア
- (3) 3Cu + 8HNO₃(묽은 질산) → 3Cu(NO₃)₂ + 4H₂O + 2 イ
- (4) CaF₂ + H₂SO₄(진한 황산, 가열) → CaSO₄ + 2 ウ
- (5) 3O₂ → (무성방전, 無声放電) → 2 エ

선택지는 다음과 같다.
1. ア를 물에 통하면 산성 수용액이 된다.
2. イ는 하방치환(下方置換)으로 포집한다.
3. ウ의 수용액은 폴리에틸렌 용기에 보관한다.
4. エ는 젖은 아이오딘화칼륨 녹말종이(ヨウ化カリウムデンプン紙)로 검출할 수 있다.

**정답**: 해답번호 15 = ②

**풀이**: 먼저 원자 수를 맞춰 기체를 정한다. ア = NO₂, イ = NO, ウ = HF, エ = O₃이다.
- ① 옳다. 3NO₂ + H₂O → 2HNO₃ + NO 반응으로 산성이 된다.
- ② **틀렸다.** NO는 물에 거의 녹지 않으므로 **수상치환(水上置換)**으로 포집한다.
  - 또 공기 중 O₂와 바로 반응해 NO₂가 되므로 공기와 닿는 치환법은 쓸 수 없다.
- ③ 옳다. 플루오린화수소산은 유리(SiO₂)를 녹인다(SiO₂ + 6HF → H₂SiF₆ + 2H₂O). 그래서 폴리에틸렌 용기에 보관한다.
- ④ 옳다. O₃는 강한 산화제이다. 2KI + O₃ + H₂O → I₂ + 2KOH + O₂ 반응으로 생긴 I₂가 녹말과 만나 청자색이 된다.

**포인트**:
- 구리와 질산의 생성 기체는 진한 질산이면 NO₂(적갈색, 하방치환), 묽은 질산이면 NO(무색, 수상치환)이다.
- HF는 유리를 부식시킨다. KI 녹말종이는 O₃, Cl₂ 같은 산화성 기체를 검출한다.

## 問4a — NaI에서 I₂를 얻는 반응(산화환원·추출) `[필수]`
- 산화제·환원제 판단과 할로젠 산화력은 기본이고 빈출이다.

**문제 요약**: 다시마 재에서 얻은 NaI 수용액에 묽은 H₂SO₄와 H₂O₂를 넣으면 2NaI + 2H₂SO₄ + H₂O₂ → 2NaHSO₄ + 2H₂O + I₂ (6) 반응이 일어난다. 관련 서술 중 **틀린 것**을 고른다.
1. 식 (6)에서 H₂O₂는 산화제로 작용한다.
2. 반응 후 헥산을 넣으면 I₂가 헥산으로 추출된다.
3. H₂O₂ 대신 염화주석(Ⅱ) SnCl₂를 써도 I₂를 만들 수 있다.
4. NaI 수용액에 Cl₂를 불어넣으면 I₂가 생긴다.

**정답**: 해답번호 16 = ③

**풀이**:
- ① 옳다. I는 −1 → 0으로 산화되고, H₂O₂의 O는 −1 → −2로 환원된다. 따라서 H₂O₂는 산화제다.
- ② 옳다. I₂는 무극성 분자라서 무극성 용매인 헥산에 잘 녹는다. 헥산층이 보라색이 된다.
- ③ **틀렸다.** I⁻를 I₂로 바꾸려면 **산화제**가 필요하다.
  - SnCl₂(Sn²⁺ → Sn⁴⁺)는 대표적인 **환원제**이므로 I⁻를 산화할 수 없다.
- ④ 옳다. 산화력은 Cl₂ > I₂이므로 Cl₂ + 2NaI → 2NaCl + I₂ 반응이 일어난다.

**포인트**:
- 할로젠 산화력 순서는 F₂ > Cl₂ > Br₂ > I₂이다. 위쪽 할로젠 단체는 아래쪽 할로젠화물 이온을 산화한다.
- 대표 환원제는 SnCl₂, H₂S, SO₂(대부분의 경우), FeSO₄, KI, (COOH)₂이다.

## 問4b — 반응식 계수 결정(산화환원) `[필수]`
- 산화수 변화로 계수를 맞추는 것은 호시 산화환원 단원의 기본기다.

**문제 요약**: 2NaIO₃ + a NaHSO₃ → b NaHSO₄ + c Na₂SO₄ + H₂O + I₂ (7) 반응에서, NaIO₃ 2 mol로부터 I₂ 1 mol이 생길 때 소비되는 NaHSO₃의 몰수를 구한다.

**정답**: 해답번호 17 = ⑤ (5 mol)

**풀이**:
1. 전자 수 맞추기
   - I는 +5 → 0이므로 원자 1개당 5e⁻를 받는다. 2개이므로 10e⁻를 받는다.
   - S는 +4 → +6이므로 1개당 2e⁻를 내놓는다.
   - 받은 전자와 내놓은 전자가 같아야 하므로 2a = 10, a = **5**이다.
2. 나머지 계수 확인
   - S 보존: b + c = 5
   - Na 보존: 2 + 5 = b + 2c, 즉 b + 2c = 7
   - 두 식을 풀면 c = 2, b = 3이다.
   - H 확인: 왼쪽 5 = 오른쪽 3 + 2 ✓
   - O 확인: 왼쪽 6 + 15 = 21 = 오른쪽 12 + 8 + 1 ✓
3. 완성식은 2NaIO₃ + 5NaHSO₃ → 3NaHSO₄ + 2Na₂SO₄ + H₂O + I₂이다.

**포인트**:
- 복잡한 산화환원식은 산화수 변화량으로 주고받는 전자 수를 먼저 맞춘다. 그다음 원자 보존으로 나머지 계수를 정한다.
- 이 문제처럼 a만 물을 때는 원자 보존식을 다 풀지 않고 전자 수만 맞춰도 된다.

## 問4c — 지하수 중 NaI 농도 계산(화학량론) `[권장]`
- 단순한 몰 비 계산이라 기초 계산력 확인용이다. 유효숫자 2자리 마킹 형식은 호시와 같다.

**문제 요약**: NaI 수용액에 CuSO₄와 FeSO₄를 넣어 CuI 침전을 얻은 뒤, CuI를 O₂와 300℃에서 반응시켜 I₂를 얻는다.
- 2NaI + 2CuSO₄ + 2FeSO₄ → 2CuI + Fe₂(SO₄)₃ + Na₂SO₄ (8)
- 2CuI + O₂ → 2CuO + I₂ (9)

지하수 2.50×10⁵ L에서 I₂ 25.4 kg이 얻어졌을 때 NaI 농도를 18.19×10⁻²⁰ mol/L 형식으로 답한다. 단, 지하수의 NaI는 모두 I₂가 되었다고 한다.

**정답**: 해답번호 18 = ⑧, 19 = ⓪, 20 = ④ → 8.0×10⁻⁴ mol/L (전부 맞아야 4점)

**풀이**:
1. I₂의 몰수: I₂ = 254 g/mol이므로 25.4×10³ g ÷ 254 g/mol = 100 mol이다.
2. 몰 비: 식 (8)에서 NaI : CuI = 2 : 2이고, 식 (9)에서 CuI : I₂ = 2 : 1이다. 따라서 NaI : I₂ = 2 : 1이다.
3. NaI의 몰수: 100 × 2 = 200 mol이다.
4. 농도: 200 mol ÷ (2.50×10⁵ L) = 8.0×10⁻⁴ mol/L이다.

**포인트**:
- 여러 단계 반응은 출발 물질과 최종 생성물의 몰 비만 뽑아 한 번에 계산한다. 이 문제에서는 NaI 2 mol → I₂ 1 mol이다.
- 이 공정에서는 FeSO₄가 Cu²⁺를 Cu⁺로 환원하는 역할을 한다. 그래서 I⁻ 전부가 CuI로 회수된다.
