## 4 벡터의 내적  *ベクトルの内積*

![그림: a⃗=OA⃗와 b⃗=OB⃗의 시작점을 O에 맞추면 ∠AOB가 두 벡터의 사이각 θ이다.](data/vecc/fig/p20-1.webp)

:::concept 개념 정리
- 내적의 정의: a⃗·b⃗ = |a⃗||b⃗|cosθ (θ는 a⃗, b⃗가 이루는 각, 0° ≤ θ ≤ 180°)
- 이루는 각은 **시작점을 붙여서** 잰다. 꼬리-머리로 이어진 두 벡터는 180° − (삼각형 내각)이 된다.
- 성분 표시: a⃗ = (a₁, a₂), b⃗ = (b₁, b₂)이면 a⃗·b⃗ = a₁b₁ + a₂b₂
- 계산 법칙: a⃗·a⃗ = |a⃗|², a⃗·b⃗ = b⃗·a⃗, a⃗·(b⃗+c⃗) = a⃗·b⃗ + a⃗·c⃗, (ka⃗)·b⃗ = k(a⃗·b⃗)
- 이루는 각: cosθ = a⃗·b⃗ / (|a⃗||b⃗|), 수직 조건: a⃗ ⊥ b⃗ ⇔ a⃗·b⃗ = 0 ⇔ a₁b₁ + a₂b₂ = 0
- 내적은 벡터가 아니라 **실수 하나**다.
- 사이각과 수직 조건을 쓰는 두 벡터는 모두 영벡터가 아니어야 한다. 영벡터가 포함되면 사이각은 정해지지 않으며 내적은 0으로 정한다.
:::

:::concept ⚡ 이 단원에서 계속 쓰는 꼼수 6개
- **정사영**: a⃗·b⃗ = |b⃗| × (a⃗를 b⃗ 방향으로 내린 그림자 길이). 각이 둔각이면 부호는 −.
- **다항식처럼 전개**: (a⃗+3b⃗)·(a⃗−2c⃗)는 (x+3y)(x−2z)와 똑같이 전개하고, x²만 |a⃗|²로 바꾼다.
- **평행사변형 법칙**: |a⃗+b⃗|² + |a⃗−b⃗|² = 2(|a⃗|²+|b⃗|²), |a⃗+b⃗|² − |a⃗−b⃗|² = 4a⃗·b⃗
- **수직 벡터 즉석 생성**: (p, q)에 수직인 벡터는 (q, −p) 또는 (−q, p). 자리 바꾸고 부호 하나만 뒤집는다.
- **루트 없는 각도**: tanθ = |a₁b₂ − a₂b₁| / (a₁b₁ + a₂b₂). 분모 부호로 예각·둔각을 가르고, 크기를 표준각으로 읽는다.
- **최솟값·넓이**: |a⃗+tb⃗|의 최솟값 = |a₁b₂ − a₂b₁| / |b⃗|, 삼각형 넓이 = ½|a₁b₂ − a₂b₁|
:::

### 기본예제 14 · 직각삼각형에서 내적 구하기
**문제** 그림의 직각삼각형 AOB(∠A = 90°, ∠O = 30°, ∠B = 60°, OA = √3, AB = 1, OB = 2)에서 다음 내적을 구하여라.
(1) OA⃗·OB⃗  (2) AB⃗·BO⃗

![그림: 기본예제 14의 직각삼각형 AOB. OA=√3, AB=1, OB=2이며 O의 각은 30°, B의 각은 60°이다.](data/vecc/fig/p20-2.webp)

**학습 목표(ねらい)** 내적의 정의대로 계산하고, 두 벡터가 이루는 각을 정확히 구한다. **해법 규칙(解法ルール)** 벡터를 평행이동하여 시작점을 붙이고 각을 잰다.

**정석 풀이**
1. (1) OA⃗와 OB⃗는 시작점이 O로 같으므로 이루는 각은 30°이다.
2. OA⃗·OB⃗ = √3 · 2 · cos30° = √3 · 2 · (√3/2) = 3
3. (2) AB⃗와 BO⃗는 꼬리-머리로 이어져 있으므로 AB⃗를 평행이동해 시작점을 B에 맞춘다. AB⃗의 연장선과 BO⃗가 이루는 각은 180° − 60° = 120°이다.
4. AB⃗·BO⃗ = 1 · 2 · cos120° = 1 · 2 · (−½) = −1

**답** (1) 3  (2) −1

![그림: 해답 예의 AB⃗와 BO⃗. AB⃗를 평행이동하여 B에서 출발시키면 BO⃗와 이루는 각은 120°이다.](data/vecc/fig/p20-3.webp)

:::fast 빠른 풀이 ① 정사영 한 줄
(1) A에서 OB에 수선을 내리면 O에서 수선의 발까지의 거리는 OA cos30° = √3 · (√3/2) = 3/2이다. 그래서 OA⃗·OB⃗ = |OB⃗| × 3/2 = 2 × 3/2 = **3**이다.
(2) AB⃗·BO⃗ = −(BA⃗·BO⃗)이다. A를 BO 위로 내린 그림자는 BA cos60° = ½이므로 BA⃗·BO⃗ = 2 × ½ = 1, 따라서 답은 **−1**이다.
(언제 쓰나: 직각이 있는 도형에서 수선의 발이 바로 보일 때 가장 빠르다. 그림자가 반대쪽으로 떨어지면 부호가 −이다.)
:::

:::fast 빠른 풀이 ② 좌표에 박아 넣기
O(0, 0), B(2, 0), A(3/2, √3/2)로 놓는다. A는 OB 위로 3/2, 높이 √3/2인 점이다.
(1) OA⃗·OB⃗ = (3/2)(2) + (√3/2)(0) = **3**
(2) AB⃗ = (1/2, −√3/2), BO⃗ = (−2, 0)이므로 AB⃗·BO⃗ = −1 + 0 = **−1**
(언제 쓰나: 각도 계산이 헷갈릴 때 쓴다. 좌표에 넣으면 각도를 따질 필요가 아예 없어서 실수가 없다.)
:::

### 유제 14 · 같은 그림에서 OA⃗·AB⃗, AO⃗·OB⃗
**문제** 기본예제 14의 그림에서 OA⃗·AB⃗와 AO⃗·OB⃗를 구하여라.

**정석 풀이**
1. OA⃗·AB⃗: 꼬리-머리로 이어져 있으므로 이루는 각은 180° − ∠OAB = 180° − 90° = 90°이다.
2. OA⃗·AB⃗ = √3 · 1 · cos90° = 0
3. AO⃗·OB⃗: AO⃗의 끝 O에서 OB⃗가 시작하므로 이루는 각은 180° − 30° = 150°이다.
4. AO⃗·OB⃗ = √3 · 2 · cos150° = √3 · 2 · (−√3/2) = −3

**답** OA⃗·AB⃗ = 0, AO⃗·OB⃗ = −3

:::fast 빠른 풀이 ① 이미 푼 것 재활용
- OA ⊥ AB(∠A = 90°)이므로 계산 없이 바로 **0**이다.
- AO⃗ = −OA⃗이므로 AO⃗·OB⃗ = −(OA⃗·OB⃗) = −3이다. 예제 14(1)의 답에 마이너스만 붙인다.
(언제 쓰나: 방향만 뒤집힌 벡터가 나오면 항상 쓸 수 있다. AO⃗·OB⃗ = −OA⃗·OB⃗)
:::

### 기본예제 15 · 성분으로 내적 계산
**학습 목표(ねらい)** 성분으로 주어진 벡터의 내적을 구한다. **책의 말풍선** 내적은 벡터가 아니라 하나의 실수 값이다.

**문제** a⃗ = (2, −1), b⃗ = (3, 4)일 때 다음 내적을 구하여라.
(1) a⃗·b⃗  (2) (2a⃗+b⃗)·(a⃗−b⃗)

**정석 풀이**
1. (1) a⃗·b⃗ = 2·3 + (−1)·4 = 2
2. (2) 2a⃗+b⃗ = (4+3, −2+4) = (7, 2), a⃗−b⃗ = (2−3, −1−4) = (−1, −5)
3. (7, 2)·(−1, −5) = −7 − 10 = −17

**답** (1) 2  (2) −17

<!-- PDF 20쪽 확인 완료: 그림 3개. 기본예제 14·15, 유제 14·15, 포인트·해법 규칙·학습 목표·말풍선 대조. -->

:::fast 빠른 풀이 ① 전개해서 숫자 3개로 끝내기
(2a⃗+b⃗)·(a⃗−b⃗) = 2|a⃗|² − a⃗·b⃗ − |b⃗|²이다. (2x+y)(x−y) = 2x² − xy − y²와 같은 꼴이다.
|a⃗|² = 5, a⃗·b⃗ = 2, |b⃗|² = 25를 넣으면 2·5 − 2 − 25 = **−17**이다.
(언제 쓰나: |a⃗|², |b⃗|², a⃗·b⃗ 세 숫자만 구해 두면 어떤 조합이 나와도 바로 계산된다. 문항이 여러 개일 때 특히 유리하다.)
:::

### 유제 15 · 성분 내적 연습
**문제** a⃗ = (3, 2), b⃗ = (−2, 4)일 때 다음 내적을 구하여라.
(1) a⃗·b⃗  (2) (a⃗+b⃗)·(a⃗−2b⃗)

**정석 풀이**
1. (1) a⃗·b⃗ = 3·(−2) + 2·4 = −6 + 8 = 2
2. (2) a⃗+b⃗ = (1, 6), a⃗−2b⃗ = (3+4, 2−8) = (7, −6)
3. (1, 6)·(7, −6) = 7 − 36 = −29

**답** (1) 2  (2) −29

:::fast 빠른 풀이 ① 세 숫자 공식
|a⃗|² = 13, |b⃗|² = 20, a⃗·b⃗ = 2이다.
(a⃗+b⃗)·(a⃗−2b⃗) = |a⃗|² − a⃗·b⃗ − 2|b⃗|² = 13 − 2 − 40 = **−29**
(언제 쓰나: 성분 벡터를 새로 만드는 것보다 덧셈·뺄셈 실수가 적다.)
:::

## 내적의 계산  *内積の計算*

**포인트·여백 주석** a⃗·a⃗ = |a⃗||a⃗|cos0° = |a⃗|²이므로 |a⃗| = √(a⃗·a⃗)이다. 교환법칙과 분배법칙이 성립하며, 실수 k에 대하여 (ka⃗)·b⃗ = a⃗·(kb⃗) = k(a⃗·b⃗)이다.

:::concept 개념 정리
- a⃗·a⃗ = |a⃗|², 거꾸로 |a⃗|² = a⃗·a⃗로 바꾸는 것이 핵심이다.
- 분배법칙이 성립하므로 (a⃗+b⃗)·(c⃗+d⃗) = a⃗·c⃗ + a⃗·d⃗ + b⃗·c⃗ + b⃗·d⃗
- 크기(|…|)가 나오면 **제곱해서 내적으로 바꾼다**.
:::

### 기본예제 16 · 내적 등식 증명
**학습 목표(ねらい)** 내적의 계산 법칙을 이용하여 내적을 계산한다. **해법 규칙·말풍선** a⃗·a⃗ = |a⃗|²뿐 아니라 그 역변형 |a⃗|² = a⃗·a⃗에도 익숙해지자.

![그림: 분배법칙의 화살표 도식. 번호 ①~④는 각각 a⃗·c⃗, a⃗·d⃗, b⃗·c⃗, b⃗·d⃗에 대응한다.](data/vecc/fig/p21-1.webp)

**문제** 다음 등식을 증명하여라.
(1) (a⃗+3b⃗)·(a⃗−2c⃗) = |a⃗|² + 3a⃗·b⃗ − 2a⃗·c⃗ − 6b⃗·c⃗
(2) |a⃗+2b⃗|² = |a⃗|² + 4a⃗·b⃗ + 4|b⃗|²

**정석 풀이**
1. (1) 좌변 = a⃗·a⃗ − a⃗·(2c⃗) + (3b⃗)·a⃗ − (3b⃗)·(2c⃗) = |a⃗|² + 3a⃗·b⃗ − 2a⃗·c⃗ − 6b⃗·c⃗ = 우변
2. (2) 좌변 = (a⃗+2b⃗)·(a⃗+2b⃗) = a⃗·a⃗ + 2a⃗·b⃗ + 2b⃗·a⃗ + 4b⃗·b⃗ = |a⃗|² + 4a⃗·b⃗ + 4|b⃗|² = 우변

**답** 증명 끝

:::fast 빠른 풀이 ① 다항식 전개로 1초 확인
(x+3y)(x−2z) = x² + 3xy − 2xz − 6yz에서 x² → |a⃗|², xy → a⃗·b⃗로 바꾸면 그대로 (1)이 된다.
(x+2y)² = x² + 4xy + 4y²도 마찬가지로 (2)가 된다.
(언제 쓰나: 내적은 교환·분배가 되므로 **두 벡터끼리의 곱**은 다항식처럼 다뤄도 안전하다. 단, 세 벡터를 곱하는 (a⃗·b⃗)c⃗는 a⃗(b⃗·c⃗)와 다르니 주의한다.)
:::

### 유제 16 · 내적 식 전개
**문제** 다음 식을 계산하여라.
(1) (a⃗−2b⃗)·(a⃗+3c⃗)  (2) |2a⃗−3b⃗|²

**정석 풀이**
1. (1) = a⃗·a⃗ + 3a⃗·c⃗ − 2b⃗·a⃗ − 6b⃗·c⃗ = |a⃗|² − 2a⃗·b⃗ + 3a⃗·c⃗ − 6b⃗·c⃗
2. (2) = (2a⃗−3b⃗)·(2a⃗−3b⃗) = 4|a⃗|² − 6a⃗·b⃗ − 6b⃗·a⃗ + 9|b⃗|² = 4|a⃗|² − 12a⃗·b⃗ + 9|b⃗|²

**답** (1) |a⃗|² − 2a⃗·b⃗ + 3a⃗·c⃗ − 6b⃗·c⃗  (2) 4|a⃗|² − 12a⃗·b⃗ + 9|b⃗|²

<!-- PDF 21쪽 확인 완료: 그림 1개. 기본예제 16·유제 16 및 포인트·여백·학습 목표·해법 규칙·말풍선 대조. -->

:::fast 빠른 풀이 ① 완전제곱식 공식 그대로
(2x−3y)² = 4x² − 12xy + 9y²이므로 바로 4|a⃗|² − 12a⃗·b⃗ + 9|b⃗|²이다.
(검산 요령: 임의로 a⃗ = (1, 0), b⃗ = (0, 1)을 넣으면 |2a⃗−3b⃗|² = 4 + 9 = 13이고, 공식도 4 − 0 + 9 = 13으로 맞는다.)
:::

### 기본예제 17 · 내적의 형태로 정리하기
**학습 목표(ねらい)** 내적의 계산 법칙을 이용한다. **시험 포인트** 시험에 자주 나오는 유형이다. **해법 규칙** |a⃗+b⃗|² = (a⃗+b⃗)·(a⃗+b⃗)로 바꾸어 분배법칙을 적용한다.

![그림: 실수 계수를 포함한 분배법칙. (ka⃗+lb⃗)·(pc⃗+qd⃗)를 네 화살표에 따라 kp a⃗·c⃗+kq a⃗·d⃗+lp b⃗·c⃗+lq b⃗·d⃗로 전개한다.](data/vecc/fig/p22-1.webp)

**문제** 다음 식을 계산하여 결과를 내적의 형태로 나타내어라.
(1) |a⃗+b⃗|² − |a⃗−b⃗|²  (2) (a⃗+4b⃗)·(a⃗−3c⃗) − (a⃗−3b⃗)·(a⃗+4c⃗)

**정석 풀이**
1. (1) |a⃗+b⃗|² = |a⃗|² + 2a⃗·b⃗ + |b⃗|², |a⃗−b⃗|² = |a⃗|² − 2a⃗·b⃗ + |b⃗|²
2. 빼면 4a⃗·b⃗이다.
3. (2) 첫째 항 = |a⃗|² − 3a⃗·c⃗ + 4a⃗·b⃗ − 12b⃗·c⃗
4. 둘째 항 = |a⃗|² + 4a⃗·c⃗ − 3a⃗·b⃗ − 12b⃗·c⃗
5. 빼면 −7a⃗·c⃗ + 7a⃗·b⃗ = 7(a⃗·b⃗ − a⃗·c⃗) = 7a⃗·(b⃗−c⃗)

**답** (1) 4a⃗·b⃗  (2) 7a⃗·(b⃗−c⃗)

:::fast 빠른 풀이 ① 지워지는 항은 아예 안 쓰기
(1) (x+y)² − (x−y)² = 4xy는 외워 둔 공식이다. 바로 **4a⃗·b⃗**
(2) 두 식 모두 |a⃗|²와 −12b⃗·c⃗가 똑같이 나오므로 빼면 사라진다. **교차항만** 본다.
- 첫째 식의 교차항: a⃗·(−3c⃗) + (4b⃗)·a⃗ = −3a⃗·c⃗ + 4a⃗·b⃗
- 둘째 식의 교차항: a⃗·(4c⃗) + (−3b⃗)·a⃗ = 4a⃗·c⃗ − 3a⃗·b⃗
- 빼면 7a⃗·b⃗ − 7a⃗·c⃗ = **7a⃗·(b⃗−c⃗)**
(언제 쓰나: 모양이 대칭인 두 식의 차이를 물으면 공통항부터 지운다. 쓰는 양이 반으로 준다.)
:::

### 유제 17 · |a⃗+2b⃗| = |a⃗−2b⃗|이면 수직
**책의 보충: 영벡터를 포함한 내적(0⃗を含むベクトルの内積)** a⃗ = 0⃗ 또는 b⃗ = 0⃗이면 두 벡터의 사이각은 정해지지 않지만 내적은 0이다. 역으로 a⃗·b⃗ = 0이라고 해서 어느 하나가 영벡터인 것은 아니다. 두 벡터가 모두 영벡터가 아니어도 사이각이 90°이면 내적은 0이다. 따라서 이 제목의 ‘수직’ 해석은 두 벡터가 모두 영벡터가 아닐 때에 한한다.

**문제** |a⃗+2b⃗| = |a⃗−2b⃗|가 성립할 때, 다음 물음에 답하여라.
(1) 양변을 제곱하여 내적 계산을 하고, a⃗·b⃗ = 0임을 보여라.
(2) a⃗ = (a₁, a₂), b⃗ = (b₁, b₂)로 두고 성분 계산으로 a⃗·b⃗ = 0임을 보여라.

**정석 풀이**
1. (1) 양변을 제곱하면 |a⃗|² + 4a⃗·b⃗ + 4|b⃗|² = |a⃗|² − 4a⃗·b⃗ + 4|b⃗|²
2. 정리하면 8a⃗·b⃗ = 0이므로 a⃗·b⃗ = 0
3. (2) a⃗+2b⃗ = (a₁+2b₁, a₂+2b₂), a⃗−2b⃗ = (a₁−2b₁, a₂−2b₂)
4. 크기의 제곱이 같으므로 (a₁+2b₁)² + (a₂+2b₂)² = (a₁−2b₁)² + (a₂−2b₂)²
5. 전개해서 정리하면 8a₁b₁ + 8a₂b₂ = 0, 즉 a₁b₁ + a₂b₂ = 0이므로 a⃗·b⃗ = 0

**답** 증명 끝

:::fast 빠른 풀이 ① 예제 17(1) 공식 재활용
|x⃗+y⃗|² − |x⃗−y⃗|² = 4x⃗·y⃗에 y⃗ = 2b⃗를 넣으면 0 = 4a⃗·(2b⃗) = 8a⃗·b⃗, 따라서 a⃗·b⃗ = 0이다. 한 줄로 끝난다.
:::

:::fast 빠른 풀이 ② 그림으로 보기
a⃗와 b⃗가 모두 영벡터가 아니고 평행하지 않을 때, a⃗와 2b⃗로 평행사변형을 만들면 a⃗+2b⃗와 a⃗−2b⃗는 두 대각선이다. 대각선 길이가 같은 평행사변형은 **직사각형**이므로 a⃗ ⊥ 2b⃗, 곧 a⃗·b⃗ = 0이다. 어느 하나가 영벡터이면 내적은 정의에 따라 바로 0이다. 두 벡터가 영벡터가 아니면서 평행한 경우에는 주어진 길이 등식이 성립하지 않는다.
(언제 쓰나: 서술형 답안은 ①로 쓰고, ②는 객관식이나 검산용으로 쓴다.)
:::

## 벡터가 이루는 각 · 수직 조건  *ベクトルのなす角・垂直条件*

<!-- PDF 22쪽 확인 완료: 그림 1개. 기본예제 17·유제 17 및 영벡터 내적 보충·해법 규칙·학습 목표 대조. -->

:::concept 개념 정리
- cosθ = a⃗·b⃗ / (|a⃗||b⃗|) = (a₁b₁ + a₂b₂) / (√(a₁²+a₂²) √(b₁²+b₂²))
- a⃗ ⊥ b⃗ ⇔ a⃗·b⃗ = 0 ⇔ a₁b₁ + a₂b₂ = 0
- 단위벡터 e⃗: |e⃗| = 1 ⇔ |e⃗|² = 1
- 위 사이각·수직 조건은 a⃗ ≠ 0⃗, b⃗ ≠ 0⃗일 때 적용한다. 사이각의 범위는 0° ≤ θ ≤ 180°이며, 두 벡터의 사이각이 90°일 때 서로 수직이라고 한다.
:::

### 기본예제 18 · 성분으로 이루는 각 구하기
**학습 목표(ねらい)** 성분으로 주어진 두 벡터의 사이각을 구한다. **시험 포인트** 시험에 자주 나오는 유형이다. **여백 주석** 내적의 정의 a⃗·b⃗ = |a⃗||b⃗|cosθ를 확실하게 기억하면 변형하여 cosθ를 구할 수 있다.

**문제** 다음 두 벡터 a⃗, b⃗가 이루는 각 θ를 구하여라.
(1) a⃗ = (1, 2), b⃗ = (1, −3)  (2) a⃗ = (−1, 2), b⃗ = (4, 2)

**정석 풀이**
1. (1) a⃗·b⃗ = 1 − 6 = −5, |a⃗| = √5, |b⃗| = √10
2. cosθ = −5 / (√5·√10) = −5 / (5√2) = −1/√2이고, 0° ≤ θ ≤ 180°이므로 θ = 135°
3. (2) a⃗·b⃗ = −4 + 4 = 0이므로 θ = 90°

**답** (1) 135°  (2) 90°

![그림: 해답 예의 단위원. cosθ=−1/√2에 대응하는 0° 이상 180° 이하의 각은 135°이다.](data/vecc/fig/p23-1.webp)

:::fast 빠른 풀이 ① 루트 없는 tan 공식
tanθ = |a₁b₂ − a₂b₁| / (a₁b₁ + a₂b₂)
(1) a₁b₂ − a₂b₁ = 1·(−3) − 2·1 = −5, 내적 = −5이므로 tanθ = 5/(−5) = −1이다. 분모가 음수라 둔각이므로 **θ = 135°**이다.
(언제 쓰나: |a⃗|, |b⃗|의 루트를 계산하지 않아도 된다. 결과가 ±1, ±√3, ±1/√3이면 표준각으로 바로 읽힌다. 분모가 0이면 90°이다.)
:::

:::fast 빠른 풀이 ② 수직은 눈으로
(2) (−1, 2)의 자리를 바꾸고 부호 하나를 뒤집으면 (2, 1)이다. b⃗ = (4, 2) = 2(2, 1)이므로 계산 없이 수직, **θ = 90°**이다.
:::

### 유제 18 · 이루는 각 연습
**문제** 다음 두 벡터 a⃗, b⃗가 이루는 각 θ를 구하여라.
(1) a⃗ = (1, √3), b⃗ = (−3, −√3)  (2) a⃗ = (2, −3), b⃗ = (3, 2)

**정석 풀이**
1. (1) a⃗·b⃗ = −3 − 3 = −6, |a⃗| = 2, |b⃗| = √(9+3) = 2√3
2. cosθ = −6 / (2·2√3) = −√3/2이므로 θ = 150°
3. (2) a⃗·b⃗ = 6 − 6 = 0이므로 θ = 90°

**답** (1) 150°  (2) 90°

<!-- PDF 23쪽 확인 완료: 그림 1개. 기본예제 18·유제 18 및 영벡터 제외 조건·사이각 범위·여백·학습 목표 대조. -->

:::fast 빠른 풀이 ① 방향각 빼기
(1) a⃗ = (1, √3)은 x축에서 **60°** 방향이다. b⃗ = (−3, −√3) = −√3(√3, 1)이고 (√3, 1)은 30° 방향이므로 b⃗는 그 반대인 **210°** 방향이다. 두 방향의 차이는 150°이고, 180°를 넘지 않으므로 그대로 **θ = 150°**이다.
(언제 쓰나: 성분이 1, √3, 2 조합처럼 특수각 모양일 때 쓴다. 차이가 180°를 넘으면 360°에서 뺀다.)
:::

:::fast 빠른 풀이 ② 자리 바꾸고 부호 하나
(2) (2, −3)의 자리를 바꾸면 (−3, 2), 여기서 첫째 성분의 부호만 뒤집으면 (3, 2)이다. 패턴 (p, q) ⊥ (−q, p)에 딱 맞으므로 계산 없이 **90°**이다.
:::

### 기본예제 19 · 수직인 단위벡터
**학습 목표(ねらい)** 수직 조건의 사용법을 이해한다. **해법 규칙** a⃗ ≠ 0⃗일 때 수직 조건 a⃗·e⃗ = 0과 단위벡터 조건 |e⃗|² = 1을 함께 쓴다. **말풍선** 내적은 수직 관계를 다루는 데 유용하다.

**문제** a⃗ = (3, 4)에 수직인 단위벡터 e⃗를 구하여라.

**정석 풀이**
1. e⃗ = (x, y)로 둔다.
2. 수직 조건 a⃗·e⃗ = 3x + 4y = 0 …①, 단위벡터 조건 x² + y² = 1 …②
3. ①에서 y = −(3/4)x를 ②에 넣으면 x² + (9/16)x² = 1, 즉 x² = 16/25이므로 x = ±4/5이다.
4. x = 4/5일 때 y = −3/5, x = −4/5일 때 y = 3/5이다.

**답** e⃗ = (4/5, −3/5), (−4/5, 3/5)

:::fast 빠른 풀이 ① 자리 바꾸고 부호 하나 → 크기로 나누기
(3, 4)에 수직인 벡터는 (4, −3)이다. 크기는 5이므로 나누면 (4/5, −3/5)이고, 반대 방향 (−4/5, 3/5)도 답이다. **연립방정식이 필요 없다.**
(언제 쓰나: 평면벡터(2차원)에서는 언제나 안전하다. 공간벡터에서는 수직인 방향이 무수히 많아서 이 방법을 쓸 수 없다.)
:::

### 유제 19 · 수직 단위벡터와 120° 벡터
**문제** a⃗ = (√3, 1)에 대하여 다음 물음에 답하여라.
(1) a⃗에 수직인 단위벡터 e⃗를 구하여라.
(2) a⃗와 120°의 각을 이루고 크기가 4인 벡터 b⃗를 구하여라.

**정석 풀이**
1. (1) e⃗ = (x, y)로 두면 √3x + y = 0, x² + y² = 1이다.
2. y = −√3x를 넣으면 4x² = 1이므로 x = ±½, y = ∓√3/2이다.
3. (2) b⃗ = (x, y)로 둔다. |a⃗| = 2이므로 a⃗·b⃗ = 2·4·cos120° = −4이다. 즉 √3x + y = −4 …①, x² + y² = 16 …②
4. ①에서 y = −4 − √3x를 ②에 넣으면 x² + 16 + 8√3x + 3x² = 16이므로 4x(x + 2√3) = 0이다.
5. x = 0이면 y = −4, x = −2√3이면 y = −4 + 6 = 2이다.

**답** (1) e⃗ = (½, −√3/2), (−½, √3/2)  (2) b⃗ = (0, −4), (−2√3, 2)

:::fast 빠른 풀이 ① (1) 자리 바꾸고 부호 하나
(√3, 1)에 수직인 벡터는 (1, −√3)이고 크기는 2이다. 나누면 (½, −√3/2), 반대 방향 (−½, √3/2)도 답이다.
:::

:::fast 빠른 풀이 ② (2) 방향각 돌리기
a⃗ = (√3, 1)은 **30°** 방향이다. 120° 벌어진 방향은 30° + 120° = 150°와 30° − 120° = −90° 두 개이다.
- 150° 방향, 크기 4: (4cos150°, 4sin150°) = (−2√3, 2)
- −90° 방향, 크기 4: (0, −4)
연립방정식 없이 바로 나온다.
(언제 쓰나: 기준 벡터가 특수각 방향(30°, 45°, 60° 등)일 때 쓴다. 평면벡터에서 "몇 도를 이루는 벡터"를 구하는 문제에는 늘 통한다.)
:::

### 기본예제 20 · 크기와 내적으로 각 구하기
**학습 목표(ねらい)** 벡터의 크기, 내적, 사이각의 관계를 이해한다. **시험 포인트** 시험에 자주 나오는 유형이다. **해법 규칙·말풍선** 크기를 다룰 때는 제곱한다. |a⃗−b⃗| 그대로는 전개할 수 없지만 |a⃗−b⃗|²은 내적으로 계산할 수 있다. |a⃗|, |b⃗|, a⃗·b⃗를 알면 cosθ = a⃗·b⃗/(|a⃗||b⃗|)를 쓴다.

**문제** |a⃗| = 3, |b⃗| = 2, |a⃗−b⃗| = √7일 때 다음 값을 구하여라.
(1) a⃗·b⃗  (2) a⃗, b⃗가 이루는 각 θ  (3) |a⃗+b⃗|

**정석 풀이**
1. (1) |a⃗−b⃗|² = 7이므로 |a⃗|² − 2a⃗·b⃗ + |b⃗|² = 7, 즉 9 − 2a⃗·b⃗ + 4 = 7이다. 따라서 a⃗·b⃗ = 3
2. (2) cosθ = 3 / (3·2) = ½이므로 θ = 60°
3. (3) |a⃗+b⃗|² = 9 + 2·3 + 4 = 19이므로 |a⃗+b⃗| = √19

**답** (1) 3  (2) 60°  (3) √19

![그림: 해답 예의 단위원. cosθ=1/2이며 0°≤θ≤180°이므로 θ=60°이다.](data/vecc/fig/p24-1.webp)

:::fast 빠른 풀이 ① (3) 평행사변형 법칙
|a⃗+b⃗|² + |a⃗−b⃗|² = 2(|a⃗|² + |b⃗|²)이므로 |a⃗+b⃗|² = 2(9 + 4) − 7 = 19, 곧 **√19**이다. a⃗·b⃗를 몰라도 바로 나온다.
:::

:::fast 빠른 풀이 ② (2) 코사인법칙
a⃗, b⃗, a⃗−b⃗는 변의 길이가 3, 2, √7인 삼각형을 만든다. √7의 대각이 θ이므로 cosθ = (9 + 4 − 7) / (2·3·2) = ½, 곧 **60°**이다.
(언제 쓰나: 세 크기가 다 주어지면 삼각형 문제로 바꿔 읽을 수 있다.)
:::

### 유제 20 · |a⃗+b⃗|에서 출발
**문제** |a⃗| = 3, |b⃗| = 4, |a⃗+b⃗| = √13일 때 다음 값을 구하여라.
(1) a⃗·b⃗  (2) |a⃗−b⃗|  (3) a⃗, b⃗가 이루는 각 θ

**정석 풀이**
1. (1) |a⃗+b⃗|² = 13이므로 9 + 2a⃗·b⃗ + 16 = 13이고, a⃗·b⃗ = −6
2. (2) |a⃗−b⃗|² = 9 − 2(−6) + 16 = 37이므로 |a⃗−b⃗| = √37
3. (3) cosθ = −6 / (3·4) = −½이므로 θ = 120°

**답** (1) −6  (2) √37  (3) 120°

(2) |a⃗−b⃗|² = 2(9 + 16) − 13 = 37이므로 **√37**이다.
(1) 4a⃗·b⃗ = |a⃗+b⃗|² − |a⃗−b⃗|² = 13 − 37 = −24이므로 a⃗·b⃗ = −6이다. 두 값이 서로 검산된다.

### 기본예제 21 · 연립으로 크기 구하기
**학습 목표(ねらい)** 내적의 계산 법칙을 이해한다. **시험 포인트** 시험에 자주 나오는 유형이다. **해법 규칙** 벡터의 합이나 차의 크기가 주어지면 양변을 제곱하고, |a⃗+2b⃗|² = (a⃗+2b⃗)·(a⃗+2b⃗)로 고쳐 쓴다. **말풍선** 분배법칙과 교환법칙을 사용하자.

**문제** |a⃗+2b⃗| = 2√19, |2a⃗−b⃗| = 7, a⃗·b⃗ = 6일 때 |a⃗|, |b⃗|를 구하여라.

**정석 풀이**
1. |a⃗+2b⃗|² = 76이므로 |a⃗|² + 4a⃗·b⃗ + 4|b⃗|² = 76, a⃗·b⃗ = 6을 넣으면 |a⃗|² + 4|b⃗|² = 52 …①
2. |2a⃗−b⃗|² = 49이므로 4|a⃗|² − 4a⃗·b⃗ + |b⃗|² = 49, 곧 4|a⃗|² + |b⃗|² = 73 …②
3. ①, ②를 연립하면 |a⃗|² = 16, |b⃗|² = 9

**답** |a⃗| = 4, |b⃗| = 3

:::fast 빠른 풀이 ① X, Y로 치환해서 더하고 빼기
X = |a⃗|², Y = |b⃗|²로 두면 X + 4Y = 52, 4X + Y = 73이다.
두 식을 더하면 5(X+Y) = 125이므로 X + Y = 25이다. 빼면 3(X − Y) = 21이므로 X − Y = 7이다.
따라서 X = 16, Y = 9이고, **|a⃗| = 4, |b⃗| = 3**이다.
(언제 쓰나: 계수가 (1, 4)와 (4, 1)처럼 대칭이면 더하기·빼기가 대입보다 빠르다. 검산: 구한 값을 ①에 넣으면 16 + 4·9 = 52로 맞는다.)
:::

### 유제 21 · |2a⃗−3b⃗| 구하기
**문제** |a⃗+b⃗| = 6, |a⃗−b⃗| = 2, |b⃗| = 3일 때 |2a⃗−3b⃗|를 구하여라.

**정석 풀이**
1. |a⃗+b⃗|² = 36: |a⃗|² + 2a⃗·b⃗ + 9 = 36 …①
2. |a⃗−b⃗|² = 4: |a⃗|² − 2a⃗·b⃗ + 9 = 4 …②
3. ① + ②: 2|a⃗|² + 18 = 40이므로 |a⃗|² = 11, ① − ②: 4a⃗·b⃗ = 32이므로 a⃗·b⃗ = 8
4. |2a⃗−3b⃗|² = 4·11 − 12·8 + 9·9 = 44 − 96 + 81 = 29

**답** √29

:::fast 빠른 풀이 ① 공식 두 방
- 4a⃗·b⃗ = 36 − 4 = 32이므로 a⃗·b⃗ = 8
- 평행사변형 법칙: |a⃗|² + |b⃗|² = (36 + 4)/2 = 20이므로 |a⃗|² = 11
- 4·11 − 12·8 + 81 = **29**
연립 과정 없이 바로 나온다.
:::

:::fast 빠른 풀이 ② u⃗ = a⃗+b⃗, w⃗ = a⃗−b⃗로 갈아타기
a⃗ = (u⃗+w⃗)/2, b⃗ = (u⃗−w⃗)/2이므로 2a⃗ − 3b⃗ = (−u⃗ + 5w⃗)/2이다.
|2a⃗−3b⃗|² = (|u⃗|² − 10u⃗·w⃗ + 25|w⃗|²)/4이고, u⃗·w⃗ = |a⃗|² − |b⃗|² = 11 − 9 = 2이다.
= (36 − 20 + 100)/4 = 116/4 = **29**
(언제 쓰나: |a⃗+b⃗|, |a⃗−b⃗|가 주어진 문제에서 쓰는 고급 기술이다. 이 문제에서는 ①이 더 빠르고, ②는 검산용이다.)
:::

### 기본예제 22 · 수직 조건으로 각 구하기
**학습 목표(ねらい)** 두 벡터가 이루는 각을 구한다. **해법 규칙·말풍선** 영벡터가 아닌 c⃗, d⃗에 대해 c⃗ ⊥ d⃗ ⇔ c⃗·d⃗ = 0을 먼저 적용하고, a⃗·b⃗ = |a⃗||b⃗|cosθ로 사이각을 구한다.

**문제** |a⃗| = 4, |b⃗| = 2이고 2a⃗+b⃗와 a⃗−3b⃗가 수직일 때, a⃗, b⃗가 이루는 각을 구하여라.

**정석 풀이**
1. 수직이므로 (2a⃗+b⃗)·(a⃗−3b⃗) = 0이다.
2. 전개하면 2|a⃗|² − 5a⃗·b⃗ − 3|b⃗|² = 0이므로 32 − 5a⃗·b⃗ − 12 = 0, 곧 a⃗·b⃗ = 4이다.
3. cosθ = 4 / (4·2) = ½이므로 θ = 60°이다.

**답** 60°

:::fast 빠른 풀이 ① 계수만 뽑아 쓰기
(2x+y)(x−3y) = 2x² − 5xy − 3y²에서 계수 (2, −5, −3)만 쓰면 2·16 − 5k − 3·4 = 0이므로 k = a⃗·b⃗ = 4이다.
그다음 cosθ = k/(|a⃗||b⃗|) = 4/8 = ½ → **60°**
(언제 쓰나: "A와 B가 수직"이면 언제나 이 2단계로 끝난다. ① 전개해서 내적 = 0 ② cos 공식)
:::

### 유제 22 · 3a⃗−b⃗ ⊥ b⃗
**문제** |a⃗| = √2, |b⃗| = 3이고 3a⃗−b⃗와 b⃗가 수직일 때, a⃗, b⃗가 이루는 각을 구하여라.

**정석 풀이**
1. (3a⃗−b⃗)·b⃗ = 0이므로 3a⃗·b⃗ − |b⃗|² = 0, 3a⃗·b⃗ = 9, a⃗·b⃗ = 3
2. cosθ = 3 / (√2·3) = 1/√2이므로 θ = 45°

**답** 45°

<!-- PDF 25쪽 확인 완료: 수학 그림 0개. 기본예제 21·22와 유제 21·22, 학습 목표·시험 표시·해법 규칙·말풍선 대조. -->

:::fast 빠른 풀이 ① 정사영으로 읽기
3a⃗ − b⃗ ⊥ b⃗라는 말은 3a⃗를 b⃗ 위로 내린 그림자가 **정확히 b⃗**라는 뜻이다. 그래서 |3a⃗|cosθ = |b⃗|, 곧 3√2 cosθ = 3이고 cosθ = 1/√2 → **45°**이다.
(언제 쓰나: "(ka⃗ − b⃗) ⊥ b⃗" 꼴은 항상 "ka⃗의 그림자 = b⃗"로 읽을 수 있다.)
:::

### 응용예제 23 · |a⃗+tb⃗|의 최솟값
**학습 목표(ねらい)** 벡터 크기의 최솟값을 이차함수의 최솟값 문제로 바꾸어 구한다. **해법 규칙·여백 주석** |a⃗+tb⃗| ≥ 0이므로 제곱을 최소로 하는 t가 원래 크기도 최소로 한다. |a⃗+tb⃗|²이 t의 이차함수라는 점에 주목한다. 이차함수 at²+bt+c의 최대·최소를 구할 때는 a(t−p)²+q로 완전제곱한다.

**문제** a⃗ = (1, −3), b⃗ = (1, 2)일 때 |a⃗+tb⃗|를 최소로 하는 t의 값과 그때의 최솟값을 구하여라.

**정석 풀이**
1. a⃗+tb⃗ = (1+t, −3+2t)
2. |a⃗+tb⃗|² = (t+1)² + (2t−3)² = 5t² − 10t + 10 = 5(t−1)² + 5
3. t = 1일 때 |a⃗+tb⃗|²의 최솟값은 5이다. |a⃗+tb⃗| ≥ 0이므로 제곱이 최소일 때 크기도 최소이다.

**답** t = 1일 때 최솟값 √5

:::fast 빠른 풀이 ① 수직이 되는 순간이 최소
최소일 때 (a⃗+tb⃗) ⊥ b⃗이므로 t = −a⃗·b⃗ / |b⃗|² = −(1 − 6)/5 = **1**이다.
최솟값² = |a⃗|² − (a⃗·b⃗)²/|b⃗|² = 10 − 25/5 = 5이므로 **√5**이다.
(언제 쓰나: |a⃗ + tb⃗| 꼴의 최솟값이면 늘 쓸 수 있다. a⃗ 끝점에서 b⃗ 방향 직선까지의 거리와 같다.)
:::

:::fast 빠른 풀이 ② 행렬식 한 줄
최솟값 = |a₁b₂ − a₂b₁| / |b⃗| = |1·2 − (−3)·1| / √5 = 5/√5 = **√5**이다.
(언제 쓰나: 평면벡터에서 최솟값만 물을 때 가장 빠르다. t도 물으면 ①의 t 공식을 같이 쓴다.)
:::

### 유제 23 · 최솟값과 수직 확인
**문제** a⃗ = (5, 10), b⃗ = (2, 1)일 때 |a⃗+tb⃗|를 최소로 하는 t의 값과 그때의 최솟값을 구하여라. 또, 이때 a⃗+tb⃗가 b⃗와 수직임을 보여라.

**정석 풀이**
1. a⃗+tb⃗ = (5+2t, 10+t)
2. |a⃗+tb⃗|² = (2t+5)² + (t+10)² = 5t² + 40t + 125 = 5(t+4)² + 45
3. t = −4일 때 최솟값은 √45 = 3√5이다.
4. 이때 a⃗+tb⃗ = (5−8, 10−4) = (−3, 6)이고, (−3, 6)·(2, 1) = −6 + 6 = 0이므로 b⃗와 수직이다.

**답** t = −4, 최솟값 3√5, 수직임은 위와 같다.

:::fast 빠른 풀이 ① 공식 두 개
t = −a⃗·b⃗/|b⃗|² = −(10 + 10)/5 = **−4**
최솟값 = |a₁b₂ − a₂b₁|/|b⃗| = |5·1 − 10·2|/√5 = 15/√5 = **3√5**
수직은 t 공식이 애초에 "(a⃗+tb⃗)·b⃗ = 0"을 풀어서 나온 것이므로 자동으로 성립한다. 답안에는 (−3, 6)·(2, 1) = 0 한 줄만 쓴다.
:::

### 응용예제 24 · 삼각형 넓이 공식 증명
**학습 목표(ねらい)** 내적을 이용하여 삼각형 넓이 공식을 증명한다. **해법 규칙·여백 주석** ∠AOB = θ일 때 S = ½ OA·OB sinθ = ½|a⃗||b⃗|sinθ이다. sin²θ+cos²θ=1이며 sinθ>0일 때 sinθ=√(1−cos²θ)이므로 내적과 연결할 수 있다. **말풍선** 자주 사용하는 공식이므로 기억해 두자. 제곱근을 풀 때 √(x²)=|x|임에 주의한다.

![그림: 넓이 공식의 삼각형 OAB. 밑변 OA에 대한 높이는 OB sinθ이며, θ는 ∠AOB이다.](data/vecc/fig/p26-1.webp)

**문제** △OAB의 넓이를 S, OA⃗ = a⃗, OB⃗ = b⃗라 할 때,
(1) S = ½√(|a⃗|²|b⃗|² − (a⃗·b⃗)²)임을 증명하여라.
(2) 또한 a⃗ = (a₁, a₂), b⃗ = (b₁, b₂)이면 S = ½|a₁b₂ − a₂b₁|임을 증명하여라.

**정석 풀이**
1. (1) ∠AOB = θ(0° < θ < 180°)로 두면 sinθ > 0이다.
2. S = ½|a⃗||b⃗|sinθ = ½|a⃗||b⃗|√(1 − cos²θ) = ½√(|a⃗|²|b⃗|² − (|a⃗||b⃗|cosθ)²) = ½√(|a⃗|²|b⃗|² − (a⃗·b⃗)²)
3. (2) |a⃗|²|b⃗|² − (a⃗·b⃗)² = (a₁² + a₂²)(b₁² + b₂²) − (a₁b₁ + a₂b₂)²
4. = a₁²b₂² − 2a₁a₂b₁b₂ + a₂²b₁² = (a₁b₂ − a₂b₁)²
5. √(x²) = |x|이므로 S = ½|a₁b₂ − a₂b₁|

**답** 증명 끝

:::fast 빠른 풀이 ① 기억법: "엇갈려 곱해서 빼고 절반"
a⃗ = (a₁, a₂), b⃗ = (b₁, b₂)를 위아래로 쓰고 X자로 곱한다(a₁b₂ − a₂b₁). 절댓값을 씌워 반으로 나누면 넓이이다. (2)의 4번 줄은 **라그랑주 항등식** (a₁² + a₂²)(b₁² + b₂²) = (a₁b₁ + a₂b₂)² + (a₁b₂ − a₂b₁)²을 외워 두면 바로 쓸 수 있다.
(언제 쓰나: 좌표가 주어진 삼각형 넓이는 이 공식이 가장 빠르다. 공간벡터에서는 (1)의 공식만 쓸 수 있다.)
:::

### 유제 24 · 세 점으로 삼각형 넓이
**문제** 세 점 A(−1, −2), B(4, 1), C(2, 5)를 꼭짓점으로 하는 △ABC의 넓이를 구하여라.

**정석 풀이**
1. AB⃗ = (5, 3), AC⃗ = (3, 7)
2. |AB⃗|² = 34, |AC⃗|² = 58, AB⃗·AC⃗ = 15 + 21 = 36
3. S = ½√(34·58 − 36²) = ½√(1972 − 1296) = ½√676 = ½·26 = 13

**답** 13

AB⃗ = (5, 3), AC⃗ = (3, 7)이므로 S = ½|5·7 − 3·3| = ½·26 = **13**이다. 큰 수 제곱을 할 필요가 없다.
