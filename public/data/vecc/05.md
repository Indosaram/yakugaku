## 내적의 성분 표시 · 벡터가 이루는 각  *内積の成分表示・ベクトルのなす角*

:::concept 개념 정리
- a⃗=(a₁, a₂, a₃), b⃗=(b₁, b₂, b₃) 일 때 내적 a⃗·b⃗ = a₁b₁ + a₂b₂ + a₃b₃
- 이루는 각 θ (0° ≤ θ ≤ 180°): cos θ = a⃗·b⃗ / (|a⃗||b⃗|) = (a₁b₁+a₂b₂+a₃b₃) / (√(a₁²+a₂²+a₃²) √(b₁²+b₂²+b₃²))
- 수직 조건: a⃗ ⊥ b⃗ ⇔ a⃗·b⃗ = 0 ⇔ a₁b₁+a₂b₂+a₃b₃ = 0
- 평면벡터 공식에 z성분이 하나 더 붙을 뿐이다.
- (참고, 교과서 범위 밖) 외적 a⃗×b⃗ = (a₂b₃−a₃b₂, a₃b₁−a₁b₃, a₁b₂−a₂b₁) 은 a⃗, b⃗ 두 벡터 모두에 수직이다.
:::

### 기본예제 54 · 벡터의 크기와 내적의 성분 표시 증명
**문제** a⃗=(a₁, a₂, a₃), b⃗=(b₁, b₂, b₃) 일 때,
(1) b⃗−a⃗ 를 성분으로 나타내고(成分で表し), |b⃗−a⃗| 를 구하여라.
(2) a⃗·b⃗ = a₁b₁+a₂b₂+a₃b₃ 임을 보여라(示せ).

**정석 풀이**
1. (1) b⃗−a⃗ = (b₁−a₁, b₂−a₂, b₃−a₃)
2. 따라서 |b⃗−a⃗| = √((b₁−a₁)² + (b₂−a₂)² + (b₃−a₃)²)
3. (2) |b⃗−a⃗|² = (b⃗−a⃗)·(b⃗−a⃗) = |b⃗|² − 2a⃗·b⃗ + |a⃗|²
4. 좌변에 (1)의 결과를 넣으면 (b₁−a₁)²+(b₂−a₂)²+(b₃−a₃)² = (b₁²+b₂²+b₃²) − 2a⃗·b⃗ + (a₁²+a₂²+a₃²)
5. 좌변을 전개하면 제곱항이 양변에서 지워지고 −2(a₁b₁+a₂b₂+a₃b₃) = −2a⃗·b⃗ 가 남는다.
6. 따라서 a⃗·b⃗ = a₁b₁+a₂b₂+a₃b₃ (증명 끝)

**답** (1) b⃗−a⃗=(b₁−a₁, b₂−a₂, b₃−a₃), |b⃗−a⃗|=√((b₁−a₁)²+(b₂−a₂)²+(b₃−a₃)²) (2) 위 증명

:::fast 빠른 풀이 ① 기본벡터 분해 증명
a⃗ = a₁e⃗₁+a₂e⃗₂+a₃e⃗₃, b⃗ = b₁e⃗₁+b₂e⃗₂+b₃e⃗₃ 로 쓴다(e⃗ᵢ 는 기본벡터). e⃗ᵢ·e⃗ᵢ=1, i≠j 이면 e⃗ᵢ·e⃗ⱼ=0 이므로, 전개하면 같은 번호끼리 곱한 항만 남아 a₁b₁+a₂b₂+a₃b₃ 이다.
(언제 쓰나: 내적의 분배법칙을 써도 되는 증명이면 이 방법이 한 줄로 끝난다. 시험에서 "(1)을 이용하여"라고 지시하면 정석 풀이처럼 써야 한다.)
:::

### 기본예제 55 · 벡터가 이루는 각 (3)
**문제** a⃗=(2, 2, 0), b⃗=(−1, −2, 1) 이 이루는 각(なす角) θ 를 구하여라.

**정석 풀이**
1. a⃗·b⃗ = 2·(−1) + 2·(−2) + 0·1 = −6
2. |a⃗| = √(4+4+0) = 2√2, |b⃗| = √(1+4+1) = √6
3. cos θ = −6 / (2√2·√6) = −6 / (4√3) = −√3/2
4. 0° ≤ θ ≤ 180° 이므로 θ = 150°

**답** θ = 150°

:::fast 빠른 풀이 ① 공통인수 먼저 빼기
a⃗ = 2(1, 1, 0) 이다. 양수배는 각을 바꾸지 않으므로 (1,1,0) 과 (−1,−2,1) 로 계산한다. 내적 −3, 크기 √2·√6 = 2√3 이므로 cos θ = −3/(2√3) = −√3/2 → θ = 150°
(언제 쓰나: 성분에 공통인수가 있으면 항상 쓸 수 있다. 음수로 묶으면 cos 의 부호가 바뀌므로 양수로만 묶는다.)
:::

### 유제 55 · 두 벡터가 이루는 각
**문제** 다음 두 벡터 a⃗, b⃗ 가 이루는 각 θ 를 구하여라.
(1) a⃗=(2, 1, 1), b⃗=(−2, 2, −4)
(2) a⃗=(1, 2, 6), b⃗=(2, 2, −1)

**정석 풀이**
1. (1) a⃗·b⃗ = −4 + 2 − 4 = −6, |a⃗| = √6, |b⃗| = √(4+4+16) = 2√6
2. cos θ = −6 / (√6·2√6) = −6/12 = −½ 이므로 θ = 120°
3. (2) a⃗·b⃗ = 2 + 4 − 6 = 0
4. 내적이 0 이므로 cos θ = 0, θ = 90°

**답** (1) θ = 120° (2) θ = 90°

:::fast 빠른 풀이 ① 공통인수 빼기 + 내적 0 먼저 확인
(1) b⃗ = 2(−1, 1, −2) 이다. (2,1,1)·(−1,1,−2) = −2+1−2 = −3 이고 두 벡터 크기는 모두 √6 이므로 cos θ = −3/6 = −½ → 120°.
(2) 크기를 구하기 전에 내적부터 계산하면 0 이다. 그러면 크기 계산 없이 바로 90° 이다.
(언제 쓰나: 크기 계산(루트)은 내적이 0 이 아닐 때만 하면 된다. 각을 묻는 문제는 항상 내적부터 계산한다.)
:::

### 기본예제 56 · 수직인 단위벡터
**문제** 두 벡터 a⃗=(1, 1, −1), b⃗=(1, −3, 1) 모두에 수직인 단위벡터(単位ベクトル) e⃗ 를 구하여라.

**정석 풀이**
1. e⃗=(x, y, z) 로 놓는다.
2. |e⃗|² = 1 에서 x²+y²+z² = 1 …①
3. a⃗⊥e⃗ 에서 x+y−z = 0 …②, b⃗⊥e⃗ 에서 x−3y+z = 0 …③
4. ②+③: 2x−2y = 0 이므로 y = x. ②에 넣으면 z = 2x
5. ①에 대입: x²+x²+4x² = 1, 즉 x = ±1/√6
6. e⃗ = (√6/6, √6/6, √6/3), (−√6/6, −√6/6, −√6/3)

**답** e⃗ = (√6/6, √6/6, √6/3), (−√6/6, −√6/6, −√6/3)

:::fast 빠른 풀이 ① 외적으로 수직 방향 바로 구하기
a⃗×b⃗ = (1·1−(−1)(−3), (−1)·1−1·1, 1·(−3)−1·1) = (−2, −2, −4) = −2(1, 1, 2).
수직 방향은 (1,1,2) 이고 크기는 √6 이다. 따라서 e⃗ = ±(1,1,2)/√6 = ±(√6/6, √6/6, √6/3)
(언제 쓰나: 두 벡터에 모두 수직인 벡터를 구할 때 항상 쓸 수 있다. 단, 외적은 일본 고교 교과 범위 밖이므로 서술형 답안에서는 정석 풀이처럼 연립방정식으로 쓰고, 외적은 답 확인용으로만 쓴다. a⃗, b⃗ 가 평행하면 외적이 0⃗ 이 되어 쓸 수 없다.)
:::

### 유제 56 · 두 벡터에 수직이고 크기가 주어진 벡터
**문제** 두 벡터 a⃗=(1, 2, 3), b⃗=(3, 1, −1) 모두에 수직이고 크기가 2√6 인 벡터를 구하여라.

**정석 풀이**
1. 구하는 벡터를 p⃗=(x, y, z) 로 놓는다.
2. a⃗·p⃗ = x+2y+3z = 0 …①, b⃗·p⃗ = 3x+y−z = 0 …②
3. ②에서 z = 3x+y. ①에 넣으면 x+2y+9x+3y = 0, 즉 10x+5y = 0, y = −2x
4. z = 3x−2x = x. 따라서 p⃗ = (x, −2x, x)
5. |p⃗|² = x²+4x²+x² = 6x² = 24 이므로 x = ±2
6. p⃗ = (2, −4, 2), (−2, 4, −2)

**답** (2, −4, 2), (−2, 4, −2)

:::fast 빠른 풀이 ① 외적 + 크기 맞추기
a⃗×b⃗ = (2·(−1)−3·1, 3·3−1·(−1), 1·1−2·3) = (−5, 10, −5) = −5(1, −2, 1).
(1,−2,1) 의 크기는 √6 이므로 2배 하면 크기 2√6 → ±(2, −4, 2)
(언제 쓰나: 기본예제 56 과 같다. 검산용으로 쓰기 좋다. 확인: (2,−4,2)·(1,2,3)=2−8+6=0, (2,−4,2)·(3,1,−1)=6−4−2=0)
:::

### 기본예제 57 · 벡터의 수직
**문제** a⃗=(3, 0, −2), b⃗=(2, 2, 1) 일 때, a⃗+tb⃗ 와 a⃗−b⃗ 가 수직이 되도록 하는 t 의 값을 구하여라.

**정석 풀이**
1. a⃗+tb⃗ = (2t+3, 2t, t−2), a⃗−b⃗ = (1, −2, −3)
2. 수직이므로 (a⃗+tb⃗)·(a⃗−b⃗) = 0
3. (2t+3)·1 + 2t·(−2) + (t−2)·(−3) = 0
4. 2t+3−4t−3t+6 = 0, 즉 5t = 9

**답** t = 9/5

:::fast 빠른 풀이 ① 성분 없이 내적만으로 계산
(a⃗+tb⃗)·(a⃗−b⃗) = |a⃗|² − a⃗·b⃗ + t(a⃗·b⃗ − |b⃗|²) = 0.
|a⃗|² = 13, |b⃗|² = 9, a⃗·b⃗ = 6−2 = 4 이므로 13−4 + t(4−9) = 0, 9 − 5t = 0 → t = 9/5
(언제 쓰나: |a⃗|², |b⃗|², a⃗·b⃗ 세 수만 있으면 되므로 성분이 복잡할수록 빠르다. 유제 57 처럼 성분이 주어지지 않은 문제에서도 그대로 쓸 수 있다.)
:::

### 유제 57 · 크기 조건으로 내적, 각, 수직 구하기
**문제** 공간벡터 a⃗, b⃗ 에서 |a⃗|=3, |b⃗|=2, |a⃗−b⃗|=√19 일 때, 다음 물음에 답하여라.
(1) a⃗·b⃗ 를 구하여라.
(2) a⃗ 와 b⃗ 가 이루는 각 θ 를 구하여라.
(3) a⃗+tb⃗ 와 a⃗−b⃗ 가 수직이 될 때 t 의 값을 구하여라.

**정석 풀이**
1. (1) |a⃗−b⃗|² = |a⃗|² − 2a⃗·b⃗ + |b⃗|² 이므로 19 = 9 − 2a⃗·b⃗ + 4
2. 2a⃗·b⃗ = −6, 따라서 a⃗·b⃗ = −3
3. (2) cos θ = −3/(3·2) = −½, 0° ≤ θ ≤ 180° 이므로 θ = 120°
4. (3) (a⃗+tb⃗)·(a⃗−b⃗) = |a⃗|² − a⃗·b⃗ + t a⃗·b⃗ − t|b⃗|² = 9 + 3 − 3t − 4t = 12 − 7t = 0
5. t = 12/7

**답** (1) a⃗·b⃗ = −3 (2) θ = 120° (3) t = 12/7

:::fast 빠른 풀이 ① 코사인 법칙으로 바로 각 구하기
세 변이 |a⃗|=3, |b⃗|=2, |a⃗−b⃗|=√19 인 삼각형으로 본다. 코사인 법칙: 19 = 9 + 4 − 2·3·2·cos θ 이므로 cos θ = −½ → θ = 120°. 그러면 a⃗·b⃗ = 3·2·(−½) = −3
(언제 쓰나: |a⃗|, |b⃗|, |a⃗±b⃗| 가 모두 주어지면 항상 쓸 수 있다. |a⃗+b⃗| 가 주어지면 끼인각이 180°−θ 이므로 부호에 주의한다.)
:::

:::fast 빠른 풀이 ② (3) 검산: 좌표 놓기
a⃗=(3, 0, 0), b⃗=(−1, √3, 0) 으로 놓으면 |b⃗|=2, a⃗·b⃗=−3 이 맞다. a⃗−b⃗=(4, −√3, 0), a⃗+tb⃗=(3−t, √3t, 0). 내적 = 12−4t−3t = 12−7t = 0 → t = 12/7
(언제 쓰나: 크기와 내적만 주어진 문제는 조건을 만족하는 좌표를 아무거나 놓고 계산해도 답이 같다.)
:::

## 12 벡터와 공간도형  *ベクトルと空間図形*

:::concept 개념 정리
- 내분점: 선분 AB 를 m:n 으로 내분하는 점 Q 는 OQ⃗ = (nOA⃗ + mOB⃗)/(m+n)
- 등식 xAP⃗ + yBP⃗ + zCP⃗ = 0⃗ (x, y, z > 0) 이면 p⃗ = (xa⃗ + yb⃗ + zc⃗)/(x+y+z). 이 점은 A, B, C 에 무게 x, y, z 를 둔 무게중심이다.
- 수직 증명: OA ⊥ BC ⇔ OA⃗·BC⃗ = 0 (O 를 시점으로 하는 위치벡터로 나타낸다)
- 네 점이 한 평면 위에 있을 조건: 한 직선 위에 있지 않은 세 점 A, B, C 가 정하는 평면 위에 점 P 가 있으면
  - AP⃗ = kAB⃗ + lAC⃗ (k, l 은 실수, 표현은 한 가지뿐)
  - p⃗ = sa⃗ + tb⃗ + uc⃗, s + t + u = 1 (계수의 합이 1)
- 점 P 가 직선 AB 위에 있을 조건: p⃗ = sa⃗ + tb⃗, s + t = 1
- 직선 l 이 평면 α 에 수직 ⇔ l 이 α 위의 평행하지 않은 두 직선 m, n 에 모두 수직
- 삼각형의 넓이: S = ½√(|a⃗|²|b⃗|² − (a⃗·b⃗)²) (공간에서도 그대로 성립)
:::

### 응용예제 58 · 위치 관계
**문제** 사면체(四面体) OABC 와 점 P 가 AP⃗ + 2BP⃗ + 3CP⃗ = 0⃗ 을 만족할 때, 점 P 와 사면체 OABC 의 위치 관계(位置関係)를 조사하여라.

**정석 풀이**
1. O 를 시점으로 하여 A(a⃗), B(b⃗), C(c⃗), P(p⃗) 로 놓는다.
2. (p⃗−a⃗) + 2(p⃗−b⃗) + 3(p⃗−c⃗) = 0⃗ 이므로 6p⃗ = a⃗ + 2b⃗ + 3c⃗, p⃗ = (a⃗+2b⃗+3c⃗)/6
3. 변형하면 p⃗ = {3·(a⃗+2b⃗)/3 + 3c⃗}/6 = {(a⃗+2b⃗)/3 + c⃗}/2
4. d⃗ = (a⃗+2b⃗)/3 로 놓으면 점 D(d⃗) 는 선분 AB 를 2:1 로 내분하는 점이다.
5. p⃗ = (c⃗+d⃗)/2 이므로 점 P 는 선분 CD 의 중점이다.

**답** 점 P 는 선분 AB 를 2:1 로 내분하는 점과 점 C 를 이은 선분의 중점이다.

:::fast 빠른 풀이 ① 무게 (질량점) 방법
계수 1, 2, 3 을 A, B, C 에 놓인 무게로 본다. A(1) 와 B(2) 를 합치면 AB 를 2:1 로 나누는 점 D 에 무게 3 이 생긴다. D(3) 와 C(3) 는 무게가 같으므로 P 는 DC 의 중점이다.
(언제 쓰나: 식이 xAP⃗ + yBP⃗ + zCP⃗ = 0⃗ 꼴이고 x, y, z 가 모두 양수일 때. 이때 P 는 항상 삼각형 ABC 의 내부에 있다. 계수 중 음수가 있으면 P 가 외부로 나가므로 정석으로 푼다. 내분비는 무게의 역비이다: A 쪽 무게 1, B 쪽 무게 2 → AD:DB = 2:1.)
:::

### 유제 58 · 위치 관계
**문제** 사면체 OABC 와 점 P 가 2AP⃗ + 3BP⃗ + 4CP⃗ = 0⃗ 을 만족할 때, 점 P 와 사면체 OABC 의 위치 관계를 조사하여라.

**정석 풀이**
1. O 를 시점으로 하면 2(p⃗−a⃗) + 3(p⃗−b⃗) + 4(p⃗−c⃗) = 0⃗ 이므로 9p⃗ = 2a⃗ + 3b⃗ + 4c⃗
2. p⃗ = (2a⃗+3b⃗+4c⃗)/9 = {5·(2a⃗+3b⃗)/5 + 4c⃗}/9
3. d⃗ = (2a⃗+3b⃗)/5 로 놓으면 D 는 선분 AB 를 3:2 로 내분하는 점이다.
4. p⃗ = (5d⃗ + 4c⃗)/9 이므로 P 는 선분 DC 를 4:5 로 내분하는 점이다.

**답** 점 P 는 선분 AB 를 3:2 로 내분하는 점 D 와 점 C 를 이은 선분 DC 를 4:5 로 내분하는 점이다(삼각형 ABC 의 내부, 즉 면 ABC 위에 있다).

:::fast 빠른 풀이 ① 무게 방법
A, B, C 에 무게 2, 3, 4. A(2)+B(3) → AB 를 3:2 로 나누는 점 D, 무게 5. D(5)+C(4) → DP:PC = 4:5.
(언제 쓰나: 응용예제 58 과 같다. 수치 검산 결과 |DP|/|PC| = 0.8 = 4/5 로 일치한다.)
:::

### 응용예제 59 · 수직임을 증명하기
**문제** 사면체 OABC 에서 OA ⊥ BC, OB ⊥ AC 이면 OC ⊥ AB 임을 증명하여라.

**정석 풀이**
1. O 를 시점으로 하여 A(a⃗), B(b⃗), C(c⃗) 로 놓는다.
2. OA ⊥ BC 이므로 a⃗·(c⃗−b⃗) = 0, 즉 a⃗·c⃗ = a⃗·b⃗ …①
3. OB ⊥ AC 이므로 b⃗·(c⃗−a⃗) = 0, 즉 b⃗·c⃗ = a⃗·b⃗ …②
4. ①, ②에서 a⃗·c⃗ = b⃗·c⃗, 즉 c⃗·(b⃗−a⃗) = 0
5. 곧 OC⃗·AB⃗ = 0 이고 OC⃗ ≠ 0⃗, AB⃗ ≠ 0⃗ 이므로 OC ⊥ AB (증명 끝)

**답** 위 증명

:::fast 빠른 풀이 ① 항등식 한 줄 증명
모든 벡터에 대해 a⃗·(c⃗−b⃗) + b⃗·(a⃗−c⃗) + c⃗·(b⃗−a⃗) = 0 이다(전개하면 모두 지워진다). 즉 OA⃗·BC⃗ + OB⃗·CA⃗ + OC⃗·AB⃗ = 0 이 항상 성립한다. 앞의 두 항이 0 이면 세 번째 항도 0 이다.
(언제 쓰나: "마주 보는 모서리 두 쌍이 수직이면 나머지 한 쌍도 수직"류 문제는 이 항등식 하나로 끝난다. 답안에는 전개 과정을 한 줄 써 둔다.)
:::

### 유제 59 · 수직임을 증명하기
**문제** 사면체 OABC 에서 AB² + OC² = AC² + OB² 이면 OA ⊥ BC 임을 증명하여라.

**정석 풀이**
1. O 를 시점으로 하여 A(a⃗), B(b⃗), C(c⃗) 로 놓는다.
2. AB² = |b⃗−a⃗|² = |b⃗|² − 2a⃗·b⃗ + |a⃗|², OC² = |c⃗|²
3. AC² = |c⃗−a⃗|² = |c⃗|² − 2a⃗·c⃗ + |a⃗|², OB² = |b⃗|²
4. 조건에 넣으면 |b⃗|² − 2a⃗·b⃗ + |a⃗|² + |c⃗|² = |c⃗|² − 2a⃗·c⃗ + |a⃗|² + |b⃗|²
5. 정리하면 a⃗·b⃗ = a⃗·c⃗, 즉 a⃗·(c⃗−b⃗) = 0
6. OA⃗·BC⃗ = 0 이고 OA⃗ ≠ 0⃗, BC⃗ ≠ 0⃗ 이므로 OA ⊥ BC (증명 끝)

**답** 위 증명

:::fast 빠른 풀이 ① A 를 시점으로 잡기
A 를 시점으로 잡고 AB⃗ = b⃗, AC⃗ = c⃗, AO⃗ = o⃗ 로 놓는다. OC² − OB² = |c⃗−o⃗|² − |b⃗−o⃗|² = |c⃗|² − |b⃗|² − 2o⃗·(c⃗−b⃗) 이다. 조건 OC² − OB² = AC² − AB² = |c⃗|² − |b⃗|² 와 비교하면 o⃗·(c⃗−b⃗) = 0, 즉 AO⃗·BC⃗ = 0.
(언제 쓰나: 증명하려는 수직선의 한쪽 끝(A)을 시점으로 두면, 나머지 항이 바로 지워진다. 기억법: "OB² − OC² = AB² − AC² ⇔ OA ⊥ BC". 두 점에서 B, C 까지 거리 제곱의 차가 같으면 두 점을 이은 선이 BC 에 수직이다.)
:::

### 발전예제 60 · 같은 평면 위의 네 점
**문제** 세 점 A(0, 1, 2), B(1, 0, 2), C(−1, 1, 3) 이 정하는 평면을 α 라 하자. 원점 O(0, 0, 0) 에서 평면 α 에 수선을 내리고, α 와의 교점을 H 라 할 때 점 H 의 좌표를 구하여라.

**정석 풀이**
1. H 는 α 위의 점이므로 AH⃗ = kAB⃗ + lAC⃗ (k, l 은 실수)
2. AB⃗ = (1, −1, 0), AC⃗ = (−1, 0, 1)
3. OH⃗ = OA⃗ + kAB⃗ + lAC⃗ = (k−l, 1−k, 2+l)
4. OH⃗ ⊥ AB⃗: (k−l) − (1−k) = 2k − l − 1 = 0 …①
5. OH⃗ ⊥ AC⃗: −(k−l) + (2+l) = −k + 2l + 2 = 0 …②
6. ①, ②에서 k = 0, l = −1
7. OH⃗ = (1, 1, 1)

**답** H(1, 1, 1)

:::fast 빠른 풀이 ① 법선벡터 사용
AB⃗ = (1,−1,0), AC⃗ = (−1,0,1) 모두에 수직인 n⃗ = (a, b, c) 는 a = b, c = a 이므로 n⃗ = (1, 1, 1) 이다. OH 는 법선 방향이므로 H = (s, s, s) 로 놓는다. 또 AH⃗·n⃗ = 0 이므로 (s)+(s−1)+(s−2) = 0, s = 1 → H(1, 1, 1)
(언제 쓰나: 원점(또는 한 점)에서 평면에 내린 수선의 발은 "법선 방향 위의 점 + 평면 조건"으로 구하는 것이 미지수 1개라 가장 빠르다. 법선벡터는 두 내적 = 0 을 풀거나 외적으로 구한다. 서술형 답안에서는 정석의 k, l 형식이 안전하다.)
:::

### 유제 60 · 네 점이 같은 평면 위에 있을 조건
**문제** 다음 네 점이 같은 평면 위에 있도록 t 의 값을 정하여라. A(1, 0, 0), B(0, 2, 0), C(0, 0, 3), D(t, 2t, 3t)

**정석 풀이**
1. D 가 평면 ABC 위에 있으므로 AD⃗ = kAB⃗ + lAC⃗ 로 쓸 수 있다.
2. AD⃗ = (t−1, 2t, 3t), AB⃗ = (−1, 2, 0), AC⃗ = (−1, 0, 3)
3. kAB⃗ + lAC⃗ = (−k−l, 2k, 3l)
4. 성분 비교: 2k = 2t 에서 k = t, 3l = 3t 에서 l = t
5. x 성분: t − 1 = −2t 이므로 3t = 1

**답** t = 1/3

:::fast 빠른 풀이 ① 계수의 합 = 1
OD⃗ = (t, 2t, 3t) = t·OA⃗ + t·OB⃗ + t·OC⃗ 이다. 이유: OA⃗=(1,0,0), OB⃗=(0,2,0), OC⃗=(0,0,3) 이므로 t(1,0,0)+t(0,2,0)+t(0,0,3) = (t, 2t, 3t). 평면 ABC 위에 있으려면 계수의 합이 1: t + t + t = 1 → t = 1/3
(언제 쓰나: OD⃗ 를 OA⃗, OB⃗, OC⃗ 로 바로 나타낼 수 있을 때. O 가 평면 ABC 위에 있으면 쓸 수 없다.)
:::

:::fast 빠른 풀이 ② 절편형 평면 방정식 (검산용)
x절편 1, y절편 2, z절편 3 인 평면은 x/1 + y/2 + z/3 = 1. D 를 대입하면 t + t + t = 1 → t = 1/3
(언제 쓰나: 세 점이 모두 좌표축 위에 있을 때만. 평면의 방정식은 교과서 발전 내용이므로 검산용으로 쓴다.)
:::

### 응용예제 61 · 삼각형의 넓이 · 사면체의 부피
**문제** 사면체 OABC 에서 O(0, 0, 0), A(3, 0, 0), B(0, 6, 0), C(0, 0, 4) 이다.
(1) △ABC 의 넓이를 구하여라.
(2) 사면체 OABC 의 부피(体積) V 를 구하여라.
(3) 점 O 에서 △ABC 에 수선을 내리고, △ABC 와의 교점을 H 라 할 때, OH 의 길이를 구하여라.
(4) 점 H 의 좌표를 구하여라.

**정석 풀이**
1. (1) AB⃗ = (−3, 6, 0), AC⃗ = (−3, 0, 4) 이므로 |AB⃗|² = 45, |AC⃗|² = 25, AB⃗·AC⃗ = 9
2. △ABC = ½√(45·25 − 9²) = ½√1044 = ½·6√29 = 3√29
3. (2) △OAB 를 밑면으로 하면 높이는 OC = 4. V = ⅓·(3·6/2)·4 = 12
4. (3) V = ⅓·△ABC·OH 이므로 ⅓·3√29·OH = 12, OH = 12/√29 = 12√29/29
5. (4) H(x, y, z) 로 놓으면 OH⃗ ⊥ AB⃗ 에서 −3x + 6y = 0, OH⃗ ⊥ AC⃗ 에서 −3x + 4z = 0
6. y = x/2, z = 3x/4 이므로 OH⃗ = (x/4)(4, 2, 3)
7. |OH⃗| = (|x|/4)√29 = 12/√29 에서 |x| = 48/29. 그림에서 x > 0 이므로 x = 48/29
8. OH⃗ = (12/29)(4, 2, 3) = (48/29, 24/29, 36/29)

**답** (1) 3√29 (2) V = 12 (3) OH = 12√29/29 (4) H(48/29, 24/29, 36/29)

:::fast 빠른 풀이 ① 절편형 평면 + 법선벡터
평면 ABC: x/3 + y/6 + z/4 = 1, 양변에 12 를 곱하면 4x + 2y + 3z = 12. 법선벡터 n⃗ = (4, 2, 3), |n⃗| = √29.
(3) 원점과 평면 사이 거리 = 12/√29 = 12√29/29
(4) H = s(4, 2, 3) 을 평면에 대입: 29s = 12, s = 12/29 → H(48/29, 24/29, 36/29)
(1) △ABC 의 넓이: 직각삼각형 세 면 △OAB=9, △OBC=12, △OCA=6 에 대해 (△ABC)² = 9² + 12² + 6² = 261 (직각사면체의 피타고라스 정리) → △ABC = √261 = 3√29
(언제 쓰나: 세 꼭짓점이 좌표축 위에 있는 직각사면체에서만. 공간 피타고라스 (S_ABC)² = S₁² + S₂² + S₃² 는 세 면이 O 에서 서로 직교할 때만 성립한다.)
:::

:::fast 빠른 풀이 ② 외적으로 넓이
AB⃗ × AC⃗ = (24, 12, 18) = 6(4, 2, 3), 크기 6√29. 넓이 = ½·6√29 = 3√29. 덤으로 법선 (4,2,3) 도 얻는다.
(언제 쓰나: 넓이 공식 ½√(|a⃗|²|b⃗|²−(a⃗·b⃗)²) 와 값이 항상 같다. 외적은 교과서 범위 밖이므로 검산용으로 쓴다.)
:::

### 유제 61 · 삼각형의 넓이
**문제** 세 점 A(1, 3, 4), B(−2, 1, 2), C(2, 4, 1) 이 있다. △ABC 의 넓이를 구하여라.

**정석 풀이**
1. AB⃗ = (−3, −2, −2), AC⃗ = (1, 1, −3)
2. |AB⃗|² = 9+4+4 = 17, |AC⃗|² = 1+1+9 = 11, AB⃗·AC⃗ = −3 − 2 + 6 = 1
3. △ABC = ½√(17·11 − 1²) = ½√186

**답** √186/2

:::fast 빠른 풀이 ① 외적의 크기
AB⃗ × AC⃗ = ((−2)(−3) − (−2)(1), (−2)(1) − (−3)(−3), (−3)(1) − (−2)(1)) = (8, −11, −1). 크기 √(64+121+1) = √186. 넓이 = √186/2
(언제 쓰나: 넓이 공식과 값이 항상 같으므로 검산용으로 좋다. 186 = 2·3·31 이므로 더 이상 간단히 되지 않는다.)
:::

## 13 벡터방정식  *ベクトル方程式*

:::concept 개념 정리
- 직선: 점 A(a⃗) 를 지나고 방향벡터(方向ベクトル) u⃗=(a, b, c) 에 평행한 직선은 p⃗ = a⃗ + tu⃗
  - 성분으로 쓰면 x = x₁+at, y = y₁+bt, z = z₁+ct (매개변수 표시, 媒介変数表示)
- 두 점 A(a⃗), B(b⃗) 를 지나는 직선: p⃗ = a⃗ + t(b⃗−a⃗) = (1−t)a⃗ + tb⃗
- 구면(球面): 중심 C(c⃗), 반지름 r → |p⃗−c⃗| = r ⇔ (x−a)² + (y−b)² + (z−c)² = r²
- 두 점 A(a⃗), B(b⃗) 를 지름의 양 끝으로 하는 구면: (p⃗−a⃗)·(p⃗−b⃗) = 0 ⇔ (x−x₁)(x−x₂) + (y−y₁)(y−y₂) + (z−z₁)(z−z₂) = 0
- 평면: 점 A(a⃗) 를 지나고 법선벡터(法線ベクトル) n⃗=(a, b, c) 에 수직인 평면은 n⃗·(p⃗−a⃗) = 0 ⇔ a(x−x₁) + b(y−y₁) + c(z−z₁) = 0
  - 일반형 ax + by + cz + d = 0 의 법선벡터는 (a, b, c)
- 수선의 발 공식(직선): 점 C 에서 직선 p⃗ = a⃗ + tu⃗ 에 내린 수선의 발은 t = (c⃗−a⃗)·u⃗ / |u⃗|²
- 수선의 발 공식(평면): 점 P₀ 에서 평면 ax+by+cz+d=0 까지의 거리 = |ax₀+by₀+cz₀+d| / √(a²+b²+c²)
:::

### 발전예제 62 · 직선의 방정식
**문제** 두 점 A(1, 2, 0), B(3, 0, 4) 를 지나는 직선 AB 가 있다. 원점 O 에서 직선 AB 에 수선을 내리고, AB 와의 교점을 H 라 한다. 점 H 의 좌표를 구하여라.

**정석 풀이**
1. 직선 AB 는 점 A 를 지나고 방향벡터가 u⃗ = AB⃗ = (2, −2, 4) 인 직선이다.
2. p⃗ = a⃗ + tu⃗ 에서 (x, y, z) = (1+2t, 2−2t, 4t)
3. H 는 이 직선 위에 있으므로 OH⃗ = (1+2t, 2−2t, 4t)
4. OH⃗ ⊥ AB⃗: (1+2t)·2 + (2−2t)·(−2) + 4t·4 = 0
5. 2 + 4t − 4 + 4t + 16t = 0, 24t = 2, t = 1/12
6. H = (1 + 1/6, 2 − 1/6, 1/3)

**답** H(7/6, 11/6, 1/3)

:::fast 빠른 풀이 ① 정사영 공식 t = (c⃗−a⃗)·u⃗ / |u⃗|²
방향벡터를 간단히 (1, −1, 2) 로 잡는다(|u⃗|² = 6). 점 O 에 대해 (O−A)·u⃗ = (−1, −2, 0)·(1, −1, 2) = −1 + 2 + 0 = 1 이므로 t = 1/6. H = A + (1/6)(1, −1, 2) = (7/6, 11/6, 1/3)
(언제 쓰나: 직선 위로 수선의 발을 구할 때 항상 쓸 수 있다. AH⃗ 는 AO⃗ 를 u⃗ 방향으로 정사영한 것이기 때문이다. 방향벡터를 줄이면 t 값도 바뀌므로, H 를 구할 때는 줄인 u⃗ 를 그대로 써야 한다.)
:::

### 유제 62 · 점에서 직선에 내린 수선의 발
**문제** 두 점 A(0, 1, 2), B(1, 3, 3) 을 지나는 직선 AB 가 있다. 점 C(4, 5, 6) 에서 직선 AB 에 수선을 내리고, AB 와의 교점을 H 라 한다. 점 H 의 좌표를 구하여라.

**정석 풀이**
1. 방향벡터 u⃗ = AB⃗ = (1, 2, 1). 직선 위의 점은 (t, 1+2t, 2+t)
2. H(t, 1+2t, 2+t) 로 놓으면 CH⃗ = (t−4, 2t−4, t−4)
3. CH⃗ ⊥ AB⃗: (t−4)·1 + (2t−4)·2 + (t−4)·1 = 0
4. 6t − 16 = 0, t = 8/3
5. H = (8/3, 1 + 16/3, 2 + 8/3) = (8/3, 19/3, 14/3)

**답** H(8/3, 19/3, 14/3)

:::fast 빠른 풀이 ① 정사영 공식
AC⃗ = (4, 4, 4), u⃗ = (1, 2, 1), |u⃗|² = 6. t = AC⃗·u⃗/|u⃗|² = (4+8+4)/6 = 8/3. H = A + (8/3)u⃗ = (8/3, 19/3, 14/3)
(언제 쓰나: 발전예제 62 와 같다. 검산: CH⃗ = (−4/3, 4/3, −4/3), CH⃗·u⃗ = −4/3 + 8/3 − 4/3 = 0 ✓)
:::

### 기본예제 63 · 구면의 방정식
**문제** 점 C(2, 3, −3) 을 중심으로 하는 반지름 5 인 구면의 방정식(球面の方程式)을 구하여라. 또, 점 A(−2, 3, 0) 이 이 구면 위에 있음을 보여라.

**정석 풀이**
1. p⃗ = (x, y, z) 로 놓으면 p⃗ − c⃗ = (x−2, y−3, z+3)
2. |p⃗ − c⃗|² = 5² 에서 (x−2)² + (y−3)² + (z+3)² = 25
3. 좌변에 A 의 좌표를 넣으면 (−2−2)² + (3−3)² + (0+3)² = 16 + 0 + 9 = 25 = 우변
4. 방정식을 만족하므로 점 A 는 이 구면 위에 있다.

**답** (x−2)² + (y−3)² + (z+3)² = 25, A 는 구면 위에 있다(위 증명).

:::fast 빠른 풀이 ① 3-4-5 직각삼각형 확인
CA⃗ = (−4, 0, 3) 이다. 성분 4, 3 을 보면 바로 |CA⃗| = 5 (3:4:5) 이므로 A 는 구면 위에 있다.
(언제 쓰나: "구면 위에 있음을 보여라" = "중심까지의 거리가 반지름과 같음을 보여라". 성분이 피타고라스 수(3,4,5 / 5,12,13 / 1,2,2→3 등)이면 암산으로 끝난다.)
:::

### 유제 63 · 구면의 방정식
**문제** 다음 구면의 방정식을 구하여라.
(1) 점 C(−4, 3, 3) 을 중심으로 하고, 점 (−3, −1, −5) 를 지나는 구면
(2) 두 점 A(1, −2, 3), B(3, 2, 5) 를 지름의 양 끝으로 하는 구면

**정석 풀이**
1. (1) 반지름 r 은 C 와 점 (−3, −1, −5) 사이의 거리: r² = (1)² + (−4)² + (−8)² = 1 + 16 + 64 = 81
2. 따라서 (x+4)² + (y−3)² + (z−3)² = 81
3. (2) 중심은 AB 의 중점 (2, 0, 4)
4. 반지름² = (1−2)² + (−2−0)² + (3−4)² = 1 + 4 + 1 = 6
5. 따라서 (x−2)² + y² + (z−4)² = 6

**답** (1) (x+4)² + (y−3)² + (z−3)² = 81 (2) (x−2)² + y² + (z−4)² = 6

:::fast 빠른 풀이 ① (2) 지름 공식 (p⃗−a⃗)·(p⃗−b⃗) = 0
(x−1)(x−3) + (y+2)(y−2) + (z−3)(z−5) = 0 을 바로 쓴다. 전개하면 x² − 4x + 3 + y² − 4 + z² − 8z + 15 = 0, 즉 (x−2)² + y² + (z−4)² = 4 + 16 − 14 = 6
(언제 쓰나: 지름의 양 끝이 주어지면 항상 쓸 수 있다. 중점과 반지름을 따로 구할 필요가 없다. 답을 표준형으로 내라고 하면 완전제곱식으로 고친다.)
:::

### 발전예제 64 · 평면의 방정식
**문제** 평면 3x + 2y + z = 6 이 있다. 다음 물음에 답하여라.
(1) 이 평면의 법선벡터(法線ベクトル) n⃗ 를 구하여라.
(2) 원점 O 에서 이 평면에 수선을 내리고, 평면과의 교점을 H 라 한다. 점 H 의 좌표를 구하여라.

**정석 풀이**
1. (1) 평면 ax + by + cz + d = 0 의 법선벡터는 (a, b, c) 이므로 n⃗ = (3, 2, 1)
2. (2) OH⃗ ∥ n⃗ 이므로 OH⃗ = tn⃗ = (3t, 2t, t)
3. H 는 평면 위의 점이므로 3·3t + 2·2t + t = 6, 14t = 6, t = 3/7
4. H = (9/7, 6/7, 3/7)

**답** (1) n⃗ = (3, 2, 1) (2) H(9/7, 6/7, 3/7)

:::fast 빠른 풀이 ① 공식 t = (우변)/|n⃗|²
원점에서 평면 n⃗·p⃗ = k 에 내린 수선의 발은 H = (k/|n⃗|²)n⃗ 이다. k = 6, |n⃗|² = 9+4+1 = 14 → H = (6/14)(3, 2, 1) = (9/7, 6/7, 3/7). 덤으로 거리 OH = 6/√14
(언제 쓰나: 원점에서 내린 수선이면 항상 쓸 수 있다. 원점이 아닌 점 P₀ 에서 내리면 t = (k − n⃗·p⃗₀)/|n⃗|², H = P₀ + tn⃗ 로 바뀐다.)
:::

### 유제 64 · 법선벡터와 한 점으로 평면 구하기
**문제** 점 A(2, 3, 4) 를 지나고 법선벡터가 n⃗ = (3, −4, 1) 인 평면의 방정식을 구하여라.

**정석 풀이**
1. n⃗·(p⃗ − a⃗) = 0 에서 3(x−2) − 4(y−3) + 1·(z−4) = 0
2. 전개: 3x − 6 − 4y + 12 + z − 4 = 0

**답** 3x − 4y + z + 2 = 0

:::fast 빠른 풀이 ① d 만 대입으로 구하기
평면은 3x − 4y + z + d = 0 꼴이다. A 를 넣으면 6 − 12 + 4 + d = 0, d = 2 → 3x − 4y + z + 2 = 0
(언제 쓰나: 법선벡터를 알면 항상 쓸 수 있다. 계수 (a, b, c) 는 그대로 두고 상수항만 구하면 되므로 전개 실수가 줄어든다.)
:::

### 참고 · 세 점으로 정해지는 평면의 방정식 (これも知っ得)
**문제** 세 점 A(−1, 2, 1), B(−2, 1, 1), C(1, 2, 3) 으로 정해지는 평면 α 의 방정식을 구하여라. (교과서 읽을거리, 답 x − y − z + 4 = 0)

**정석 풀이**
1. 방법 1 (연립방정식): ax + by + cz + d = 0 에 세 점을 넣는다.
   −a + 2b + c + d = 0, −2a + b + c + d = 0, a + 2b + 3c + d = 0
2. b, c, d 를 a 로 나타내면 b = −a, c = −a, d = 4a
3. a(x − y − z + 4) = 0 이고 a ≠ 0 이므로 x − y − z + 4 = 0
4. 방법 2 (법선벡터): AB⃗ = (−1, −1, 0), AC⃗ = (2, 0, 2). n⃗ = (a, b, c) 로 놓으면 −a − b = 0, 2a + 2c = 0 에서 n⃗ = (a, −a, −a)
5. n⃗ = (1, −1, −1) 로 잡으면 1·(x+1) − 1·(y−2) − 1·(z−1) = 0, 즉 x − y − z + 4 = 0

**답** x − y − z + 4 = 0

:::fast 빠른 풀이 ① 외적으로 법선벡터
AB⃗ × AC⃗ = ((−1)·2 − 0·0, 0·2 − (−1)·2, (−1)·0 − (−1)·2) = (−2, 2, 2) = −2(1, −1, −1). 법선 (1, −1, −1), A 를 대입하면 −1 − 2 − 1 + d = 0, d = 4 → x − y − z + 4 = 0
(언제 쓰나: 세 점이 주어진 평면은 항상 쓸 수 있다. 외적은 교과서 범위 밖이므로 검산용으로 쓴다. 마지막에 세 점을 모두 대입해서 0 이 되는지 확인한다(확인 완료).)
:::
