### 응용예제 32 · 교점의 위치벡터 (2)
**문제** 평행사변형(平行四辺形) ABCD에서 변 BC의 중점을 M, 변 CD를 1:2로 내분(内分)하는 점을 N이라 하고, AN과 DM의 교점(交点)을 P라 한다.
(1) AB⃗ = a⃗, AD⃗ = b⃗로 둘 때, AP⃗를 a⃗, b⃗로 나타내라.
(2) CP와 AD의 교점을 Q라 할 때, AQ:QD를 구하라.

**정석 풀이**
1. (1) MP:PD = t:(1−t)로 두면 AP⃗ = (1−t)AM⃗ + tAD⃗ = (1−t)(a⃗ + ½b⃗) + tb⃗ = (1−t)a⃗ + (1+t)/2·b⃗ …①
2. A, P, N은 한 직선 위에 있으므로 AP⃗ = kAN⃗. AN⃗ = (2AC⃗ + AD⃗)/3 = (2(a⃗+b⃗) + b⃗)/3 이므로 AP⃗ = (2k/3)a⃗ + kb⃗ …②
3. a⃗ ≠ 0⃗, b⃗ ≠ 0⃗, a⃗ ∦ b⃗이므로 표현은 하나뿐(1通り). ①, ②의 계수 비교: 1−t = 2k/3, (1+t)/2 = k → k = ¾, t = ½
4. AP⃗ = ½a⃗ + ¾b⃗
5. (2) Q는 AD 위의 점이므로 AQ⃗ = l·b⃗ …③
6. CQ:QP = s:(1−s)로 두면 AQ⃗ = (1−s)AC⃗ + sAP⃗ = (1−s)(a⃗+b⃗) + s(½a⃗ + ¾b⃗) = (1 − s/2)a⃗ + (1 − s/4)b⃗ …④
7. ③, ④ 비교: 1 − s/2 = 0, 1 − s/4 = l → s = 2, l = ½
8. AQ⃗ = ½b⃗ 이므로 AQ:QD = 1:1

**답** (1) AP⃗ = ½a⃗ + ¾b⃗  (2) AQ:QD = 1:1

:::fast 빠른 풀이 ① 좌표 놓기 (a⃗=(1,0), b⃗=(0,1))
계수 비교만 필요한 문제이므로 평행사변형을 단위정사각형으로 바꿔도 비율·계수는 그대로입니다(아핀 변환 불변).
A(0,0), B(1,0), D(0,1), C(1,1) → M(1, ½), N = CD를 1:2로 내분 = (⅔, 1).
직선 AN: y = (3/2)x. 직선 DM: y = 1 − x/2.
연립: (3/2)x = 1 − x/2 → x = ½, y = ¾ → P(½, ¾) → AP⃗ = ½a⃗ + ¾b⃗.
(2) 직선 CP: C(1,1), P(½,¾) → 기울기 ½, y = ½x + ½. x = 0이면 y = ½ → Q(0, ½) → AQ:QD = 1:1.
(언제 쓰나: 길이·각도가 안 나오고 "계수·비율"만 묻는 문제. 내적·길이를 묻는 문제에서는 직각으로 바꾸면 안 됨.)
:::

:::fast 빠른 풀이 ② 닮음(평행선)으로 비율 바로 읽기
(2)만: AN을 연장하면 BC와 만나지 않으니, 대신 P의 좌표 결과 AP⃗ = ½a⃗ + ¾b⃗를 쓰면 C(1,1)에서 P로 가는 방향이 (−½, −¼) = −¼(2, 1). C에서 a⃗ 방향으로 −1만큼 가면 AD 위에 도착하므로 b⃗ 성분은 1 − ½ = ½ → AQ = ½AD.
(언제 쓰나: (1)의 결과가 있을 때 "직선 위 점의 한 성분이 0이 되는 지점"을 찾는 방식. 방향벡터 비례만 쓰므로 항상 안전.)
:::

### 유제 32 · 교점의 위치벡터와 비
**문제** 평행사변형 ABCD에서 변 AB를 2:1, 변 BC를 3:2, 변 CD를 2:1로 내분하는 점을 각각 L, M, N이라 하고, AM과 LN의 교점을 P라 한다.
(1) AB⃗ = a⃗, AD⃗ = b⃗로 둘 때 AP⃗를 a⃗, b⃗로 나타내라.
(2) LP:PN을 구하라.

**정석 풀이**
1. AL⃗ = ⅔a⃗, AM⃗ = a⃗ + ⅗b⃗, AN⃗ = AC⃗ + ⅔CD⃗ = (a⃗+b⃗) − ⅔a⃗ = ⅓a⃗ + b⃗
2. P는 AM 위: AP⃗ = kAM⃗ = ka⃗ + (3k/5)b⃗ …①
3. LP:PN = t:(1−t)로 두면 AP⃗ = (1−t)AL⃗ + tAN⃗ = (1−t)·⅔a⃗ + t(⅓a⃗ + b⃗) = (⅔ − t/3)a⃗ + tb⃗ …②
4. a⃗ ≠ 0⃗, b⃗ ≠ 0⃗, a⃗ ∦ b⃗이므로 계수 비교: k = ⅔ − t/3, 3k/5 = t
5. k = ⅔ − k/5 → (6/5)k = ⅔ → k = 5/9, t = ⅓
6. AP⃗ = (5/9)a⃗ + ⅓b⃗, LP:PN = t:(1−t) = 1:2

**답** (1) AP⃗ = (5/9)a⃗ + (1/3)b⃗  (2) LP:PN = 1:2

:::fast 빠른 풀이 ① 단위정사각형 좌표
A(0,0), B(1,0), C(1,1), D(0,1) → L(⅔, 0), M(1, ⅗), N(⅓, 1).
직선 AM: y = (3/5)x. L→N 방향 (−⅓, 1)이므로 LN 위의 점 = (⅔ − t/3, t).
대입: t = (3/5)(⅔ − t/3) = ⅖ − t/5 → (6/5)t = ⅖ → t = ⅓ → P(5/9, ⅓).
→ AP⃗ = (5/9)a⃗ + ⅓b⃗, LP:PN = ⅓ : ⅔ = 1:2.
(언제 쓰나: 위치벡터의 계수·선분비만 물을 때. 아핀 변환은 평행·내분비를 보존하므로 안전. 길이·내적 문제에는 사용 금지.)
:::

:::fast 빠른 풀이 ② 높이(b⃗ 성분)로 비 읽기
LN 위에서 b⃗ 성분은 L에서 0, N에서 1로 일정하게 증가합니다. 따라서 LP:PN = (P의 b⃗ 성분) : (1 − P의 b⃗ 성분) = ⅓ : ⅔ = 1:2. P를 구하자마자 비를 바로 읽을 수 있습니다.
(언제 쓰나: 선분의 두 끝점이 서로 평행한 두 변(AB, CD) 위에 있을 때. 한 성분이 0→1로 바뀌는 경우에만 바로 쓸 수 있음.)
:::

### 응용예제 33 · 중선정리의 증명
**문제** △ABC에서 변 BC의 중점을 M이라 할 때, AB² + AC² = 2(AM² + BM²)임을 증명하라. (중선정리, 中線定理)

**정석 풀이**
1. 시점을 M으로: MA⃗ = a⃗, MB⃗ = b⃗로 두면 MC⃗ = −b⃗
2. AB² + AC² = |b⃗ − a⃗|² + |−b⃗ − a⃗|² = (|b⃗|² − 2a⃗·b⃗ + |a⃗|²) + (|b⃗|² + 2a⃗·b⃗ + |a⃗|²) = 2(|a⃗|² + |b⃗|²)
3. 2(AM² + BM²) = 2(|−a⃗|² + |−b⃗|²) = 2(|a⃗|² + |b⃗|²)
4. 따라서 AB² + AC² = 2(AM² + BM²) (증명 끝)

:::fast 빠른 풀이 ① 평행사변형 법칙 한 줄
|x⃗+y⃗|² + |x⃗−y⃗|² = 2(|x⃗|² + |y⃗|²)에 x⃗ = MA⃗, y⃗ = MB⃗를 넣으면 x⃗ − y⃗ = BA⃗, x⃗ + y⃗ = MA⃗ − MC⃗ = CA⃗. 바로 AB² + AC² = 2(AM² + BM²).
(언제 쓰나: "제곱의 합"이 나오고 중점이 있으면 거의 항상 이 항등식. 중점이 아니면 x⃗+y⃗ 형태가 안 나와 실패.)
:::

:::fast 빠른 풀이 ② 좌표 증명 아이디어
M(0,0), B(−m,0), C(m,0), A(p,q)로 두면 AB² + AC² = (p+m)² + q² + (p−m)² + q² = 2(p² + q²) + 2m² = 2(AM² + BM²).
(언제 쓰나: 서술형이 아니라 확인용. 시험 답안에서는 벡터 증명을 쓰는 편이 무난.)
:::

### 유제 33 · 무게중심과 제곱의 합
**문제** △ABC의 무게중심(重心)을 G라 할 때, 다음 등식을 증명하라.
AB² + AC² = BG² + CG² + 4AG²

**정석 풀이**
1. 시점을 G로: GA⃗ = a⃗, GB⃗ = b⃗, GC⃗ = c⃗로 두면, G가 무게중심이므로 a⃗ + b⃗ + c⃗ = 0⃗, 즉 b⃗ + c⃗ = −a⃗
2. AB² + AC² = |b⃗ − a⃗|² + |c⃗ − a⃗|² = |b⃗|² + |c⃗|² + 2|a⃗|² − 2a⃗·(b⃗ + c⃗)
3. = |b⃗|² + |c⃗|² + 2|a⃗|² − 2a⃗·(−a⃗) = |b⃗|² + |c⃗|² + 4|a⃗|²
4. = BG² + CG² + 4AG² (증명 끝)

:::fast 빠른 풀이 ① 중선정리 두 번
BC의 중점 M에서, A, G, M은 일직선이고 AG = 2GM, AM = 3GM.
△ABC에 중선정리: AB² + AC² = 2AM² + 2BM² = 18GM² + 2BM².
△GBC에 중선정리: BG² + CG² = 2GM² + 2BM². 여기에 4AG² = 16GM²를 더하면 18GM² + 2BM². 두 값이 같으므로 성립.
(언제 쓰나: 바로 앞 예제 결과를 쓸 수 있을 때. 증명 문제에서 이미 증명한 정리를 인용하는 것은 정당.)
:::

### 응용예제 34 · 수직 관계의 증명
**문제** △ABC와 점 H가 주어져 있다. HB ⊥ CA, HC ⊥ AB이면 AH ⊥ BC임을 증명하라.

**정석 풀이**
1. 시점을 H로: HA⃗ = a⃗, HB⃗ = b⃗, HC⃗ = c⃗
2. HB ⊥ CA → HB⃗·CA⃗ = 0 → b⃗·(a⃗ − c⃗) = 0 → a⃗·b⃗ = b⃗·c⃗ …①
3. HC ⊥ AB → HC⃗·AB⃗ = 0 → c⃗·(b⃗ − a⃗) = 0 → a⃗·c⃗ = b⃗·c⃗ …②
4. HA⃗·BC⃗ = a⃗·(c⃗ − b⃗) = a⃗·c⃗ − a⃗·b⃗ = b⃗·c⃗ − b⃗·c⃗ = 0 (①, ②)
5. 따라서 AH ⊥ BC (증명 끝). 이 점 H를 수심(垂心)이라 한다.

:::fast 빠른 풀이 ① 세 내적의 합이 항등적으로 0
어떤 점 H에 대해서도 HA⃗·BC⃗ + HB⃗·CA⃗ + HC⃗·AB⃗ = a⃗·(c⃗−b⃗) + b⃗·(a⃗−c⃗) + c⃗·(b⃗−a⃗) = 0 (전개하면 모두 소거).
따라서 두 개가 0이면 나머지 하나도 자동으로 0.
(언제 쓰나: "두 수직 → 세 번째 수직" 유형 전반. 항등식이므로 실패하는 경우 없음.)
:::

### 유제 34 · 외심·무게중심·수심 (오일러 직선)
**문제** △ABC의 외심(外心)을 O, 무게중심을 G라 하고, OH⃗ = OA⃗ + OB⃗ + OC⃗로 점 H를 정할 때,
(1) 점 H는 △ABC의 수심(垂心)임을 증명하라.
(2) 세 점 O, G, H는 한 직선 위에 있음을 증명하라.

(※ 스캔 인쇄가 작아 (1)의 "垂心"이 "重心"처럼 보일 수 있으나, 내용상 수심이다.)

**정석 풀이**
1. OA⃗ = a⃗, OB⃗ = b⃗, OC⃗ = c⃗로 두면, O가 외심이므로 |a⃗| = |b⃗| = |c⃗| (= 외접원 반지름 R)
2. (1) AH⃗ = OH⃗ − OA⃗ = b⃗ + c⃗, BC⃗ = c⃗ − b⃗
3. AH⃗·BC⃗ = (c⃗ + b⃗)·(c⃗ − b⃗) = |c⃗|² − |b⃗|² = 0 → AH ⊥ BC (H = A인 경우도 포함)
4. 같은 방법으로 BH⃗·CA⃗ = (a⃗ + c⃗)·(a⃗ − c⃗) = |a⃗|² − |c⃗|² = 0 → BH ⊥ CA
5. 따라서 H는 두 수선 위에 있으므로 수심이다.
6. (2) OG⃗ = (a⃗ + b⃗ + c⃗)/3 = ⅓OH⃗
7. 따라서 O, G, H는 한 직선 위에 있다 (OG:GH = 1:2). (증명 끝)

:::fast 빠른 풀이 ① 합·차의 내적 = 제곱의 차
(x⃗+y⃗)·(x⃗−y⃗) = |x⃗|² − |y⃗|²이므로, 길이가 같은 두 벡터의 합과 차는 항상 수직(마름모의 대각선). AH⃗ = b⃗ + c⃗, BC⃗ = c⃗ − b⃗를 보는 순간 끝.
(언제 쓰나: 외심을 시점으로 하여 |a⃗|=|b⃗|=|c⃗|인 상황. 시점이 외심이 아니면 성립 안 함.)
:::

:::fast 빠른 풀이 ② 수치 점검(검산용)
A(0,0), B(4,0), C(1,3)로 놓으면 외심 O(2,1), OH⃗ = OA⃗+OB⃗+OC⃗ → H(1,1). 실제 수심: C에서의 수선 x=1, A에서 BC(방향 (−3,3))에 수직인 직선 y=x → (1,1). 일치. G(5/3,1) = O + ⅓(H−O) ✓.
(언제 쓰나: 증명 방향이 맞는지 시험지 여백에서 30초 확인. 증명 자체를 대체하지는 않음.)
:::

### 응용예제 35 · 각을 이등분하는 벡터
**문제** △OAB에서 ∠AOB의 이등분선과 변 AB의 교점을 D라 할 때, AD:DB = OA:OB임을 증명하라.

**정석 풀이**
1. OA⃗ = a⃗, OB⃗ = b⃗로 두고, a⃗, b⃗와 같은 방향의 단위벡터(単位ベクトル)를 OE⃗ = a⃗/|a⃗|, OF⃗ = b⃗/|b⃗|로 둔다.
2. OP⃗ = OE⃗ + OF⃗인 점 P를 잡으면 평행사변형 OEPF는 OE = OF = 1이므로 마름모(ひし形). 마름모의 대각선은 각을 이등분하므로 OP는 ∠AOB의 이등분선이고, OP(의 연장)와 AB의 교점이 D이다.
3. OP⃗ = a⃗/|a⃗| + b⃗/|b⃗| = (|b⃗|a⃗ + |a⃗|b⃗)/(|a⃗||b⃗|) = (|a⃗|+|b⃗|)/(|a⃗||b⃗|) · (|b⃗|a⃗ + |a⃗|b⃗)/(|a⃗|+|b⃗|)
4. (|b⃗|a⃗ + |a⃗|b⃗)/(|a⃗|+|b⃗|)는 계수의 합이 1이므로 그 종점은 변 AB 위에 있다. 이것은 OP 위에도 있으므로 OD⃗ = (|b⃗|a⃗ + |a⃗|b⃗)/(|a⃗|+|b⃗|).
5. 따라서 D는 AB를 |a⃗|:|b⃗|로 내분한다. 즉 AD:DB = OA:OB (증명 끝)

:::fast 빠른 풀이 ① 넓이비(높이가 같은 삼각형)
△OAD와 △ODB는 AB 위의 밑변 AD, DB를 가지고 높이가 같으므로 넓이비 = AD:DB.
한편 넓이를 ½·OA·OD·sin(θ/2), ½·OB·OD·sin(θ/2)로 쓰면 넓이비 = OA:OB. 따라서 AD:DB = OA:OB.
(언제 쓰나: 증명 아이디어로 가장 빠름. 벡터 단원 시험에서 "벡터로 증명하라"고 지정되면 정석 풀이를 써야 함.)
:::

:::fast 빠른 풀이 ② 외워 둘 공식: 각의 이등분 방향 = 단위벡터의 합
∠AOB의 이등분선 방향벡터는 a⃗/|a⃗| + b⃗/|b⃗|, 또는 같은 방향인 |b⃗|a⃗ + |a⃗|b⃗. 이 형태를 보면 바로 "AB를 |a⃗|:|b⃗|로 내분"이라고 읽으면 됩니다.
(언제 쓰나: 내각의 이등분선. 외각의 이등분선은 a⃗/|a⃗| − b⃗/|b⃗| 방향이며 외분이 되므로 부호에 주의.)
:::

### 참고 (これも知っ得) · 삼각형의 내심·외심·수심
**문제** OA = 5, OB = 4, AB = 6인 △OAB에서 OA⃗ = a⃗, OB⃗ = b⃗라 할 때, 내심(内心) I, 외심(外心) P, 수심(垂心) H의 위치벡터를 a⃗, b⃗로 나타내라. (교과서 해설 칼럼)

**정석 풀이**
1. 내심: ∠AOB의 이등분선과 AB의 교점 D에 대해 AD:DB = 5:4, AD = 6·5/9 = 10/3.
2. AI는 ∠OAD의 이등분선이므로 OI:ID = AO:AD = 5 : 10/3 = 3:2 → OI⃗ = ⅗OD⃗ = ⅗·(4a⃗ + 5b⃗)/9 = (4a⃗ + 5b⃗)/15
3. 외심: |b⃗ − a⃗|² = 36 → 16 − 2a⃗·b⃗ + 25 = 36 → a⃗·b⃗ = 5/2.
4. OP⃗ = ma⃗ + nb⃗, OA, OB의 중점 M, N에 대해 MP⃗·OA⃗ = 0, NP⃗·OB⃗ = 0 → 25(m − ½) + (5/2)n = 0, (5/2)m + 16(n − ½) = 0 → m = 16/35, n = 3/7.
5. 수심: OH⃗ = pa⃗ + qb⃗, AH⃗·OB⃗ = 0, BH⃗·OA⃗ = 0 → (5/2)(p−1) + 16q = 0, 25p + (5/2)(q−1) = 0 → p = 3/35, q = 1/7.

**답** OI⃗ = (4a⃗ + 5b⃗)/15, OP⃗(외심) = (16/35)a⃗ + (3/7)b⃗, OH⃗ = (3/35)a⃗ + (1/7)b⃗

:::fast 빠른 풀이 ① 내심 = 마주 보는 변의 길이로 가중평균
내심 I = (꼭짓점 × 그 꼭짓점의 대변 길이)의 가중평균. O의 대변 AB = 6, A의 대변 OB = 4, B의 대변 OA = 5:
OI⃗ = (6·0⃗ + 4a⃗ + 5b⃗)/(6+4+5) = (4a⃗ + 5b⃗)/15.
(언제 쓰나: 세 변의 길이를 알 때 내심은 항상 이것. 외심·수심에는 이런 단순 가중치가 없음.)
:::

:::fast 빠른 풀이 ② 오일러 직선으로 수심 바로 구하기
외심 P를 시점으로 하면 PH⃗ = PO⃗ + PA⃗ + PB⃗ (유제 34). O를 시점으로 고치면 OH⃗ = OA⃗ + OB⃗ − 2OP⃗ = a⃗ + b⃗ − 2(16/35 a⃗ + 3/7 b⃗) = (3/35)a⃗ + (1/7)b⃗.
(언제 쓰나: 외심을 이미 구했을 때 수심은 연립 없이 한 줄. 반대로 수심에서 외심도 가능.)
:::

## 7 벡터방정식  *ベクトル方程式*

:::concept 개념 정리
- 점 A(a⃗)를 지나고 u⃗(≠0⃗)에 평행한 직선: p⃗ = a⃗ + tu⃗ (u⃗ = 방향벡터(方向ベクトル), t = 매개변수(媒介変数, パラメータ))
- 두 점 A(a⃗), B(b⃗)를 지나는 직선: p⃗ = a⃗ + t(b⃗ − a⃗) = (1−t)a⃗ + tb⃗ = sa⃗ + tb⃗ (s + t = 1)
- 점 A(a⃗)를 지나고 n⃗에 수직인 직선: (p⃗ − a⃗)·n⃗ = 0 (n⃗ = 법선벡터(法線ベクトル))
- 성분 표시(매개변수 표시): A(x₁, y₁), u⃗ = (a, b) → x = x₁ + at, y = y₁ + bt
- 직선 ax + by + c = 0의 법선벡터는 n⃗ = (a, b), 방향벡터는 (−b, a) 또는 (b, −a)
- 원: |p⃗ − c⃗| = r 또는 (p⃗ − a⃗)·(p⃗ − b⃗) = 0 (AB가 지름)
:::

### 기본예제 36 · 직선의 매개변수 표시
**문제** 다음 직선을 매개변수 t를 써서 나타내라.
(1) 점 A(2, 3)을 지나고 u⃗ = (1, 2)에 평행한 직선
(2) 두 점 A(−2, 2), B(2, 0)을 지나는 직선

**정석 풀이**
1. 동점을 P(x, y)로 두고 성분으로 나타낸다.
2. (1) p⃗ = a⃗ + tu⃗ → (x, y) = (2, 3) + t(1, 2) → x = 2 + t, y = 3 + 2t
3. (2) AB⃗ = (2, 0) − (−2, 2) = (4, −2). p⃗ = a⃗ + t(b⃗ − a⃗) → (x, y) = (−2, 2) + t(4, −2) → x = −2 + 4t, y = 2 − 2t

**답** (1) x = 2 + t, y = 3 + 2t  (2) x = −2 + 4t, y = 2 − 2t

:::fast 빠른 풀이 ① t를 소거해 검산
(1) t = x − 2 → y = 3 + 2(x − 2) → y = 2x − 1 (기울기 = u⃗의 y/x = 2). (2) t = (x+2)/4 → y = 2 − (x+2)/2 → x + 2y − 2 = 0. A, B 대입: −2 + 4 − 2 = 0 ✓, 2 + 0 − 2 = 0 ✓.
(언제 쓰나: 매개변수 표시는 답이 여러 형태(시작점·방향벡터 선택)로 가능하므로, 소거한 일반식으로 맞는지 확인. (2)는 (x, y) = (2, 0) + t(4, −2)나 방향 (2, −1)도 정답.)
:::

### 유제 36 · 직선의 매개변수 표시
**문제** 다음 직선을 매개변수 t를 써서 나타내라.
(1) 점 A(2, −1)을 지나고 u⃗ = (3, 4)에 평행한 직선
(2) 두 점 A(1, 2), B(−2, 1)을 지나는 직선

**정석 풀이**
1. (1) (x, y) = (2, −1) + t(3, 4) → x = 2 + 3t, y = −1 + 4t
2. (2) AB⃗ = (−2 − 1, 1 − 2) = (−3, −1). (x, y) = (1, 2) + t(−3, −1) → x = 1 − 3t, y = 2 − t

**답** (1) x = 2 + 3t, y = −1 + 4t  (2) x = 1 − 3t, y = 2 − t

:::fast 빠른 풀이 ① 일반식으로 바꿔 검산
(1) 방향 (3, 4) → 법선 (4, −3): 4(x − 2) − 3(y + 1) = 0 → 4x − 3y − 11 = 0. (2) 방향 (−3, −1) → 법선 (1, −3): (x − 1) − 3(y − 2) = 0 → x − 3y + 5 = 0. B(−2, 1): −2 − 3 + 5 = 0 ✓.
(언제 쓰나: 방향벡터 (a, b)의 법선은 (b, −a). 매개변수 표시의 답이 유일하지 않으므로(예: (2)를 (−2, 1) + t(3, 1)로 써도 정답) 일반식으로 같은 직선인지 확인할 때 유용.)
:::

### 기본예제 37 · n⃗에 수직인 직선
**문제** 점 A(2, 1)을 지나고 n⃗ = (3, 4)에 수직인 직선에 대하여
(1) 점 A의 위치벡터를 a⃗, 동점을 P(p⃗)로 하여 벡터방정식으로 나타내라.
(2) 동점을 P(x, y)로 하여 x, y의 방정식으로 나타내라.

**정석 풀이**
1. (1) AP⃗ = p⃗ − a⃗, AP⃗ ⊥ n⃗ (또는 AP⃗ = 0⃗) → AP⃗·n⃗ = 0 → (p⃗ − a⃗)·n⃗ = 0
2. (2) p⃗ − a⃗ = (x − 2, y − 1), n⃗ = (3, 4) → 3(x − 2) + 4(y − 1) = 0 → 3x + 4y − 10 = 0

**답** (1) (p⃗ − a⃗)·n⃗ = 0  (2) 3x + 4y − 10 = 0

:::fast 빠른 풀이 ① 법선벡터 = 계수, 상수는 대입으로
법선 (3, 4) → 3x + 4y + c = 0. A(2, 1) 대입: 6 + 4 + c = 0 → c = −10. 답 3x + 4y − 10 = 0.
(언제 쓰나: "점 + 법선벡터"가 주어진 모든 직선. 2초 컷. 3차원에서는 같은 방법으로 평면의 방정식이 됨.)
:::

### 유제 37 · 법선벡터로 직선의 방정식
**문제** 다음 직선의 방정식을 구하라.
(1) 점 A(4, 1)을 지나고 n⃗ = (2, −3)에 수직인 직선
(2) 점 A(−2, 3)을 지나고 n⃗ = (−2, 1)에 수직인 직선

**정석 풀이**
1. (1) (x − 4, y − 1)·(2, −3) = 0 → 2(x − 4) − 3(y − 1) = 0 → 2x − 3y − 5 = 0
2. (2) (x + 2, y − 3)·(−2, 1) = 0 → −2(x + 2) + (y − 3) = 0 → −2x + y − 7 = 0 → 2x − y + 7 = 0

**답** (1) 2x − 3y − 5 = 0  (2) 2x − y + 7 = 0

:::fast 빠른 풀이 ① 계수 고정 + 점 대입
(1) 2x − 3y + c = 0, (4, 1): 8 − 3 + c = 0 → c = −5. (2) −2x + y + c = 0, (−2, 3): 4 + 3 + c = 0 → c = −7 → −2x + y − 7 = 0, 즉 2x − y + 7 = 0.
(언제 쓰나: 항상 안전. 마지막에 점을 다시 대입해 0이 나오는지만 확인.)
:::

### 기본예제 38 · 점의 존재 범위
**문제** 한 직선 위에 있지 않은 세 점 O, A, B에 대하여 OP⃗ = sOA⃗ + tOB⃗로 둔다. 실수 s, t가 다음 관계를 만족할 때 점 P의 존재 범위(存在範囲)를 그림으로 나타내라.
(1) s = 1, t = 1  (2) s = 2, t = −1  (3) 2s + t = 2  (4) s + t ≤ 1, s ≥ 0, t ≥ 0

**정석 풀이**
1. OQ⃗ = xe⃗₁ + ye⃗₂ (보통 xy좌표)를 OP⃗ = sOA⃗ + tOB⃗로 "바꿔 읽는다": OA⃗, OB⃗를 축으로 하는 비스듬한 좌표(s, t)라고 생각한다.
2. (1) (x, y) = (1, 1) ↔ (s, t) = (1, 1): OP⃗ = OA⃗ + OB⃗, 즉 OA, OB를 두 변으로 하는 평행사변형의 네 번째 꼭짓점.
3. (2) (s, t) = (2, −1): OP⃗ = 2OA⃗ − OB⃗인 한 점.
4. (3) 직선 2x + y = 2 ((1,0)과 (0,2)를 지나는 직선) ↔ 직선 2s + t = 2. s + t/2 = 1이므로 OP⃗ = sOA⃗ + (t/2)(2OB⃗). OB'⃗ = 2OB⃗로 두면 직선 AB'.
5. (4) x + y ≤ 1, x ≥ 0, y ≥ 0 (삼각형) ↔ △OAB의 내부와 둘레(경계 포함).

**답** (1) OP⃗ = OA⃗ + OB⃗인 점 (2) OP⃗ = 2OA⃗ − OB⃗인 점 (3) OB'⃗ = 2OB⃗일 때 직선 AB' (4) △OAB의 내부 및 경계

:::fast 빠른 풀이 ① "계수 합 = 1" 맞추기
조건식을 (계수₁) + (계수₂) = 1 꼴로 나눈 뒤, 나눈 숫자를 벡터 쪽으로 옮긴다. 2s + t = 2 → s + (t/2) = 1 → OP⃗ = s·OA⃗ + (t/2)·(2OB⃗) → 직선 A–(2OB⃗의 끝점).
(언제 쓰나: 일차 등식·부등식 조건 전부. 부등식이면 "합 ≤ 1, 각 계수 ≥ 0" → 삼각형, "합 = 1, 각 계수 ≥ 0" → 선분. 계수의 부호 조건이 없으면 직선 전체.)
:::

### 유제 38 · 점의 존재 범위
**문제** 기본예제 38에서 s, t가 다음 관계를 만족할 때 점 P의 존재 범위를 그림으로 나타내라.
(1) s = t  (2) 2s + 3t = 6, s ≥ 0, t ≥ 0  (3) 3s − t = 3  (4) 1 ≤ s + t ≤ 2, s ≥ 0, t ≥ 0

**정석 풀이**
1. (1) s = t이면 OP⃗ = t(OA⃗ + OB⃗). OC⃗ = OA⃗ + OB⃗로 두면 (C는 평행사변형 OACB의 꼭짓점) OP⃗ = tOC⃗, t는 모든 실수 → 직선 OC (평행사변형 OACB의 대각선 OC를 포함하는 직선).
2. (2) 양변을 6으로 나누면 s/3 + t/2 = 1. OP⃗ = (s/3)(3OA⃗) + (t/2)(2OB⃗). OA'⃗ = 3OA⃗, OB'⃗ = 2OB⃗로 두면 s/3 + t/2 = 1, s/3 ≥ 0, t/2 ≥ 0 → 선분 A'B'.
3. (3) 3으로 나누면 s − t/3 = 1, 즉 s + (−t/3) = 1. OP⃗ = sOA⃗ + (−t/3)(−3OB⃗). OC'⃗ = −3OB⃗로 두면 계수 합이 1, 부호 제한 없음 → 직선 AC'.
4. (4) s + t = k (1 ≤ k ≤ 2)로 두면 OP⃗ = (s/k)(kOA⃗) + (t/k)(kOB⃗), s/k + t/k = 1, 각 계수 ≥ 0 → 점 P는 kOA⃗, kOB⃗의 끝점을 잇는 선분 위. k를 1부터 2까지 움직이면, OA'⃗ = 2OA⃗, OB'⃗ = 2OB⃗일 때 사다리꼴 ABB'A'의 내부 및 경계.

**답** (1) OC⃗ = OA⃗ + OB⃗인 점 C에 대해 직선 OC (2) OA'⃗ = 3OA⃗, OB'⃗ = 2OB⃗인 선분 A'B' (3) OC'⃗ = −3OB⃗인 점 C'에 대해 직선 AC' (4) OA'⃗ = 2OA⃗, OB'⃗ = 2OB⃗일 때 사다리꼴 ABB'A'의 내부 및 경계

:::fast 빠른 풀이 ① xy평면에서 그린 뒤 옮기기
(s, t)를 보통 좌표 (x, y)로 보고 그린다: (1) 직선 y = x, (2) (3,0)–(0,2) 선분, (3) (1,0)과 (0,−3)을 지나는 직선, (4) x + y = 1과 x + y = 2 사이의 띠를 제1사분면으로 자른 사다리꼴. 그다음 x축 1칸 → OA⃗, y축 1칸 → OB⃗로 옮겨 그린다. 예: (3)은 (1,0) → A, (0,−3) → −3OB⃗의 끝점.
(언제 쓰나: 일차 조건이면 항상 안전(아핀 대응). 절편 두 개만 찾으면 그림이 끝남.)
:::

### 응용예제 39 · 두 직선이 이루는 각
**문제** 두 직선 x + √3y + 2 = 0, x − √3y − 3 = 0이 이루는 각을 구하라.

**정석 풀이**
1. 법선벡터 n⃗₁ = (1, √3), n⃗₂ = (1, −√3).
2. n⃗₁, n⃗₂가 이루는 각을 θ (0° ≤ θ ≤ 180°)라 하면 cosθ = n⃗₁·n⃗₂/(|n⃗₁||n⃗₂|) = (1 − 3)/(2·2) = −½
3. θ = 120°. 두 직선이 이루는 각은 보통 예각으로 답하므로 180° − 120° = 60°

**답** 60°

:::fast 빠른 풀이 ① 절댓값을 붙인 cos
두 직선이 이루는 예각 φ는 cosφ = |n⃗₁·n⃗₂|/(|n⃗₁||n⃗₂|) = |−2|/4 = ½ → φ = 60°. 둔각 처리 단계를 생략.
(언제 쓰나: "두 직선이 이루는 각"은 항상 예각(또는 직각)이므로 언제나 안전. "벡터가 이루는 각"에는 절댓값을 붙이면 안 됨.)
:::

:::fast 빠른 풀이 ② 기울기 = tan으로 읽기
y = −x/√3 − 2/√3 (기울기 −1/√3 → 경사각 150°), y = x/√3 − √3 (기울기 1/√3 → 경사각 30°). 차이 120° → 예각 60°.
(언제 쓰나: 기울기가 √3, 1, 1/√3처럼 특수각일 때. 수직선(x = c)이 끼면 경사각 90°로 처리.)
:::

### 유제 39 · 두 직선이 이루는 각
**문제** 두 직선 x − 3y + 2 = 0, 2x − y − 3 = 0이 이루는 각을 구하라.

**정석 풀이**
1. n⃗₁ = (1, −3), n⃗₂ = (2, −1)
2. n⃗₁·n⃗₂ = 2 + 3 = 5, |n⃗₁| = √10, |n⃗₂| = √5
3. cosθ = 5/(√10·√5) = 5/(5√2) = 1/√2 → θ = 45° (이미 예각)

**답** 45°

:::fast 빠른 풀이 ① tan 덧셈정리
기울기 m₁ = ⅓, m₂ = 2. tanφ = |(m₂ − m₁)/(1 + m₁m₂)| = |(5/3)/(1 + 2/3)| = 1 → φ = 45°.
(언제 쓰나: 기울기가 깔끔할 때. 1 + m₁m₂ = 0이면 직교(90°)이고 이 식은 정의되지 않음.)
:::

### 기본예제 40 · 점과 직선 사이의 거리
**문제** 점 P(x₀, y₀)와 직선 l: ax + by + c = 0 사이의 거리 d는 d = |ax₀ + by₀ + c|/√(a² + b²)임을 증명하라.

**정석 풀이**
1. P에서 l에 수선 PH를 내리면 d = PH.
2. l의 법선벡터는 n⃗ = (a, b). PH⃗ ∥ n⃗이므로 실수 t를 써서 PH⃗ = t(a, b).
3. OH⃗ = OP⃗ + PH⃗ = (x₀ + at, y₀ + bt)
4. H는 l 위의 점이므로 a(x₀ + at) + b(y₀ + bt) + c = 0 → t = −(ax₀ + by₀ + c)/(a² + b²)
5. d = |PH⃗| = |t|√(a² + b²) = |ax₀ + by₀ + c|/√(a² + b²) (증명 끝)

:::fast 빠른 풀이 ① 정사영(projection)으로 한 줄
l 위의 아무 점 Q(x₁, y₁)를 잡으면 (ax₁ + by₁ = −c), 거리 = QP⃗의 n⃗ 방향 정사영의 길이 = |QP⃗·n⃗|/|n⃗| = |a(x₀ − x₁) + b(y₀ − y₁)|/√(a²+b²) = |ax₀ + by₀ + c|/√(a²+b²).
(언제 쓰나: 증명 아이디어로 가장 짧음. 공간에서 점과 평면 사이 거리도 같은 논리로 바로 나옴.)
:::

### 유제 40 · 수선의 발과 거리
**문제** 점 P(−1, 6)에서 직선 l: x − 2y − 2 = 0에 수선 PH를 내린다. PH의 길이와 점 H의 좌표를 구하라.

**정석 풀이**
1. 법선벡터 n⃗ = (1, −2). PH⃗ = t(1, −2) → OH⃗ = (−1 + t, 6 − 2t)
2. H는 l 위: (−1 + t) − 2(6 − 2t) − 2 = 0 → 5t − 15 = 0 → t = 3
3. H(2, 0), PH = |t|·|n⃗| = 3√5

**답** PH = 3√5, H(2, 0)

:::fast 빠른 풀이 ① 공식 + t 공식
PH = |−1 − 12 − 2|/√5 = 15/√5 = 3√5. H는 t = −(ax₀ + by₀ + c)/(a² + b²) = −(−15)/5 = 3 → H = P + 3(1, −2) = (2, 0).
(언제 쓰나: 거리와 수선의 발을 동시에 물을 때. t의 부호를 그대로 써야 H가 맞음 (절댓값 X).)
:::

### 기본예제 41 · 원의 벡터방정식 (1)
**문제** 평면 위의 서로 다른 두 정점 A, B에 대하여 |AP⃗ + BP⃗| = 6을 만족하는 동점 P는 어떤 도형을 그리는가? (원의 벡터방정식, 円のベクトル方程式)

**정석 풀이**
1. A(a⃗), B(b⃗), P(p⃗)로 둔다.
2. |(p⃗ − a⃗) + (p⃗ − b⃗)| = 6 → |2p⃗ − (a⃗ + b⃗)| = 6
3. 양변을 2로 나누면 |p⃗ − (a⃗ + b⃗)/2| = 3
4. (a⃗ + b⃗)/2는 선분 AB의 중점의 위치벡터이므로 |p⃗ − c⃗| = r 꼴.

**답** 선분 AB의 중점을 중심으로 하는 반지름 3인 원

:::fast 빠른 풀이 ① 중점 벡터 공식
AB의 중점을 M이라 하면 AP⃗ + BP⃗ = 2MP⃗ (∵ MA⃗ + MB⃗ = 0⃗). 따라서 |2MP⃗| = 6 → MP = 3. 바로 "M 중심 반지름 3인 원".
(언제 쓰나: XP⃗ + YP⃗ + … 꼴의 합은 "그 점들의 무게중심 G에 대해 (개수)·GP⃗". 계수가 서로 다르면 가중 무게중심을 쓰고, 계수 합이 0이면 P가 사라지므로 이 방법이 통하지 않음.)
:::

### 유제 41 · 원의 벡터방정식
**문제** △ABC에 대하여 |AP⃗ + BP⃗ + CP⃗| = 6을 만족하는 동점 P는 어떤 도형을 그리는가?

**정석 풀이**
1. A(a⃗), B(b⃗), C(c⃗), P(p⃗)로 두면 |(p⃗ − a⃗) + (p⃗ − b⃗) + (p⃗ − c⃗)| = 6 → |3p⃗ − (a⃗ + b⃗ + c⃗)| = 6
2. 3으로 나누면 |p⃗ − (a⃗ + b⃗ + c⃗)/3| = 2
3. (a⃗ + b⃗ + c⃗)/3은 △ABC의 무게중심(重心) G의 위치벡터.

**답** △ABC의 무게중심 G를 중심으로 하는 반지름 2인 원

:::fast 빠른 풀이 ① 무게중심 합 공식
GA⃗ + GB⃗ + GC⃗ = 0⃗이므로 AP⃗ + BP⃗ + CP⃗ = 3GP⃗. |3GP⃗| = 6 → GP = 2.
(언제 쓰나: 세 점 합이면 무게중심 G, 계수 3. 위와 같은 제약.)
:::

### 기본예제 42 · 원의 벡터방정식 (2)
**문제** 평면 위의 서로 다른 두 점 A(a⃗), B(b⃗)를 지름의 양 끝으로 하는 원의 벡터방정식을 구하라.

**정석 풀이**
1. 선분 AB를 지름으로 하는 원 위에 점 P(p⃗)를 잡는다.
2. P가 A, B와 다를 때, AB가 지름이므로 ∠APB = 90° (원주각).
3. AP⃗ ⊥ BP⃗를 내적으로: AP⃗·BP⃗ = 0 …①
4. P가 A 또는 B와 일치할 때도 영벡터가 되어 ①이 성립.
5. 따라서 (p⃗ − a⃗)·(p⃗ − b⃗) = 0

**답** (p⃗ − a⃗)·(p⃗ − b⃗) = 0

:::fast 빠른 풀이 ① 중심·반지름에서 전개해 확인
중심 (a⃗+b⃗)/2, 반지름 |a⃗−b⃗|/2: |p⃗ − (a⃗+b⃗)/2|² = |a⃗−b⃗|²/4 를 전개하면 |p⃗|² − p⃗·(a⃗+b⃗) + (|a⃗+b⃗|² − |a⃗−b⃗|²)/4 = 0, 그리고 (|a⃗+b⃗|² − |a⃗−b⃗|²)/4 = a⃗·b⃗ 이므로 |p⃗|² − p⃗·(a⃗+b⃗) + a⃗·b⃗ = 0 = (p⃗−a⃗)·(p⃗−b⃗).
(언제 쓰나: 원주각을 쓰지 않는 다른 증명. a⃗·b⃗ = (|a⃗+b⃗|² − |a⃗−b⃗|²)/4 항등식을 쓰므로 항상 성립.)
:::

### 유제 42 · 지름의 양 끝이 주어진 원
**문제** 두 점 A(2, 1), B(4, 7)을 지름의 양 끝으로 하는 원의 방정식을 구하라.

**정석 풀이**
1. P(x, y)에 대해 (p⃗ − a⃗)·(p⃗ − b⃗) = 0 → (x − 2)(x − 4) + (y − 1)(y − 7) = 0
2. 전개: x² − 6x + 8 + y² − 8y + 7 = 0 → x² + y² − 6x − 8y + 15 = 0
3. 완전제곱: (x − 3)² + (y − 4)² = 10

**답** (x − 3)² + (y − 4)² = 10 (= x² + y² − 6x − 8y + 15 = 0)

:::fast 빠른 풀이 ① 중심 = 중점, 반지름² = (반지름 벡터)²
중심 = AB 중점 (3, 4). 반지름² = (3 − 2)² + (4 − 1)² = 1 + 9 = 10. 바로 (x − 3)² + (y − 4)² = 10.
(언제 쓰나: 항상 가능. 검산: B(4,7) 대입 1 + 9 = 10 ✓.)
:::

### 참고 (これも知っ得) · 원의 접선의 벡터방정식
**내용** 중심 C(c⃗), 반지름 r인 원 위의 점 A(a⃗)에서의 접선 l 위의 점 P(p⃗)에 대해 (p⃗ − c⃗)·(a⃗ − c⃗) = r²임을 보인다.

**정석 풀이**
1. 〔방법 1〕 ∠PCA = θ로 두면 ∠PAC = 90°이므로 |CP⃗|cosθ = |CA⃗|. 따라서 CP⃗·CA⃗ = |CP⃗||CA⃗|cosθ = |CA⃗|² = r² → (p⃗ − c⃗)·(a⃗ − c⃗) = r²
2. 〔방법 2〕 AP⃗ ⊥ CA⃗이므로 (p⃗ − a⃗)·(a⃗ − c⃗) = 0. p⃗ − a⃗ = (p⃗ − c⃗) − (a⃗ − c⃗)를 대입하면 (p⃗ − c⃗)·(a⃗ − c⃗) − |a⃗ − c⃗|² = 0, |a⃗ − c⃗| = r이므로 (p⃗ − c⃗)·(a⃗ − c⃗) = r²

**답** (p⃗ − c⃗)·(a⃗ − c⃗) = r²

:::fast 빠른 풀이 ① 성분으로 외우기 ("반만 바꾸기")
원 (x − a)² + (y − b)² = r² 위의 점 (x₁, y₁)에서의 접선: (x₁ − a)(x − a) + (y₁ − b)(y − b) = r². 제곱 하나를 "접점 하나 × 변수 하나"로 바꾸면 끝.
(언제 쓰나: 접점이 원 위에 있을 때만. 원 밖의 점에서 그은 접선에 그대로 쓰면 틀림(그건 극선(polar)이 됨).)
:::
