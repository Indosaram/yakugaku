## 5 위치벡터  *位置ベクトル*

**제2절: 벡터와 도형(ベクトルと図形)**

![그림: 점 O를 고정했을 때 OP⃗=p⃗인 점 P를 P(p⃗)로 표시한다.](data/vecc/fig/p27-1.webp)

:::concept 개념 정리
- 점 O를 고정하면 임의의 점 P에 대해 OP⃗ = p⃗ 가 하나로 정해진다. 이 p⃗를 O를 시점(始点)으로 하는 P의 위치벡터(位置ベクトル)라 하고 P(p⃗)로 쓴다.
- PQ⃗ = q⃗ − p⃗ (종점 − 시점)
- 분점: A(a⃗), B(b⃗)에서 선분 AB를 m : n으로 나누는 점 P(p⃗)는 p⃗ = (n a⃗ + m b⃗)/(m + n) (たすきがけ: a⃗ 아래 m, b⃗ 아래 n을 쓰고 엇갈려 곱한다)
- mn > 0 이면 내분, mn < 0 이면 외분. 예: 2 : 1 외분 = 2 : (−1)로 나누는 점
- 중점: p⃗ = (a⃗ + b⃗)/2
- 무게중심(重心): △ABC의 무게중심 G(g⃗)는 g⃗ = (a⃗ + b⃗ + c⃗)/3
- 좌표평면에서 시점을 원점 O로 잡으면 점 A(a₁, a₂) ⟺ OA⃗ = (a₁, a₂)
- 검산 습관: 분점 공식의 계수 합은 항상 1이다. 예: (2a⃗+3b⃗)/5 → 2/5+3/5 = 1
:::

![그림: 분점 공식의 엇갈려 곱하기. A(a⃗) 아래의 m과 B(b⃗) 아래의 n을 엇갈려 곱하여 n a⃗+m b⃗를 만든다.](data/vecc/fig/p27-2.webp)

**공식의 근거 ①** 벡터의 차 PQ⃗ = OQ⃗−OP⃗에서 q⃗−p⃗가 된다. ‘終点−始点’은 ‘종점−시점’이라는 뜻이다.

![그림: O에서 P와 Q로 향하는 p⃗, q⃗ 및 P에서 Q로 향하는 차벡터.](data/vecc/fig/p27-3.webp)

**공식의 근거 ②** AP⃗ = m AB⃗/(m+n)이므로 p⃗−a⃗ = m(b⃗−a⃗)/(m+n)이다. p⃗에 대해 풀면 분점 공식을 얻는다.

![그림: AP:PB=m:n인 분점 P와 세 위치벡터 a⃗, b⃗, p⃗.](data/vecc/fig/p27-4.webp)

**공식의 근거 ③** BC의 중점을 M이라 하면 무게중심 G는 중선 AM을 2:1로 내분한다. 따라서 g⃗ = (OA⃗+2OM⃗)/3 = {a⃗+2(b⃗+c⃗)/2}/3 = (a⃗+b⃗+c⃗)/3이다.

![그림: 삼각형 ABC의 무게중심 G. M은 BC의 중점이고 AG:GM=2:1이다. ‘重心’은 무게중심이다.](data/vecc/fig/p27-5.webp)

### 기본예제 25 · 분점의 위치벡터

**학습 목표(ねらい)** 분점의 위치벡터를 나타내는 방법에 익숙해진다. **해법 규칙** p⃗ = (n a⃗+m b⃗)/(m+n)에서 3:2 내분은 m=3, n=2, 3:2 외분은 m=3, n=−2로 놓는다. **말풍선** 외분에서는 m, n 중 작은 쪽을 음수로 놓으면 계산하기 쉽다.

![그림: 선분 AB의 3:2 내분점 P와 3:2 외분점 Q. P는 A와 B 사이에, Q는 B 바깥쪽에 있다.](data/vecc/fig/p28-1.webp)

**문제** 두 점 A, B의 위치벡터가 각각 a⃗, b⃗일 때, 선분 AB를 3 : 2로 내분(内分)하는 점 P(p⃗)와 외분(外分)하는 점 Q(q⃗)를 a⃗, b⃗로 나타내어라.

**정석 풀이**
1. 분점 공식 p⃗ = (n a⃗ + m b⃗)/(m + n)을 쓴다.
2. 3 : 2 내분이면 m = 3, n = 2이므로 p⃗ = (2a⃗ + 3b⃗)/(3 + 2) = (2a⃗ + 3b⃗)/5
3. 3 : 2 외분이면 m = 3, n = −2이므로 q⃗ = ((−2)a⃗ + 3b⃗)/(3 + (−2)) = −2a⃗ + 3b⃗

**답** p⃗ = (2a⃗ + 3b⃗)/5, q⃗ = −2a⃗ + 3b⃗

![그림: 내분에서 A(a⃗), B(b⃗) 아래의 비 3:2를 엇갈려 곱하면 분자는 2a⃗+3b⃗가 된다.](data/vecc/fig/p28-2.webp)

![그림: 외분에서 비를 3:(−2)로 놓아 엇갈려 곱하면 분자는 −2a⃗+3b⃗, 분모는 1이다.](data/vecc/fig/p28-3.webp)

:::fast 빠른 풀이 ① 시점 이동: A에서 출발하기
p⃗ = a⃗ + (3/5)(b⃗ − a⃗) = (2/5)a⃗ + (3/5)b⃗.
외분점 Q는 A에서 B 방향으로 AB의 3배만큼 간 점이므로 (AQ : QB = 3 : 2, Q는 B 바깥쪽) q⃗ = a⃗ + 3(b⃗ − a⃗) = −2a⃗ + 3b⃗ → 답 일치.
(언제 쓰나: 비율이 "A에서 몇 배 간 점"으로 바로 보일 때. 공식에서 부호를 헷갈릴 때 검산용으로 좋다.)
:::

:::fast 빠른 풀이 ② 계수 합 = 1 검산
외분은 작은 쪽 숫자를 음수로 두면 계산이 편하다 (3 : (−2)). 결과 −2a⃗ + 3b⃗의 계수 합이 −2 + 3 = 1이면 직선 AB 위의 점이 맞다. 계수 하나가 음수면 외분점이다.
(언제 쓰나: 항상 쓸 수 있는 검산. 계수 합이 1이 아니면 계산이 틀렸다.)
:::

### 유제 25 · 분점의 위치벡터

**문제** 두 점 A(a⃗), B(b⃗)에 대해, 선분 AB를 1 : 2로 내분하는 점 P(p⃗)와 외분하는 점 Q(q⃗)를 a⃗, b⃗로 나타내어라.

**정석 풀이**
1. 내분: m = 1, n = 2 → p⃗ = (2a⃗ + 1·b⃗)/(1 + 2) = (2a⃗ + b⃗)/3
2. 외분: 작은 쪽을 음수로 두어 m = −1, n = 2 → q⃗ = (2a⃗ + (−1)b⃗)/(−1 + 2) = 2a⃗ − b⃗
   (m = 1, n = −2로 해도 (−2a⃗ + b⃗)/(−1) = 2a⃗ − b⃗로 같다.)

**답** p⃗ = (2a⃗ + b⃗)/3, q⃗ = 2a⃗ − b⃗

:::fast 빠른 풀이 ① 시점 이동
1 : 2 외분점 Q는 A 바깥쪽에 있고 QA : AB = 1 : 1이므로, A에서 B 반대 방향으로 AB만큼 간 점이다.
q⃗ = a⃗ − (b⃗ − a⃗) = 2a⃗ − b⃗. 즉 A는 QB의 중점이다.
p⃗ = a⃗ + (1/3)(b⃗ − a⃗) = (2a⃗ + b⃗)/3 → 답 일치.
(언제 쓰나: 비율이 1 : 2처럼 단순해서 그림이 바로 그려질 때. 계수 합 2 − 1 = 1로 검산한다.)
:::

### 응용예제 26 · 무게중심이 일치함을 증명

**학습 목표(ねらい)** 삼각형 무게중심의 위치벡터를 구하고 두 점이 일치함을 증명한다. **해법 규칙** 두 점 G, G′이 일치하는 것과 그 위치벡터가 같은 것은 동치이다. **여백 주석** 시작점은 일반적인 점 O로 잡아도 되고 A로 잡아도 된다. A를 시작점으로 잡으면 g⃗ = (0⃗+b⃗+c⃗)/3이다.

![그림: 삼각형 ABC의 변을 같은 방향으로 2:1 내분한 D, E, F와 두 삼각형의 무게중심 G, G′. O는 임의의 시작점이다.](data/vecc/fig/p28-4.webp)

**문제** △ABC의 변 BC, CA, AB를 2 : 1로 내분하는 점을 각각 D, E, F라 할 때, △ABC의 무게중심(重心) G와 △DEF의 무게중심 G′이 일치함을 증명하여라.

**정석 풀이** (증명)
1. A, B, C, D, E, F, G, G′의 위치벡터를 a⃗, b⃗, c⃗, d⃗, e⃗, f⃗, g⃗, g⃗′라 한다.
2. D는 BC를 2 : 1로 내분하므로 d⃗ = (b⃗ + 2c⃗)/3. 같은 방법으로 e⃗ = (c⃗ + 2a⃗)/3, f⃗ = (a⃗ + 2b⃗)/3
3. g⃗ = (a⃗ + b⃗ + c⃗)/3
4. g⃗′ = (d⃗ + e⃗ + f⃗)/3 = (1/3)·{(b⃗ + 2c⃗)/3 + (c⃗ + 2a⃗)/3 + (a⃗ + 2b⃗)/3} = (a⃗ + b⃗ + c⃗)/3
5. 따라서 g⃗ = g⃗′이고, 두 무게중심은 일치한다. (증명 끝)

**답** g⃗ = g⃗′ = (a⃗ + b⃗ + c⃗)/3 이므로 G와 G′은 일치한다.

:::fast 빠른 풀이 ① 계수 세기
d⃗ + e⃗ + f⃗에서 a⃗의 계수만 세어 보면 e⃗에서 2/3, f⃗에서 1/3, 합 1이다. b⃗, c⃗도 대칭으로 각각 1이다. 따라서 d⃗ + e⃗ + f⃗ = a⃗ + b⃗ + c⃗이고, 3으로 나누면 끝.
(언제 쓰나: 세 변을 모두 같은 비 m : n으로 같은 방향으로 나눌 때는 항상 성립한다. 각 꼭짓점의 계수가 m/(m+n) + n/(m+n) = 1이 되기 때문이다. 비가 변마다 다르면 성립하지 않는다.)
:::

:::fast 빠른 풀이 ② 시점을 A로
시점을 A로 잡으면 a⃗ = 0⃗이므로 문자 하나가 줄어든다. g⃗ = (b⃗ + c⃗)/3이고 d⃗ + e⃗ + f⃗ = (b⃗+2c⃗)/3 + (1/3)c⃗ + (2/3)b⃗ = b⃗ + c⃗.
(언제 쓰나: 증명 문제에서 계산량을 줄이고 싶을 때. 시점은 어디에 잡아도 결론이 같다.)
:::

### 기본예제 27 · 좌표와 위치벡터

**문제** 세 점 A(−1, −1), B(3, 1), C(1, 2)에 대하여 다음 물음에 답하여라.
(1) BC⃗의 성분(成分)을 구하여라.
(2) BP⃗ = (−2, 3)일 때, 점 P의 좌표를 구하여라.
(3) 평행사변형(平行四辺形) ABCD를 만들 때, 점 D의 좌표를 구하여라.
(4) 세 점 A, B, Q가 한 직선 위에 있다고 한다. 점 Q의 좌표를 (x, y)라 할 때, x, y의 관계식을 구하여라.

**학습 목표(ねらい)** 좌표와 위치벡터의 관계를 이해하고 좌표평면 위의 점의 좌표를 구한다. **시험 포인트** 시험에 자주 나오는 유형이다. **해법 규칙·여백** 시작점을 원점 O로 잡으면 점 A의 좌표가 (a₁,a₂)인 것과 OA⃗=(a₁,a₂)인 것은 동치이며, 점의 위치벡터와 좌표의 성분이 일치한다. 평행사변형의 조건은 책 12쪽을 참조한다.

![그림: 좌표평면 위 A(−1,−1), B(3,1), C(1,2), D(−3,0), P(1,4)와 직선 AB 위의 Q.](data/vecc/fig/p29-1.webp)

**정석 풀이**
1. 시점을 원점 O로 잡으면 OA⃗ = (−1, −1), OB⃗ = (3, 1), OC⃗ = (1, 2)
2. (1) BC⃗ = OC⃗ − OB⃗ = (1, 2) − (3, 1) = (−2, 1)
3. (2) OP⃗ = OB⃗ + BP⃗ = (3, 1) + (−2, 3) = (1, 4) → P(1, 4)
4. (3) ABCD가 평행사변형 ⟺ AD⃗ = BC⃗. OD⃗ − OA⃗ = BC⃗이므로 OD⃗ = (−1, −1) + (−2, 1) = (−3, 0) → D(−3, 0)
5. (4) A, B, Q가 한 직선 위 ⟺ AQ⃗ = kAB⃗ (k는 실수). OQ⃗ = (1 − k)OA⃗ + kOB⃗
   (x, y) = (1 − k)(−1, −1) + k(3, 1) = (−1 + 4k, −1 + 2k)
   x = −1 + 4k, y = −1 + 2k에서 (첫째 식) − (둘째 식)×2로 k를 소거하면 x − 2y = 1

**답** (1) (−2, 1) (2) P(1, 4) (3) D(−3, 0) (4) x − 2y = 1

**책의 보충·말풍선** AQ⃗=kAB⃗와 OQ⃗=(1−k)OA⃗+kOB⃗는 서로 식을 변형한 것이므로 같은 조건을 나타낸다. 뒤의 식은 점 Q를 위치벡터로 나타낸 것이다. 분모를 k+(1−k)=1로 쓰면 Q가 AB를 k:(1−k)로 나누는 점임을 알 수 있다. k를 변수로 생각하면 Q는 직선 AB 위를 움직인다.

:::fast 빠른 풀이 ① 평행사변형은 "대각선 중점 공유" → D = A + C − B
평행사변형 ABCD의 대각선 AC와 BD는 중점이 같으므로 A + C = B + D, 즉 D = A + C − B = (−1+1−3, −1+2−1) = (−3, 0).
(언제 쓰나: 꼭짓점 순서가 정해진 평행사변형에서 항상 쓸 수 있다. 마주 보는 꼭짓점끼리 합이 같다. 순서를 잘못 읽으면 엉뚱한 점이 나오니 이름 순서를 꼭 확인한다.)
:::

:::fast 빠른 풀이 ② (4)는 그냥 직선의 방정식
A, B를 지나는 직선의 기울기는 (1 − (−1))/(3 − (−1)) = 1/2. y + 1 = (1/2)(x + 1) → 2y + 2 = x + 1 → x − 2y = 1.
(언제 쓰나: "관계식"만 묻는 경우. 매개변수 k로 Q를 나타내라는 요구가 있으면 정석 풀이를 써야 한다. 검산: A(−1,−1): −1+2 = 1, B(3,1): 3−2 = 1, 둘 다 맞다.)
:::

### 유제 27 · 좌표와 위치벡터

**문제** 세 점 A(1, 2), B(−1, −2), C(4, 1)에 대하여 다음 물음에 답하여라.
(1) CB⃗의 성분을 구하여라.
(2) 평행사변형 ADBC를 만들 때, 점 D의 좌표를 구하여라.
(3) 세 점 A, B, P가 한 직선 위에 있다고 한다. 점 P의 좌표를 (x, y)라 할 때, x, y의 관계식을 구하여라.

**정석 풀이**
1. (1) CB⃗ = OB⃗ − OC⃗ = (−1, −2) − (4, 1) = (−5, −3)
2. (2) 꼭짓점 순서가 A → D → B → C이므로 ADBC가 평행사변형 ⟺ AD⃗ = CB⃗.
   OD⃗ = OA⃗ + CB⃗ = (1, 2) + (−5, −3) = (−4, −1) → D(−4, −1)
3. (3) AP⃗ = kAB⃗ 로 놓으면 OP⃗ = (1 − k)OA⃗ + kOB⃗ = (1 − k)(1, 2) + k(−1, −2) = (1 − 2k, 2 − 4k)
   x = 1 − 2k, y = 2 − 4k에서 y = 2x, 즉 2x − y = 0

**답** (1) (−5, −3) (2) D(−4, −1) (3) 2x − y = 0 (y = 2x)

:::fast 빠른 풀이 ① 마주 보는 꼭짓점의 합
ADBC에서 마주 보는 꼭짓점은 A와 B, D와 C. A + B = D + C → D = A + B − C = (1−1−4, 2−2−1) = (−4, −1).
(언제 쓰나: 평행사변형 이름의 1·3번째, 2·4번째 글자가 서로 마주 본다. 이번처럼 이름이 ABCD 순서가 아닐 때 특히 실수를 줄여 준다.)
:::

:::fast 빠른 풀이 ② (3) 원점을 지나는 직선임을 알아채기
B = −A이므로 A와 B는 원점에 대해 대칭이고, 직선 AB는 원점과 A(1, 2)를 지난다 → y = 2x.
(언제 쓰나: 두 점의 좌표가 부호만 반대일 때. 일반적인 경우에는 기울기를 계산해 직선의 방정식을 쓴다.)
:::

## 6 벡터의 도형에의 응용  *ベクトルの図形への応用*

:::concept 개념 정리
- 세 점 P, Q, R이 한 직선 위에 있다 ⟺ PQ⃗ = kPR⃗ 를 만족하는 실수 k가 있다.
- 시점을 한 꼭짓점(A)으로 잡고 두 벡터 AB⃗ = b⃗, AC⃗ = c⃗ (일차독립)로 모든 점을 나타낸다.
- a⃗ ≠ 0⃗, b⃗ ≠ 0⃗, a⃗ ∦ b⃗일 때: m a⃗ + n b⃗ = s a⃗ + t b⃗ ⟺ m = s, n = t (계수 비교)
- n a⃗ + m b⃗ = (m + n)·(n a⃗ + m b⃗)/(m + n): 분점 꼴로 묶어 읽는다.
- 점 Q가 직선 AB 위에 있다 ⟺ OQ⃗ = s OA⃗ + t OB⃗ (s + t = 1) (계수 합 = 1)
- △ABC 내부의 점 P가 l AP⃗ + m BP⃗ + n CP⃗ = 0⃗ (l, m, n > 0)을 만족하면 AP⃗ = (m b⃗ + n c⃗)/(l + m + n)이고, 넓이비는 △PBC : △PCA : △PAB = l : m : n
- 체바의 정리(チェバの定理): (AF/FB)·(BD/DC)·(CE/EA) = 1 (세 cevian이 한 점에서 만날 때)
- 메넬라우스의 정리(メネラウスの定理): 직선이 삼각형의 세 변(또는 연장선)과 만날 때 세 비율의 곱 = 1. 그 역도 성립하므로 세 점이 한 직선 위에 있음을 보일 때도 쓸 수 있다.
:::

### 기본예제 28 · 한 직선 위의 세 점

**학습 목표(ねらい)** 벡터를 사용하여 한 직선 위에 있는 세 점을 나타낸다. **시험 포인트** 시험에 자주 나오는 유형이다. **해법 규칙** 시작점을 A로 잡고 AB⃗=b⃗, AC⃗=c⃗로 놓는다. AP⃗, AQ⃗, AR⃗을 먼저 나타내고, 이어서 PQ⃗, PR⃗을 구하여 PQ⃗=kPR⃗이라는 관계를 이끌어 낸다.

**문제** △ABC의 변 AB를 1 : 2로 내분하는 점을 P, 변 BC를 3 : 1로 외분하는 점을 Q, 변 CA를 2 : 3으로 내분하는 점을 R이라 할 때, 세 점 P, Q, R이 한 직선 위에 있음(一直線上にある)을 증명하여라.

![그림: AP:PB=1:2, BQ:QC=3:1, CR:RA=2:3인 P·Q·R의 배치. Q는 BC의 C쪽 연장선 위에 있다.](data/vecc/fig/p30-1.webp)

![그림: BC의 3:1 외분을 3:(−1)로 바꾸어 B(b⃗), C(c⃗)에 엇갈려 곱한다.](data/vecc/fig/p30-2.webp)

**해답 여백** 3:1 외분은 3:(−1)로 나누는 것과 같다. PQ⃗와 PR⃗의 공통 벡터 −5b⃗+9c⃗를 소거하여 두 벡터의 배율을 구한다.

**정석 풀이** (증명)
1. A를 시점으로 AB⃗ = b⃗, AC⃗ = c⃗로 놓는다.
2. P는 AB를 1 : 2로 내분하므로 AP⃗ = (1/3)b⃗
3. Q는 BC를 3 : 1로 외분, 즉 3 : (−1)로 나누므로 AQ⃗ = (−b⃗ + 3c⃗)/(3 − 1) = (−b⃗ + 3c⃗)/2
4. R은 AC를 3 : 2로 내분하므로 (CA를 2 : 3으로 내분) AR⃗ = (3/5)c⃗
5. PQ⃗ = AQ⃗ − AP⃗ = (−b⃗ + 3c⃗)/2 − (1/3)b⃗ = (−5b⃗ + 9c⃗)/6
   PR⃗ = AR⃗ − AP⃗ = (3/5)c⃗ − (1/3)b⃗ = (−5b⃗ + 9c⃗)/15
6. 따라서 PQ⃗ = (15/6)PR⃗ = (5/2)PR⃗이므로 세 점 P, Q, R은 한 직선 위에 있다. (증명 끝)

**답** PQ⃗ = (5/2)PR⃗ 이므로 P, Q, R은 한 직선 위에 있다.

:::fast 빠른 풀이 ① 메넬라우스 정리의 역
(AP/PB)·(BQ/QC)·(CR/RA) = (1/2)·(3/1)·(2/3) = 1.
세 점 중 Q 하나만 변의 연장선 위에 있으므로 (외분점이 1개 또는 3개), 메넬라우스 정리의 역에 의해 P, Q, R은 한 직선 위에 있다.
(언제 쓰나: 세 점이 각각 세 변(또는 연장선) 위에 있을 때 객관식·검산용으로 매우 빠르다. 외분점이 0개 또는 2개이면 곱이 1이어도 한 직선 위에 있지 않다. 서술형 "벡터로 증명하라"에서는 정석 풀이를 쓴다.)
:::

:::fast 빠른 풀이 ② 계수 합 = 1
b⃗ = 3AP⃗, c⃗ = (5/3)AR⃗를 AQ⃗에 대입하면 AQ⃗ = −(1/2)·3AP⃗ + (3/2)·(5/3)AR⃗ = −(3/2)AP⃗ + (5/2)AR⃗.
계수 합이 −3/2 + 5/2 = 1이므로 Q는 직선 PR 위에 있다. (계수에서 PQ : QR의 비도 바로 읽힌다: PQ⃗ = (5/2)PR⃗.)
(언제 쓰나: 시점 A에서 본 세 점 중 두 점이 각각 b⃗, c⃗ 방향 위에 있을 때 특히 빠르다. 시점이 세 점 중 하나와 같은 직선 위에 있으면 이 방법을 쓰지 않는다.)
:::

### 유제 28 · 한 직선 위의 세 점

**문제** 평행사변형 ABCD에서 변 BC의 중점을 P, 대각선 BD를 1 : 2로 내분하는 점을 Q라 하자. 이때 세 점 A, Q, P가 한 직선 위에 있음을 증명하여라.

**정석 풀이** (증명)
1. A를 시점으로 AB⃗ = b⃗, AD⃗ = d⃗로 놓는다. 평행사변형이므로 AC⃗ = b⃗ + d⃗, BC⃗ = AD⃗ = d⃗
2. P는 BC의 중점이므로 AP⃗ = b⃗ + (1/2)d⃗ = (2b⃗ + d⃗)/2
3. Q는 BD를 1 : 2로 내분하므로 AQ⃗ = (2b⃗ + d⃗)/3
4. 따라서 AQ⃗ = (2/3)AP⃗이므로 세 점 A, Q, P는 한 직선 위에 있다. (증명 끝)

**답** AQ⃗ = (2/3)AP⃗ 이므로 A, Q, P는 한 직선 위에 있다. (AQ : QP = 2 : 1)

<!-- PDF 30쪽 확인 완료: 그림 2개. 기본예제 28·유제 28, 내외분 비와 해법 규칙·해답 여백 대조. -->

:::fast 빠른 풀이 ① 무게중심으로 보기
대각선의 교점을 O라 하면 O는 BD와 AC의 중점이다. BQ = (1/3)BD, BO = (1/2)BD이므로 BQ : QO = 2 : 1.
△ABC에서 BO는 중선이므로 Q는 △ABC의 무게중심이다. AP도 △ABC의 중선(P는 BC의 중점)이므로 무게중심 Q를 지나고, AQ : QP = 2 : 1.
(언제 쓰나: 평행사변형 대각선의 1/3 지점이 나오면 대부분 무게중심이다. 비율이 1/3이 아니면 벡터 계산으로 돌아간다.)
:::

### 기본예제 29 · 점 P의 위치

**학습 목표(ねらい)** 위치벡터를 사용하여 도형 위의 점의 위치를 조사한다. **시험 포인트** 시험에 자주 나오는 유형이다. **해법 규칙** A를 시작점으로 한 B, C, P의 위치벡터를 b⃗, c⃗, p⃗로 놓고 분점 공식과 연결한다.

![그림: A를 시작점으로 한 b⃗=AB⃗, c⃗=AC⃗, p⃗=AP⃗. P는 BC를 1:2로 내분한다. 빨간 일본어는 ‘시작점을 A로 잡는다’라는 뜻이다.](data/vecc/fig/p31-1.webp)

**문제** 평면 위에 점 P와 △ABC가 있고, AP⃗ + BP⃗ + CP⃗ = AB⃗를 만족한다. 점 P는 △ABC와 어떤 위치 관계에 있는가?

**정석 풀이**
1. A를 시점으로 B, C, P의 위치벡터를 b⃗, c⃗, p⃗라 한다.
2. 조건식: AP⃗ + (AP⃗ − AB⃗) + (AP⃗ − AC⃗) = AB⃗ → p⃗ + (p⃗ − b⃗) + (p⃗ − c⃗) = b⃗
3. 3p⃗ = 2b⃗ + c⃗ → p⃗ = (2b⃗ + c⃗)/(1 + 2)
4. 이것은 BC를 1 : 2로 내분하는 점의 위치벡터이다.

**답** 점 P는 변 BC를 1 : 2로 내분하는 위치에 있다.

:::fast 빠른 풀이 ① 벡터를 이항해서 한 번에
AB⃗ − AP⃗ = PB⃗이므로 조건식은 BP⃗ + CP⃗ = PB⃗ → CP⃗ = PB⃗ − BP⃗ = 2PB⃗.
CP⃗와 PB⃗가 같은 방향이고 길이가 2 : 1이므로 P는 선분 CB 위에서 CP : PB = 2 : 1, 즉 BP : PC = 1 : 2.
(언제 쓰나: 조건식의 일부가 "AB⃗ − AP⃗ = PB⃗"처럼 바로 합쳐질 때. 합쳐지는 쌍이 안 보이면 시점을 정해서 정석대로 푼다.)
:::

### 응용예제 30 · 점의 위치와 넓이비

**학습 목표(ねらい)** 점의 위치 관계를 조사하고 넓이비 문제로 발전시킨다. **해법 규칙** 기본예제 29와 같은 방법으로 생각하되, n a⃗+m b⃗=(m+n){(n a⃗+m b⃗)/(m+n)}로 묶어 분점의 위치벡터를 읽는다. **여백** 위치벡터의 시작점은 어디로 잡아도 된다.

![그림: A를 시작점으로 잡은 넓이비 해설. BD:DC=5:4, AP:PD=3:1이다. 빨간 일본어는 ‘시작점을 A로 잡는다’라는 뜻이다.](data/vecc/fig/p31-2.webp)

**넓이 계산 여백** 높이가 같은 삼각형의 넓이는 밑변의 길이에 비례한다. 따라서 △ABD:△ACD=5:4, △ABP:△DBP=3:1, △ACP:△DCP=3:1을 이용한다.

**문제** △ABC의 내부에 점 P가 있고, 3AP⃗ + 4BP⃗ + 5CP⃗ = 0⃗를 만족한다. 넓이비(面積比) △PBC : △PCA : △PAB를 구하여라.

**정석 풀이**
1. A를 시점으로 AB⃗ = b⃗, AC⃗ = c⃗, AP⃗ = p⃗로 놓는다.
2. 조건식: 3p⃗ + 4(p⃗ − b⃗) + 5(p⃗ − c⃗) = 0⃗ → 12p⃗ = 4b⃗ + 5c⃗
3. p⃗ = (4b⃗ + 5c⃗)/12 = (9/12)·(4b⃗ + 5c⃗)/9 = (3/4)·(4b⃗ + 5c⃗)/9
4. 변 BC를 5 : 4로 내분하는 점을 D라 하면 AD⃗ = (4b⃗ + 5c⃗)/9이므로 p⃗ = (3/4)AD⃗. 즉 P는 선분 AD를 3 : 1로 내분한다.
5. △ABC = S라 하면 BD : DC = 5 : 4이므로 △ABD = (5/9)S, △ACD = (4/9)S. 또 AP : PD = 3 : 1.
   △PBC = (1/4)S
   △PCA = (3/4)·△ACD = (3/4)·(4/9)S = (1/3)S
   △PAB = (3/4)·△ABD = (3/4)·(5/9)S = (5/12)S
6. △PBC : △PCA : △PAB = 1/4 : 1/3 : 5/12 = 3 : 4 : 5

**답** 3 : 4 : 5

:::fast 빠른 풀이 ① 계수가 곧 넓이비
l AP⃗ + m BP⃗ + n CP⃗ = 0⃗ (l, m, n > 0)이면 △PBC : △PCA : △PAB = l : m : n이다. 각 계수는 그 꼭짓점의 "맞은편" 삼각형에 대응한다 (A의 계수 3 ↔ △PBC).
→ 3 : 4 : 5. 덤으로 AP : PD = (m + n) : l = 9 : 3 = 3 : 1, BD : DC = n : m = 5 : 4.
(언제 쓰나: 식이 정확히 l AP⃗ + m BP⃗ + n CP⃗ = 0⃗ 꼴이고 계수가 모두 양수(P가 내부)일 때. 식이 다른 꼴이면 먼저 이 꼴로 정리한다. 서술형에서는 정석 풀이의 근거를 써야 한다.)
:::

:::fast 빠른 풀이 ② 질량중심(무게중심) 해석
A, B, C에 각각 질량 3, 4, 5를 놓으면 P가 질량중심이다. B, C를 합친 질량 9가 D에 모이고 BD : DC = 5 : 4, A(3)와 D(9)의 질량중심이 P이므로 AP : PD = 9 : 3 = 3 : 1. 넓이 계산은 정석 풀이 5와 같다.
(언제 쓰나: 분점의 위치를 빠르게 잡을 때. 질량이 음수가 되면 P가 외부에 있어 넓이비 공식을 그대로 쓸 수 없다.)
:::

### 유제 30 · 점의 위치와 넓이비

**문제** △ABC의 내부에 점 P가 있고, 2AP⃗ + 3BP⃗ + 4CP⃗ = 0⃗를 만족한다. △PBC : △PCA : △PAB를 구하여라.

**정석 풀이**
1. A를 시점으로 AB⃗ = b⃗, AC⃗ = c⃗, AP⃗ = p⃗.
2. 2p⃗ + 3(p⃗ − b⃗) + 4(p⃗ − c⃗) = 0⃗ → 9p⃗ = 3b⃗ + 4c⃗
3. p⃗ = (3b⃗ + 4c⃗)/9 = (7/9)·(3b⃗ + 4c⃗)/7
4. BC를 4 : 3으로 내분하는 점을 D라 하면 AD⃗ = (3b⃗ + 4c⃗)/7, p⃗ = (7/9)AD⃗. 즉 AP : PD = 7 : 2.
5. △ABC = S라 하면 △ABD = (4/7)S, △ACD = (3/7)S.
   △PBC = (2/9)S
   △PCA = (7/9)·(3/7)S = (3/9)S
   △PAB = (7/9)·(4/7)S = (4/9)S
6. △PBC : △PCA : △PAB = 2 : 3 : 4

**답** 2 : 3 : 4

:::fast 빠른 풀이 ① 계수가 곧 넓이비
계수 2, 3, 4가 모두 양수이므로 △PBC : △PCA : △PAB = 2 : 3 : 4. 검산: AP : PD = (3 + 4) : 2 = 7 : 2, 정석 풀이와 같다.
(언제 쓰나: 응용예제 30과 같다. 계수 중 음수가 있으면 쓸 수 없다.)
:::

### 응용예제 31 · 교점의 위치벡터 (1)

**학습 목표(ねらい)** 교점의 위치벡터를 구하는 방법을 이해한다. **시험 포인트** 시험에 자주 나오는 유형이다. **해법 규칙** P는 AN의 분점이면서 BM의 분점이다. OP⃗를 두 가지 방법으로 나타내고, a⃗와 b⃗가 영벡터가 아니며 서로 평행하지 않을 때 m a⃗+n b⃗=s a⃗+t b⃗ ⇔ m=s, n=t를 이용한다.

![그림: OM:MA=2:1, ON:NB=3:2인 삼각형 OAB. AN과 BM의 교점 P에 대해 AP:PN=t:(1−t), BP:PM=s:(1−s)로 놓는다.](data/vecc/fig/p32-1.webp)

**해답 여백** ON⃗=(3/5)b⃗, OM⃗=(2/3)a⃗이다. AP:PN=t:(1−t)로 놓으면 분점 공식의 분모가 1이 된다. AP⃗=tAN⃗로 놓아도 같은 뜻이다(책 27쪽 참조).

**문제** △OAB에서 변 OA를 2 : 1로, 변 OB를 3 : 2로 내분하는 점을 각각 M, N이라 하고, AN과 BM의 교점(交点)을 P라 한다.
(1) OA⃗ = a⃗, OB⃗ = b⃗라 할 때, OP⃗를 a⃗, b⃗로 나타내어라.
(2) 직선 OP와 변 AB의 교점을 Q라 할 때, AQ : QB를 구하여라.

**정석 풀이**
1. OM⃗ = (2/3)a⃗, ON⃗ = (3/5)b⃗
2. P가 선분 AN을 t : (1 − t)로 나누는 점이라 하면 OP⃗ = (1 − t)a⃗ + (3t/5)b⃗ … ①
3. P가 선분 BM을 s : (1 − s)로 나누는 점이라 하면 OP⃗ = (2s/3)a⃗ + (1 − s)b⃗ … ②
4. a⃗ ≠ 0⃗, b⃗ ≠ 0⃗, a⃗ ∦ b⃗이므로 OP⃗의 표현은 하나뿐이다. ①, ②의 계수를 비교하면 1 − t = 2s/3, 3t/5 = 1 − s
5. 풀면 t = 5/9, s = 2/3. ①에 대입하면 OP⃗ = (4/9)a⃗ + (1/3)b⃗
6. (2) OP⃗ = (4a⃗ + 3b⃗)/9 = (7/9)·(4a⃗ + 3b⃗)/7 = (7/9)OR⃗로 놓으면, R은 변 AB를 3 : 4로 내분하는 점이다. O, P, R은 한 직선 위에 있으므로 R은 직선 OP와 AB의 교점 Q와 일치한다.

**답** (1) OP⃗ = (4/9)a⃗ + (1/3)b⃗ (2) AQ : QB = 3 : 4

**책의 보충: 계수 합 조건** Q가 직선 AB 위에 있으면 AQ:QB=t:(1−t)라는 유향 분점 표현으로 OQ⃗=(1−t)OA⃗+tOB⃗가 된다. 이를 OQ⃗=sOA⃗+tOB⃗, s+t=1로 쓸 수 있다. 반대로 이 과정을 거꾸로 적용할 수 있으므로, 위의 일차독립 조건 아래에서는 Q가 직선 AB 위에 있기 위한 조건이 s+t=1이다. (2)는 이 조건을 이용해서도 풀 수 있다.

:::fast 빠른 풀이 ① 계수 합 = 1을 두 번
OP⃗ = x a⃗ + y b⃗로 놓는다.
P는 직선 AN 위: a⃗ = OA⃗, b⃗ = (5/3)ON⃗이므로 OP⃗ = x OA⃗ + (5y/3) ON⃗ → x + (5/3)y = 1
P는 직선 BM 위: a⃗ = (3/2)OM⃗이므로 OP⃗ = (3x/2) OM⃗ + y OB⃗ → (3/2)x + y = 1
연립하면 x = 4/9, y = 1/3. (2)는 Q가 AB 위이므로 OQ⃗ = k OP⃗에서 계수 합 k(4/9 + 1/3) = 1 → OQ⃗ = (4a⃗ + 3b⃗)/7 → AQ : QB = 3 : 4.
(언제 쓰나: 교점 문제 대부분에서 미지수 s, t 없이 바로 연립 1차방정식이 된다. 각 직선의 두 점을 a⃗, b⃗ 방향 위의 점으로 고쳐 쓸 수 있을 때 쓴다.)
:::

:::fast 빠른 풀이 ② 체바의 정리로 (2) 암산
세 직선 AN, BM, OQ가 한 점 P에서 만나므로 (OM/MA)·(AQ/QB)·(BN/NO) = 1 → 2·(AQ/QB)·(2/3) = 1 → AQ/QB = 3/4.
메넬라우스 정리를 쓰면 OP : PQ = 7 : 2도 나온다.
(언제 쓰나: 비율만 묻는 (2)에서. (1)처럼 벡터로 나타내라는 문제에는 빠른 풀이 ①을 쓴다.)
:::

### 유제 31 · 교점의 위치벡터

**문제** △OAB에서 변 OA를 2 : 3으로, 변 OB를 1 : 2로 내분하는 점을 각각 M, N이라 하고, AN과 BM의 교점을 P라 한다.
(1) OA⃗ = a⃗, OB⃗ = b⃗라 할 때, OP⃗를 a⃗, b⃗로 나타내어라.
(2) 직선 OP와 변 AB의 교점을 Q라 할 때, AQ : QB를 구하여라.

**정석 풀이**
1. OM⃗ = (2/5)a⃗, ON⃗ = (1/3)b⃗
2. AP : PN = t : (1 − t)로 놓으면 OP⃗ = (1 − t)a⃗ + (t/3)b⃗ … ①
3. BP : PM = s : (1 − s)로 놓으면 OP⃗ = (2s/5)a⃗ + (1 − s)b⃗ … ②
4. a⃗ ≠ 0⃗, b⃗ ≠ 0⃗, a⃗ ∦ b⃗이므로 계수를 비교하면 1 − t = 2s/5, t/3 = 1 − s
5. 둘째 식에서 t = 3 − 3s. 첫째 식에 대입하면 −2 + 3s = 2s/5 → 13s/5 = 2 → s = 10/13, t = 9/13
6. OP⃗ = (4/13)a⃗ + (3/13)b⃗
7. (2) OP⃗ = (4a⃗ + 3b⃗)/13 = (7/13)·(4a⃗ + 3b⃗)/7. (4a⃗ + 3b⃗)/7은 AB를 3 : 4로 내분하는 점이고 직선 OP 위에 있으므로 이것이 Q이다.

**답** (1) OP⃗ = (4/13)a⃗ + (3/13)b⃗ (2) AQ : QB = 3 : 4

<!-- PDF 32쪽 확인 완료: 그림 1개. 응용예제 31·유제 31의 전 소문항 및 계수 비교 조건·분점 매개변수·계수 합 보충 대조. -->

:::fast 빠른 풀이 ① 계수 합 = 1을 두 번
OP⃗ = x a⃗ + y b⃗.
직선 AN 위: b⃗ = 3ON⃗ → x + 3y = 1
직선 BM 위: a⃗ = (5/2)OM⃗ → (5/2)x + y = 1
y = (1 − x)/3을 대입하면 (5/2)x + (1 − x)/3 = 1 → 15x + 2 − 2x = 6 → x = 4/13, y = 3/13 → 답 일치.
(언제 쓰나: 응용예제 31과 같다.)
:::

:::fast 빠른 풀이 ② 체바의 정리
(OM/MA)·(AQ/QB)·(BN/NO) = (2/3)·(AQ/QB)·(2/1) = 1 → AQ/QB = 3/4.
덤: OQ⃗ = (4a⃗ + 3b⃗)/7, OP⃗ = (7/13)OQ⃗이므로 OP : PQ = 7 : 6.
(언제 쓰나: 비율만 묻는 (2)의 검산이나 객관식. 세 직선이 한 점에서 만난다는 조건이 있어야 쓸 수 있다.)
:::

## 알아두면 좋은 보충 · 체바의 정리와 메넬라우스의 정리

**문제: 기본예제 29의 일반화** △ABC의 내부에 점 P가 있고 l AP⃗+m BP⃗+n CP⃗=0⃗를 만족할 때, P는 △ABC에 대해 어떤 위치에 있는가? 조금 어려운 보충 내용이다. 내부의 점에 대응하는 계수는 l>0, m>0, n>0으로 잡을 수 있으며, 여기서는 처음부터 이 조건을 가정한다.

**풀이** A, B, C, P의 위치벡터를 각각 a⃗, b⃗, c⃗, p⃗라 하면

l(p⃗−a⃗)+m(p⃗−b⃗)+n(p⃗−c⃗)=0⃗,

p⃗ = (l a⃗+m b⃗+n c⃗)/(l+m+n)
= {l a⃗+(m+n)(m b⃗+n c⃗)/(m+n)}/{l+(m+n)}.

**책의 말풍선** “이 점은 도대체 어디에 있는 걸까?” — 위 식을 분점 꼴로 변형하여 위치를 읽는다.

BC를 n:m으로 내분하는 점을 D(d⃗)라 하면 d⃗=(m b⃗+n c⃗)/(m+n)이다. 따라서 p⃗={l a⃗+(m+n)d⃗}/{l+(m+n)}이므로 P는 AD를 (m+n):l로 내분한다.

![그림: 임의의 시작점 O에서 본 위치벡터 a⃗, b⃗, c⃗. BD:DC=n:m이고 AP:PD=(m+n):l이다.](data/vecc/fig/p33-1.webp)

같은 변형을 문자의 조합을 바꾸어 적용한다. CA를 l:n으로 내분하는 점을 E, AB를 m:l로 내분하는 점을 F라 하면 P는 BE를 (l+n):m으로, CF를 (l+m):n으로 각각 내분한다.

![그림: AD, BE, CF가 P에서 만나는 일반 도형. AF:FB=m:l, BD:DC=n:m, CE:EA=l:n이며 각 중간 선분의 비도 표시되어 있다.](data/vecc/fig/p33-2.webp)

**체바의 정리(チェバの定理)** 위 비를 곱하면

(AF/FB)·(BD/DC)·(CE/EA) = (m/l)·(n/m)·(l/n) = 1.

**메넬라우스의 정리(メネラウスの定理)** △ABD의 변 또는 그 연장선과 만나는 직선 FPC에 주목하면

(AF/FB)·(BC/CD)·(DP/PA)
= (m/l)·((n+m)/m)·(l/(m+n)) = 1.

**응용예제 31(2)에 적용** 이 두 정리를 쓰면 비율을 암산으로 구할 수 있다.

![그림: 응용예제 31의 삼각형 OAB에 체바의 정리를 적용한다. OM:MA=2:1, ON:NB=3:2이며 AN, BM, OQ가 P에서 만난다.](data/vecc/fig/p33-3.webp)

체바의 정리로 (OM/MA)·(AQ/QB)·(BN/NO) = (2/1)·(AQ/QB)·(2/3) = 1이므로 AQ/QB=3/4, 즉 AQ:QB=3:4이다. 또 △OAQ에 직선 MPB를 적용하면 메넬라우스의 정리에 의해 (OM/MA)·(AB/BQ)·(QP/PO)=1이다. AB/BQ=7/4이므로 2·(7/4)·(PQ/OP)=1, 따라서 OP:PQ=7:2도 얻는다.
