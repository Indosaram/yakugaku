## 8 공간의 좌표  *空間の座標*

**제3절: 공간벡터(空間ベクトル)**

![그림: 공간의 세 좌표평면. 일본어 ‘평면’ 표기는 각각 xy평면, yz평면, zx평면](data/vecc/fig/p44-1.webp)
![그림: 좌표축 위의 점 A(a, 0, 0), B(0, b, 0), C(0, 0, c)와 점 P(a, b, c)](data/vecc/fig/p44-2.webp)

:::concept 점의 좌표
P를 지나고 각 좌표평면에 평행한 세 평면이 x축, y축, z축과 만나는 점을 A, B, C라 하고 각 축에서의 좌표를 a, b, c라 한다. 세 실수의 쌍 (a, b, c)를 P의 좌표라 하고 a, b, c를 각각 x좌표, y좌표, z좌표라 한다. 점 P의 좌표가 (a, b, c)일 때 P(a, b, c)로 나타낸다. 원점은 O(0, 0, 0), A의 좌표는 (a, 0, 0), B의 좌표는 (0, b, 0), C의 좌표는 (0, 0, c)이다.
:::

### 과제학습 · 카메라 삼각대의 다리는 왜 세 개일까?
![그림: 한 직선 위에 있지 않은 세 점 A, B, C가 결정하는 평면](data/vecc/fig/p44-3.webp)
한 직선 위에 있지 않은 세 점은 오직 하나의 평면을 결정한다. 울퉁불퉁한 곳에서도 삼각대는 발끝 세 점을 지나는 평면 위에서 안정된다. 다리가 네 개라면 ₄C₃ = 4개의 평면이 가능하므로 오히려 덜컹거리기 쉽다.

:::concept 개념 정리
- 원점 O에서 서로 직교하는 x축·y축·z축 = 좌표축(座標軸). xy평면·yz평면·zx평면 = 좌표평면(座標平面).
- 점 P의 좌표 (a, b, c): |x좌표| = yz평면까지 거리, |y좌표| = zx평면까지 거리, |z좌표| = xy평면까지 거리.
- 대칭점 부호 규칙 (P(a, b, c) 기준)
  - xy평면 대칭 → (a, b, −c): 평면 이름에 **없는** 문자만 부호 반전
  - x축 대칭 → (a, −b, −c): 축 이름 **이외의** 문자 부호 반전
  - 원점 대칭 → (−a, −b, −c): 전부 반전
- 좌표평면 위로 내린 수선의 발: 그 평면에 없는 좌표를 0으로 (zx평면 → y = 0).
- 점 (a, b, c)를 지나고 x축에 수직인 평면: x = a (y축 → y = b, z축 → z = c).
:::

### 기본예제 43 · 공간의 점의 좌표
![그림: P(1, 3, 2)에서 zx평면에 내린 수선의 발 Q와 대칭점 R, S](data/vecc/fig/p45-1.webp)

:::concept 목표·해법 규칙
공간의 점의 표시법을 알고 좌표를 읽고 구한다. x, y, z좌표의 절댓값은 각각 yz평면, zx평면, xy평면에서의 거리를 나타낸다. 시험에 나오는 유형이다.
:::
**문제** 점 P(1, 3, 2)에 대하여 다음을 구하라.
(1) 점 P에서 zx평면에 내린 수선과 zx평면의 교점 Q의 좌표
(2) xy평면에 관한 P의 대칭점(対称点) R의 좌표
(3) y축에 관한 P의 대칭점 S의 좌표

**정석 풀이**
1. (1) Q는 zx평면 위의 점이므로 y좌표 = 0. x, z좌표는 그대로 → Q(1, 0, 2).
2. (2) xy평면에 대한 대칭은 xy평면까지의 거리(z좌표)의 부호만 바뀜 → R(1, 3, −2).
3. (3) y축에 대한 대칭은 y좌표는 그대로, x와 z의 부호가 바뀜 → S(−1, 3, −2).

**답** (1) Q(1, 0, 2) (2) R(1, 3, −2) (3) S(−1, 3, −2)

:::fast 빠른 풀이 ① 문자 지우기 규칙
- 평면 대칭: 평면 이름(xy)에 **없는** 문자(z)만 부호 반전.
- 축 대칭: 축 이름(y)에 **있는** 문자만 그대로, 나머지 반전.
- 수선의 발: 평면 이름에 없는 문자를 0으로.
→ Q(1, 0, 2), R(1, 3, −2), S(−1, 3, −2)
(언제 쓰나: 좌표평면·좌표축·원점에 대한 대칭이면 항상 안전. x = 1 같은 일반 평면에 대한 대칭에는 그대로 쓰면 안 됨(중점 공식 필요).)
:::

### 유제 43 · 대칭점 7종
**문제** 다음 평면, 축, 점에 관하여 점 P(1, −2, 3)과 대칭인 점의 좌표를 말하라.
(1) xy평면 (2) yz평면 (3) zx평면 (4) x축 (5) y축 (6) z축 (7) 원점

**정석 풀이**
1. 평면에 대한 대칭: 그 평면까지의 거리를 나타내는 좌표 하나만 부호 반전.
   (1) z 반전 → (1, −2, −3) (2) x 반전 → (−1, −2, 3) (3) y 반전 → (1, 2, 3)
2. 축에 대한 대칭: 그 축 좌표는 그대로, 나머지 두 좌표 부호 반전.
   (4) (1, 2, −3) (5) (−1, −2, −3) (6) (−1, 2, 3)
3. 원점 대칭: 세 좌표 모두 반전 → (7) (−1, 2, −3)

**답** (1) (1, −2, −3) (2) (−1, −2, 3) (3) (1, 2, 3) (4) (1, 2, −3) (5) (−1, −2, −3) (6) (−1, 2, 3) (7) (−1, 2, −3)

:::fast 빠른 풀이 ① 반전 개수로 검산
평면 대칭 = 1개 반전, 축 대칭 = 2개 반전, 원점 = 3개 반전. 그리고 "평면 대칭 + 그 평면에 수직인 축 대칭 = 원점 대칭"이므로 (1)과 (6)의 결과는 서로 부호만 반대여야 한다: (1, −2, −3)과 (−1, 2, 3) ✓. (2)↔(4), (3)↔(5)도 같은 관계로 검산된다.
(언제 쓰나: 7개를 한꺼번에 쓸 때 실수 체크용. 좌표평면/좌표축에 대해서만 성립.)
:::

### 기본예제 44 · 좌표축에 수직인 평면
![그림: 점 P(a, b, c)를 지나고 x축에 수직이며 yz평면과 평행한 평면](data/vecc/fig/p45-2.webp)

:::concept 목표·해법 규칙
좌표축에 수직인 평면의 방정식을 구한다. P(a, b, c)를 지나고 x축에 수직인 평면은 yz평면에 평행하며 그 위의 모든 점의 x좌표가 a이다. 이 관계 x = a를 그 평면의 방정식이라고 한다.
:::
**문제** 점 P(a, b, c)를 지나고 x축, y축, z축에 각각 수직인 평면의 방정식을 구하라.

**정석 풀이**
1. P를 지나고 x축에 수직인 평면은 yz평면에 평행하고, 그 위의 모든 점의 x좌표는 a이다 → x = a.
2. 같은 방법으로 y축에 수직 → y = b, z축에 수직 → z = c.

**답** x = a, y = b, z = c

:::fast 시간 단축 팁
"○축에 수직인 평면 = ○ = (P의 ○좌표)". 축 이름과 같은 문자만 남긴다. (주의: "○축에 **평행**한 평면"과 헷갈리지 말 것 — 평행이면 그 문자가 식에서 사라진다. 예: yz평면에 평행 = x축에 수직.)
:::

### 유제 44 · 좌표축에 수직인 평면
**문제** 점 P(2, −1, 3)을 지나고 x축, y축, z축에 각각 수직인 평면의 방정식을 구하라.

**정석 풀이**
1. x축에 수직인 평면 위의 점은 모두 x좌표가 2 → x = 2.
2. y축에 수직 → y = −1, z축에 수직 → z = 3.

**답** x = 2, y = −1, z = 3

:::fast 시간 단축 팁
기본예제 44 공식에 대입만 하면 끝. 부호(y = −1)만 확인.
:::

## 9 공간의 벡터와 성분  *空間のベクトルと成分*
![그림: 공간에서도 평행이동하여 겹치는 유향선분은 같은 벡터](data/vecc/fig/p46-1.webp)

:::concept 개념 정리
- 공간벡터도 평면과 똑같이 "방향 + 크기", 평행이동해서 겹치면 같은 벡터.
- 평행육면체(平行六面体): 마주 보는 면이 합동인 평행사변형 → 같은 방향의 모서리 = 같은 벡터.
- 기본벡터 e⃗₁ = (1, 0, 0), e⃗₂ = (0, 1, 0), e⃗₃ = (0, 0, 1): a⃗ = a₁e⃗₁ + a₂e⃗₂ + a₃e⃗₃ = (a₁, a₂, a₃) (성분 표시)
- a⃗ = (a₁, a₂, a₃), b⃗ = (b₁, b₂, b₃)일 때
  - |a⃗| = √(a₁² + a₂² + a₃²)
  - a⃗ = b⃗ ⇔ a₁ = b₁, a₂ = b₂, a₃ = b₃
  - a⃗ ± b⃗ = (a₁ ± b₁, a₂ ± b₂, a₃ ± b₃), ka⃗ = (ka₁, ka₂, ka₃)
- a⃗와 같은 방향의 단위벡터: a⃗/|a⃗|
- 4점 O, A, B, C가 한 평면 위에 있지 않으면 임의의 p⃗는 p⃗ = la⃗ + mb⃗ + nc⃗ 꼴로 단 한 가지로 표시된다.
- |a⃗ + tb⃗|의 최솟값: |a⃗ + tb⃗|²을 t의 2차식으로 → 완전제곱. 최소일 때 (a⃗ + tb⃗) ⊥ b⃗.
:::

### 기본예제 45 · 벡터의 합·차
![그림: 평행육면체 ABCD-EFGH의 모서리벡터와 대각선](data/vecc/fig/p46-2.webp)

:::concept 목표·해법 규칙·곁글
벡터의 합과 차를 능숙하게 사용한다. 서로 평행한 세 쌍의 평면으로 둘러싸인 입체가 평행육면체이며, 마주 보는 면은 각각 합동인 평행사변형이다. 같은 벡터를 찾아 a⃗, b⃗, c⃗의 합이나 차로 나타낸다. 단면 AFGD도 평행사변형이다. 시험에 나오는 유형이다.
:::
**문제** 평행육면체 ABCD-EFGH에서 AB⃗ = a⃗, AD⃗ = b⃗, AE⃗ = c⃗일 때 다음 벡터를 a⃗, b⃗, c⃗로 나타내라.
(1) EG⃗ (2) AG⃗ (3) FD⃗

**정석 풀이**
1. (1) 면 EFGH는 면 ABCD와 합동이고 평행 → EG⃗ = AC⃗ = AB⃗ + BC⃗ = a⃗ + b⃗.
2. (2) AG⃗ = AC⃗ + CG⃗ = (a⃗ + b⃗) + c⃗.
3. (3) FD⃗ = AD⃗ − AF⃗ = b⃗ − (a⃗ + c⃗) = −a⃗ + b⃗ − c⃗.

**답** (1) a⃗ + b⃗ (2) a⃗ + b⃗ + c⃗ (3) −a⃗ + b⃗ − c⃗

:::fast 빠른 풀이 ① 꼭짓점 좌표 붙이기
A를 원점으로 놓고 각 꼭짓점을 (a⃗, b⃗, c⃗의 계수)로 적는다: A(0,0,0), B(1,0,0), D(0,1,0), E(0,0,1), C(1,1,0), F(1,0,1), G(1,1,1), H(0,1,1).
벡터 = 끝점 − 시점:
EG⃗ = (1,1,1) − (0,0,1) = (1,1,0) → a⃗ + b⃗
AG⃗ = (1,1,1) → a⃗ + b⃗ + c⃗
FD⃗ = (0,1,0) − (1,0,1) = (−1,1,−1) → −a⃗ + b⃗ − c⃗
(언제 쓰나: 평행육면체·직육면체 문제 전부. 기울어진 평행육면체여도 a⃗, b⃗, c⃗를 축으로 보는 것이라 항상 안전. 단, 꼭짓점 이름 배치(어느 점이 어느 점 위에 있는지)를 먼저 그림에서 정확히 읽어야 한다.)
:::

### 기본예제 46 · 벡터 표시
![그림: AB와 FG의 중점 M, N을 표시한 평행육면체](data/vecc/fig/p46-3.webp)

:::concept 목표·해법 규칙
벡터의 실수배, 합·차의 사용법을 이해한다. ka⃗는 k > 0이면 a⃗와 같은 방향으로, k < 0이면 반대 방향으로 늘이거나 줄인 벡터이다.
:::
**문제** 평행육면체 ABCD-EFGH에서 AB, FG의 중점을 각각 M, N이라 한다. AB⃗ = a⃗, AD⃗ = b⃗, AE⃗ = c⃗일 때 다음 벡터를 a⃗, b⃗, c⃗로 나타내라.
(1) DE⃗ + BG⃗ (2) MD⃗ + MN⃗

**정석 풀이**
1. (1) DE⃗ + BG⃗ = (AE⃗ − AD⃗) + AH⃗ = (c⃗ − b⃗) + (b⃗ + c⃗) = 2c⃗. (BG⃗ = AH⃗)
2. (2) MD⃗ + MN⃗ = (AD⃗ − AM⃗) + (MB⃗ + BF⃗ + FN⃗)
   = (b⃗ − ½a⃗) + (½a⃗ + c⃗ + ½b⃗) = (3/2)b⃗ + c⃗.

**답** (1) 2c⃗ (2) (3/2)b⃗ + c⃗

:::fast 빠른 풀이 ① 계수 좌표
A(0,0,0) 기준 계수 좌표: B(1,0,0), D(0,1,0), E(0,0,1), F(1,0,1), G(1,1,1), H(0,1,1), M(½,0,0), N = (F+G)/2 = (1,½,1).
(1) DE⃗ = (0,−1,1), BG⃗ = (0,1,1) → 합 (0,0,2) = 2c⃗
(2) MD⃗ = (−½,1,0), MN⃗ = (½,½,1) → 합 (0, 3/2, 1) = (3/2)b⃗ + c⃗
(언제 쓰나: 중점·분점이 섞여도 좌표 평균만 내면 되므로 항상 안전.)
:::

:::fast 빠른 풀이 ② 합을 "2 × 중점"으로
XY⃗ + XZ⃗ = 2 × (X → YZ의 중점). (2) MD⃗ + MN⃗ = 2·(DN 중점 − M) = (D + N) − 2M = (0,1,0) + (1,½,1) − (1,0,0) = (0, 3/2, 1). 시점이 같은 두 벡터의 합에 쓴다.
(언제 쓰나: 시점이 같은 두 벡터의 합일 때만. (1)처럼 시점이 다르면 ①로.)
:::

### 유제 46 · 벡터 표시
**문제** 기본예제 46의 평행육면체에서 다음 벡터를 a⃗, b⃗, c⃗로 나타내라.
(1) EM⃗ (2) AN⃗ (3) EN⃗ + EM⃗

**정석 풀이**
1. (1) EM⃗ = AM⃗ − AE⃗ = ½a⃗ − c⃗.
2. (2) AN⃗ = AB⃗ + BF⃗ + FN⃗ = a⃗ + c⃗ + ½b⃗ (FN⃗ = ½FG⃗ = ½b⃗).
3. (3) EN⃗ = AN⃗ − AE⃗ = a⃗ + ½b⃗. 따라서 EN⃗ + EM⃗ = (a⃗ + ½b⃗) + (½a⃗ − c⃗) = (3/2)a⃗ + ½b⃗ − c⃗.

**답** (1) ½a⃗ − c⃗ (2) a⃗ + ½b⃗ + c⃗ (3) (3/2)a⃗ + ½b⃗ − c⃗

:::fast 빠른 풀이 ① 계수 좌표
E(0,0,1), M(½,0,0), N(1,½,1).
(1) M − E = (½,0,−1) (2) N − A = (1,½,1) (3) (N − E) + (M − E) = (1,½,0) + (½,0,−1) = (3/2,½,−1)
→ 각각 ½a⃗ − c⃗, a⃗ + ½b⃗ + c⃗, (3/2)a⃗ + ½b⃗ − c⃗
(언제 쓰나: 기본예제 46과 같음. 검산: 임의의 a⃗, b⃗, c⃗로 수치 대입해 확인함.)
:::

### 벡터의 성분
![그림: 기본벡터 e⃗₁, e⃗₂, e⃗₃를 이용한 공간벡터 a⃗의 성분 표시](data/vecc/fig/p47-1.webp)

:::concept 성분 표시와 곁글
x축, y축, z축 방향의 단위벡터를 각각 e⃗₁, e⃗₂, e⃗₃로 한다. a⃗ = OA⃗인 점 A를 잡으면 a⃗ = a₁e⃗₁ + a₂e⃗₂ + a₃e⃗₃로 유일하게 표시되며 a₁, a₂, a₃를 각각 x성분, y성분, z성분이라 한다. a⃗ = (a₁, a₂, a₃)는 평면의 경우에 z성분만 더한 것이다. 시점을 원점으로 잡으면 성분 표시는 종점의 좌표와 일치한다. 기본벡터의 성분은 e⃗₁ = (1, 0, 0), e⃗₂ = (0, 1, 0), e⃗₃ = (0, 0, 1)이다.
:::

### 기본예제 47 · 벡터의 계산

:::concept 목표·해법 규칙·곁글
공간벡터의 성분 계산을 한다. 평면의 계산에 z성분이 더해진다는 점만 주의하면 된다. |a⃗| = √(a₁² + a₂² + a₃²)이며, a⃗와 같은 방향의 단위벡터는 e⃗ = a⃗/|a⃗|이다. 시험에 나오는 유형이다.
:::
**문제** a⃗ = (2, −3, 6), b⃗ = (1, 3, −4)일 때
(1) a⃗ + 2b⃗를 성분으로 나타내고, 그 크기를 구하라.
(2) a⃗와 같은 방향의 단위벡터를 구하라.

**정석 풀이**
1. (1) a⃗ + 2b⃗ = (2, −3, 6) + (2, 6, −8) = (4, 3, −2).
2. |a⃗ + 2b⃗| = √(16 + 9 + 4) = √29.
3. (2) |a⃗| = √(4 + 9 + 36) = √49 = 7 → a⃗/|a⃗| = (2/7, −3/7, 6/7).

**답** (1) (4, 3, −2), √29 (2) (2/7, −3/7, 6/7)

:::fast 시간 단축 팁
- 자주 나오는 "깔끔한 크기" 조합을 외워 두면 빠르다: (2,3,6)→7, (1,2,2)→3, (2,6,9)→11, (1,4,8)→9, (4,4,7)→9.
- 단위벡터 검산: 성분 제곱합이 1인지 (4 + 9 + 36)/49 = 1로 확인.
- "같은 방향"은 +a⃗/|a⃗| 하나뿐, "평행한 단위벡터"면 ± 두 개.
:::

### 유제 47 · 벡터의 계산
**문제** a⃗ = (−1, 2, −3), b⃗ = (1, 3, −2)일 때
(1) 2a⃗ − b⃗를 성분으로 나타내고, 그 크기를 구하라.
(2) 4x⃗ + b⃗ = 2a⃗ − 3b⃗ + 2x⃗를 만족하는 x⃗와 그 크기를 구하라.

**정석 풀이**
1. (1) 2a⃗ − b⃗ = (−2, 4, −6) − (1, 3, −2) = (−3, 1, −4). 크기 √(9 + 1 + 16) = √26.
2. (2) 4x⃗ − 2x⃗ = 2a⃗ − 3b⃗ − b⃗ → 2x⃗ = 2a⃗ − 4b⃗ → x⃗ = a⃗ − 2b⃗.
3. x⃗ = (−1, 2, −3) − (2, 6, −4) = (−3, −4, 1). 크기 √(9 + 16 + 1) = √26.

**답** (1) (−3, 1, −4), √26 (2) x⃗ = (−3, −4, 1), |x⃗| = √26

:::fast 빠른 풀이 ① 벡터식을 문자식처럼 먼저 정리
성분을 넣기 전에 x에 대한 일차방정식처럼 이항해 x⃗ = a⃗ − 2b⃗까지 만든 뒤 한 번만 성분 계산. 검산: 4x⃗ + b⃗ = (−11, −13, 2), 2a⃗ − 3b⃗ + 2x⃗ = (−11, −13, 2)로 일치.
(언제 쓰나: 벡터 방정식은 항상. 성분을 먼저 대입하면 계산량이 3배.)
:::

### 기본예제 48 · 벡터의 분해

:::concept 목표·해법 규칙·곁글
공간벡터를 분해한다. p⃗ = la⃗ + mb⃗ + nc⃗로 놓고, (a₁, a₂, a₃) = (b₁, b₂, b₃) ⇔ a₁ = b₁, a₂ = b₂, a₃ = b₃라는 상등 조건을 이용한다. 공간의 네 점 O, A, B, C가 한 평면 위에 없고 OA⃗ = a⃗, OB⃗ = b⃗, OC⃗ = c⃗이면 임의의 p⃗는 la⃗ + mb⃗ + nc⃗ 꼴로 단 한 가지로 표시된다(기본예제 10 참조). 시험에 나오는 유형이다.
:::
**문제** a⃗ = (1, 1, 0), b⃗ = (1, 0, 1), c⃗ = (0, 1, 1)일 때 p⃗ = (4, −3, 5)를 la⃗ + mb⃗ + nc⃗ 꼴로 나타내라.

**정석 풀이**
1. p⃗ = la⃗ + mb⃗ + nc⃗를 성분으로: (4, −3, 5) = (l + m, l + n, m + n).
2. l + m = 4 …①, l + n = −3 …②, m + n = 5 …③
3. (① + ② + ③) ÷ 2 → l + m + n = 3 …④
4. ④ − ③: l = −2, ④ − ②: m = 6, ④ − ①: n = −1.

**답** p⃗ = −2a⃗ + 6b⃗ − c⃗

:::fast 빠른 풀이 ① "두 개씩 합" 공식
x + y = P, x + z = Q, y + z = R이면 x = (P + Q − R)/2, y = (P − Q + R)/2, z = (−P + Q + R)/2.
l = (4 − 3 − 5)/2 = −2, m = (4 + 3 + 5)/2 = 6, n = (−4 − 3 + 5)/2 = −1 → 답 −2a⃗ + 6b⃗ − c⃗
(언제 쓰나: a⃗, b⃗, c⃗가 이 예제처럼 (1,1,0)형 "두 개씩 1" 구조일 때만. 일반 벡터엔 가감법으로.)
:::

### 유제 48 · 벡터의 분해
**문제** a⃗ = (2, 3, 1), b⃗ = (−1, 0, 1), c⃗ = (3, 4, −1)일 때 p⃗ = (1, 5, 6)을 la⃗ + mb⃗ + nc⃗ 꼴로 나타내라.

**정석 풀이**
1. 성분 비교: 2l − m + 3n = 1 …①, 3l + 4n = 5 …②, l + m − n = 6 …③
2. ① + ③로 m 소거: 3l + 2n = 7 …④
3. ② − ④: 2n = −2 → n = −1. ④에서 3l = 9 → l = 3.
4. ③에서 m = 6 − l + n = 6 − 3 − 1 = 2.

**답** p⃗ = 3a⃗ + 2b⃗ − c⃗

:::fast 빠른 풀이 ① 0이 있는 성분부터
b⃗의 y성분이 0이라 ② 식에 m이 없다 → ②를 축으로 두고, m의 계수가 −1, +1인 ①과 ③을 더해 한 번에 m 소거. 3l + 4n = 5와 3l + 2n = 7이 l의 계수까지 같아서 빼기 한 번으로 끝.
검산: 3(2,3,1) + 2(−1,0,1) − (3,4,−1) = (1, 5, 6) ✓
(언제 쓰나: 성분 중 0이 있는 벡터가 있으면 항상 그 식부터. 0이 없으면 일반 가감법.)
:::

### 응용예제 49 · 벡터 크기의 최솟값
![그림: p⃗ = a⃗ + tb⃗의 끝점 P가 움직이는 직선과 원점에서의 최단거리](data/vecc/fig/p48-1.webp)

:::concept 목표·해법 규칙·곁글
벡터 크기의 최솟값을 이차함수의 최솟값으로 바꾸어 구한다. |a⃗ + tb⃗| ≥ 0이므로 그 제곱을 최소로 하는 t가 크기도 최소로 한다. 크기의 문제는 제곱해서 생각하자. 응용예제 23에 z성분만 더한 문제이다. p⃗ = a⃗ + tb⃗는 고정점 A(a⃗)를 지나고 b⃗에 평행한 직선의 방정식이다. OP⃗ = p⃗인 점 P는 이 직선 위를 움직이므로 |p⃗|의 최솟값은 O와 직선 AP 사이의 거리이다. 이때 OP⃗ ⊥ AP⃗, 즉 p⃗ ⊥ b⃗이다.
:::
**문제** a⃗ = (2, 6, 1), b⃗ = (−1, −1, 2)이고 p⃗ = a⃗ + tb⃗라 할 때 |p⃗|의 최솟값을 구하라.

**정석 풀이**
1. p⃗ = (2 − t, 6 − t, 1 + 2t).
2. |p⃗|² = (2 − t)² + (6 − t)² + (1 + 2t)² = 6t² − 12t + 41 = 6(t − 1)² + 35.
3. t = 1일 때 |p⃗|²의 최솟값 35. |p⃗| ≥ 0이므로 |p⃗|도 이때 최소.

**답** t = 1일 때 최솟값 √35

:::fast 빠른 풀이 ① 수직 조건 (정사영)
최소일 때 p⃗ ⊥ b⃗ → (a⃗ + tb⃗)·b⃗ = 0 → t = −a⃗·b⃗/|b⃗|².
a⃗·b⃗ = −2 − 6 + 2 = −6, |b⃗|² = 6 → t = 1.
최솟값² = |a⃗|² − (a⃗·b⃗)²/|b⃗|² = 41 − 36/6 = 35 → √35
(언제 쓰나: t가 모든 실수를 움직일 때 항상 안전. t의 범위가 제한되면(0 ≤ t ≤ 1 등) 꼭짓점 t가 범위 안인지 확인해야 함.)
:::

### 유제 49 · 벡터 크기의 최솟값
**문제** a⃗ = (3, −2, 1), b⃗ = (−2, 0, 1)이고 p⃗ = a⃗ + tb⃗라 할 때 |p⃗|의 최솟값을 구하라.

**정석 풀이**
1. p⃗ = (3 − 2t, −2, 1 + t).
2. |p⃗|² = (3 − 2t)² + 4 + (1 + t)² = 5t² − 10t + 14 = 5(t − 1)² + 9.
3. t = 1일 때 |p⃗|² 최소 9.

**답** t = 1일 때 최솟값 3

:::fast 빠른 풀이 ① 수직 조건 (정사영)
a⃗·b⃗ = −6 + 0 + 1 = −5, |b⃗|² = 5 → t = 5/5 = 1.
최솟값² = |a⃗|² − (a⃗·b⃗)²/|b⃗|² = 14 − 25/5 = 9 → 3
(언제 쓰나: 응용예제 49와 같음. t 범위 제한이 있으면 확인 필수.)
:::

## 10 공간의 위치벡터  *空間の位置ベクトル*
![그림: 선분 AB를 m 대 n으로 나누는 점 P의 위치벡터](data/vecc/fig/p49-1.webp)
![그림: 원점을 시점으로 하는 공간의 두 위치벡터와 AB⃗](data/vecc/fig/p49-2.webp)

:::concept 곁글 · 좌표와 위치벡터
분점 공식의 가중치는 엇갈려 곱한다. 좌표가 정해진 공간에서는 위치벡터의 시점을 보통 좌표의 원점 O로 잡는다. 그러면 위치벡터의 성분 표시가 그 점의 좌표와 일치한다. 이 관계를 이해하면 좌표로 된 분점 공식이나 무게중심 공식을 별도로 외울 필요가 없다. 예를 들어 OG⃗ = (OA⃗ + OB⃗ + OC⃗)/3에 각 점의 좌표를 성분으로 대입하면 무게중심 G의 좌표 공식이 바로 나온다.
:::

:::concept 개념 정리
- 위치벡터(位置ベクトル): OP⃗ = p⃗일 때 P(p⃗).
- AB⃗ = OB⃗ − OA⃗ = b⃗ − a⃗ (끝점 − 시점)
- 선분 AB를 m : n으로 나누는 점: p⃗ = (na⃗ + mb⃗)/(m + n) (mn > 0 내분, mn < 0 외분 → 외분은 q⃗ = (−na⃗ + mb⃗)/(m − n))
- 중점: (a⃗ + b⃗)/2, △ABC의 무게중심: g⃗ = (a⃗ + b⃗ + c⃗)/3
- 원점을 시점으로 하면 "위치벡터의 성분 = 그 점의 좌표":
  AB⃗ = (b₁ − a₁, b₂ − a₂, b₃ − a₃), |AB⃗| = √((b₁ − a₁)² + (b₂ − a₂)² + (b₃ − a₃)²)
- 무게중심 좌표: ((a₁ + b₁ + c₁)/3, (a₂ + b₂ + c₂)/3, (a₃ + b₃ + c₃)/3)
- 사각형 PQRS가 평행사변형 ⇔ PQ⃗ = SR⃗, 세 점 O, T, G가 일직선 ⇔ OT⃗ = kOG⃗
:::

### 기본예제 50 · 점의 좌표와 벡터

:::concept 목표·해법 규칙·곁글
점의 좌표와 두 점을 잇는 벡터의 관계를 이해한다. 위치벡터의 시점을 원점 O로 잡으면 위치벡터의 성분 표시가 그 점의 좌표와 같다. AB⃗ = OB⃗ − OA⃗에서 가운데 글자 O가 같아 소거되며, ‘종점 − 시점’으로 기억한다. a⃗ = (a₁, a₂, a₃)이면 |a⃗| = √(a₁² + a₂² + a₃²)이다.
:::
**문제** 두 점 A(−1, 2, −1), B(2, 4, 5)가 주어졌을 때 AB⃗와 |AB⃗|를 구하라.

**정석 풀이**
1. 원점 O를 시점으로: OA⃗ = (−1, 2, −1), OB⃗ = (2, 4, 5).
2. AB⃗ = OB⃗ − OA⃗ = (3, 2, 6).
3. |AB⃗| = √(9 + 4 + 36) = √49 = 7.

**답** AB⃗ = (3, 2, 6), |AB⃗| = 7

:::fast 시간 단축 팁
"B 좌표 − A 좌표"를 바로 쓴다(끝점 − 시점). (3, 2, 6)은 크기 7인 단골 조합이라 바로 7.
:::

### 유제 50 · 점의 좌표와 벡터
**문제** 두 점 A(3, 4, −1), B(1, 2, 3)이 주어졌을 때 AB⃗와 |AB⃗|를 구하라.

**정석 풀이**
1. AB⃗ = OB⃗ − OA⃗ = (1 − 3, 2 − 4, 3 − (−1)) = (−2, −2, 4).
2. |AB⃗| = √(4 + 4 + 16) = √24 = 2√6.

**답** AB⃗ = (−2, −2, 4), |AB⃗| = 2√6

:::fast 시간 단축 팁
공통인수를 먼저 뺀다: (−2, −2, 4) = 2(−1, −1, 2) → |AB⃗| = 2√(1 + 1 + 4) = 2√6. 제곱근 정리가 줄어든다.
:::

### 기본예제 51 · 분점의 좌표

:::concept 목표·해법 규칙·곁글
위치벡터를 이용하여 선분의 분점과 대칭점을 구한다. A(a⃗), B(b⃗)에 대해 m:n 내분점은 p⃗ = (na⃗ + mb⃗)/(m + n), 외분점은 q⃗ = (−na⃗ + mb⃗)/(m − n)이다. (2)는 A가 BR의 중점임을 이용한다. 기본예제 25와 같은 풀이이며, 분점의 가중치는 엇갈려 곱한다. 시험에 나오는 유형이다.
:::
**문제** 두 점 A(3, −5, −2), B(−7, 5, 8)에 대하여
(1) 선분 AB를 3 : 2로 내분하는 점 P와 외분하는 점 Q의 좌표를 구하라.
(2) 점 A에 관하여 점 B의 대칭점 R의 좌표를 구하라.

**정석 풀이**
1. (1) OP⃗ = (2OA⃗ + 3OB⃗)/(3 + 2) = ⅕{2(3, −5, −2) + 3(−7, 5, 8)} = ⅕(−15, 5, 20) = (−3, 1, 4).
2. OQ⃗ = (−2OA⃗ + 3OB⃗)/(3 − 2) = −2(3, −5, −2) + 3(−7, 5, 8) = (−27, 25, 28).
3. (2) A는 선분 BR의 중점 → OA⃗ = (OB⃗ + OR⃗)/2 → OR⃗ = 2OA⃗ − OB⃗ = (6, −10, −4) − (−7, 5, 8) = (13, −15, −12).

**답** (1) P(−3, 1, 4), Q(−27, 25, 28) (2) R(13, −15, −12)

:::fast 빠른 풀이 ① "A에서 출발해 AB⃗의 몇 배" (매개변수)
AB⃗ = (−10, 10, 10).
- 3 : 2 내분 = A + (3/5)AB⃗ = (3, −5, −2) + (−6, 6, 6) = (−3, 1, 4)
- 3 : 2 외분 = A + 3AB⃗ (m/(m − n) = 3) = (3, −5, −2) + (−30, 30, 30) = (−27, 25, 28)
- A에 대한 B의 대칭점 = A − AB⃗ = (13, −15, −12)
(언제 쓰나: AB⃗가 깔끔한 수(여기선 ±10)일 때 특히 빠름. 내분 m:n → m/(m+n), 외분 → m/(m−n)배. 분모 m − n의 부호를 틀리지 말 것.)
:::

:::fast 빠른 풀이 ② 외분 = 음수 비율의 내분 (たすきがけ)
3 : 2 외분은 3 : (−2) 내분으로 보고 내분 공식에 그대로: (−2A + 3B)/(3 − 2). 공식을 하나만 외우면 된다(가중치는 "가까운 쪽 점에 먼 쪽 비율"을 곱하는 たすきがけ).
(언제 쓰나: 항상 성립. 어느 쪽에 −를 붙이든 결과는 같다(−3 : 2로 해도 동일).)
:::

### 유제 51 · 분점과 무게중심의 좌표
**문제** A(3, 7, 6), B(1, −1, 2), C(2, −3, 1)에 대하여
(1) 선분 AB를 1 : 3으로 내분하는 점 P, 외분하는 점 Q의 좌표를 구하라.
(2) △ABC의 무게중심 G의 좌표를 구하라.

**정석 풀이**
1. (1) OP⃗ = (3OA⃗ + OB⃗)/4 = ¼{(9, 21, 18) + (1, −1, 2)} = ¼(10, 20, 20) = (5/2, 5, 5).
2. OQ⃗ = (−3OA⃗ + OB⃗)/(1 − 3) = (3OA⃗ − OB⃗)/2 = ½{(9, 21, 18) − (1, −1, 2)} = ½(8, 22, 16) = (4, 11, 8).
3. (2) OG⃗ = (OA⃗ + OB⃗ + OC⃗)/3 = ⅓(6, 3, 9) = (2, 1, 3).

**답** (1) P(5/2, 5, 5), Q(4, 11, 8) (2) G(2, 1, 3)

:::fast 빠른 풀이 ① A + k·AB⃗
AB⃗ = (−2, −8, −4).
- 1 : 3 내분 = A + ¼AB⃗ = (3, 7, 6) + (−½, −2, −1) = (5/2, 5, 5)
- 1 : 3 외분 = A + (1/(1 − 3))AB⃗ = A − ½AB⃗ = (3, 7, 6) + (1, 4, 2) = (4, 11, 8)
(언제 쓰나: 항상 성립. 외분에서 m < n이면 k가 음수 → 점은 A 바깥쪽(B 반대편)에 생긴다는 것으로 위치 검산 가능.)
:::

### 기본예제 52 · 도형의 성질 증명
![그림: 사면체 OABC의 모서리 중점 P, Q, R, S와 교점 T, 무게중심 G](data/vecc/fig/p51-1.webp)

:::concept 목표·해법 규칙·곁글
위치벡터로 도형의 성질을 증명한다. 사각형 PQRS가 평행사변형임을 보이려면 PQ⃗ = SR⃗를 보이고, O, T, G가 한 직선 위에 있음을 보이려면 OT⃗ = kOG⃗를 보이면 된다. 도형의 성질을 증명하는 방법도 평면의 경우와 같다.
:::
**문제** 사면체 OABC에서 모서리 OA, AB, BC, CO의 중점을 각각 P, Q, R, S라 한다.
(1) 사각형 PQRS가 평행사변형임을 증명하라.
(2) PR과 SQ의 교점을 T, △ABC의 무게중심을 G라 할 때, 세 점 O, T, G가 한 직선 위에 있음을 증명하라.

**정석 풀이**
1. O를 시점으로 A(a⃗), B(b⃗), C(c⃗). OP⃗ = a⃗/2, OQ⃗ = (a⃗ + b⃗)/2, OR⃗ = (b⃗ + c⃗)/2, OS⃗ = c⃗/2.
2. (1) PQ⃗ = OQ⃗ − OP⃗ = b⃗/2, SR⃗ = OR⃗ − OS⃗ = b⃗/2 → PQ⃗ = SR⃗. 따라서 PQRS는 평행사변형이다. (끝)
3. (2) 평행사변형의 대각선은 서로의 중점에서 만나므로 OT⃗ = (OP⃗ + OR⃗)/2 = ½(a⃗/2 + (b⃗ + c⃗)/2) = ¼(a⃗ + b⃗ + c⃗).
4. OG⃗ = ⅓(a⃗ + b⃗ + c⃗) → OT⃗ = (3/4)OG⃗. 따라서 O, T, G는 한 직선 위에 있다. (끝)

**답** (증명 완료) OT⃗ = (3/4)OG⃗

:::fast 빠른 풀이 ① 중점연결정리 + 네 점 평균
(1) △OAB에서 PQ는 중점연결 → PQ ∥ OB, PQ = ½OB. △OCB에서 SR도 OB에 평행하고 ½OB. 마주 보는 한 쌍이 평행하고 길이가 같으므로 평행사변형.
(2) T = (P + Q + R + S)/4 (평행사변형의 중심 = 네 꼭짓점 평균) = (a⃗/2 + (a⃗+b⃗)/2 + (b⃗+c⃗)/2 + c⃗/2)/4 = (a⃗ + b⃗ + c⃗)/4. 이것이 OG⃗의 실수배라는 것만 보이면 끝.
(언제 쓰나: 평행사변형 대각선 교점은 항상 네 꼭짓점의 평균이라 안전. T가 사면체 OABC의 무게중심 (O + A + B + C)/4라는 것과도 일치 — 사면체 무게중심은 꼭짓점과 마주 보는 면의 무게중심을 3 : 1로 내분.)
:::

### 유제 52 · 평행육면체의 대각선과 3등분점
![그림: 평행육면체 OAPB-CRSQ의 두 삼각형의 무게중심 G₁, G₂와 대각선 OS](data/vecc/fig/p51-2.webp)
**문제** 그림과 같이 OA, OB, OC를 세 모서리로 갖는 평행육면체 OAPB-CRSQ가 있다. OA⃗ = a⃗, OB⃗ = b⃗, OC⃗ = c⃗라 한다.
(1) △ABC의 무게중심을 G₁, △PQR의 무게중심을 G₂라 할 때 OG₁⃗, OG₂⃗를 a⃗, b⃗, c⃗로 나타내라.
(2) G₁, G₂는 선분 OS의 3등분점임을 보여라.

**정석 풀이**
1. 꼭짓점의 위치벡터: OP⃗ = a⃗ + b⃗ (면 OAPB), OR⃗ = a⃗ + c⃗, OQ⃗ = b⃗ + c⃗, OS⃗ = a⃗ + b⃗ + c⃗ (면 CRSQ는 OAPB를 c⃗만큼 이동).
2. (1) OG₁⃗ = (a⃗ + b⃗ + c⃗)/3.
   OG₂⃗ = (OP⃗ + OQ⃗ + OR⃗)/3 = {(a⃗ + b⃗) + (b⃗ + c⃗) + (a⃗ + c⃗)}/3 = (2/3)(a⃗ + b⃗ + c⃗).
3. (2) OS⃗ = a⃗ + b⃗ + c⃗이므로 OG₁⃗ = ⅓OS⃗, OG₂⃗ = (2/3)OS⃗.
   따라서 G₁, G₂는 선분 OS 위에 있고 OG₁ : G₁G₂ : G₂S = 1 : 1 : 1, 즉 OS의 3등분점이다. (끝)

**답** (1) OG₁⃗ = ⅓(a⃗ + b⃗ + c⃗), OG₂⃗ = ⅔(a⃗ + b⃗ + c⃗) (2) 증명 완료

:::fast 빠른 풀이 ① 계수 좌표
O(0,0,0), A(1,0,0), B(0,1,0), C(0,0,1), P(1,1,0), Q(0,1,1), R(1,0,1), S(1,1,1).
G₁ = (A + B + C)/3 = (⅓, ⅓, ⅓), G₂ = (P + Q + R)/3 = (⅔, ⅔, ⅔). S = (1,1,1)이므로 대각선 OS 위의 1/3, 2/3 지점 — 한눈에 3등분점.
(언제 쓰나: 평행육면체는 a⃗, b⃗, c⃗를 축으로 하는 "비스듬한 단위정육면체"라 항상 안전. 꼭짓점 이름(R = a⃗ + c⃗, Q = b⃗ + c⃗)은 그림에서 확인할 것 — 바뀌어도 P + Q + R의 합은 같아서 이 문제 답은 변하지 않는다.)
:::

## 11 공간 벡터의 내적  *空間のベクトルの内積*
![그림: 공간의 두 벡터의 시점을 O로 맞추어 재는 각 θ](data/vecc/fig/p52-1.webp)

:::concept 개념 정리
- a⃗, b⃗가 이루는 각 θ (0° ≤ θ ≤ 180°, 시점을 맞춰서 잼): a⃗·b⃗ = |a⃗||b⃗|cos θ — 정의는 평면과 동일.
- 계산법칙: a⃗·a⃗ = |a⃗|², a⃗·b⃗ = b⃗·a⃗, a⃗·(b⃗ + c⃗) = a⃗·b⃗ + a⃗·c⃗, (ka⃗)·b⃗ = a⃗·(kb⃗) = k(a⃗·b⃗)
- 성분: a⃗·b⃗ = a₁b₁ + a₂b₂ + a₃b₃
- 수직이면 내적 0. 시점이 다르면 같은 벡터로 평행이동해 시점을 맞춘다.
:::

### 기본예제 53 · 내적 (정육면체)
![그림: 한 변의 길이가 1인 정육면체 ABCD-EFGH](data/vecc/fig/p52-2.webp)

:::concept 목표·해법 규칙·곁글
정의에 대입하여 내적을 구한다. 두 벡터가 이루는 삼각형에 주목하여 cos θ를 구하고 a⃗·b⃗ = |a⃗||b⃗|cos θ에 대입한다. (4)는 먼저 두 벡터의 시점을 맞춘다. 이때 EC = AG = √3이다.
:::
**문제** 한 변의 길이가 1인 정육면체 ABCD-EFGH에서 다음 내적을 구하라.
(1) AC⃗·AE⃗ (2) AC⃗·AF⃗ (3) AC⃗·AG⃗ (4) AB⃗·EC⃗

**정석 풀이**
1. (1) AE는 면 ABCD에 수직 → AC ⊥ AE → AC⃗·AE⃗ = 0.
2. (2) △CAF는 세 변이 모두 면대각선 √2인 정삼각형 → ∠CAF = 60°. AC⃗·AF⃗ = √2·√2·cos 60° = 1.
3. (3) AC = √2, AG = √3, ∠ACG = 90° → cos∠GAC = √2/√3. AC⃗·AG⃗ = √2·√3·(√2/√3) = 2.

![그림: AC = √2, CG = 1, AG = √3인 직각삼각형 ACG](data/vecc/fig/p52-3.webp)

4. (4) AB⃗ = EF⃗로 시점을 E에 맞춘다. EC = √3, ∠CFE = 90°이므로 cos∠CEF = EF/EC = 1/√3. AB⃗·EC⃗ = 1·√3·(1/√3) = 1.

**답** (1) 0 (2) 1 (3) 2 (4) 1

:::fast 빠른 풀이 ① 정육면체 좌표 놓기
E를 원점, EF를 x축, EH를 y축, EA를 z축: A(0,0,1), B(1,0,1), C(1,1,1), D(0,1,1), E(0,0,0), F(1,0,0), G(1,1,0), H(0,1,0).
AC⃗ = (1,1,0), AE⃗ = (0,0,−1), AF⃗ = (1,0,−1), AG⃗ = (1,1,−1), AB⃗ = (1,0,0), EC⃗ = (1,1,1).
(1) 0 (2) 1 (3) 1 + 1 = 2 (4) 1
(언제 쓰나: 정육면체·직육면체 내적은 이게 가장 빠르고 각도를 안 찾아도 된다. 꼭짓점 배치를 그림과 맞추는 것만 주의.)
:::

:::fast 빠른 풀이 ② 정사영
a⃗·b⃗ = |a⃗| × (b⃗를 a⃗ 방향으로 정사영한 길이). (3) AG⃗를 면 ABCD 방향으로 내리면 AC⃗ 그 자체 → AC⃗·AG⃗ = |AC⃗|² = 2. (4) EC⃗를 EF 방향으로 정사영하면 길이 1 → 1·1 = 1.
(언제 쓰나: 한 벡터의 끝에서 다른 벡터에 내린 수선의 발이 꼭짓점과 겹칠 때 즉시 답. 정사영이 반대 방향이면 음수.)
:::

### 유제 53 · 내적 (정육면체)
**문제** 기본예제 53의 정육면체에서 다음 내적을 구하라.
(1) AC⃗·DG⃗ (2) AC⃗·GE⃗ (3) AC⃗·HF⃗

**정석 풀이**
1. (1) DG⃗ = AF⃗ (면 ABFE와 면 DCGH는 평행이동 관계). 기본예제 53 (2)에서 AC⃗·AF⃗ = 1 → AC⃗·DG⃗ = 1.
2. (2) GE⃗ = −EG⃗ = −AC⃗ → AC⃗·GE⃗ = −|AC⃗|² = −2.
3. (3) HF⃗ = DB⃗이고 정사각형 ABCD의 두 대각선 AC ⊥ DB → AC⃗·HF⃗ = 0.

**답** (1) 1 (2) −2 (3) 0

:::fast 빠른 풀이 ① 정육면체 좌표
(기본예제 53과 같은 좌표) AC⃗ = (1,1,0), DG⃗ = G − D = (1,0,−1), GE⃗ = (−1,−1,0), HF⃗ = (1,−1,0).
(1) 1 + 0 + 0 = 1 (2) −1 − 1 = −2 (3) 1 − 1 = 0
(언제 쓰나: 기본예제 53과 같음. 답이 음수가 나와도 이상한 게 아니다 — 이루는 각이 둔각(여기서 180°)이면 음수.)
:::
