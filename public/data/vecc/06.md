## 정기테스트 예상문제  *定期テスト予想問題*

:::concept 개념 정리 (1장 벡터 총정리)
- 성분: a⃗=(a₁,a₂) 이면 |a⃗|=√(a₁²+a₂²), a⃗ 방향 단위벡터(単位ベクトル) = a⃗/|a⃗|
- 내적(内積): a⃗·b⃗ = |a⃗||b⃗|cosθ = a₁b₁+a₂b₂(+a₃b₃), cosθ = a⃗·b⃗/(|a⃗||b⃗|)
- 크기는 제곱해서 다룬다: |a⃗±b⃗|² = |a⃗|² ± 2a⃗·b⃗ + |b⃗|²
- 분점: m:n 내분 (na⃗+mb⃗)/(m+n), 외분 (−na⃗+mb⃗)/(m−n)
- 평행 ⇔ b⃗=ka⃗ (평면은 a₁b₂−a₂b₁=0), 수직 ⇔ a⃗·b⃗=0
- 삼각형 넓이 S = ½√(|a⃗|²|b⃗|²−(a⃗·b⃗)²) = ½|a₁b₂−a₂b₁|
- 세 점 일직선 ⇔ OP⃗=sOA⃗+tOB⃗ 에서 s+t=1 / 1차독립이면 계수비교
:::

### 정기테스트 1 · 벡터의 성분 계산
**문제** a⃗=(−3, 4), b⃗=(1, 2) 일 때
(1) c⃗=2a⃗−3b⃗ 의 성분과 크기를 구하라.
(2) 3b⃗−(a⃗−3x⃗)=a⃗+b⃗+x⃗ 를 만족하는 x⃗ 의 성분을 구하라.
(3) a⃗ 와 같은 방향의 단위벡터를 구하라.
(4) d⃗=(−11, 8) 을 ma⃗+nb⃗ 꼴로 나타내라.

**정석 풀이**
1. (1) c⃗ = (−6, 8) − (3, 6) = (−9, 2), |c⃗| = √(81+4) = √85
2. (2) 좌변 = 3b⃗ − a⃗ + 3x⃗. 3b⃗−a⃗+3x⃗ = a⃗+b⃗+x⃗ → 2x⃗ = 2a⃗ − 2b⃗ → x⃗ = a⃗ − b⃗ = (−4, 2)
3. (3) |a⃗| = √(9+16) = 5 → a⃗/|a⃗| = (−3/5, 4/5)
4. (4) (−3m+n, 4m+2n) = (−11, 8) → −3m+n=−11, 4m+2n=8(2m+n=4). 빼면 5m=15, m=3, n=−2

**답** (1) c⃗=(−9, 2), |c⃗|=√85 (2) x⃗=(−4, 2) (3) (−3/5, 4/5) (4) d⃗=3a⃗−2b⃗

:::fast 빠른 풀이 ① 벡터식은 문자처럼 먼저 정리
(2)는 성분을 넣기 전에 x⃗ 에 대해 일차방정식처럼 풀어 x⃗=a⃗−b⃗ 를 얻고 마지막에 한 번만 대입 → (−4, 2).
(4)는 (−3,4)가 3-4-5 직각삼각형이므로 |a⃗|=5 를 바로 쓰고, d⃗ 의 y성분 8=4m+2n, x성분 −11=−3m+n 에서 n=−11+3m 대입 → 4m−22+6m=8, m=3.
(언제 쓰나: 미지벡터가 하나뿐인 일차식이면 항상 안전. 검산: 3a⃗−2b⃗=(−9−2, 12−4)=(−11, 8) ✓)
:::

### 정기테스트 2 · 크기 조건으로 내적·각·최솟값
**문제** |a⃗|=4, |b⃗|=1, |a⃗−b⃗|=√21 일 때
(1) a⃗·b⃗ 의 값 (2) a⃗, b⃗ 가 이루는 각 θ (0°≦θ≦180°) (3) |a⃗+b⃗| (4) c⃗=a⃗+tb⃗ 일 때 |c⃗| 의 최솟값

**정석 풀이**
1. (1) |a⃗−b⃗|² = 16 − 2a⃗·b⃗ + 1 = 21 → a⃗·b⃗ = −2
2. (2) cosθ = −2/(4·1) = −½ → θ = 120°
3. (3) |a⃗+b⃗|² = 16 + 2(−2) + 1 = 13 → |a⃗+b⃗| = √13
4. (4) |c⃗|² = |a⃗|² + 2t a⃗·b⃗ + t²|b⃗|² = t² − 4t + 16 = (t−2)² + 12 → t=2 에서 최소 √12 = 2√3

**답** (1) −2 (2) 120° (3) √13 (4) 2√3 (t=2)

:::fast 빠른 풀이 ① 평행사변형 법칙
|a⃗+b⃗|² + |a⃗−b⃗|² = 2(|a⃗|²+|b⃗|²) = 34 → |a⃗+b⃗|² = 34 − 21 = 13 → √13. 내적을 거치지 않고 (3)이 바로 나온다.
(언제 쓰나: |a⃗|, |b⃗|, |a⃗±b⃗| 중 셋을 알 때 항상 성립.)
:::

:::fast 빠른 풀이 ② 최솟값 = 수선의 길이
|a⃗+tb⃗| 의 최솟값은 a⃗ 끝점에서 b⃗ 방향 직선까지의 거리 = |a⃗|sinθ = 4·sin120° = 2√3. 이때 t = −(a⃗·b⃗)/|b⃗|² = 2.
(언제 쓰나: t 가 실수 전체를 움직일 때만. t 에 범위가 있으면 이차함수 풀이로.)
:::

### 정기테스트 3 · 좌표평면의 세 점
**문제** A(1, 2), B(3, 1), C(4, −2) 일 때
(1) 선분 AC를 2:3으로 내분하는 점과 외분하는 점의 좌표 (2) ∠ABC의 크기 (3) △ABC의 넓이 (4) 점 P(2t, 3t)에 대해 AP⃗∥BC⃗ 인 t, AP⃗⊥BC⃗ 인 t

**정석 풀이**
1. (1) 내분: ((3·1+2·4)/5, (3·2+2·(−2))/5) = (11/5, 2/5). 외분: ((−3·1+2·4)/(2−3), (−3·2+2·(−2))/(2−3)) = (−5, 10)
2. (2) BA⃗=(−2, 1), BC⃗=(1, −3). BA⃗·BC⃗ = −2−3 = −5, |BA⃗|=√5, |BC⃗|=√10 → cos∠ABC = −5/√50 = −1/√2 → 135°
3. (3) S = ½|BA⃗||BC⃗|sin135° = ½·√50·(1/√2) = 5/2
4. (4) AP⃗=(2t−1, 3t−2), BC⃗=(1, −3).
   평행: (2t−1)(−3) − (3t−2)·1 = 0 → −9t+5=0 → t=5/9
   수직: (2t−1) − 3(3t−2) = 0 → −7t+5=0 → t=5/7

**답** (1) 내분점 (11/5, 2/5), 외분점 (−5, 10) (2) 135° (3) 5/2 (4) 평행 t=5/9, 수직 t=5/7

:::fast 빠른 풀이 ① 넓이는 성분 공식
BA⃗=(−2,1), BC⃗=(1,−3) → S = ½|(−2)(−3) − 1·1| = ½·5 = 5/2. 각을 몰라도 된다.
(언제 쓰나: 평면 벡터면 항상. 공간에서는 ½√(|a⃗|²|b⃗|²−(a⃗·b⃗)²) 를 쓴다.)
:::

:::fast 빠른 풀이 ② 외분은 "넘어간 만큼 더 가기"
2:3 외분점은 A에서 AC⃗ 반대방향으로 2배: A − 2AC⃗ = (1,2) − 2(3,−4) = (−5, 10). (m:n 외분, m<n 이면 A − m/(n−m)·AC⃗)
(언제 쓰나: 외분 공식 부호를 헷갈릴 때 검산용으로 좋다.)
:::

### 정기테스트 4 · 3AP⃗+2BP⃗+CP⃗=0⃗ 의 넓이비
**문제** △ABC 내부의 점 P가 3AP⃗+2BP⃗+CP⃗=0⃗ 를 만족한다. △PBC : △PCA : △PAB 를 구하라.

**정석 풀이**
1. A를 시점으로: 3AP⃗ + 2(AP⃗−AB⃗) + (AP⃗−AC⃗) = 0⃗ → 6AP⃗ = 2AB⃗ + AC⃗
2. AP⃗ = (3/6)·(2AB⃗+AC⃗)/3 = ½·AD⃗ (D는 BC를 1:2로 내분하는 점, AD⃗=(2AB⃗+AC⃗)/3)
3. 즉 BD:DC=1:2, AP:PD=1:1. △ABC의 넓이를 S라 하면
   △PBC = ½S (높이가 AD의 절반), △PAB = ½·△ABD = ½·(1/3)S = S/6, △PCA = ½·△ADC = ½·(2/3)S = S/3
4. △PBC:△PCA:△PAB = 1/2 : 1/3 : 1/6 = 3:2:1

**답** 3 : 2 : 1

:::fast 빠른 풀이 ① 계수 = 마주보는 넓이 (무게중심 좌표)
αPA⃗+βPB⃗+γPC⃗=0⃗ (α,β,γ>0) 이면 △PBC:△PCA:△PAB = α:β:γ. 주어진 식은 −(3PA⃗+2PB⃗+PC⃗)=0⃗ 이므로 바로 3:2:1.
(언제 쓰나: 세 계수가 모두 같은 부호(P가 내부)일 때 안전. 식이 AP⃗ 꼴이면 부호를 PA⃗ 꼴로 맞춘 뒤 쓴다. 좌표로 수치 검산 완료.)
:::

### 정기테스트 5 · 두 선분의 교점 (△OAB)
**문제** △OAB에서 변 OA를 3:2로, 변 AB를 4:3으로 내분하는 점을 각각 M, N이라 하고 ON과 BM의 교점을 P라 한다. OA⃗=a⃗, OB⃗=b⃗ 일 때
(1) OP⃗ 를 a⃗, b⃗ 로 나타내라. (2) 직선 AP와 변 OB의 교점을 Q라 할 때 OQ:QB를 구하라.

**정석 풀이**
1. OM⃗ = (3/5)a⃗, ON⃗ = (3a⃗+4b⃗)/7
2. P는 ON 위: OP⃗ = s·ON⃗ = (3s/7)a⃗ + (4s/7)b⃗
3. P는 BM 위: BP:PM = t:(1−t) 로 두면 OP⃗ = (1−t)b⃗ + t·OM⃗ = (3t/5)a⃗ + (1−t)b⃗
4. a⃗, b⃗ 는 1차독립이므로 3s/7 = 3t/5, 4s/7 = 1−t → s = 7t/5, 4t/5 = 1−t → t = 5/9, s = 7/9
5. OP⃗ = (1/3)a⃗ + (4/9)b⃗
6. (2) Q는 AP 위: OQ⃗ = (1−u)a⃗ + u·OP⃗ = (1−u+u/3)a⃗ + (4u/9)b⃗. Q는 OB 위이므로 a⃗ 계수 = 0 → u = 3/2 → OQ⃗ = (2/3)b⃗
7. OQ:QB = 2:1

**답** (1) OP⃗ = (1/3)a⃗ + (4/9)b⃗ (2) OQ:QB = 2:1

:::fast 빠른 풀이 ① 계수합 = 1 로 한 번에
OP⃗ = s·ON⃗ = (3s/7)a⃗ + (4s/7)b⃗ 를 OM⃗ 과 b⃗ 로 바꾸면 a⃗ = (5/3)OM⃗ → OP⃗ = (5s/7)OM⃗ + (4s/7)b⃗. P가 BM 위이므로 5s/7 + 4s/7 = 1 → s = 7/9. 미지수 하나로 끝.
(2)도 같은 방법: OQ⃗ = k·b⃗ 로 두면 b⃗ = OQ⃗/k → OP⃗ = (1/3)a⃗ + (4/(9k))OQ⃗. P가 AQ 위이므로 1/3 + 4/(9k) = 1 → k = 2/3 → OQ⃗ = (2/3)b⃗.
(언제 쓰나: 교점이 "시점 O를 지나는 직선"과 "두 점을 잇는 선분" 위에 있을 때 항상.)
:::

:::fast 빠른 풀이 ② 체바의 정리로 (2) 검산
세 선분 AQ, BM, ON이 한 점 P에서 만나므로 (OM/MA)(AN/NB)(BQ/QO) = 1 → (3/2)(4/3)(BQ/QO) = 1 → BQ/QO = 1/2 → OQ:QB = 2:1.
(언제 쓰나: 세 체바선이 한 점에서 만날 때만. 비만 묻는 문제의 검산으로 최강.)
:::

### 정기테스트 6 · 평행사변형 안의 교점과 내적
**문제** 평행사변형 ABCD에서 선분 BC, CD를 1:2로 내분하는 점을 각각 M, N이라 하고 AN과 DM의 교점을 P라 한다.
(1) AB⃗=a⃗, AD⃗=b⃗ 일 때 AP⃗ 를 a⃗, b⃗ 로 나타내라.
(2) CP와 AD의 교점을 Q라 할 때 AQ:QD를 구하라.
(3) AB=2, AD=4, ∠BAD=120° 일 때 AD⃗·CQ⃗ 의 값을 구하라.

**정석 풀이**
1. AM⃗ = a⃗ + (1/3)b⃗, AN⃗ = AC⃗ + (1/3)CD⃗ = a⃗+b⃗ − (1/3)a⃗ = (2/3)a⃗ + b⃗
2. AP⃗ = k·AN⃗ = (2k/3)a⃗ + k b⃗
3. DP:PM = t:(1−t): AP⃗ = (1−t)b⃗ + t·AM⃗ = t a⃗ + (1 − 2t/3)b⃗
4. 계수비교: 2k/3 = t, k = 1 − 2t/3 = 1 − 4k/9 → k = 9/13, t = 6/13
5. AP⃗ = (6/13)a⃗ + (9/13)b⃗
6. (2) CP⃗ = AP⃗ − AC⃗ = −(7/13)a⃗ − (4/13)b⃗. AQ⃗ = AC⃗ + m·CP⃗ = (1 − 7m/13)a⃗ + (1 − 4m/13)b⃗ = l b⃗ → m = 13/7, l = 1 − 4/7 = 3/7
7. AQ⃗ = (3/7)b⃗ → AQ:QD = 3:4
8. (3) CQ⃗ = AQ⃗ − AC⃗ = −a⃗ − (4/7)b⃗. a⃗·b⃗ = 2·4·cos120° = −4, |b⃗|² = 16
9. AD⃗·CQ⃗ = b⃗·(−a⃗ − (4/7)b⃗) = 4 − 64/7 = −36/7

**답** (1) AP⃗ = (6/13)a⃗ + (9/13)b⃗ (2) AQ:QD = 3:4 (3) −36/7

:::fast 빠른 풀이 ① 계수합 = 1 (P는 DM 위)
AP⃗ = k((2/3)a⃗ + b⃗). a⃗ = AM⃗ − (1/3)b⃗ 로 바꾸면 AP⃗ = (2k/3)AM⃗ + (k − 2k/9)b⃗ = (2k/3)AM⃗ + (7k/9)AD⃗. 계수합 1: 2k/3 + 7k/9 = 13k/9 = 1 → k = 9/13.
(2)는 C(=a⃗+b⃗)와 P를 잇는 직선에서 a⃗ 계수가 0인 점: AQ⃗ = C + m(P−C) 에서 1 − m(7/13) = 0 → m=13/7, b⃗ 계수 1 − (4/13)(13/7) = 3/7.
(언제 쓰나: 기준 벡터 둘이 1차독립일 때 항상.)
:::

:::fast 빠른 풀이 ② 좌표 대입 검산
A(0,0), B(2,0), D(−2, 2√3) 로 놓으면 C(0, 2√3), Q = (3/7)D = (−6/7, 6√3/7). CQ⃗ = (−6/7, −8√3/7), AD⃗·CQ⃗ = 12/7 − 48/7 = −36/7 ✓
(언제 쓰나: 길이·각이 주어진 (3) 같은 수치 문제. 비만 묻는 (1)(2)는 아무 평행사변형이나 놓아도 된다.)
:::

### 정기테스트 7 · 각의 이등분선과 수선의 교점
**문제** OA=3, OB=2, ∠AOB=60° 인 △OAB에서 ∠AOB의 이등분선과 A에서 OB에 내린 수선의 교점을 P라 한다. OA⃗=a⃗, OB⃗=b⃗ 일 때 OP⃗ 를 a⃗, b⃗ 로 나타내라.

**정석 풀이**
1. 이등분선 방향은 a⃗/|a⃗| + b⃗/|b⃗| = a⃗/3 + b⃗/2 → OP⃗ = k(a⃗/3 + b⃗/2)
2. AP⃗ ⊥ b⃗: (OP⃗ − a⃗)·b⃗ = 0. a⃗·b⃗ = 3·2·cos60° = 3, |b⃗|² = 4
3. (k/3)·3 + (k/2)·4 − 3 = 0 → 3k = 3 → k = 1
4. OP⃗ = (1/3)a⃗ + (1/2)b⃗

**답** OP⃗ = (1/3)a⃗ + (1/2)b⃗

:::fast 빠른 풀이 ① 이등분선 정리로 내분
수선의 발 H: OH = OA cos60° = 3/2 → OH⃗ = (3/4)b⃗. △OAH에서 OP는 ∠O의 이등분선이므로 AP:PH = OA:OH = 3 : 3/2 = 2:1.
OP⃗ = (1·a⃗ + 2·OH⃗)/3 = (a⃗ + (3/2)b⃗)/3 = (1/3)a⃗ + (1/2)b⃗.
(언제 쓰나: 이등분선이 삼각형의 한 변과 만날 때 항상. 수치 검산: ∠AOP=∠POB=30°, AP⃗·b⃗=0 확인.)
:::

### 정기테스트 8 · 공간벡터를 세 벡터로 분해
**문제** a⃗=(1, 2, 0), b⃗=(2, 0, −1), c⃗=(3, −1, 2) 일 때 p⃗=(4, 6, 7) 을 la⃗+mb⃗+nc⃗ 꼴로 나타내라.

**정석 풀이**
1. la⃗+mb⃗+nc⃗ = (l+2m+3n, 2l−n, −m+2n) = (4, 6, 7)
2. 2l − n = 6 → l = (6+n)/2, −m + 2n = 7 → m = 2n − 7
3. 첫 식에 대입: (6+n)/2 + 2(2n−7) + 3n = 4. 양변×2 → 6 + n + 8n − 28 + 6n = 8 → 15n = 30 → n = 2
4. l = 4, m = −3

**답** p⃗ = 4a⃗ − 3b⃗ + 2c⃗

:::fast 시간 단축 팁 · 0이 있는 성분부터
진짜 지름길은 없지만, a⃗ 의 z성분 0, b⃗ 의 y성분 0 덕분에 y식·z식이 미지수 2개짜리다. 두 식으로 l, m 을 n 으로 표현 → x식에 대입하면 1원 1차방정식 하나로 끝. 마지막에 4a⃗−3b⃗+2c⃗ = (4−6+6, 8+0−2, 0+3+4) = (4, 6, 7) ✓ 검산.
(언제 쓰나: 성분에 0이 있으면 그 성분 식부터 쓰는 것이 항상 빠르다.)
:::

### 정기테스트 9 · 세 점 O, P, G가 일직선 (증명)
**문제** 사면체 OABC에서 변 OA를 2:1로 내분하는 점을 M, 변 BC의 중점을 N, 선분 MN을 4:3으로 내분하는 점을 P라 한다. △ABC의 무게중심을 G라 할 때 세 점 O, P, G가 한 직선 위에 있음을 증명하라.

**정석 풀이 (증명)**
1. OA⃗=a⃗, OB⃗=b⃗, OC⃗=c⃗ 라 하면 OM⃗ = (2/3)a⃗, ON⃗ = (b⃗+c⃗)/2
2. OP⃗ = (3·OM⃗ + 4·ON⃗)/7 = (2a⃗ + 2b⃗ + 2c⃗)/7 = (2/7)(a⃗+b⃗+c⃗)
3. OG⃗ = (a⃗+b⃗+c⃗)/3
4. 따라서 OP⃗ = (6/7)·OG⃗ 이므로 세 점 O, P, G는 한 직선 위에 있다. ∎ (OP:OG = 6:7)

**답** OP⃗ = (6/7)OG⃗ 이므로 일직선 (증명 끝)

:::fast 빠른 풀이 ① "대칭식이 나오면 끝" 관찰
OP⃗ 를 계산했을 때 a⃗, b⃗, c⃗ 의 계수가 모두 같으면(2/7) 그것은 자동으로 a⃗+b⃗+c⃗ 의 실수배, 즉 OG⃗ 방향이다. 내분 계산 한 줄 후 "계수가 같다"만 확인하면 증명 완료.
(언제 쓰나: G가 무게중심일 때. 계수가 다르게 나오면 일직선이 아니다.)
:::

### 정기테스트 10 · 공간 좌표의 분점·평행사변형·각·단위벡터
**문제** A(3, 1, 4), B(2, −1, 3), C(4, 0, 2) 일 때
(1) 선분 AB를 2:1로 내분하는 점과 외분하는 점 (2) 사각형 ABCD가 평행사변형이 되는 점 D (3) ∠ABC의 크기 (4) AB⃗ 와 같은 방향의 단위벡터

**정석 풀이**
1. (1) 내분: (A + 2B)/3 = ((3+4)/3, (1−2)/3, (4+6)/3) = (7/3, −1/3, 10/3). 외분: (−A + 2B)/(2−1) = (1, −3, 2)
2. (2) AD⃗ = BC⃗ → D = A + C − B = (3+4−2, 1+0+1, 4+2−3) = (5, 2, 3)
3. (3) BA⃗ = (1, 2, 1), BC⃗ = (2, 1, −1). 내적 = 2+2−1 = 3, |BA⃗| = |BC⃗| = √6 → cos = 3/6 = ½ → 60°
4. (4) AB⃗ = (−1, −2, −1), |AB⃗| = √6 → (−1/√6, −2/√6, −1/√6) = (−√6/6, −√6/3, −√6/6)

**답** (1) 내분점 (7/3, −1/3, 10/3), 외분점 (1, −3, 2) (2) D(5, 2, 3) (3) 60° (4) (−√6/6, −√6/3, −√6/6)

:::fast 빠른 풀이 ① 평행사변형은 "대각선 중점 일치"
ABCD 순서면 A, C가 마주보므로 A + C = B + D → D = A + C − B. 공식 하나로 끝.
(언제 쓰나: 꼭짓점 순서가 ABCD로 정해졌을 때만. 순서 지정이 없으면 D가 3개 나온다.)
:::

:::fast 빠른 풀이 ② 외분 = B를 넘어 AB⃗ 만큼 더
2:1 외분점은 B + AB⃗ = (2,−1,3) + (−1,−2,−1) = (1, −3, 2). 이등변(|BA⃗|=|BC⃗|=√6)에 cos=½ 이면 정삼각형이므로 AC도 √6인지 확인하면 검산: AC⃗=(1,−1,−2), |AC⃗|=√6 ✓
(언제 쓰나: 외분비가 2:1, 1:2처럼 차가 1일 때 특히 빠르다.)
:::

### 정기테스트 11 · 사면체의 넓이·부피·수선의 발
**문제** 사면체 OABC에서 O(0,0,0), A(2,0,0), B(0,4,0), C(0,0,6) 일 때
(1) △ABC의 넓이 (2) 사면체 OABC의 부피 (3) O에서 평면 ABC에 내린 수선의 발 H의 좌표

**정석 풀이**
1. (1) AB⃗ = (−2, 4, 0), AC⃗ = (−2, 0, 6). |AB⃗|² = 20, |AC⃗|² = 40, AB⃗·AC⃗ = 4
   S = ½√(20·40 − 16) = ½√784 = ½·28 = 14
2. (2) 밑면 OAB(직각삼각형 넓이 ½·2·4=4), 높이 OC=6 → V = ⅓·4·6 = 8
3. (3) V = ⅓·S·OH → 8 = ⅓·14·OH → OH = 12/7
4. OH⃗ ⊥ AB⃗, OH⃗ ⊥ AC⃗ 인 방향: (x,y,z)에 대해 −2x+4y=0, −2x+6z=0 → (6, 3, 2) 방향 (|(6,3,2)|=7)
5. OH⃗ = (12/7)·(6,3,2)/7 = (72/49, 36/49, 24/49)

**답** (1) 14 (2) 8 (3) H(72/49, 36/49, 24/49)

:::fast 빠른 풀이 ① 절편형 평면과 법선벡터
평면 ABC: x/2 + y/4 + z/6 = 1 ⇔ 6x + 3y + 2z = 12. 법선 (6,3,2), |n⃗|=7.
H = t(6,3,2) 를 평면에 대입: 49t = 12 → t = 12/49 → H(72/49, 36/49, 24/49). OH = 12/7 도 동시에.
(언제 쓰나: 세 점이 좌표축 위에 있을 때(절편형) 가장 빠르다. 법선벡터·평면 방정식은 교과 범위 밖일 수 있으니 서술형 답안은 정석 풀이로.)
:::

:::fast 빠른 풀이 ② 직각 사면체 넓이 공식 (드 구아의 정리)
세 모서리가 O에서 서로 수직이면 (△ABC)² = (△OAB)² + (△OBC)² + (△OCA)² = 4² + 12² + 6² = 16 + 144 + 36 = 196 → △ABC = 14.
(언제 쓰나: O에서 세 모서리가 직교하는 사면체에서만. 일반 사면체에는 쓰지 말 것.)
:::
