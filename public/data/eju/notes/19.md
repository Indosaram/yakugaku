## 한눈에 보기

- **산화수(酸化数)**는 어떤 원자가 얼마나 산화되었는지, 또는 환원되었는지를 나타내는 숫자다.
- 산소·수소·전자를 기준으로 판단하면, 한 물질이 수소와 산소를 동시에 얻는 경우처럼 기준끼리 결론이 엇갈릴 수 있다. 산화수를 쓰면 판단 기준이 하나로 정리된다.
- 산화수가 **증가하면 산화(酸化)**, **감소하면 환원(還元)**이다.
- 한 반응에서 증가한 산화수의 총합과 감소한 산화수의 총합은 항상 같다.

## 개념 정리

### 산화수가 필요한 이유

산화·환원은 앞에서 배운 여러 기준으로 판단할 수 있다. 산소를 얻으면 산화, 수소를 얻으면 환원이다. 그런데 한 물질이 산소와 수소를 동시에 얻으면 어느 쪽으로 판단해야 할지 애매해진다. 이런 경우에 "얼마나 산화(환원)되었는가"를 숫자로 나타내 판단을 통일하는 것이 산화수다.

### 산화수를 정하는 규칙

| 번호 | 규칙 | 예 |
|---|---|---|
| ① | **단체(単体)** 속 원자의 산화수는 0 | H₂, O₂, Cu, C → 모두 0 |
| ② | **화합물(化合物)** 속 H는 +1, O는 −2 | H₂O: H +1, O −2 |
| ② 예외 | **과산화수소(過酸化水素)** H₂O₂ 속 O는 −1 | H: +1×2, O: −1×2 → 합 0 |
| ③ | 전하가 없는 화합물은 산화수의 총합이 0 | NH₃, SO₂ |
| ④ | **단원자 이온(単原子イオン)**의 산화수는 그 이온의 전하와 같다 | Na⁺ +1, Cl⁻ −1, Cu²⁺ +2 |
| ⑤ | **다원자 이온(多原子イオン)**은 산화수의 총합이 이온의 전하와 같다 | SO₄²⁻ 총합 −2, NH₄⁺ 총합 +1 |

단체란 한 종류의 원소로만 이루어진 물질을 말한다.

### 모르는 원자의 산화수 구하기

H(+1)와 O(−2)를 기준으로 두고, 나머지 원자의 산화수를 미지수 x로 놓아 총합 조건을 맞춘다.

- **NH₃**: x + (+1)×3 = 0 → N = **−3**
- **SO₂**: x + (−2)×2 = 0 → S = **+4**
- **SO₄²⁻**: x + (−2)×4 = −2 → S = **+6**
- **NH₄⁺**: x + (+1)×4 = +1 → N = **−3**

### 산화수로 산화·환원 판단하기

반응 전후의 산화수를 비교해서 판단한다.

- 산화수 증가 → 그 원자는 **산화되었다**
- 산화수 감소 → 그 원자는 **환원되었다**

**예: 2CuO + C → 2Cu + CO₂**

| 원자 | 반응 전 | 반응 후 | 변화 | 판단 |
|---|---|---|---|---|
| Cu | +2 (CuO) | 0 (단체) | −2, 2개이므로 총 −4 | 환원 |
| C | 0 (단체) | +4 (CO₂) | +4 | 산화 |
| O | −2 | −2 | 변화 없음 | — |

산화와 환원은 항상 동시에 일어난다. 따라서 **산화된 원자의 산화수 증가 총합(+4)은 환원된 원자의 산화수 감소 총합(−4)과 같다.**

### 산화·환원을 판단하는 네 가지 기준

| 기준 | 산화 | 환원 |
|---|---|---|
| 산소 | 얻는다 | 잃는다 |
| 수소 | 잃는다 | 얻는다 |
| 전자 | 잃는다 | 얻는다 |
| 산화수 | 증가 | 감소 |

## 꼭 외울 것

- 단체의 산화수는 0이다.
- 화합물 속 H는 +1, O는 −2이다. 단, H₂O₂ 속 O는 −1이다.
- 산화수의 총합은 중성 화합물이면 0, 이온이면 그 이온의 전하와 같다.
- 산화수 증가는 산화, 감소는 환원이다.
- 증가한 산화수의 총합과 감소한 산화수의 총합은 같다.

## 자주 틀리는 함정

- **원자 개수를 빼먹는 실수**: 2CuO에서 Cu의 감소량은 2가 아니라 2×2 = **4**다. 계수와 아래첨자를 반드시 곱해서 센다.
- **O를 무조건 −2로 두는 실수**: H₂O₂에서는 −1이고, O₂처럼 단체일 때는 0이다.
- **이온의 총합을 0으로 두는 실수**: SO₄²⁻의 총합은 −2이다. 0으로 계산하면 S가 +8이라는 틀린 값이 나온다.
- **같은 원소는 산화수도 같다고 생각하는 실수**: NH₃와 NH₄⁺의 N은 둘 다 −3이지만, SO₂(+4)와 SO₄²⁻(+6)의 S는 다르다. 화합물마다 직접 계산해야 한다.

## 확인 문제

**문제 1** 다음 중 황(S)의 산화수가 가장 큰 것은?
① S ② H₂S ③ SO₂ ④ H₂SO₄

> **정답** ④ — S는 단체이므로 0, H₂S는 −2, SO₂는 +4이다. H₂SO₄는 (+1)×2 + x + (−2)×4 = 0에서 x = +6으로 가장 크다.

**문제 2** 산소 원자의 산화수가 −1인 물질은?
① H₂O ② O₂ ③ H₂O₂ ④ CO₂

> **정답** ③ — 과산화수소는 예외로 O가 −1이다. H₂O와 CO₂의 O는 −2이고, O₂는 단체이므로 0이다.

**문제 3** 반응 2CuO + C → 2Cu + CO₂에 대한 설명으로 옳은 것은?
① Cu는 산화되었다.
② C의 산화수는 0에서 +4로 증가하였고, C는 산화되었다.
③ Cu의 산화수 감소 총합은 2이다.
④ O의 산화수는 −2에서 0으로 변하였다.

> **정답** ② — Cu는 +2에서 0으로 감소했으므로 환원되었다. Cu가 2개이므로 감소 총합은 4이며, 이는 C의 증가량 +4와 같다. O는 반응 전후 모두 −2로 변하지 않는다.
