## 한눈에 보기

- **산화제(酸化剤)**: 상대 물질을 산화시키는 물질. 자신은 **환원**된다(전자를 얻고, 산화수가 감소).
- **환원제(還元剤)**: 상대 물질을 환원시키는 물질. 자신은 **산화**된다(전자를 잃고, 산화수가 증가).
- 대표적인 산화제는 KMnO₄, 열농황산, 묽은 질산, 진한 질산이다. 대표적인 환원제는 H₂S, KI이다.
- H₂O₂와 SO₂는 반응 상대에 따라 산화제로도, 환원제로도 작용한다.

## 개념 정리

### 산화제·환원제의 정의
소화가 필요할 때 소화제를 먹듯, 어떤 물질을 산화시키고 싶으면 산화제를, 환원시키고 싶으면 환원제를 넣는다.

| | 상대에게 하는 일 | 자신의 변화 | 전자 | 자신의 산화수 |
|---|---|---|---|---|
| 산화제 | 산화시킨다 | 환원된다 | 얻는다 | 감소 |
| 환원제 | 환원시킨다 | 산화된다 | 잃는다 | 증가 |

### 대표적인 산화제
**과망간산칼륨(過マンガン酸カリウム) KMnO₄**
- 산성: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O (Mn: +7 → +2)
- 중성·염기성: MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻ (Mn: +7 → +4)

산성에서는 Mn이 받는 전자 수가 5개로 더 많아 산화력이 강하다. 그래서 보통 **황산 산성(硫酸酸性)**에서 사용한다. 이때 황산은 H⁺만 공급할 뿐 산화제도 환원제도 아니다. 참고로 염산은 KMnO₄에 산화되고 질산은 자체에 산화력이 있어서, 산성 조건을 만들 때 쓰지 않는다.

**산화력이 있는 산(酸化力のある酸)**

| 산 | 반쪽 반응식 | 생성 기체 |
|---|---|---|
| 열농황산(熱濃硫酸) | H₂SO₄ + 2H⁺ + 2e⁻ → SO₂ + 2H₂O (S: +6 → +4) | SO₂ |
| 묽은 질산(希硝酸) | HNO₃ + 3H⁺ + 3e⁻ → NO + 2H₂O (N: +5 → +2) | NO |
| 진한 질산(濃硝酸) | HNO₃ + H⁺ + e⁻ → NO₂ + H₂O (N: +5 → +4) | NO₂ |

생성 기체는 "묽은 쪽은 숫자가 작은 NO, 진한 쪽은 숫자가 큰 NO₂"로 외운다.

### 대표적인 환원제
- 황화수소 H₂S: H₂S → S + 2H⁺ + 2e⁻ (S: −2 → 0)
- 아이오딘화칼륨(ヨウ化カリウム) KI: 2I⁻ → I₂ + 2e⁻ (I: −1 → 0)

### 양쪽으로 작용하는 물질
과산화수소 H₂O₂는 보통 산화제로 쓰인다. 그러나 KMnO₄처럼 자신보다 강한 산화제를 만나면 환원제로 작용한다.
- 산화제: H₂O₂ + 2H⁺ + 2e⁻ → 2H₂O (O: −1 → −2)
- 환원제: H₂O₂ → O₂ + 2H⁺ + 2e⁻ (O: −1 → 0)

이산화황 SO₂는 보통 환원제로 쓰인다. 그러나 H₂S처럼 더 강한 환원제를 만나면 산화제로 작용한다.
- 환원제: SO₂ + 2H₂O → SO₄²⁻ + 4H⁺ + 2e⁻ (S: +4 → +6)
- 산화제: SO₂ + 4H⁺ + 4e⁻ → S + 2H₂O (S: +4 → 0)

## 꼭 외울 것
- 산화제는 자신이 환원되고(전자 획득, 산화수 감소), 환원제는 자신이 산화된다(전자 방출, 산화수 증가).
- KMnO₄는 산성에서 Mn²⁺(5e⁻)로, 중성·염기성에서 MnO₂(3e⁻)로 변한다.
- 열농황산은 SO₂, 묽은 질산은 NO, 진한 질산은 NO₂를 낸다.
- H₂O₂에서 O의 산화수는 예외적으로 −1이다.
- H₂O₂와 SO₂는 산화제와 환원제 양쪽으로 작용한다.

## 자주 틀리는 함정
- "산화제는 산화된다"는 틀린 말이다. 산화제는 남을 산화시키고 자신은 환원된다.
- 황산 산성 KMnO₄ 반응에서 황산을 산화제로 고르면 안 된다. 산화제는 KMnO₄이고, 황산은 H⁺ 공급원일 뿐이다.
- 묽은 질산과 진한 질산의 생성 기체(NO/NO₂)를 서로 바꿔 쓰는 실수가 잦다.
- SO₂의 산화수를 계산할 때 S를 기준으로 계산한다. SO₄²⁻에서 S는 +6이다.

## 확인 문제

**문1** 다음 중 산화제로서 반응할 때 전자를 가장 많이 받는(1 mol당) 것은?
① 진한 질산 ② 묽은 질산 ③ 황산 산성 KMnO₄ ④ 열농황산

> **정답** ③ — 1 mol당 받는 전자 수는 진한 질산 1, 묽은 질산 3, 황산 산성 KMnO₄ 5(MnO₄⁻ → Mn²⁺), 열농황산 2이다.

**문2** 다음 반응에서 SO₂가 산화제로 작용하는 것은?
① SO₂ + H₂O₂ → H₂SO₄
② SO₂ + 2H₂S → 3S + 2H₂O
③ SO₂ + I₂ + 2H₂O → H₂SO₄ + 2HI
④ 5SO₂ + 2KMnO₄ + 2H₂O → K₂SO₄ + 2MnSO₄ + 2H₂SO₄

> **정답** ② — ②에서 S의 산화수가 +4에서 0으로 감소하므로 SO₂는 환원되었고, 산화제로 작용한 것이다. 나머지 반응에서는 모두 S가 +6으로 증가하므로 SO₂는 환원제다.

**문3** 황산 산성 KMnO₄ 수용액에 H₂O₂를 가했을 때의 설명으로 옳은 것은?
① H₂O₂는 산화제이다. ② 황산이 산화제이다. ③ O₂가 발생한다. ④ Mn의 산화수는 +7에서 +4가 된다.

> **정답** ③ — 더 강한 산화제인 KMnO₄를 만나 H₂O₂는 환원제로 작용하고(O: −1 → 0), O₂가 발생한다. 산성 조건이므로 Mn은 +7에서 +2가 된다. 황산은 H⁺를 공급할 뿐이다.
