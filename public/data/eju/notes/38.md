## 한눈에 보기
- 염소 Cl₂(塩素)를 실험실에서 얻는 대표적인 방법은 4가지다. 시험에 가장 많이 나오는 것은 **산화망가니즈(IV) + 진한 염산 가열**이다.
- 이 반응에서 MnO₂는 촉매가 아니라 **산화제(酸化剤)**다. Mn의 산화수가 +4에서 +2로 내려간다.
- 발생한 기체에는 Cl₂ 외에 HCl과 H₂O가 섞여 있다. 그래서 **물 → 진한 황산** 순서로 세기병(洗気びん)에 통과시켜 정제한다.
- Cl₂는 **하방치환(下方置換)**으로 포집한다.

## 개념 정리
### 1. 염소의 제법 4가지
| 방법 | 반응식 | 비고 |
|---|---|---|
| ① 산화망가니즈(IV) + 진한 염산 (가열) | MnO₂ + 4HCl → MnCl₂ + 2H₂O + Cl₂ | 가장 중요. Mn: +4 → +2 |
| ② 산화망가니즈(IV) + 염화나트륨 + 진한 황산 (가열) | MnO₂ + 2NaCl + 2H₂SO₄ → MnSO₄ + Na₂SO₄ + 2H₂O + Cl₂ | Mn: +4 → +2 |
| ③ 표백분 + 염산 | CaCl(ClO)·H₂O + 2HCl → CaCl₂ + 2H₂O + Cl₂ | 상온에서도 반응 |
| ③′ 고도 표백분 + 염산 | Ca(ClO)₂·2H₂O + 4HCl → CaCl₂ + 4H₂O + 2Cl₂ | 고농도 표백분 |
| ④ 염화나트륨 수용액의 전기분해(電気分解) | 양극: 2Cl⁻ → Cl₂ + 2e⁻ | 공업적 제법 |

### 2. MnO₂의 역할 — 촉매가 아니다
- MnO₂는 H₂O₂ 분해나 KClO₃ 분해에서는 **촉매(触媒)**로 쓰인다. 촉매는 자신은 변하지 않고 반응 속도만 높이는 물질이다.
- ①에서는 MnO₂가 MnCl₂로 바뀐다. Mn의 산화수(酸化数)는 +4에서 +2로 감소한다.
  - 자신은 환원(還元)되고, 상대(Cl⁻ → Cl₂, −1 → 0)를 산화시킨다. 따라서 **산화제**다.
- 이온 반응식: MnO₂ + 4H⁺ + 2e⁻ → Mn²⁺ + 2H₂O
- ②에서도 MnO₂가 MnSO₄로 바뀐다. Mn이 +4에서 +2가 되므로 역시 산화제다.

### 3. 표백분(さらし粉)
- 표백분은 CaCl(ClO)·H₂O, 고도 표백분(高度さらし粉)은 Ca(ClO)₂·2H₂O로 쓴다.
- 두 경우 모두 산을 가하면 **CaCl₂ + H₂O + Cl₂**가 생긴다.
- 고도 표백분은 ClO⁻를 2개 가지므로, 1 mol당 생기는 Cl₂도 2 mol이다.

### 4. 전기분해
NaCl 수용액을 전기분해하면 할로젠화물 이온 Cl⁻가 물보다 먼저 전자를 내놓는다. 그래서 양극에서 Cl₂가 발생한다.

### 5. 실험 장치: MnO₂ + 진한 염산
1. 플라스크에 MnO₂를 넣고, 분액 깔때기로 진한 염산을 조금씩 떨어뜨리며 가열한다.
2. 진한 염산은 휘발성이다. 가열하면 염화수소의 용해도가 줄어 **HCl 기체**가 빠져나오고, **수증기 H₂O**도 함께 나온다.
   - 그래서 발생 기체는 Cl₂, HCl, H₂O의 3종류다.
3. 세기병 ①: **물**에 통과시킨다. 물에 매우 잘 녹는 HCl이 제거된다.
4. 세기병 ②: **진한 황산**에 통과시킨다. 흡습성(吸湿性)으로 H₂O가 제거된다.
5. 포집: Cl₂의 분자량은 71로, 공기의 평균 분자량 29보다 크다. 또 물에 녹고 물과 반응하므로 **하방치환**으로 모은다.
   - 수상치환(水上置換)을 쓰면 다시 수분이 섞여 건조한 의미가 없어진다.

## 꼭 외울 것
- MnO₂ + 4HCl → MnCl₂ + 2H₂O + Cl₂ (가열)
- MnO₂는 이 반응에서 **산화제**이며, Mn의 산화수는 +4 → +2로 변한다.
- 불순물 HCl은 **물**로, H₂O는 **진한 황산**으로 제거한다.
- 세기병 순서는 반드시 **물 → 진한 황산**이다.
- Cl₂ 포집은 **하방치환**이다(분자량 71 > 29, 수용성).
- 표백분: CaCl(ClO)·H₂O + 2HCl → CaCl₂ + 2H₂O + Cl₂

## 자주 틀리는 함정
- **"MnO₂는 촉매"라고 고르는 실수**: 염소 제법에서는 Mn²⁺로 변하므로 산화제다. 촉매인 경우(H₂O₂, KClO₃ 분해)와 구별해야 한다.
- **세기병 순서를 반대로 하는 실수**: 진한 황산으로 먼저 건조한 뒤 물을 통과시키면 다시 수증기가 섞인다.
- **진한 황산으로 HCl도 제거된다고 보는 실수**: 진한 황산은 HCl을 흡수하지 못한다. HCl 제거는 물의 역할이다.
- **수상치환을 고르는 실수**: Cl₂는 물에 녹고, 건조한 기체를 다시 적시게 된다.
- **고도 표백분의 계수를 착각하는 실수**: 고도 표백분은 HCl 4, Cl₂ 2다. 일반 표백분(HCl 2, Cl₂ 1)과 헷갈리지 말 것.
- **②에서 생성물을 MnCl₂로 쓰는 실수**: 황산을 쓰므로 생성물은 MnSO₄다.

## 확인 문제
**문 1** 산화망가니즈(IV)에 진한 염산을 가하여 가열할 때, 산화망가니즈(IV)의 역할과 Mn의 산화수 변화로 옳은 것은?
① 촉매, 변화 없음 ② 환원제, +2 → +4 ③ 산화제, +4 → +2 ④ 산화제, +4 → +1

> **정답** ③ — MnO₂는 MnCl₂로 변하므로 촉매가 아니다. Mn의 산화수가 +4에서 +2로 감소하므로, MnO₂는 자신이 환원되면서 Cl⁻를 산화시키는 산화제다.

**문 2** 문 1의 장치에서 발생한 기체를 순수한 건조 염소로 얻기 위한 세기병 내용물(앞 → 뒤)과 포집법의 조합으로 옳은 것은?
① 진한 황산 → 물, 하방치환 ② 물 → 진한 황산, 하방치환 ③ 물 → 진한 황산, 수상치환 ④ 진한 황산 → 물, 상방치환

> **정답** ② — 물로 HCl을 먼저 제거하고 진한 황산으로 H₂O를 제거한다. 순서가 바뀌면 다시 수분이 섞인다. Cl₂는 공기보다 무겁고(71 > 29) 물에 녹으므로 하방치환으로 포집한다.

**문 3** 고도 표백분 Ca(ClO)₂·2H₂O 1.0 mol에 충분한 양의 염산을 가했을 때 발생하는 Cl₂의 물질량[mol]은?
① 0.5 ② 1.0 ③ 2.0 ④ 4.0

> **정답** ③ — 반응식은 Ca(ClO)₂·2H₂O + 4HCl → CaCl₂ + 4H₂O + 2Cl₂이므로, 1 mol에서 Cl₂ 2 mol이 생긴다. 일반 표백분 CaCl(ClO)·H₂O라면 1 mol이다.
