## 한눈에 보기

- 다니엘 전지(ダニエル電池)는 아연판과 구리판을 각각 **황산아연 수용액**과 **황산구리(Ⅱ) 수용액**에 담그고, 두 용액을 **초벌구이판(素焼き板)**으로 칸막이한 대표적인 **일차전지(一次電池)**이다.
- 이온화 경향(イオン化傾向)이 큰 Zn이 **음극(負極)**, Cu가 **양극(正極)**이 된다.
- 음극에서는 Zn이 녹아 질량이 **감소**하고, 양극에서는 Cu가 석출되어 질량이 **증가**한다.
- ZnSO₄ 수용액의 농도는 **증가**하고, CuSO₄ 수용액의 농도는 **감소**한다.
- 초벌구이판은 **두 수용액이 섞이는 것은 막고, 이온은 통과시킨다.**

## 개념 정리

### 볼타 전지와의 비교

| | 볼타 전지 | 다니엘 전지 |
|---|---|---|
| 전극 | Zn, Cu | Zn, Cu |
| 전해액 | 묽은 황산 H₂SO₄ 한 종류 | ZnSO₄aq, CuSO₄aq 두 종류 |
| 칸막이 | 없음 | 초벌구이판(또는 염다리) |
| 양극 반응 | 2H⁺ + 2e⁻ → H₂ | Cu²⁺ + 2e⁻ → Cu |

### 초벌구이판의 역할

도자기는 흙으로 빚은 뒤 한 번 굽고(초벌구이, 素焼き), 유약을 바른 뒤 다시 굽는다(재벌구이). 초벌구이만 한 판은 흙 입자가 살짝 녹았다가 굳어서 **미세한 구멍이 많은** 판이 된다.
- 구멍이 작아서 **액체(수용액)는 잘 섞이지 않는다.**
- 이온은 그 작은 구멍을 **통과할 수 있다.**

이 판 덕분에 두 수용액이 섞이지 않으면서도 이온이 오가며 전기적 균형을 유지한다. 한국 교과서에서 쓰는 **염다리(塩橋)**도 같은 역할을 한다.

### 각 전극의 반응

이온화 경향은 Zn > Cu이므로 Zn이 양이온이 되어 녹아 나오고, 전자는 도선을 통해 Cu 쪽으로 이동한다.

- **음극(−)**: Zn → Zn²⁺ + 2e⁻ … 전자를 내놓는 **산화(酸化)**
- **양극(+)**: Cu²⁺ + 2e⁻ → Cu … 전자를 받아들이는 **환원(還元)**

구리판으로 들어온 전자는 금속 자체를 음이온으로 만들지 않는다. 대신 용액 속 양이온 Cu²⁺가 전자를 받아 Cu로 석출된다.
(보충) 전체 반응은 Zn + Cu²⁺ → Zn²⁺ + Cu이며, 기전력은 약 1.1 V이다.

### 전지식(電池式)

(−) Zn | ZnSO₄aq | CuSO₄aq | Cu (+)

### 반응이 진행될 때의 변화

| 항목 | 변화 | 이유 |
|---|---|---|
| Zn판 질량 | 감소 | Zn → Zn²⁺로 녹아 나감 |
| Cu판 질량 | 증가 | Cu²⁺ → Cu로 석출 |
| ZnSO₄aq 농도 | 증가 | Zn²⁺가 늘고, SO₄²⁻가 넘어옴 |
| CuSO₄aq 농도 | 감소 | Cu²⁺가 석출되고, 남은 SO₄²⁻는 판을 통과해 넘어감 |

### 칸막이를 바꾸거나 없애면?

- **유리판·플라스틱판**: 구멍이 없어 이온이 통과하지 못한다. 양쪽 용액의 전하 균형이 무너지면서 전자가 더 이상 이동하지 못하므로 **반응이 곧 멈춘다.**
- **칸막이 없음**: 두 용액이 섞여서 Zn 표면에서 Cu²⁺가 직접 전자를 받는다. Cu가 Zn판에 바로 석출되고, 전자가 도선을 거치지 않으므로 **도선에 전류가 흐르지 않는다.**

## 꼭 외울 것

- 다니엘 전지의 전지식: (−) Zn | ZnSO₄aq | CuSO₄aq | Cu (+)
- 음극 반응: Zn → Zn²⁺ + 2e⁻ (산화)
- 양극 반응: Cu²⁺ + 2e⁻ → Cu (환원)
- 초벌구이판은 **용액의 혼합은 막고, 이온은 통과시킨다.**
- 농도 변화: ZnSO₄ ↑, CuSO₄ ↓
- 질량 변화: Zn판 ↓, Cu판 ↑

## 자주 틀리는 함정

- **"전자가 용액 속을 지나간다"** → 틀림. 전자는 도선으로만 이동하고, 용액과 초벌구이판에서는 **이온**이 이동한다.
- **양극에서 H₂가 발생한다고 쓰는 실수** → 그것은 볼타 전지이다. 다니엘 전지의 양극에서는 Cu가 석출된다.
- **"칸막이를 없애면 반응이 더 빨라져 전류가 커진다"** → 틀림. Zn과 Cu²⁺가 직접 반응하므로 도선에는 전류가 흐르지 않는다.
- **유리판으로 바꿔도 된다고 생각하는 실수** → 이온이 통과하지 못해 반응이 바로 멈춘다.
- **CuSO₄aq에서 Cu²⁺만 줄어든다고 생각하는 실수** → SO₄²⁻도 초벌구이판을 통해 Zn 쪽으로 이동하므로 CuSO₄의 농도 자체가 감소한다.

## 확인 문제

**問1** 다니엘 전지를 방전시켰을 때의 변화로 옳은 것은?
① 아연판의 질량이 증가한다.
② 황산구리(Ⅱ) 수용액의 농도가 증가한다.
③ 황산아연 수용액의 농도가 증가한다.
④ 구리판에서 수소가 발생한다.

> **정답** ③ — Zn²⁺가 녹아 나오고 SO₄²⁻가 초벌구이판을 통해 넘어오므로 ZnSO₄의 농도가 증가한다. ①은 감소, ②는 감소가 맞다. ④는 볼타 전지의 양극 반응이다.

**問2** 다니엘 전지의 초벌구이판을 유리판으로 바꾸었을 때 일어나는 현상으로 옳은 것은?
① 두 용액이 섞여 아연판에 구리가 석출된다.
② 이온이 이동하지 못해 곧 전류가 흐르지 않게 된다.
③ 기전력이 커져 전류가 오래 흐른다.
④ 구리판이 녹아 Cu²⁺가 된다.

> **정답** ② — 유리판에는 미세한 구멍이 없어 이온이 통과하지 못한다. 전하 균형이 무너지면서 전자 이동이 멈춘다. ①은 칸막이를 없앴을 때 일어나는 현상이다.

**問3** 다니엘 전지에 대한 설명으로 옳은 것은?
① 음극에서는 Cu²⁺ + 2e⁻ → Cu의 환원 반응이 일어난다.
② 전자는 도선을 통해 구리판에서 아연판으로 이동한다.
③ 양극에서는 Zn → Zn²⁺ + 2e⁻의 산화 반응이 일어난다.
④ 음극에서는 산화 반응, 양극에서는 환원 반응이 일어난다.

> **정답** ④ — 음극(Zn)에서는 Zn → Zn²⁺ + 2e⁻(산화), 양극(Cu)에서는 Cu²⁺ + 2e⁻ → Cu(환원)가 일어난다. 전자는 도선을 따라 아연판에서 구리판으로 이동한다.
