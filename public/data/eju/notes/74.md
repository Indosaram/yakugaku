## 한눈에 보기

- **엔탈피(エンタルピー, H)**: 물질이 가지고 있는 화학적 에너지. 시험에서는 엔탈피 자체보다 그 **변화량 ΔH**를 다룬다.
- **ΔH = (생성물의 엔탈피 합) − (반응물의 엔탈피 합)**
- 발열 반응이면 ΔH < 0, 흡열 반응이면 ΔH > 0이다.
- 기존 **열화학 방정식(熱化学方程式)**과 의미는 같다. 다만 바라보는 관점이 달라서 **부호가 반대**로 쓰인다.
- 헤스의 법칙과 생성 엔탈피를 이용한 계산은 그대로 적용된다.

## 개념 정리

### 1. 엔탈피와 반응 엔탈피

모든 물질은 화학적 에너지를 가지며, 그 크기는 물질의 종류에 따라 다르다. 메탄처럼 불에 잘 타는 물질은 큰 에너지를 가지고 있어서, 연소할 때 열과 빛을 낸다. 물질이 가진 이 에너지를 **엔탈피**라고 한다. 엔탈피는 온도와 압력에 따라 달라진다.

실제로 관심을 두는 것은 물질에서 에너지를 얼마나 꺼낼 수 있는지, 또는 에너지를 얼마나 넣어야 물질이 변하는지이다. 그래서 화학 반응에서 방출되거나 흡수되는 열량을 **반응 엔탈피(反応エンタルピー)** ΔH로 나타낸다.

ΔH = ΣH(생성물) − ΣH(반응물)

| 반응 | 물질의 에너지 | ΔH의 부호 |
|---|---|---|
| 흡열 반응(吸熱反応) | 주위에서 열을 받아 증가 | **+** (큰 값 − 작은 값) |
| 발열 반응(発熱反応) | 주위로 열을 내보내 감소 | **−** (작은 값 − 큰 값) |

### 2. 열화학 방정식과 엔탈피 표기 비교

예시 반응: CH₄ 1 mol이 O₂ 2 mol과 반응하여 CO₂ 1 mol과 H₂O(액) 2 mol이 생기고, 891 kJ의 열이 발생한다.

| | 열화학 방정식 | 엔탈피 표기 |
|---|---|---|
| 표기 | CH₄ + 2O₂ = CO₂ + 2H₂O(액) + 891 kJ | CH₄ + 2O₂ → CO₂ + 2H₂O(액)　ΔH = −891 kJ |
| 의미 | 좌변의 에너지 합 = 우변의 에너지 합 | 물질의 에너지가 891 kJ 줄었다 |
| 발열 | **+**로 씀 | **−**로 씀 |
| 흡열 | **−**로 씀 | **+**로 씀 |
| 관점 | 주위(外界)가 얻은 에너지 | 물질, 즉 계(系) 자체의 에너지 변화 |

- **열화학 방정식**: 발열 반응에서는 생성물의 에너지가 낮아진다. 따라서 빠져나간 열량을 우변에 더해야 좌변과 같아진다. 주위가 891 kJ을 얻었으므로 +로 쓴다.
- **엔탈피**: 화학 반응식과 에너지를 따로 적는다. 물질 자체가 891 kJ을 잃었으므로 ΔH = −891 kJ이다.

### 3. 에너지 도표로 이해하기

반응물의 에너지 준위가 생성물보다 높으면, 그 차이만큼이 밖으로 빠져나간다. 이것이 발열이다.

- 열화학 방정식: 낮은 쪽(생성물)에 차이만큼을 **더해** 양변을 맞춘다.
- 엔탈피: 높은 곳에서 낮은 곳으로 **줄어든** 양을 −로 나타낸다.

### 4. 헤스의 법칙과 생성 엔탈피

- **헤스의 법칙(ヘスの法則)**: 반응열(ΔH)은 처음 상태와 나중 상태만으로 정해지며, 반응 경로와는 무관하다.
- **생성 엔탈피(生成エンタルピー)**를 이용하면 다음과 같이 계산한다.
  ΔH(반응) = Σ(생성물의 생성 엔탈피) − Σ(반응물의 생성 엔탈피)
  이것이 기존의 "생생 마 반생"과 같은 방식이다.
- 식이 복잡해서 연립하기 어려울 때는 열화학 방정식 형태로 바꾼다. 그러면 좌변 = 우변이므로 이항하고 대입하면 풀린다. 그래서 열화학 방정식을 먼저 이해해 두면 유리하다.

## 꼭 외울 것

- ΔH = H(생성물) − H(반응물)
- 발열이면 ΔH < 0, 흡열이면 ΔH > 0
- 열화학 방정식의 "+Q kJ"은 엔탈피 표기의 "ΔH = −Q kJ"과 같다. 부호만 반대이다.
- 열화학 방정식은 주위의 관점, 엔탈피는 물질(계)의 관점이다.
- 헤스의 법칙과 "생성물 − 반응물" 계산은 엔탈피에도 그대로 쓴다.

## 자주 틀리는 함정

1. **부호 혼동**: 발열 반응이라고 해서 ΔH를 +로 쓰면 틀린다. ΔH는 물질의 관점이므로 발열이면 −이다.
2. **표기 혼합**: 엔탈피 표기에서는 반응식에 열량을 더하지 않는다. 화살표(→)로 반응식을 쓰고, ΔH는 따로 적는다.
3. **뺄셈 순서**: ΔH는 반드시 "나중 − 처음", 즉 생성물 − 반응물 순서로 계산한다.
4. **계수와 상태**: ΔH는 반응식의 계수(몰수)에 비례한다. H₂O가 액체인지 기체인지에 따라서도 값이 달라진다.

## 확인 문제

**문제 1** 열화학 방정식 CH₄ + 2O₂ = CO₂ + 2H₂O(액) + 891 kJ을 엔탈피를 써서 바르게 나타낸 것은?

① CH₄ + 2O₂ → CO₂ + 2H₂O(액)　ΔH = +891 kJ
② CH₄ + 2O₂ → CO₂ + 2H₂O(액)　ΔH = −891 kJ
③ CH₄ + 2O₂ → CO₂ + 2H₂O(액) + 891 kJ　ΔH = −891 kJ
④ CO₂ + 2H₂O(액) → CH₄ + 2O₂　ΔH = −891 kJ

> **정답** ② — 발열 반응이므로 물질의 엔탈피가 줄어들어 ΔH는 음수이다. ③은 반응식에 열량을 함께 써서 표기가 섞였다. ④는 역반응이므로 ΔH = +891 kJ이어야 한다.

**문제 2** 어떤 반응의 ΔH가 +50 kJ이다. 이에 대한 설명으로 옳은 것은?

① 발열 반응이며, 생성물의 엔탈피가 반응물보다 크다.
② 발열 반응이며, 생성물의 엔탈피가 반응물보다 작다.
③ 흡열 반응이며, 생성물의 엔탈피가 반응물보다 크다.
④ 흡열 반응이며, 열화학 방정식에서는 우변에 +50 kJ로 쓴다.

> **정답** ③ — ΔH > 0이면 물질이 에너지를 얻은 것이므로 흡열 반응이고, 생성물의 엔탈피가 더 크다. 열화학 방정식에서는 우변에 −50 kJ로 쓴다.

**문제 3** 생성 엔탈피가 CH₄(기) −75 kJ/mol, CO₂(기) −394 kJ/mol, H₂O(액) −286 kJ/mol일 때, CH₄ 1 mol의 연소 엔탈피 ΔH는?

① +891 kJ　② −605 kJ　③ −891 kJ　④ −1041 kJ

> **정답** ③ — ΔH = [(−394) + 2×(−286)] − (−75) = −966 + 75 = −891 kJ이다. O₂는 홑원소 물질이므로 생성 엔탈피가 0이다.
