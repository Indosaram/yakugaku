## 한눈에 보기

- 침전의 색은 **음이온별로 묶어서** 외우면 빠르다. Cl⁻, S²⁻, OH⁻, SO₄²⁻, CrO₄²⁻ 다섯 가지를 다룬다.
- 염화물·황산염 침전은 **모두 흰색**이다.
- 황화물(硫化物)은 **액성(液性)에 따라 침전 여부가 달라진다**. 산성에서도 침전하는 것은 대부분 검은색이다.
- 수산화물(水酸化物)은 **"원래 이온 색 + 흰색"** 으로 생각하면 된다.
- 크롬산염(クロム酸塩)은 **Ag₂CrO₄만 적갈색**이고 나머지는 노란색이다.

## 개념 정리

### 1. 염화물 이온 Cl⁻과의 침전

Cl⁻과 침전을 만드는 대표 이온은 Ag⁺와 Pb²⁺ 두 가지이다.

| 침전 | 색 | 참고 |
|---|---|---|
| AgCl | 흰색(白色) | 빛을 받으면 분해되어 Ag가 석출된다(감광성) |
| PbCl₂ | 흰색 | 뜨거운 물에 녹는다 |

### 2. 황화물 이온 S²⁻과의 침전

황화수소(硫化水素) H₂S를 통하면 황화물이 침전한다. 산성에서는 S²⁻ 농도가 낮아서 용해도가 아주 작은 황화물만 침전한다. 염기성에서는 S²⁻ 농도가 높아서 더 많은 황화물이 침전한다.

| 조건 | 침전 | 색 |
|---|---|---|
| **액성에 관계없이**(산성에서도) 침전 | Ag₂S, CuS, PbS, HgS | 검은색(黒色) |
| | (보충) CdS | 노란색 |
| **중성·염기성에서만** 침전 | ZnS | 흰색 |
| | FeS, NiS | 검은색 |
| | MnS | 엷은 분홍색(淡赤色) |

- 산성에서 침전하는 것들은 "검게 탄다"로 묶어서 기억한다.
- 중성·염기성 그룹에서는 **ZnS 흰색, MnS 분홍색** 두 개만 따로 기억한다. 나머지는 검은색이다.
- MnS는 Mn과 일본어 **モモイロ(복숭아색)** 의 M을 연결해서 외운다.

### 3. 수산화물 이온 OH⁻과의 침전

수산화물 침전의 색은 **"수용액 속 이온의 원래 색 + 흰색"** 으로 생각하면 된다.

| 이온(색) | 침전 | 침전 색 |
|---|---|---|
| Al³⁺(무색) | Al(OH)₃ | 흰색 |
| Zn²⁺(무색) | Zn(OH)₂ | 흰색 |
| Cu²⁺(청색) | Cu(OH)₂ | 청백색(青白色) |
| Fe²⁺(담녹색) | Fe(OH)₂ | 녹백색(緑白色) |
| Fe³⁺(황갈색) | Fe(OH)₃ | 적갈색(赤褐色) |

(보충) Ag⁺에 OH⁻를 넣으면 수산화물이 아니라 산화은 Ag₂O(갈색)가 생긴다.
2Ag⁺ + 2OH⁻ → Ag₂O + H₂O

### 4. 황산 이온 SO₄²⁻과의 침전

외우는 말은 **「そんなバカな(손나 바카나)」** 다. 침전이 되는 이온은 다음 세 가지이다.

- **Ba**²⁺ → BaSO₄
- **Ca**²⁺ → CaSO₄
- **Pb**²⁺ → PbSO₄

세 침전은 모두 **흰색**이다. "그런 바보 같은 일이!" 하고 머리가 하얘진다고 연결해 두자.

알아 두면 좋은 용도는 다음과 같다.
- BaSO₄: 물과 산에 녹지 않으므로 X선 조영제(造影剤)로 쓴다.
- CaSO₄·2H₂O: 석고(セッコウ)이다.

### 5. 크롬산 이온 CrO₄²⁻과의 침전

| 침전 | 색 |
|---|---|
| PbCrO₄ | 노란색(黄色) |
| BaCrO₄ | 노란색 |
| Ag₂CrO₄ | 적갈색(赤褐色) |

## 꼭 외울 것

- AgCl, PbCl₂는 흰색이다. PbCl₂는 뜨거운 물에 녹는다.
- 산성에서도 침전하는 황화물은 CuS, PbS, Ag₂S, HgS(검은색)와 CdS(노란색)이다.
- 중성·염기성에서만 침전하는 황화물은 ZnS(흰색), FeS·NiS(검은색), MnS(엷은 분홍색)이다.
- 수산화물 색은 Cu(OH)₂ 청백색, Fe(OH)₂ 녹백색, Fe(OH)₃ 적갈색, Al(OH)₃·Zn(OH)₂ 흰색이다.
- 황산염 침전은 「そんなバカな」, 즉 BaSO₄·CaSO₄·PbSO₄이며 모두 흰색이다.
- 크롬산염은 PbCrO₄·BaCrO₄가 노란색, Ag₂CrO₄가 적갈색이다.

## 자주 틀리는 함정

- **ZnS를 검은색으로 착각하는 실수**가 많다. ZnS는 황화물 중 드물게 **흰색**이다.
- **ZnS는 산성에서 침전하지 않는다.** 산성 조건에서 H₂S를 통해도 Zn²⁺는 용액에 남는다.
- **Fe(OH)₂와 Fe(OH)₃를 혼동하지 말 것.** 2가는 녹백색, 3가는 적갈색이다.
- **Ag⁺ + OH⁻의 생성물은 AgOH가 아니다.** Ag₂O(갈색)가 생긴다.
- **크롬산염이 모두 노란색인 것은 아니다.** Ag₂CrO₄만 적갈색이다.
- **CaSO₄도 침전으로 취급한다.** 물에 약간 녹지만 입시에서는 흰색 침전으로 다룬다.

## 확인 문제

**문제 1** 염산으로 산성으로 만든 수용액에 H₂S를 통했을 때, 침전이 생기지 **않는** 금속 이온은?

① Cu²⁺ ② Pb²⁺ ③ Zn²⁺ ④ Ag⁺

> **정답** ③ — Zn²⁺는 중성·염기성에서만 ZnS(흰색)로 침전한다. 산성에서는 S²⁻ 농도가 낮아 침전하지 않는다. 나머지 세 이온은 산성에서도 검은 황화물을 만든다.

**문제 2** 다음 침전과 색의 조합 중 **잘못된** 것은?

① Cu(OH)₂ — 청백색 ② Fe(OH)₃ — 적갈색 ③ MnS — 엷은 분홍색 ④ Ag₂CrO₄ — 노란색

> **정답** ④ — Ag₂CrO₄는 적갈색이다. 노란색인 것은 PbCrO₄와 BaCrO₄이다.

**문제 3** 수용액에 묽은 황산을 가했을 때 흰색 침전이 생기는 이온만으로 짝지어진 것은?

① Ba²⁺, Cu²⁺ ② Ca²⁺, Pb²⁺ ③ Zn²⁺, Ba²⁺ ④ Fe³⁺, Pb²⁺

> **정답** ② — 「そんなバカな」의 Ba²⁺·Ca²⁺·Pb²⁺가 흰색 황산염 침전을 만든다. Cu²⁺, Zn²⁺, Fe³⁺의 황산염은 물에 녹는다.
