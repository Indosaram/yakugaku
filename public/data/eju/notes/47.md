## 한눈에 보기

- 철 이온에는 **철(II) 이온 Fe²⁺**과 **철(III) 이온 Fe³⁺**이 있다. 시험에서는 대부분 **"2가냐 3가냐"를 색으로 구별하는 문제**가 나온다.
- 기본 암기 축은 다음과 같다. **2가 = 녹색 계열, 3가 = 갈색 계열.**
- NaOH, K₄[Fe(CN)₆], K₃[Fe(CN)₆], KSCN, H₂O₂를 넣었을 때의 침전·용액 색과 반응을 정리한다.

## 개념 정리

### 1. 철 이온의 색
| 이온 | 색 | 암기 |
|---|---|---|
| Fe²⁺ | 담녹색(淡緑色) | 녹색 계열 |
| Fe³⁺ | 황갈색(黄褐色) | 갈색 계열 |

"담녹색, 진녹색, 녹백색"처럼 미세한 색 차이를 묻는 경우는 드물다. **녹색 계열인지 갈색 계열인지**를 구별하는 것이 핵심이다.

### 2. NaOH 수용액과의 반응: "OH⁻가 붙으면 흰색이 섞인다"
- Fe²⁺ + 2OH⁻ → Fe(OH)₂ : **녹백색 침전(緑白色沈殿)**
 녹색에 흰색이 더해진 색이다.
- Fe³⁺ + 3OH⁻ → Fe(OH)₃ : **적갈색 침전(赤褐色沈殿)**
 갈색에 흰색이 섞여 약간 불그스름해진 색으로 기억한다.
- Fe(OH)₃는 실제로는 산화수산화철 등이 섞인 혼합물이지만, 입시에서는 수산화철(III)로 표기해도 된다.

### 3. 시안화물 착이온의 산화수 구하기
착화합물에 들어 있는 철이 몇 가인지 먼저 계산해야 한다. CN⁻의 전하는 −1이다.

| 화합물 | 계산 | 철의 산화수 |
|---|---|---|
| K₄[Fe(CN)₆] 헥사시아니도철(II)산칼륨(ヘキサシアニド鉄(II)酸カリウム) | 착이온 전하 −4 = x + 6×(−1) | x = **+2** |
| K₃[Fe(CN)₆] 헥사시아니도철(III)산칼륨(ヘキサシアニド鉄(III)酸カリウム) | 착이온 전하 −3 = x + 6×(−1) | x = **+3** |

### 4. 착화합물 시약과의 반응: 색 조합 암기법
| 시약 \ 이온 | Fe²⁺ (녹) | Fe³⁺ (갈) |
|---|---|---|
| K₄[Fe(CN)₆] (2가, 녹) | 녹+녹 → **청백색 침전**(青白色沈殿) | 2가+3가 → **농청색 침전**(濃青色沈殿) |
| K₃[Fe(CN)₆] (3가, 갈) | 3가+2가 → **농청색 침전** | 갈+갈 → **암갈색 용액**(褐色溶液, 침전 아님) |

- 녹색 계열끼리 만나면 녹색이 강해져 푸른빛을 띤 **청백색 침전**이 된다.
- **2가와 3가가 만나면 어느 조합이든 농청색 침전**이 생긴다.
- 갈색 계열끼리 만나면 색이 더 진해져 **암갈색 용액**이 된다. 침전이 생기지 않는다는 점에 주의한다.

### 5. 티오시안산칼륨 KSCN: Fe³⁺ 전용 검출 시약
- KSCN은 티오시안산칼륨(チオシアン酸カリウム)이다.
- Fe²⁺와는 거의 반응하지 않는다.
- Fe³⁺와 만나면 피처럼 붉은 **혈적색 용액(血赤色溶液)**이 된다.
- 문제에 "혈적색"이 나오면 **KSCN + Fe³⁺**를 바로 떠올린다.

### 6. 과산화수소 H₂O₂와의 반응
- **Fe²⁺에 넣을 때**: H₂O₂는 산화제(酸化剤)로 작용한다. Fe²⁺를 Fe³⁺로 산화시키므로 용액이 담녹색에서 황갈색으로 변한다.
 2Fe²⁺ + H₂O₂ + 2H⁺ → 2Fe³⁺ + 2H₂O
- **Fe³⁺에 넣을 때**: Fe³⁺는 더 이상 산화되지 않는다. 대신 Fe³⁺가 **촉매(触媒)**로 작용해 H₂O₂가 분해되고 산소가 발생한다. MnO₂와 같은 역할이다.
 2H₂O₂ → 2H₂O + O₂

## 꼭 외울 것

- Fe²⁺는 담녹색, Fe³⁺는 황갈색이다.
- Fe(OH)₂는 녹백색 침전, Fe(OH)₃는 적갈색 침전이다.
- K₄[Fe(CN)₆]의 철은 +2가, K₃[Fe(CN)₆]의 철은 +3가이다.
- 2가와 3가가 만나면 농청색 침전이 생긴다.
- 2가끼리는 청백색 침전, 3가끼리는 암갈색 용액이 된다.
- KSCN + Fe³⁺는 혈적색 용액이다.
- H₂O₂는 Fe²⁺에 대해서는 산화제, Fe³⁺와 함께 있을 때는 Fe³⁺가 분해 촉매가 되어 O₂가 발생한다.

## 자주 틀리는 함정

- **K₃[Fe(CN)₆] + Fe³⁺를 침전으로 착각한다.** 이 조합은 침전이 아니라 **용액**의 색이 진해질 뿐이다.
- **시약 이름의 숫자와 철의 가수를 혼동한다.** K₄는 철(II), K₃는 철(III)이다. 반드시 산화수를 계산해서 확인한다.
- **KSCN으로 Fe²⁺를 검출할 수 있다고 생각한다.** KSCN의 혈적색은 Fe³⁺ 전용이다.
- **H₂O₂가 Fe³⁺를 더 산화시킨다고 생각한다.** Fe³⁺는 산화되지 않고 촉매로만 작용하며, 이때 O₂가 발생한다.

## 확인 문제

**문제 1** 다음 중 농청색 침전이 생기는 조합을 고르시오.
① Fe²⁺ + KSCN
② Fe³⁺ + K₃[Fe(CN)₆]
③ Fe²⁺ + K₃[Fe(CN)₆]
④ Fe²⁺ + K₄[Fe(CN)₆]

> **정답** ③ — K₃[Fe(CN)₆]의 철은 +3가이므로 Fe²⁺와 만나면 2가와 3가의 조합이 되어 농청색 침전이 생긴다. ②는 암갈색 용액, ④는 청백색 침전이 되고, ①은 거의 변화가 없다.

**문제 2** 어떤 철 이온 수용액에 NaOH 수용액을 넣었더니 적갈색 침전이 생겼다. 이 수용액에 대한 설명으로 옳은 것을 고르시오.
① KSCN 수용액을 넣으면 혈적색 용액이 된다.
② 수용액은 담녹색이다.
③ K₄[Fe(CN)₆] 수용액을 넣으면 청백색 침전이 생긴다.
④ H₂O₂를 넣으면 철 이온이 더 산화된다.

> **정답** ① — 적갈색 침전은 Fe(OH)₃이므로 이 수용액에는 Fe³⁺가 들어 있다. Fe³⁺ 수용액은 황갈색이고, K₄[Fe(CN)₆]와는 농청색 침전을 만든다. H₂O₂를 넣으면 Fe³⁺는 산화되지 않고 분해 촉매로 작용한다.

**문제 3** 황산철(II) 수용액에 과산화수소수를 넣었을 때의 변화로 옳은 것을 고르시오.
① H₂O₂가 환원제로 작용하여 용액이 무색이 된다.
② Fe²⁺가 Fe³⁺로 산화되어 용액이 황갈색으로 변한다.
③ Fe²⁺가 촉매로 작용하여 O₂만 발생하고 색은 변하지 않는다.
④ 녹백색 침전이 생긴다.

> **정답** ② — H₂O₂는 산화제로 작용한다(2Fe²⁺ + H₂O₂ + 2H⁺ → 2Fe³⁺ + 2H₂O). 따라서 용액은 담녹색에서 황갈색으로 변한다. 촉매로 작용해 O₂를 발생시키는 것은 Fe³⁺이고, 녹백색 침전은 NaOH를 넣었을 때 생긴다.
