## 한눈에 보기

- 탄산칼슘(炭酸カルシウム) CaCO₃는 석회석, 대리석, 조개껍데기, 달걀 껍데기의 주성분이다.
- **석회수 + CO₂**를 반응시키면 CaCO₃가 침전하여 용액이 뿌옇게 흐려진다(백탁). 이 반응은 CO₂ 검출법으로 쓰인다.
- CO₂를 **과잉**으로 넣으면 Ca(HCO₃)₂가 생겨 녹고 용액이 투명해진다. 이 용액을 **가열**하면 다시 CaCO₃가 생겨 흐려진다.
- 석회석을 가열하면 **생석회** CaO, 생석회에 물을 넣으면 **소석회** Ca(OH)₂, 소석회에 CO₂를 넣으면 다시 **CaCO₃**가 된다. 세 물질은 반응으로 순환한다.

## 개념 정리

### 1. 자연 속의 탄산칼슘
- 자연계에서는 주로 **석회석(石灰石)** 으로 존재한다. 석회석이 많은 지역에는 **종유동(鍾乳洞, 석회동굴)** 이 생긴다.
- 탄산칼슘이 퇴적되어 생긴 암석이 석회암이고, 석회암이 열과 압력을 받아 변성된 것이 **대리석(大理石, 대리암)** 이다.
- 탄산염은 강산과 반응하여 CO₂를 낸다.
 CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑

### 2. 석회수와 이산화탄소: 백탁 → 투명 → 백탁
**석회수(石灰水)** 는 수산화칼슘 Ca(OH)₂의 수용액이다.

| 단계 | 조작 | 반응식 | 겉보기 |
|---|---|---|---|
| ① | 석회수에 CO₂를 통함 | Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O | 흰 침전이 생겨 **백탁(白濁)** |
| ② | CO₂를 과잉으로 통함 | CaCO₃ + CO₂ + H₂O → Ca(HCO₃)₂ | 침전이 녹아 **투명** |
| ③ | ②의 용액을 가열 | Ca(HCO₃)₂ → CaCO₃↓ + CO₂ + H₂O | 다시 **백탁** |

- ②에서 생기는 **탄산수소칼슘(炭酸水素カルシウム)** Ca(HCO₃)₂는 물에 녹아 Ca²⁺와 2HCO₃⁻로 전리한다. 이온이 되므로 침전이 사라진 것처럼 보인다.
- ③에서는 가열로 CO₂가 빠져나가 ②의 역반응이 일어난다.
- ②와 ③은 같은 반응의 정반응과 역반응이다. 자연에서는 CO₂를 품은 빗물이 석회석을 녹이고(②), 녹은 성분에서 CO₂가 빠져 CaCO₃가 다시 석출하면(③) **종유석(鍾乳石)** 과 **석순(石筍)** 이 생긴다.

### 3. 생석회와 소석회
**(1) 석회석의 열분해 → 생석회**
 CaCO₃ → CaO + CO₂↑ (가열)
- 산화칼슘 CaO를 **생석회(生石灰)** 라 한다. 돌에 열에너지를 주어 "살아난" 석회라는 뜻으로 기억하면 된다.

**(2) 생석회 + 물 → 소석회**
 CaO + H₂O → Ca(OH)₂ (발열)
- 수산화칼슘 Ca(OH)₂를 **소석회(消石灰)** 라 한다. 에너지가 "꺼진(消)" 석회라는 뜻이다. 이때 많은 열이 나온다.
- CaO는 물과 잘 반응하므로 건조제(乾燥剤)로도 쓰인다.

**(3) 소석회 + CO₂ → 탄산칼슘**
 Ca(OH)₂ + CO₂ → CaCO₃ + H₂O
- 소석회의 수용액이 바로 석회수이다. 따라서 2절의 ① 반응과 같다.

### 4. 순환 정리
```
CaCO₃ (석회석) ──가열, −CO₂──▶ CaO (생석회)
     ▲                                │ +H₂O
     └──── +CO₂ ── Ca(OH)₂ (소석회) ◀─┘
```

## 꼭 외울 것

- 석회수 = Ca(OH)₂ 수용액이다. CO₂를 통하면 CaCO₃가 침전하여 백탁된다(CO₂ 검출).
- CO₂ 과잉 → Ca(HCO₃)₂(수용성)가 되어 투명해진다. 가열 → CaCO₃가 되어 다시 백탁된다.
- 생석회 = CaO = 산화칼슘. 소석회 = Ca(OH)₂ = 수산화칼슘.
- CaCO₃ → CaO + CO₂, CaO + H₂O → Ca(OH)₂(발열)
- CaCO₃ 식량 100, CaO 식량 56, CO₂ 분자량 44.

## 자주 틀리는 함정

- **생석회와 소석회를 바꿔 쓰는 실수.** 물과 반응하기 "전"이 생석회(CaO), "후"가 소석회(Ca(OH)₂)이다.
- **"CO₂를 계속 넣으면 침전이 더 많아진다"는 오답.** 과잉 CO₂에서는 침전이 오히려 녹는다.
- **Ca(HCO₃)₂를 고체 침전으로 착각하는 실수.** Ca(HCO₃)₂는 수용액 속에서만 존재하는 이온 상태이다.
- **투명해진 용액을 가열해도 변화가 없다고 보는 실수.** 가열하면 CO₂가 빠져나가 다시 흐려진다.
- **석회수의 정체를 혼동하는 실수.** 석회수는 CaO 수용액이 아니라 Ca(OH)₂ 수용액이다. CaO는 물에 넣는 순간 Ca(OH)₂로 바뀐다.

## 확인 문제

**문제 1** 석회수에 이산화탄소를 계속 통했다. 이에 대한 설명으로 옳은 것은?
① 처음부터 끝까지 용액은 투명하다.
② 처음 생긴 흰 침전은 Ca(OH)₂이다.
③ CO₂를 과잉으로 통하면 침전이 녹아 용액이 투명해진다.
④ 투명해진 용액을 가열해도 아무 변화가 없다.

> **정답** ③ — 처음에는 CaCO₃가 침전하여 백탁된다(①, ② 오답). 과잉의 CO₂는 수용성 Ca(HCO₃)₂를 만들어 용액을 투명하게 한다. 이 용액을 가열하면 CO₂가 빠지며 CaCO₃가 다시 침전한다(④ 오답).

**문제 2** 물질과 관용명의 조합으로 옳은 것은?
① CaO — 소석회
② Ca(OH)₂ — 생석회
③ CaCO₃ — 생석회
④ Ca(OH)₂ — 소석회

> **정답** ④ — CaO가 생석회, Ca(OH)₂가 소석회이다. CaCO₃는 석회석과 대리석의 주성분이다.

**문제 3** 탄산칼슘 10.0 g을 완전히 열분해했을 때 남는 고체의 질량은? (원자량 C=12, O=16, Ca=40)
① 4.4 g
② 5.6 g
③ 7.4 g
④ 10.0 g

> **정답** ② — 반응식은 CaCO₃ → CaO + CO₂이다. CaCO₃ 10.0 g은 10.0/100 = 0.100 mol이다. 남는 고체는 CaO 0.100 mol이므로 0.100 × 56 = 5.6 g이다. ①의 4.4 g은 빠져나간 CO₂의 질량이다.
