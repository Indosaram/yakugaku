## 한눈에 보기

- **약산의 유리(弱酸の遊離)**: 약산의 염(塩)에 강산을 넣으면 약산이 다시 빠져나온다.
  CH₃COONa + HCl → CH₃COOH + NaCl
- **약염기의 유리(弱塩基の遊離)**: 약염기의 염에 강염기를 넣으면 약염기가 다시 빠져나온다.
  NH₄Cl + NaOH → NH₃ + H₂O + NaCl
- 핵심 원리: **강한 쪽이 염을 차지하고, 약한 쪽이 쫓겨난다.**
- 이 반응으로 염이 된 약산·약염기를 원래 모습으로 되돌릴 수 있어서, 물질의 분리·정제(精製)에 자주 쓰인다.

## 개념 정리

### 1. 염을 보는 관점

아세트산나트륨 CH₃COONa는 약산인 아세트산 CH₃COOH와 강염기인 NaOH로부터 만들어진 염이다.

- 산 쪽에서 보면 **약산의 염**이다.
- 염기 쪽에서 보면 **강염기의 염**이다.

어느 관점으로 볼지는 반응 상대에 따라 정한다. 상대가 산(HCl)이면 "약산의 염"으로 본다. 상대가 염기(NaOH)이면 "약염기의 염"처럼 염기 쪽 관점으로 본다.

### 2. 약산의 유리

CH₃COONa는 물속에서 CH₃COO⁻와 Na⁺로 나뉘어 있다. 여기에 강산 HCl을 넣으면 반응은 다음과 같이 진행된다.

1. CH₃COO⁻는 H⁺를 받는 힘이 강하다. 그래서 HCl이 내놓은 H⁺와 결합해 약산인 CH₃COOH로 되돌아간다.
2. 남은 Cl⁻는 Na⁺와 짝을 이루어 **강산의 염** NaCl이 된다.

CH₃COONa + HCl → CH₃COOH + NaCl
(이온반응식: CH₃COO⁻ + H⁺ → CH₃COOH)

> 일반화: **약산의 염 + 강산 → 약산 + 강산의 염**

### 3. 약염기의 유리

염화암모늄 NH₄Cl의 NH₄⁺는 약염기인 암모니아 NH₃에서 나온 이온이다. 따라서 NH₄Cl은 **약염기의 염**이다. 여기에 강염기 NaOH를 넣으면 다음과 같이 반응한다.

1. 강염기의 OH⁻가 NH₄⁺의 H⁺를 빼앗는다.
2. NH₄⁺는 NH₃로 되돌아가고, OH⁻는 H₂O가 된다.
3. 남은 Na⁺와 Cl⁻는 **강염기의 염** NaCl이 된다.

NH₄Cl + NaOH → NH₃ + H₂O + NaCl
(이온반응식: NH₄⁺ + OH⁻ → NH₃ + H₂O)

> 일반화: **약염기의 염 + 강염기 → 약염기 + 강염기의 염**

(보충) 실험실에서 암모니아를 만드는 반응도 같은 원리다.
2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2NH₃ + 2H₂O

### 4. 비교 정리

| 구분 | 출발 물질 | 넣는 것 | 되돌아 나오는 것 | 새로 생기는 염 |
|---|---|---|---|---|
| 약산의 유리 | 약산의 염 (CH₃COONa) | 강산 (HCl) | 약산 (CH₃COOH) | 강산의 염 (NaCl) |
| 약염기의 유리 | 약염기의 염 (NH₄Cl) | 강염기 (NaOH) | 약염기 (NH₃) | 강염기의 염 (NaCl) |

### 5. 왜 중요한가

염 형태의 약산·약염기는 이온이라서 물에 잘 녹는다. 강산이나 강염기를 넣어 분자 형태로 되돌리면 성질이 달라지므로, 이를 이용해 물질을 분리할 수 있다. 정제 과정의 상당수가 이 두 반응을 이용하며, 유기화학의 추출(抽出)에서도 반복해서 등장한다.

## 꼭 외울 것

- 약산의 염 + 강산 → 약산 + 강산의 염 (**弱酸の遊離**)
- 약염기의 염 + 강염기 → 약염기 + 강염기의 염 (**弱塩基の遊離**)
- CH₃COONa + HCl → CH₃COOH + NaCl
- NH₄Cl + NaOH → NH₃ + H₂O + NaCl
- 판단 기준은 **"강한 산(염기)이 이긴다"**. 강한 쪽이 염으로 남고, 약한 쪽이 유리된다.

## 자주 틀리는 함정

- **역반응은 일어나지 않는다.** NaCl + CH₃COOH → HCl + CH₃COONa 같은 반응은 없다. 약산이 강산을 쫓아낼 수는 없다.
- **NH₄Cl의 관점 혼동.** NH₄Cl은 강산(HCl)의 염이기도 하다. 그러므로 NH₄Cl에 HCl을 넣어도 아무 일도 일어나지 않는다. 반응이 일어나려면 강염기를 넣어야 한다.
- **약염기 유리의 생성물에서 H₂O를 빠뜨리기 쉽다.** NH₄⁺에서 H⁺를 빼앗은 OH⁻는 물이 된다.
- 반응을 일으키는 것은 "산이 강하냐 약하냐"이다. 농도나 양과 혼동하지 말 것.

## 확인 문제

**문 1** 다음 중 혼합했을 때 반응이 **일어나지 않는** 조합은?
① CH₃COONa 수용액 + HCl
② NH₄Cl + NaOH
③ NaCl 수용액 + CH₃COOH
④ CH₃COONa 수용액 + H₂SO₄

> **정답** ③ — 약산(CH₃COOH)은 강산의 염(NaCl)에서 강산(HCl)을 유리시킬 수 없다. ①과 ④는 강산에 의한 약산의 유리, ②는 강염기에 의한 약염기의 유리이다.

**문 2** 염화암모늄에 수산화나트륨 수용액을 넣고 가열했을 때 발생하는 기체로 옳은 것은?
① HCl　② NH₃　③ H₂　④ Cl₂

> **정답** ② — NH₄Cl + NaOH → NH₃ + H₂O + NaCl. 약염기의 염에 강염기를 넣었으므로 약염기 NH₃가 유리된다.

**문 3** 산 HA, HB에 대해 NaA + HB → NaB + HA 반응이 진행된다는 것을 알았다. 옳은 것은?
① HA가 HB보다 강한 산이다.
② HB가 HA보다 강한 산이다.
③ HA와 HB의 세기는 같다.
④ 이 결과만으로는 판단할 수 없다.

> **정답** ② — 약산의 유리에서는 강한 산이 염으로 남고 약한 산이 유리된다. 유리된 것이 HA이므로 HA가 더 약하고, HB가 더 강한 산이다.
