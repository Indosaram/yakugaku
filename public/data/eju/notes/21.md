## 한눈에 보기

- **반반응식(半反応式)**은 산화환원 반응 전체 중 **산화제 쪽 변화만** 또는 **환원제 쪽 변화만** 따로 떼어 쓴 식이다. 전자 e⁻가 식에 직접 나타난다.
- 계수는 외우는 것이 아니라 **정해진 순서로 맞춰서** 만든다. 반응물과 생성물만 알면 누구나 만들 수 있다.
- 순서는 ① 반응물과 생성물 쓰기 → ② 산화수 변화만큼 e⁻ 넣기 → ③ 전하를 H⁺로 맞추기 → ④ 원자 수를 H₂O로 맞추기이다.
- 대표 예: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O

## 개념 정리

### 반반응식이란
과망간산칼륨 KMnO₄는 산성 용액에서 **산화제(酸化剤)**로 작용한다. 전체 반응에서는 산화와 환원이 동시에 일어난다. 그중 산화제인 MnO₄⁻가 일으키는 **환원** 변화만 쓴 식이 다음과 같다.

MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O

이처럼 전체 반응의 '절반'만 쓴 식이 반반응식(半反応式, 이온전자식)이다. 8이나 5 같은 계수는 식을 보기만 해서는 알 수 없다. 아래 규칙에 따라 차례로 정해야 한다.

### 반반응식 만드는 4단계 (MnO₄⁻ → Mn²⁺)

| 단계 | 할 일 | 결과 |
|---|---|---|
| ① | 반응물 → 생성물을 쓴다 | MnO₄⁻ → Mn²⁺ |
| ② | **산화수(酸化数)** 변화만큼 e⁻를 넣는다 | MnO₄⁻ + 5e⁻ → Mn²⁺ |
| ③ | 양변의 **전하** 합이 같도록 H⁺를 넣는다 | MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ |
| ④ | 양변의 **원자 수**가 같도록 H₂O를 넣는다 | MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O |

**② 전자 넣기**
산화수가 변하는 원자인 Mn만 비교한다.
- MnO₄⁻에서 O는 −2이고 4개이므로 합이 −8이다. 이온 전체가 −1이어야 하므로 Mn의 산화수는 **+7**이다.
- Mn²⁺에서 Mn의 산화수는 **+2**이다.

좌변이 5만큼 크다. e⁻ 1개는 −1의 몫을 하므로, 좌변에 **e⁻ 5개**를 넣으면 양변이 +2로 같아진다.

**③ H⁺로 전하 맞추기**
- 좌변 전하: MnO₄⁻(−1) + 5e⁻(−5) = **−6**
- 우변 전하: Mn²⁺ = **+2**

H⁺는 1개당 +1을 더한다. 따라서 좌변에 **H⁺ 8개**를 넣으면 −6+8 = +2가 되어 양변 전하가 같아진다.

**④ H₂O로 원자 수 맞추기**
좌변에는 O가 4개, H가 8개 있지만 우변에는 O와 H가 하나도 없다. H 8개와 O 4개로 **H₂O 4개**를 만들어 우변에 넣으면 원자 수가 맞는다.

마지막으로 산화수, 전하, 원자 수가 모두 양변에서 같은지 확인하면 반반응식이 완성된다.

## 꼭 외울 것

- 산성 조건의 순서: **e⁻(산화수) → H⁺(전하) → H₂O(원자)**
- 산화제의 반반응식은 e⁻가 **좌변**에 온다(전자를 받음 = 환원된다).
- 환원제의 반반응식은 e⁻가 **우변**에 온다(전자를 내놓음 = 산화된다).
- MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O (산성, Mn: +7 → +2)

## 자주 틀리는 함정

- **e⁻ 개수는 원자 1개당 변화 × 원자 수이다.** 예를 들어 Cr₂O₇²⁻ → 2Cr³⁺에서 Cr 1개는 +6 → +3으로 3만큼 변하고, Cr이 2개이므로 e⁻는 6개이다.
- **전하를 맞출 때는 e⁻의 전하도 반드시 포함한다.** MnO₄⁻ 단계에서 e⁻ 5개의 −5를 빠뜨리면 H⁺ 개수가 틀린다.
- **H⁺와 H₂O의 역할을 바꾸지 않는다.** H₂O는 전하가 0이므로 전하 맞추기에는 쓸 수 없다. H⁺로 전하를 먼저 맞추고, H₂O로 원자를 맞춘다.
- **산화수 비교는 변하는 원자만 한다.** O와 H는 보통 산화수가 변하지 않으므로 비교 대상이 아니다.

## 확인 문제

**문1** 산성 수용액에서 MnO₄⁻의 반반응식 MnO₄⁻ + aH⁺ + be⁻ → Mn²⁺ + cH₂O 에서 (a, b, c)로 옳은 것은?

① (4, 3, 2)
② (8, 3, 4)
③ (8, 5, 4)
④ (16, 5, 8)

> **정답** ③ — Mn의 산화수는 +7에서 +2로 바뀌므로 e⁻ 5개가 필요하다. 이때 좌변 전하는 −6, 우변은 +2이므로 H⁺ 8개를 넣는다. 남은 H 8개와 O 4개로 H₂O 4개를 만든다.

**문2** 산성 수용액에서 Cr₂O₇²⁻가 Cr³⁺로 변하는 반반응식을 완성할 때, 좌변에 들어가는 e⁻와 H⁺의 수로 옳은 것은?

① e⁻ 3, H⁺ 7
② e⁻ 3, H⁺ 14
③ e⁻ 6, H⁺ 7
④ e⁻ 6, H⁺ 14

> **정답** ④ — Cr은 +6에서 +3으로 변하고 2개이므로 e⁻는 6개이다. 좌변 전하는 −2 + (−6) = −8, 우변은 2Cr³⁺로 +6이므로 H⁺ 14개가 필요하다. 완성된 식은 Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O이다.

**문3** 반반응식에 관한 설명으로 옳은 것은?

① H₂O는 양변의 전하를 맞추기 위해 넣는다.
② 환원제의 반반응식에서는 e⁻가 우변에 나타난다.
③ 산화수를 비교할 때는 O 원자의 산화수 변화를 기준으로 한다.
④ 반반응식의 계수는 반응물과 생성물만으로는 결정할 수 없다.

> **정답** ② — 환원제는 전자를 내놓으므로 e⁻가 생성물 쪽(우변)에 온다. 예: SO₂ + 2H₂O → SO₄²⁻ + 4H⁺ + 2e⁻. ①은 H⁺의 역할이다. ③에서 비교 기준은 산화수가 변하는 원자이다. ④는 반응물과 생성물만 알면 4단계로 계수를 결정할 수 있으므로 틀렸다.
