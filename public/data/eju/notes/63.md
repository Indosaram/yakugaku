## 한눈에 보기

- **아민(アミン)**: 암모니아(NH₃)의 H 원자를 탄화수소기로 바꾼 화합물. –NH₂를 **아미노기(アミノ基)**라 한다.
- **방향족 아민(芳香族アミン)**: 벤젠 고리에 아미노기가 붙은 화합물. 대표 물질은 **아닐린(アニリン)** C₆H₅NH₂이다.
- **제법**: 벤젠 → (혼산, 니트로화) → 니트로벤젠 → (Sn + HCl, 환원) → 아닐린
- **성질 5가지**: 무색 액체이며 특유의 냄새가 난다 / 공기 중에서 산화되어 적갈색이 된다 / 약염기성이다 / 표백분으로 적자색이 된다 / 이크롬산칼륨으로 아닐린 블랙(검은색)이 생긴다

## 개념 정리

### 1. 아민과 아닐린
암모니아 NH₃의 수소 하나를 탄화수소기 R로 바꾸면 R–NH₂가 된다. 이런 화합물이 아민이다. R가 벤젠 고리(페닐기 C₆H₅–)이면 방향족 아민이 된다. 그중 C₆H₅NH₂를 아닐린이라고 한다.

### 2. 아닐린의 제법
**① 니트로화(ニトロ化)**
벤젠에 진한 질산과 진한 황산의 혼합물인 **혼산(混酸)**을 넣고 가열하면 **니트로벤젠(ニトロベンゼン)**이 생긴다.

C₆H₆ + HNO₃ → C₆H₅NO₂ + H₂O

진한 황산은 촉매로 작용하며 탈수를 돕는다. HNO₃에서 H₂O가 빠지고 남은 –NO₂가 벤젠 고리에 결합한다.

**② 환원(還元)**
니트로벤젠과 아닐린을 비교하면 –NO₂가 –NH₂로 바뀌었다. 산소가 빠지고 수소가 들어갔으므로 환원이다. 환원제는 **주석(スズ) Sn**이고 염산과 함께 쓴다. 주석은 +2보다 +4 상태가 안정하다. 그래서 자신은 Sn⁴⁺까지 산화되면서 상대를 환원시킨다.

산성 용액 속에서 실제로 먼저 생기는 것은 아닐린 염산염이다.

2C₆H₅NO₂ + 3Sn + 14HCl → 2C₆H₅NH₃Cl + 3SnCl₄ + 4H₂O

여기에 NaOH를 넣으면 아닐린이 유리된다(아래 3-③ 참고).

### 3. 아닐린의 특징
| 번호 | 성질 | 색·결과 |
|---|---|---|
| ① | 특유의 냄새를 가진 무색 액체 | 무색 |
| ② | 공기 중에서 서서히 산화 | 적갈색 |
| ③ | 약염기성, 염산과 중화 | 아닐린 염산염 |
| ④ | 표백분(さらし粉)으로 산화 | 적자색(赤紫色), 검출 반응 |
| ⑤ | 이크롬산칼륨(二クロム酸カリウム, 황산 산성)으로 산화 | 검은 침전, 아닐린 블랙 |

**③ 약염기성과 염 생성**
아닐린은 암모니아처럼 약염기성을 띤다. NH₃ + HCl → NH₄Cl과 같은 방식으로 염산과 중화하여 **아닐린 염산염(アニリン塩酸塩)**이 된다.

C₆H₅NH₂ + HCl → C₆H₅NH₃Cl

아닐린 염산염은 약염기의 염이다. 여기에 NaOH 같은 강염기를 가하면 **약염기의 유리(弱塩基の遊離)**가 일어나 아닐린이 다시 생긴다.

C₆H₅NH₃Cl + NaOH → C₆H₅NH₂ + NaCl + H₂O

**④ 표백분 반응**
표백분은 화학에서 두 번 등장한다.
- 무기화학: 염산을 가하면 Cl₂가 발생하는 염소 제법
- 유기화학: 아닐린이 적자색으로 변하는 아닐린 검출 반응

**⑤ 아닐린 블랙(アニリンブラック)**
이크롬산칼륨으로 산화하면 생기는 검은 물질이다. 검은색 염료로 쓰인다.

## 꼭 외울 것

- 제법 순서: 벤젠 →(혼산) 니트로벤젠 →(Sn, HCl) 아닐린 염산염 →(NaOH) 아닐린
- Sn은 환원제이고, 자신은 산화되어 +4가 된다.
- 색 세 가지를 구별한다.
  - 공기 산화: **적갈색**
  - 표백분: **적자색**
  - K₂Cr₂O₇: **검은색**(아닐린 블랙)
- 아닐린은 약염기이므로 염산에 녹아 염을 만들고, 강염기를 넣으면 다시 유리된다.

## 자주 틀리는 함정

- **상태**: 아닐린은 고체가 아니라 **액체**이며, 순수한 상태에서는 **무색**이다.
- **색 혼동**: 공기 산화의 "적갈색"과 표백분의 "적자색"을 바꿔 쓴 선지가 단골이다.
- **산·염기 혼동**: 아닐린은 산성이 아니라 **약염기성**이다. NaOH와는 반응하지 않고 HCl과 반응한다.
- **산화·환원 혼동**: 니트로벤젠 → 아닐린은 **환원**이다. Sn은 환원**제**이므로 자신은 **산화**된다.
- **혼산 속 황산의 역할**: 황산은 니트로기의 공급원이 아니라 촉매(탈수 작용)다.

## 확인 문제

**문1** 아닐린의 성질로 옳은 것을 고르시오.
① 상온에서 무색의 결정이다.
② 수용액은 약산성을 나타낸다.
③ 표백분 수용액을 가하면 적자색을 나타낸다.
④ 공기 중에 두면 청색으로 변한다.

> **정답** ③ — 표백분에 의한 적자색 변화는 아닐린 검출 반응이다. 아닐린은 무색 액체(①)이고 약염기성(②)이며, 공기 중에서는 적갈색(④)으로 변한다.

**문2** 니트로벤젠에 주석과 진한 염산을 가해 가열하였다. 이 반응에 대한 설명으로 옳은 것을 고르시오.
① 니트로벤젠은 산화된다.
② 주석은 환원제로 작용한다.
③ 반응 직후 용액 속에는 주로 유리된 아닐린이 존재한다.
④ 주석의 산화수는 감소한다.

> **정답** ② — –NO₂가 –NH₂로 바뀌므로 니트로벤젠은 환원된다. 주석은 산화수가 증가하는 환원제다. 산성 용액이므로 반응 직후에는 아닐린 염산염으로 존재하고, NaOH를 가해야 아닐린이 유리된다.

**문3** 아닐린 염산염 수용액에 수산화나트륨 수용액을 가했을 때 일어나는 현상은?
① 아닐린이 유리된다.
② 아닐린 블랙이 침전된다.
③ 니트로벤젠이 생성된다.
④ 염소 기체가 발생한다.

> **정답** ① — 약염기의 염에 강염기를 가하면 약염기가 유리된다. 반응식은 C₆H₅NH₃Cl + NaOH → C₆H₅NH₂ + NaCl + H₂O이다. 아닐린 블랙(②)은 이크롬산칼륨으로 산화할 때 생기고, 염소 발생(④)은 표백분에 염산을 가할 때 일어난다.
