## 한눈에 보기

- **산화(酸化)**와 **환원(還元)**은 한 반응 안에서 **반드시 동시에** 일어난다. 한 물질이 산화되면 다른 물질은 반드시 환원된다. 이런 반응을 **산화환원반응(酸化還元反応)**이라 한다.
- 산화·환원을 판단하는 기준은 세 가지다. **산소**, **수소**, **전자(電子)**.
- 요약하면 **산화 = 산소만 얻고, 수소와 전자는 잃는다.** **환원 = 산소만 잃고, 수소와 전자는 얻는다.**
- 반응에서 무엇이 이동하는지 보고 기준을 고른다. 산소가 이동하면 산소 기준, 수소가 이동하면 수소 기준, 원자 이동이 안 보이면 전자 기준을 쓴다.

## 개념 정리

### 1. 산화와 환원은 동시에 일어난다

두 물질이 반응할 때 한쪽이 산화되면 다른 쪽은 반드시 환원된다. 이 관계는 어떤 기준으로 판단해도 같다. 산화만 일어나거나 환원만 일어나는 반응은 없다.

### 2. 산소 기준

| | 산소(O) |
|---|---|
| 산화 | 산소를 **얻는다** |
| 환원 | 산소를 **잃는다** |

**예** CuO + H₂ → Cu + H₂O

- CuO → Cu: 산소를 잃었으므로 CuO는 **환원**되었다.
- H₂ → H₂O: 산소를 얻었으므로 H₂는 **산화**되었다.

"산소와 화합한다(酸素と化合する)"를 떠올리면 "산화 = 산소를 얻음"을 쉽게 기억할 수 있다.

### 3. 수소 기준

| | 수소(H) |
|---|---|
| 산화 | 수소를 **잃는다** |
| 환원 | 수소를 **얻는다** |

수소 기준은 산소 기준과 **방향이 반대**다.

**예** H₂O₂ + H₂S → 2H₂O + S

- H₂O₂ → 2H₂O: H₂S에게서 수소를 받았으므로 H₂O₂는 **환원**되었다.
- H₂S → S: 수소를 잃었으므로 H₂S는 **산화**되었다.

### 4. 전자 기준

산소도 수소도 이동하지 않는 반응이 있다. 이때는 **전자의 이동**으로 판단한다. 전자 기준이 가장 일반적인 정의다.

| | 전자(e⁻) |
|---|---|
| 산화 | 전자를 **잃는다** |
| 환원 | 전자를 **얻는다** |

**예** Cu + Cl₂ → CuCl₂

생성물 CuCl₂는 Cu²⁺와 Cl⁻로 이루어진 이온 결정(イオン結晶)이다. 원자가 이온이 되려면 전자가 오가야 한다.

- Cu → Cu²⁺ + 2e⁻: 전자를 잃었으므로 Cu는 **산화**되었다.
- Cl₂ + 2e⁻ → 2Cl⁻: 전자를 얻었으므로 Cl₂는 **환원**되었다. Cl 원자 하나당 전자 1개, Cl₂ 전체로는 2개를 받는다.
- Cu가 잃은 전자 수와 Cl₂가 얻은 전자 수는 같다(2개).

### 5. 세 기준 종합

| 기준 | 산화 | 환원 |
|---|---|---|
| 산소 O | 얻음 | 잃음 |
| 수소 H | 잃음 | 얻음 |
| 전자 e⁻ | 잃음 | 얻음 |

## 꼭 외울 것

- **산화: O 획득 / H 상실 / e⁻ 상실**
- **환원: O 상실 / H 획득 / e⁻ 획득**
- "**산소만** 반대"라고 외운다. 산화에서 산소만 얻고 나머지는 모두 잃는다.
- 산화와 환원은 항상 동시에 일어나며, 주고받는 전자 수는 같다.
- 반응식 세 개를 기억해 둔다.
  - CuO + H₂ → Cu + H₂O
  - H₂O₂ + H₂S → 2H₂O + S
  - Cu + Cl₂ → CuCl₂

## 자주 틀리는 함정

1. **수소 기준을 산소 기준과 같은 방향으로 착각한다.** 수소를 얻는 것은 산화가 아니라 **환원**이다.
2. **전자 기준을 거꾸로 외운다.** 전자를 얻는 쪽은 **환원**이다. Cl₂ + 2e⁻ → 2Cl⁻처럼 음이온이 되는 쪽이 환원된 것이다.
3. **원자가 이동하지 않으면 산화환원반응이 아니라고 판단한다.** Cu + Cl₂ → CuCl₂처럼 O나 H가 없어도 전자가 이동하면 산화환원반응이다.
4. **산화 또는 환원 한쪽만 표시한다.** 한 물질이 산화되었다면 반드시 다른 물질이 환원되었는지 함께 확인한다.
5. **Cl₂가 받는 전자 수를 Cl 원자 기준으로 혼동한다.** Cl 원자 하나는 e⁻ 1개, Cl₂ 분자는 e⁻ 2개를 받는다.

## 확인 문제

**문제 1** 다음 반응에 대한 설명으로 옳은 것은?
CuO + H₂ → Cu + H₂O

① CuO는 산소를 얻었으므로 산화되었다.
② H₂는 산소를 얻었으므로 산화되었다.
③ H₂는 산소를 잃었으므로 환원되었다.
④ 이 반응에서는 환원만 일어난다.

> **정답** ② — H₂는 H₂O가 되면서 산소를 얻었으므로 산화되었다. CuO는 산소를 잃고 Cu가 되었으므로 환원되었다. 산화와 환원은 항상 동시에 일어나므로 ④는 틀렸다.

**문제 2** H₂O₂ + H₂S → 2H₂O + S에서 산화된 물질과 그 근거로 옳은 조합은?

① H₂O₂ — 수소를 얻었다
② H₂O₂ — 산소를 잃었다
③ H₂S — 수소를 잃었다
④ H₂S — 수소를 얻었다

> **정답** ③ — H₂S는 수소를 잃고 S가 되었으므로 산화되었다. H₂O₂는 수소를 얻었으므로 환원되었다. 수소 기준에서는 수소를 잃는 쪽이 산화다.

**문제 3** Cu + Cl₂ → CuCl₂에 대한 설명으로 **틀린** 것은?

① Cu는 전자 2개를 잃고 Cu²⁺가 된다.
② Cl₂는 전자를 얻었으므로 환원되었다.
③ Cu가 잃은 전자 수와 Cl₂가 얻은 전자 수는 같다.
④ 산소와 수소가 이동하지 않으므로 산화환원반응이 아니다.

> **정답** ④ — O나 H가 이동하지 않아도 전자가 이동하면 산화환원반응이다. Cu는 전자를 잃어 산화되고(Cu → Cu²⁺ + 2e⁻), Cl₂는 전자를 얻어 환원된다(Cl₂ + 2e⁻ → 2Cl⁻).
