## 한눈에 보기

- 이번 장은 **가열해야만 기체가 발생하는 반응**을 네 가지 유형으로 나누어 정리한다.
  1. **고체끼리의 반응**: 고체는 섞어 두기만 해서는 잘 반응하지 않으므로 가열이 필요하다. (NH₃, CH₄)
  2. **열분해(熱分解)**: 한 물질이 열을 받아 더 안정한 물질로 분해된다. (CO₂, O₂)
  3. **진한 황산(濃硫酸)의 반응**: 반응에 따라 불휘발성·산화력·탈수 작용 중 어떤 성질이 쓰이는지 구별해야 한다. (HCl, SO₂, CO)
  4. **MnO₂가 산화제로 작용하는 반응**: 촉매가 아니라 산화제(酸化剤)로 작용한다. (Cl₂)
- 반응식을 통째로 외우기보다 **"왜 이 기체가 나오는가"라는 원리**로 이해하는 것이 핵심이다.

## 개념 정리

### 1. 고체끼리의 반응

**(1) 암모니아 발생: 약염기의 유리(弱塩基の遊離)**

2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2H₂O + 2NH₃↑

- NH₄Cl은 약염기 NH₃와 강산 HCl로 이루어진 염이다.
- 여기에 강염기 Ca(OH)₂를 넣으면 약염기인 NH₃가 밀려나 유리된다.
- 원리는 "약염기의 염 + 강염기 → 강염기의 염 + 약염기"이다. 약산의 유리와 함께 자주 출제된다.

**(2) 메탄 발생**

CH₃COONa + NaOH → Na₂CO₃ + CH₄↑

- 아세트산나트륨(酢酸ナトリウム)과 수산화나트륨을 함께 가열한다.
- 구동력은 **Na₂CO₃의 안정성**이다. 탄산(H₂CO₃)은 불안정해서 금방 CO₂로 분해되지만, Na⁺ 두 개가 CO₃²⁻를 붙잡은 Na₂CO₃는 가열해도 분해되지 않을 만큼 안정하다.
- Na가 COO 부분을 가져가 Na₂CO₃가 되고, 남은 CH₃와 H가 결합해 CH₄가 된다.

### 2. 열분해

| 반응물 | 반응식 | 발생 기체 |
|---|---|---|
| 탄산수소나트륨 NaHCO₃ | 2NaHCO₃ → Na₂CO₃ + H₂O + CO₂↑ | CO₂ |
| 탄산칼슘 CaCO₃ | CaCO₃ → CaO + CO₂↑ | CO₂ |
| 염소산칼륨 KClO₃ (+MnO₂) | 2KClO₃ → 2KCl + 3O₂↑ | O₂ |

- **NaHCO₃**: Na가 하나뿐이라 탄산 부분이 불안정하다. 가열하면 CO₂가 빠져나가고, 안정한 Na₂CO₃가 남는다. 즉 불안정한 물질에서 안정한 물질로 바뀌는 반응이다.
- **CaCO₃**: 가열하면 CO₂가 빠져나가고 산화칼슘 CaO(생석회)가 남는다.
- **KClO₃**: 이산화망가니즈 MnO₂가 **촉매(触媒)** 로 작용한다.
- O₂ 발생 반응 두 가지를 비교해 두자.

| 반응 | 촉매 | 가열 |
|---|---|---|
| 2H₂O₂ → 2H₂O + O₂ | MnO₂ | 불필요 |
| 2KClO₃ → 2KCl + 3O₂ | MnO₂ | **필요** |

### 3. 진한 황산의 반응

**(1) 불휘발성(不揮発性)을 이용하는 반응 → HCl 발생**

NaCl + H₂SO₄ → NaHSO₄ + HCl↑

- 염산은 HCl 기체가 물에 녹은 수용액이다. 끓이면 HCl이 날아가 버리므로 HCl은 **휘발성 산(揮発性の酸)** 이다.
- 황산은 그 자체가 끓는점이 높은 액체이므로 가열해도 날아가지 않는 **불휘발성 산**이다.
- 원리는 "휘발성 산의 염 + 불휘발성 산 → 휘발성 산(기체)↑ + 불휘발성 산의 염"이다.

**(2) 산화력을 이용하는 반응 → SO₂ 발생**

Cu + 2H₂SO₄ → CuSO₄ + 2H₂O + SO₂↑

- 진한 황산을 가열한 **열농황산(熱濃硫酸)** 은 질산과 마찬가지로 산화력이 강하다.
- 그래서 이온화 경향이 H보다 작은 Cu도 강제로 산화시켜 CuSO₄로 만든다.
- 황산 자신은 환원되어 SO₂가 된다.

**(3) 탈수 작용(脱水作用)을 이용하는 반응 → CO 발생**

HCOOH → CO↑ + H₂O

- 폼산(ギ酸, HCOOH)에 진한 황산을 넣고 가열한다.
- 진한 황산이 유기물에서 H와 O를 2 : 1 비율로 빼앗아 H₂O로 만든다.
- 그 결과 남은 부분이 일산화탄소가 된다.

### 4. MnO₂가 산화제로 작용하는 반응

MnO₂ + 4HCl → MnCl₂ + Cl₂↑ + 2H₂O

- 진한 염산에 MnO₂를 넣고 가열하면 Cl₂가 발생한다. 휘발한 HCl과 H₂O도 함께 섞여 나온다.
- Mn의 산화수(酸化数)는 +4(MnO₂)에서 +2(MnCl₂)로 감소한다. 즉 MnO₂ 자신은 환원되면서 HCl의 Cl⁻를 Cl₂로 산화시킨다.
- 따라서 이 반응에서 MnO₂는 촉매가 아니라 **산화제**이다.

## 꼭 외울 것

| 발생 기체 | 시약 | 원리 |
|---|---|---|
| NH₃ | NH₄Cl + Ca(OH)₂ | 약염기의 유리 |
| CH₄ | CH₃COONa + NaOH | Na₂CO₃의 안정성 |
| CO₂ | NaHCO₃ 또는 CaCO₃ 가열 | 열분해 |
| O₂ | KClO₃ + MnO₂ | 열분해(MnO₂ = 촉매) |
| HCl | NaCl + 진한 H₂SO₄ | 황산의 불휘발성 |
| SO₂ | Cu + 열농황산 | 황산의 산화력 |
| CO | HCOOH + 진한 H₂SO₄ | 황산의 탈수 작용 |
| Cl₂ | MnO₂ + 진한 HCl | MnO₂ = 산화제 |

## 자주 틀리는 함정

- **MnO₂의 역할 혼동**: H₂O₂·KClO₃와 반응할 때는 촉매, 진한 HCl과 반응할 때는 산화제이다. 산화수가 변하는지(+4→+2) 확인하면 구별된다.
- **진한 황산의 성질 혼동**: HCl 발생은 불휘발성, SO₂ 발생은 산화력, CO 발생은 탈수 작용이다. "황산이 쓰였다"만으로는 답이 되지 않는다.
- **열분해 생성물 혼동**: NaHCO₃를 가열하면 Na₂CO₃가 남는다(Na₂O가 아니다). Na₂CO₃ 자체는 가열해도 분해되지 않는다.
- **H₂O₂와 KClO₃의 가열 조건**: 둘 다 MnO₂를 쓰지만, 가열이 필요한 것은 KClO₃뿐이다.
- **Cu + 묽은 황산**: 반응하지 않는다. 진한 황산을 **가열**해야 SO₂가 발생한다.

## 확인 문제

**문1** 다음 반응 중 MnO₂가 촉매가 아니라 산화제로 작용하는 것은?

① 과산화수소수에 MnO₂를 넣는다.
② 염소산칼륨에 MnO₂를 섞어 가열한다.
③ 진한 염산에 MnO₂를 넣고 가열한다.
④ 아세트산나트륨과 수산화나트륨을 가열한다.

> **정답** ③ — Mn의 산화수가 +4에서 +2로 감소하여 Cl⁻를 Cl₂로 산화시키므로 산화제이다. ①, ②에서는 MnO₂가 촉매이고, ④에는 MnO₂가 쓰이지 않는다.

**문2** 다음 반응 (a)~(c)에서 이용되는 진한 황산의 성질을 순서대로 바르게 짝지은 것은?
(a) NaCl + H₂SO₄ → HCl 발생 (b) Cu + 열농황산 → SO₂ 발생 (c) HCOOH + 진한 황산 → CO 발생

① 산화력 – 불휘발성 – 탈수 작용
② 불휘발성 – 산화력 – 탈수 작용
③ 탈수 작용 – 산화력 – 불휘발성
④ 불휘발성 – 탈수 작용 – 산화력

> **정답** ② — (a)는 불휘발성 산이 휘발성 산 HCl을 몰아낸다. (b)는 열농황산의 산화력으로 Cu가 산화되고 황산은 SO₂로 환원된다. (c)는 H와 O를 2 : 1로 빼앗는 탈수 작용이다.

**문3** 탄산수소나트륨 16.8 g을 완전히 열분해했을 때 발생하는 CO₂의 표준 상태에서의 부피는? (NaHCO₃ = 84, 기체 1 mol = 22.4 L)

① 1.12 L
② 4.48 L
③ 3.36 L
④ 2.24 L

> **정답** ④ — NaHCO₃는 16.8 ÷ 84 = 0.200 mol이다. 2NaHCO₃ → Na₂CO₃ + H₂O + CO₂이므로 CO₂는 그 절반인 0.100 mol이고, 0.100 × 22.4 = 2.24 L이다.
