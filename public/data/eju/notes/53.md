## 한눈에 보기

- **구조이성체(構造異性体)**: 분자식(分子式)은 같지만 원자의 연결 순서(구조)가 달라 서로 다른 물질이 되는 화합물이다.
- 알케인(알칸, アルカン)의 이성체는 **가장 긴 탄소 사슬(주사슬, 主鎖)을 하나씩 줄여 가며** 찾는다.
- 이름은 **주사슬 이름 + 치환기(置換基) 이름 + 위치 번호**로 붙인다. 번호는 **작은 쪽**을 쓴다.
- C₄H₁₀의 이성체는 2종, C₅H₁₂의 이성체는 3종이다.

## 개념 정리

### 1. 이성체와 구조이성체

**이성체(異性体)** 는 분자식은 같지만 서로 다른 물질을 말한다. 그중 탄소 골격의 모양이나 원자의 결합 순서가 다른 것을 **구조이성체**라고 한다. 단일결합만 있는 사슬형 알케인은 일반식이 CₙH₂ₙ₊₂이므로, 탄소 골격만 정하면 나머지 자리는 수소가 채운다.

### 2. 이성체를 찾는 순서

1. 탄소 n개를 모두 일렬로 이은 가장 긴 사슬부터 그린다.
2. 주사슬을 탄소 1개씩 줄이고, 남은 탄소를 곁가지로 붙인다.
3. 곁가지는 **양 끝 탄소(1번, 마지막 번)에 붙일 수 없다.** 끝에 붙이면 사슬이 그대로 길어져 주사슬이 늘어나기 때문이다.
4. 뒤집거나 회전했을 때 겹치는 구조는 같은 물질이므로 한 번만 센다.

### 3. 명명법(命名法)의 기본

- **알킬기(アルキル基)**: 알케인에서 H 1개를 뺀 원자단이다. 메탄에서 만든 것은 메틸기(メチル基, –CH₃), 에탄에서 만든 것은 에틸기(エチル基, –C₂H₅)이다.
- 이름은 「위치 번호-치환기 이름 + 주사슬 알케인 이름」 형식으로 붙인다.
- 같은 치환기가 2개이면 **다이(ジ)** 를 붙이고, 위치 번호는 **각각** 적는다. 예: 2,2-다이메틸프로판
- 번호는 치환기 위치가 **작아지는 방향**으로 매긴다.

### 4. C₄H₁₀의 구조이성체 (2종)

| 주사슬 | 구조 | 이름 |
|---|---|---|
| C 4개 | CH₃–CH₂–CH₂–CH₃ | 부탄(ブタン) |
| C 3개 | CH₃–CH(CH₃)–CH₃ | 2-메틸프로판(2-メチルプロパン) |

### 5. C₅H₁₂의 구조이성체 (3종)

| 주사슬 | 구조 | 이름 |
|---|---|---|
| C 5개 | CH₃–CH₂–CH₂–CH₂–CH₃ | 펜탄(ペンタン) |
| C 4개 | CH₃–CH(CH₃)–CH₂–CH₃ | 2-메틸부탄 |
| C 3개 | CH₃–C(CH₃)₂–CH₃ | 2,2-다이메틸프로판 |

- "3-메틸부탄"은 2-메틸부탄을 뒤집은 것과 같은 구조이다. 작은 번호를 써서 **2-메틸부탄**으로 부른다.
- 프로판의 2번 탄소에 에틸기를 붙인 구조("2-에틸프로판")는 실제로는 가장 긴 사슬이 C 4개이다. 따라서 이 구조는 **2-메틸부탄**과 같은 물질이다.

## 꼭 외울 것

- 알케인 일반식: **CₙH₂ₙ₊₂**
- C₄H₁₀의 이성체는 **2종**: 부탄, 2-메틸프로판
- C₅H₁₂의 이성체는 **3종**: 펜탄, 2-메틸부탄, 2,2-다이메틸프로판
- 주사슬은 항상 **가장 긴 탄소 사슬**로 잡는다.
- 치환기 번호는 **작은 쪽**으로 매기고, 같은 치환기가 여러 개이면 다이(2), 트라이(3)를 붙인다.

## 자주 틀리는 함정

- **끝 탄소에 메틸기 붙이기**: 1-메틸프로판은 사실 부탄이다. 끝에 붙인 곁가지는 주사슬의 일부가 된다.
- **큰 번호 쓰기**: 3-메틸부탄은 틀린 이름이다. 올바른 이름은 2-메틸부탄이다.
- **에틸기 곁가지 착각**: 2번 탄소에 에틸기가 붙은 것처럼 그려도, 이어서 세면 주사슬이 길어진다.
- **중복 세기**: 그림 모양이 달라도 회전하거나 뒤집어서 겹치면 같은 물질이다.
- **번호 생략**: 2,2-다이메틸프로판에서 "2"를 한 번만 쓰면 안 된다. 치환기 수만큼 번호를 적는다.

## 확인 문제

**문제 1.** 분자식 C₅H₁₂로 나타나는 알케인의 구조이성체는 모두 몇 종류인가?
① 2종 ② 3종 ③ 4종 ④ 5종

> **정답** ② — 주사슬이 C 5개인 펜탄, C 4개인 2-메틸부탄, C 3개인 2,2-다이메틸프로판의 3종이다.

**문제 2.** CH₃–CH₂–CH(CH₃)–CH₃의 올바른 이름은?
① 3-메틸부탄 ② 2-에틸프로판 ③ 2-메틸부탄 ④ 1,1-다이메틸프로판

> **정답** ③ — 가장 긴 사슬은 C 4개(부탄)이다. 메틸기가 작은 번호인 2번에 오도록 번호를 매기므로 2-메틸부탄이다.

**문제 3.** 다음 중 펜탄의 구조이성체가 **아닌** 것은?
① 2-메틸부탄 ② 2,2-다이메틸프로판 ③ CH₃–CH₂–CH(CH₃)–CH₃ ④ 2-메틸프로판

> **정답** ④ — 2-메틸프로판의 분자식은 C₄H₁₀이다. 분자식이 C₅H₁₂인 펜탄과 다르므로 이성체가 아니다. ③은 2-메틸부탄(C₅H₁₂)이다.
