## 한눈에 보기

가열하지 않아도 기체가 발생하는 대표 반응은 네 가지 유형이다. 반응식을 통째로 외우기보다 **왜 그 반응이 일어나는지**를 이해하면 생성물을 스스로 유도할 수 있다.

| 유형 | 원리 | 대표 반응 | 발생 기체 |
|---|---|---|---|
| ① 산 + 금속 | 이온화 경향 차이 | Zn + H₂SO₄ | H₂ |
| ② 강산 + 약산의 염 | 약산의 유리(弱酸の遊離) | CaCO₃ + HCl, FeS + H₂SO₄, 표백분 + HCl | CO₂, H₂S, Cl₂ |
| ③ 질산 + 구리 | 산화력이 있는 산 | Cu + 묽은/진한 HNO₃ | NO / NO₂ |
| ④ 과산화수소 분해 | 촉매 작용 | H₂O₂ + MnO₂ | O₂ |

## 개념 정리

### 1. 산과 금속 — 이온화 경향(イオン化傾向)
산은 H⁺를 내놓는 물질(염산, 황산 등)이다. 수소보다 이온화 경향이 큰 금속은 H⁺에게 전자를 주고 자신이 양이온이 된다. 전자를 받은 H⁺는 H₂ 기체로 빠져나간다.

- Zn + H₂SO₄ → ZnSO₄ + H₂↑
- Fe + 2HCl → FeCl₂ + H₂↑

수소보다 이온화 경향이 작은 금속(Cu, Hg, Ag, Pt, Au)은 묽은 염산이나 묽은 황산과 반응하지 않는다.

### 2. 강산에 의한 약산의 유리
약산의 염에 강산을 넣으면, 강산이 염의 짝을 차지하고 약산이 원래 모습으로 되돌아 나온다. 즉 **약산의 염 + 강산 → 강산의 염 + 약산**이다.

**(1) 탄산칼슘 + 염산 → CO₂**
CaCO₃는 약산인 탄산(H₂CO₃)의 염이다.
CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑
유리된 H₂CO₃는 불안정해서 H₂O와 CO₂로 분해된다. 김이 빠진 탄산음료를 떠올리면 된다.

**(2) 황화철(Ⅱ) + 묽은 황산 → H₂S**
FeS는 약산인 황화수소(H₂S)의 염이다.
FeS + H₂SO₄ → FeSO₄ + H₂S↑

**(3) 표백분 + 염산 → Cl₂**
표백분(さらし粉)은 CaCl(ClO)·H₂O이며, 약산인 차아염소산(次亜塩素酸, HClO) 성분을 포함한다.
CaCl(ClO)·H₂O + 2HCl → CaCl₂ + 2H₂O + Cl₂↑
※ 엄밀히는 유리된 HClO가 HCl과 산화환원 반응을 해서 Cl₂가 생긴다. 입시에서는 "**표백분 + 염산 → 염소**"로 기억하면 충분하며, 염소의 제법으로 출제된다.

### 3. 질산과 구리 — 산화력이 있는 산
질산(HNO₃)과 열농황산은 **산화력이 있는 산**이다. 그래서 수소보다 이온화 경향이 작은 Cu, Ag도 강제로 산화시켜 녹인다. 이때 발생하는 기체는 H₂가 아니라 질소 산화물이다.

| 질산 | 반응식 | 기체 |
|---|---|---|
| 묽은 질산(希硝酸) | 3Cu + 8HNO₃ → 3Cu(NO₃)₂ + 4H₂O + 2NO↑ | 일산화질소 NO (무색) |
| 진한 질산(濃硝酸) | Cu + 4HNO₃ → Cu(NO₃)₂ + 2H₂O + 2NO₂↑ | 이산화질소 NO₂ (적갈색) |

**암기법**
- 묽다 → 숫자가 작다 → O가 1개인 **NO**
- 진하다 → 숫자가 크다 → O가 2개인 **NO₂**
- 묽은 질산은 앞 계수 "**3, 8**"만 기억하고 나머지 계수는 원자 수를 맞춰 쓴다.

### 4. 과산화수소의 분해 — 촉매
과산화수소 H₂O₂는 물(H₂O)에 O가 하나 더 붙은 꼴이다. 산화망가니즈(Ⅳ) MnO₂를 넣으면 가열하지 않아도 거품을 내며 산소가 발생한다.
2H₂O₂ → 2H₂O + O₂↑ (MnO₂는 촉매)

## 꼭 외울 것

- Zn + H₂SO₄ → ZnSO₄ + H₂
- CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂
- FeS + H₂SO₄ → FeSO₄ + H₂S
- CaCl(ClO)·H₂O + 2HCl → CaCl₂ + 2H₂O + Cl₂
- 3Cu + 8HNO₃(묽은) → 3Cu(NO₃)₂ + 4H₂O + 2NO
- Cu + 4HNO₃(진한) → Cu(NO₃)₂ + 2H₂O + 2NO₂
- 2H₂O₂ → 2H₂O + O₂ (촉매 MnO₂)

## 자주 틀리는 함정

- **Cu + 묽은 염산/묽은 황산은 반응하지 않는다.** Cu는 질산이나 열농황산 같은 산화력 있는 산에만 녹는다.
- **Cu + 질산에서는 H₂가 나오지 않는다.** 생성되는 기체는 NO 또는 NO₂이다.
- **묽은 질산과 진한 질산의 생성물을 반대로 쓰기 쉽다.** 묽은 쪽이 NO, 진한 쪽이 NO₂이다.
- **MnO₂는 반응물이 아니라 촉매다.** 반응 전후에 변하지 않으므로 반응식 화살표 위에 쓴다.
- Fe, Al, Ni는 진한 질산에서 부동태(不動態)가 되어 녹지 않는다.

## 확인 문제

**문제 1** 실온에서 묽은 염산에 넣었을 때 수소가 발생하는 금속은?
① Cu ② Ag ③ Zn ④ Au

> **정답** ③ — Zn은 수소보다 이온화 경향이 커서 H⁺에 전자를 주고 H₂를 발생시킨다. 나머지 셋은 수소보다 이온화 경향이 작아 반응하지 않는다.

**문제 2** 다음 조합 중 적갈색 기체가 발생하는 것은?
① 구리 + 묽은 질산 ② 구리 + 진한 질산 ③ 아연 + 묽은 황산 ④ 황화철(Ⅱ) + 묽은 황산

> **정답** ② — 진한 질산은 구리를 산화시켜 적갈색의 NO₂를 발생시킨다. ①은 무색의 NO, ③은 H₂, ④는 H₂S가 발생한다.

**문제 3** 다음 중 '강산에 의한 약산의 유리'로 설명할 수 **없는** 반응은?
① CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂
② FeS + H₂SO₄ → FeSO₄ + H₂S
③ Zn + H₂SO₄ → ZnSO₄ + H₂
④ CH₃COONa + HCl → NaCl + CH₃COOH

> **정답** ③ — ③은 이온화 경향 차이에 의해 금속이 산화되는 산화환원 반응이다. ①②④는 약산(탄산, 황화수소, 아세트산)의 염에 강산을 넣어 약산이 되돌아 나오는 반응이다.
