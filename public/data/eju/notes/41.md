## 한눈에 보기

- **일산화질소(一酸化窒素) NO**: 구리 + **묽은 질산(希硝酸)**으로 만든다. 무색이고 물에 녹지 않으며, 공기 중 산소와 반응한다. 포집은 **수상치환(水上置換)**.
- **이산화질소(二酸化窒素) NO₂**: 구리 + **진한 질산(濃硝酸)**으로 만든다. 적갈색이고 물에 녹아 질산이 되며, 산소와는 반응하지 않는다. 포집은 **하방치환(下方置換)**.
- 시험에서는 두 기체의 성질을 서로 바꿔 놓은 선택지가 자주 나온다. 아래 표의 대비를 확실히 익혀 두자.

## 개념 정리

### 1. 구리가 질산에 녹는 이유

구리는 이온화 경향(イオン化傾向)이 수소보다 작다. 그래서 염산이나 묽은 황산 같은 일반적인 산에는 녹지 않는다. 그러나 질산은 **산화력이 있는 산(酸化力のある酸)**이라서 구리를 강제로 산화시킨다. 이때 발생하는 기체는 H₂가 아니라 질소산화물이다. 어떤 기체가 나오는지는 질산의 농도로 결정된다.

| 질산의 농도 | 발생 기체 | N의 산화수 변화 |
|---|---|---|
| 묽은 질산 | NO | +5 → +2 |
| 진한 질산 | NO₂ | +5 → +4 |

암기법: 묽다 → 숫자가 작다 → O가 1개인 NO. 진하다 → 숫자가 크다 → O가 2개인 NO₂.

### 2. 제법의 반응식

**묽은 질산** (계수 **3·8**):
3Cu + 8HNO₃ → 3Cu(NO₃)₂ + 2NO + 4H₂O

계수를 맞추는 흐름은 다음과 같다.
- Cu 3개가 Cu²⁺가 되므로 Cu(NO₃)₂ 3개를 만드는 데 NO₃⁻ 6개가 쓰인다.
- 남은 NO₃⁻ 2개에서 NO 2개가 생기고, 이때 남는 O 4개가 H 8개와 결합해 H₂O 4개가 된다.

**진한 질산** (계수 **1·4**):
Cu + 4HNO₃ → Cu(NO₃)₂ + 2NO₂ + 2H₂O

마찬가지로 Cu(NO₃)₂ 1개에 NO₃⁻ 2개가 쓰인다. 남은 NO₃⁻ 2개에서 NO₂ 2개가 생기고, 남는 O 2개가 H 4개와 결합해 H₂O 2개가 된다.

반응식에 "묽은/진한"이 적혀 있지 않아도 계수만 보고 어떤 기체가 나오는지 판단할 수 있어야 한다.

### 3. 성질 비교

| 항목 | NO | NO₂ |
|---|---|---|
| 색 | 무색(無色) | 적갈색(赤褐色) |
| O₂와 반응 | 반응함 → NO₂ | 반응하지 않음 |
| 물에 대한 용해 | 녹지 않음 | 녹아서 HNO₃ 생성 |
| 분자량 | 30 | 46 (공기 평균 약 29보다 무거움) |
| 포집법 | 수상치환 | 하방치환 |

- **NO의 산화**: 2NO + O₂ → 2NO₂. 무색이던 기체가 공기에 닿으면 적갈색으로 변한다.
- **NO₂와 물의 반응**: 3NO₂ + H₂O → 2HNO₃ + NO

### 4. 포집법(捕集法)

- **NO**: 공기와 반응하므로 상방치환(上方置換)이나 하방치환처럼 공기와 접하는 방법은 쓸 수 없다. 물에는 녹지 않으므로 **수상치환**으로 모은다.
- **NO₂**: 물과 반응하므로 수상치환은 쓸 수 없다. 공기와는 반응하지 않고, 분자량이 46으로 공기(29)보다 무거우므로 **하방치환**으로 모은다.

## 꼭 외울 것

- 3Cu + 8HNO₃(묽은) → 3Cu(NO₃)₂ + 2NO + 4H₂O
- Cu + 4HNO₃(진한) → Cu(NO₃)₂ + 2NO₂ + 2H₂O
- 2NO + O₂ → 2NO₂ (무색 → 적갈색)
- 3NO₂ + H₂O → 2HNO₃ + NO
- NO는 무색·수상치환, NO₂는 적갈색·하방치환

## 자주 틀리는 함정

- **색을 반대로 기억하는 실수**: 적갈색인 것은 NO₂다. NO는 무색이다.
- **NO₂가 산소와 반응한다는 착각**: 산소와 반응해 NO₂로 바뀌는 것은 NO다.
- **NO₂를 수상치환으로 모으는 실수**: NO₂는 물에 녹아 질산이 되므로 수상치환은 쓸 수 없다.
- **구리와 산에서 H₂가 나온다는 착각**: 구리는 질산과 반응해도 H₂가 아니라 NO나 NO₂를 낸다.
- **NO₂와 물의 반응 계수 혼동**: NO₂ 3분자 중 2분자만 HNO₃가 되고, 1분자는 NO로 다시 나온다.

## 확인 문제

**문1** NO와 NO₂에 관한 기술로 옳은 것은?
① NO는 적갈색 기체이며 물에 잘 녹는다.
② NO₂는 공기 중 산소와 반응하여 무색 기체로 변한다.
③ 무색인 NO는 공기에 닿으면 적갈색의 NO₂로 변한다.
④ 구리는 이온화 경향이 수소보다 커서 묽은 염산에 녹아 H₂를 발생한다.

> **정답** ③ — 2NO + O₂ → 2NO₂. ①은 NO₂의 성질이다. ②에서 NO₂는 산소와 반응하지 않는다. ④에서 구리는 수소보다 이온화 경향이 작아 염산에 녹지 않는다.

**문2** 구리 0.30 mol을 묽은 질산과 완전히 반응시켰을 때 발생하는 기체의 물질량은?
① 0.10 mol ② 0.20 mol ③ 0.30 mol ④ 0.80 mol

> **정답** ② — 3Cu + 8HNO₃ → 3Cu(NO₃)₂ + 2NO + 4H₂O에서 Cu : NO = 3 : 2이므로 0.30 × 2/3 = 0.20 mol이다.

**문3** NO와 NO₂의 포집법을 순서대로 바르게 짝지은 것은?
① 수상치환, 하방치환
② 하방치환, 수상치환
③ 상방치환, 하방치환
④ 수상치환, 상방치환

> **정답** ① — NO는 공기와 반응하고 물에 녹지 않으므로 수상치환으로 모은다. NO₂는 물에 녹고 분자량이 46으로 공기(약 29)보다 무거우므로 하방치환으로 모은다.
